# 代码库概览

## 简介

我们所有的代码仓库都存放在 [Github](https://github.com/pancakeswap) 上。其中大多数是公开的，你可以自由地提交 issue 或 pull request。在此之前，请确保你已阅读完整本指南以及每个仓库特定的准则。

## Github 仓库

* Frontend：主前端。它包含下面未列出的所有功能。
  * [sdk](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/swap-sdk) - 用于在 Pancakeswap 之上构建应用程序的 SDK
  * [aptos-swap-sdk](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/aptos-swap-sdk) - Swap SDK 的 Aptos 版本
  * [swap-sdk-core](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/swap-sdk-core) - Swap SDK 共享代码
  * [wagmi](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/wagmi) - [wagmi](https://github.com/wagmi-dev/wagmi) 的扩展，包括 bsc 链和币安钱包连接器
  * [awgmi](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/awgmi) - 使用类似 wagmi 的 React hooks 连接 Aptos，包括钱包适配器。
* Smart Contract：部署在 BSC 和 ETH 上的所有智能合约。
* Smart Contract：部署在 Aptos 上的 Move 版本的所有智能合约。
* Subgraph：用于查询事件和实体的 GraphQL 端点。
