# Aperçu de la base de code

## Introduction

Tous nos dépôts sont stockés sur [Github](https://github.com/pancakeswap). La plupart sont publics, et vous pouvez librement soumettre une issue ou une pull request. Assurez-vous de lire l'intégralité de ce guide ainsi que les directives spécifiques à chaque dépôt avant de commencer.

## Dépôts Github

* Frontend : Le frontend principal. Il contient toutes les fonctionnalités non listées ci-dessous.
  * [sdk](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/swap-sdk) - Un SDK pour créer des applications sur PancakeSwap
  * [aptos-swap-sdk](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/aptos-swap-sdk) - Version Aptos du Swap SDK
  * [swap-sdk-core](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/swap-sdk-core) - Code partagé du Swap SDK
  * [wagmi](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/wagmi) - Extension pour [wagmi](https://github.com/wagmi-dev/wagmi), incluant la chaîne BSC et le connecteur Binance wallet
  * [awgmi](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/awgmi) - Connexion à Aptos avec des hooks React similaires à wagmi. Inclut les adaptateurs de portefeuille.
* Smart Contract : Tous les smart contracts déployés sur BSC et ETH.
* Smart Contract : Tous les smart contracts en version Move déployés sur Aptos.
* Subgraph : Endpoint GraphQL pour interroger les événements et entités.
