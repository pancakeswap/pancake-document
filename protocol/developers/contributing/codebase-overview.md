# Codebase-Übersicht

## Einführung

Alle unsere Repositories sind auf [Github](https://github.com/pancakeswap) gespeichert. Die meisten sind öffentlich, und Sie können frei ein Issue oder einen Pull Request einreichen. Stellen Sie sicher, dass Sie diese gesamte Anleitung sowie die für jedes Repository spezifischen Richtlinien gelesen haben.

## Github-Repositories

* Frontend: Das Haupt-Frontend. Es enthält alle Features, die unten nicht aufgeführt sind.
  * [sdk](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/swap-sdk) — Ein SDK zum Entwickeln von Anwendungen auf PancakeSwap
  * [aptos-swap-sdk](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/aptos-swap-sdk) — Aptos-Version des Swap SDK
  * [swap-sdk-core](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/swap-sdk-core) — Gemeinsamer Code des Swap SDK
  * [wagmi](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/wagmi) — Erweiterung für [wagmi](https://github.com/wagmi-dev/wagmi), einschließlich BSC-Chain und Binance Wallet-Connector
  * [awgmi](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/awgmi) — Verbindung zu Aptos mit ähnlichen wagmi React-Hooks. Einschließlich Wallet-Adaptern.
* Smart Contract: Alle Smart Contracts, die auf BSC und ETH deployed sind.
* Smart Contract: Alle Move-Version der Smart Contracts, die auf Aptos deployed sind.
* Subgraph: GraphQL-Endpunkt zum Abfragen von Events und Entities.
