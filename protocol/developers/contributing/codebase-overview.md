# Gambaran Umum Basis Kode

## Pengantar

Semua repositori kami disimpan di [Github](https://github.com/pancakeswap). Sebagian besar bersifat publik, dan Anda dapat mengajukan isu atau pull request secara bebas. Pastikan Anda membaca seluruh panduan ini, dan panduan khusus untuk setiap repositori sebelumnya.

## Repositori Github

* Frontend: Frontend utama. Berisi semua fitur yang tidak tercantum di bawah ini.
  * [sdk](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/swap-sdk) - SDK untuk membangun aplikasi di atas Pancakeswap
  * [aptos-swap-sdk](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/aptos-swap-sdk) - Versi Aptos dari Swap SDK
  * [swap-sdk-core](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/swap-sdk-core) - Kode bersama Swap SDK
  * [wagmi](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/wagmi) - Ekstensi untuk [wagmi](https://github.com/wagmi-dev/wagmi), termasuk chain bsc dan konektor dompet binance
  * [awgmi](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/awgmi) - terhubung ke Aptos dengan React hooks mirip wagmi. Termasuk adaptor dompet.
* Smart Contract: Semua smart contract yang di-deploy di BSC dan ETH.
* Smart Contract: Semua versi Move dari smart contract yang di-deploy di Aptos.
* Subgraph: Endpoint GraphQL untuk mengkueri event dan entitas.
