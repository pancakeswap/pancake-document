# Descripción general del código base

## Introducción

Todos nuestros repositorios están almacenados en [Github](https://github.com/pancakeswap). La mayoría de ellos son públicos y puedes enviar libremente un issue o un pull request. Asegúrate de leer toda esta guía y las directrices específicas de cada repositorio antes.

## Repositorios de Github

* Frontend: El frontend principal. Contiene todas las funcionalidades que no se enumeran a continuación.
  * [sdk](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/swap-sdk) - Un SDK para construir aplicaciones sobre PancakeSwap
  * [aptos-swap-sdk](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/aptos-swap-sdk) - Versión Aptos del SDK de Intercambio
  * [swap-sdk-core](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/swap-sdk-core) - Código compartido del SDK de Intercambio
  * [wagmi](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/wagmi) - Extensión para [wagmi](https://github.com/wagmi-dev/wagmi), incluyendo la cadena bsc y el conector de Binance wallet
  * [awgmi](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/awgmi) - conecta con Aptos usando hooks de React similares a wagmi. Incluye adaptadores de billetera.
* Smart Contract: Todos los contratos inteligentes desplegados en BSC y ETH.
* Smart Contract: Todos los contratos inteligentes en versión Move desplegados en Aptos.
* Subgraph: Endpoint de GraphQL para consultar eventos y entidades.
