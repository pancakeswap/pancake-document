# Обзор кодовой базы

## Введение

Все наши репозитории хранятся на [Github](https://github.com/pancakeswap). Большинство из них публичные, и ты можешь свободно открывать issue или отправлять pull request. Убедись, что ты прочитал это руководство целиком, а также специфические инструкции для каждого репозитория.

## Репозитории на Github

* Frontend: Основной фронтенд. Содержит все функции, которые не перечислены ниже.
  * [sdk](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/swap-sdk) — SDK для создания приложений на базе PancakeSwap
  * [aptos-swap-sdk](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/aptos-swap-sdk) — версия Swap SDK для Aptos
  * [swap-sdk-core](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/swap-sdk-core) — общий код Swap SDK
  * [wagmi](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/wagmi) — расширение для [wagmi](https://github.com/wagmi-dev/wagmi), включая BSC-цепочку и коннектор кошелька Binance
  * [awgmi](https://github.com/pancakeswap/pancake-frontend/blob/develop/packages/awgmi) — подключение к Aptos с аналогичными React-хуками wagmi, включая адаптеры кошельков
* Smart Contract: Все смарт-контракты, развёрнутые на BSC и ETH.
* Smart Contract: Все версии смарт-контрактов на Move, развёрнутые на Aptos.
* Subgraph: Конечная точка GraphQL для запроса событий и сущностей.
