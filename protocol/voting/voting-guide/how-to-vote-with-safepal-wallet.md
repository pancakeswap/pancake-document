# Mit SafePal Wallet abstimmen

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-voting-with-safepal-header.png)

Sie können die SafePal Wallet verwenden, um über offene Themen in PancakeSwap abzustimmen. Befolgen Sie die nachstehenden Schritte, um Ihre Stimme direkt aus der SafePal Wallet abzugeben.

1\. Öffnen Sie Ihre SafePal Wallet und wählen Sie das dApp-Browser-Symbol im Menü unten.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Safepal-1.PNG)

2\. Geben Sie die URL der Abstimmungsseite in die Adressleiste ein. Wenn Sie die direkte URL zur gewünschten Abstimmung nicht kennen, können Sie zur [PancakeSwap-Abstimmungsseite](https://voting.pancakeswap.finance/) gehen und die Abstimmung von dort aus finden.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Safepal-2.PNG)

3\. Klicken Sie auf die Schaltfläche "Wallet verbinden" oben auf Ihrem Bildschirm (siehe Abbildung).&#x20;

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Safepal-3.PNG)

4\. Klicken Sie auf **Injected** als Wallet. Ihre Wallet ist nun verbunden, und Sie können jetzt über PancakeSwap-Vorschläge abstimmen.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Safepal-4.PNG)
