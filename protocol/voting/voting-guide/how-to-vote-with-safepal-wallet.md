# Comment voter avec SafePal Wallet

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-voting-with-safepal-header.png)

Vous pouvez utiliser le portefeuille SafePal pour voter sur les propositions ouvertes de PancakeSwap. Suivez les étapes ci-dessous pour exprimer votre vote depuis l'application SafePal.

1\. Ouvrez votre portefeuille SafePal et sélectionnez l'icône du navigateur dApp dans le menu en bas.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Safepal-1.PNG)

2\. Saisissez l'URL de la page de vote dans la barre d'adresse. Si vous ne connaissez pas l'URL directe du vote auquel vous souhaitez participer, rendez-vous sur la [page de vote PancakeSwap](https://voting.pancakeswap.finance/) et trouvez le vote depuis là.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Safepal-2.PNG)

3\. Cliquez sur le bouton de connexion du portefeuille en haut de votre écran (voir l'image).&#x20;

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Safepal-3.PNG)

4\. Cliquez sur **Injected** comme portefeuille. Votre portefeuille sera maintenant connecté et vous pouvez voter sur les propositions PancakeSwap.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Safepal-4.PNG)
