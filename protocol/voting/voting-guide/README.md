# 투표하는 방법

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-voting-header.png)

거버넌스 투표 참여는 쉽고 완전히 **무료**입니다. 가스비도 낼 필요가 없습니다! 투표하는 방법, 다음 제안 확인 방법, 투표하는 방법에 대해 알아보세요.

### 투표하는 방법

#### 투표 제안으로 이동

새로운 제안을 게시할 때마다 항상 투표 페이지 링크를 첨부합니다. 소식과 업데이트를 위해 [소셜 채널](../../../welcome-to-pancakeswap/contact-us/social-accounts.md)을 꼭 팔로우하세요.

또는 [PancakeSwap 자체 투표 포털](https://voting.pancakeswap.finance/?_gl=1*pc8o0h*_ga*MTUzNDEzNDQxMy4xNjAwNzkzNDM4*_ga_334KNG3DMQ*MTYwNDMwMTk4Ni42MC4xLjE2MDQzMDM3MDIuMA..#/)[ ](https://pancakeswap.finance/voting)을 방문하여 목록에서 제안을 둘러볼 수 있습니다. 제안이 보이지 않는다면 "예정" 탭에 있을 수 있습니다.

#### 제안을 읽고 투표할 선택지 고르기

![the proposal page](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-1.png)

제안 페이지에서는 다음을 확인할 수 있습니다.

* 제안 내용
* 투표 선택지
* 스냅샷 블록 및 투표 기간과 같은 제안의 세부 정보
* 최신 투표 결과
* 투표 목록

제안을 주의 깊게 읽고 투표하려는 선택지를 클릭하세요.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-2.png)

#### 투표 확인 및 제출

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-6.png)

모든 세부 정보를 확인하고 "투표 확인"을 클릭한 다음 지갑에서 메시지 서명을 확인하세요.

완료되었습니다. 투표가 성공적으로 제출되었습니다.

**스냅샷 블록 확인**

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-3.png)

투표권은 스냅샷 블록에서 찍은 스냅샷을 기준으로 계산됩니다. 따라서 제안이 게시된 후에 CAKE를 더 구매하거나 입금해도 해당 제안에 대한 투표권은 늘어나지 않습니다.

스냅샷 블록의 정확한 시간을 알고 싶다면 블록 번호를 클릭하고 BscScan 페이지에서 타임스탬프를 확인하세요.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-7.png)
