# Wie man abstimmt

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-voting-header.png)

Die Teilnahme an Governance-Abstimmungen ist einfach und absolut **KOSTENLOS**. Sie müssen nicht einmal Gasgebühren bezahlen! Erfahren Sie, wie Sie abstimmen, den nächsten Vorschlag verfolgen und Ihre Stimme abgeben.

### So stimmen Sie ab

#### Zum Abstimmungsvorschlag navigieren

Wenn wir einen neuen Vorschlag veröffentlichen, fügen wir immer den Link zur Abstimmungsseite hinzu. Folgen Sie daher [unseren Social-Media-Kanälen](../../../welcome-to-pancakeswap/contact-us/social-accounts.md) für Neuigkeiten und Updates.

Alternativ können Sie [PancakeSwaps nationales Abstimmungsportal](https://voting.pancakeswap.finance/?_gl=1*pc8o0h*_ga*MTUzNDEzNDQxMy4xNjAwNzkzNDM4*_ga_334KNG3DMQ*MTYwNDMwMTk4Ni42MC4xLjE2MDQzMDM3MDIuMA..#/) besuchen, um die Vorschläge in einer Liste zu durchsuchen. Wenn Sie den Vorschlag nicht sehen, befindet er sich möglicherweise im Tab "bald".

#### Vorschlag lesen und Abstimmungsoption wählen

![die Vorschlagsseite](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-1.png)

Auf der Vorschlagsseite finden Sie:

* Den Inhalt des Vorschlags
* Die Abstimmungsoptionen
* Die Details des Vorschlags wie Snapshot-Block und Abstimmungsfenster
* Das aktuelle Abstimmungsergebnis
* Die Liste der Stimmen

Lesen Sie den Vorschlag sorgfältig und klicken Sie auf die Option, für die Sie abstimmen möchten.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-2.png)

#### Stimme bestätigen und abgeben

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-6.png)

Bestätigen Sie alle Details und klicken Sie auf "Abstimmung bestätigen", dann bestätigen Sie in Ihrer Wallet, um die Nachricht zu unterzeichnen.

Fertig, Sie haben Ihre Stimme erfolgreich abgegeben.

### So überprüfen Sie die Details

{% tabs %}
{% tab title="Stimmrecht überprüfen" %}
Bevor Sie Ihre Stimme abgeben, sehen Sie ein Fenster "Abstimmung bestätigen".

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/cc%202025-05-15T13_38_57.460Z.png" alt="" width="188"><figcaption></figcaption></figure>

In diesem Fenster können Sie folgende Informationen einsehen:

* Die gewählte Option
* Ihr Stimmrecht

Ihr Stimmrecht entspricht Ihrem CAKE-Guthaben zum Zeitpunkt des Snapshot-Blocks.
{% endtab %}

{% tab title="Snapshot-Block überprüfen" %}
**Snapshot-Block überprüfen**

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-3.png)

Das Stimmrecht wird auf Basis eines Snapshots berechnet, der im Snapshot-Block aufgenommen wird. Daher erhöht das Kaufen oder Einzahlen von mehr CAKE nach der Veröffentlichung des Vorschlags das Stimmrecht für diesen speziellen Vorschlag nicht.

Wenn Sie den genauen Zeitpunkt des Snapshot-Blocks wissen möchten, klicken Sie einfach auf die Blocknummer und suchen Sie den Zeitstempel auf der BscScan-Seite.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-7.png)
