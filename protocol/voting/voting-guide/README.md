# Cara Memilih

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-voting-header.png)

Berpartisipasi dalam pemungutan suara Tata Kelola sangat mudah, dan sepenuhnya **GRATIS**. Anda bahkan tidak perlu membayar biaya gas! Pelajari cara memilih, pantau proposal berikutnya, dan berikan suara Anda.

### Cara memilih

#### Navigasi ke proposal suara

Setiap kali kami menerbitkan proposal baru, kami selalu menyertakan tautan ke halaman pemungutan suara. Pastikan Anda mengikuti [saluran sosial kami](../../../welcome-to-pancakeswap/contact-us/social-accounts.md) untuk berita dan pembaruan.

Atau, Anda dapat mengunjungi [portal pemungutan suara asli PancakeSwap](https://voting.pancakeswap.finance/?_gl=1*pc8o0h*_ga*MTUzNDEzNDQxMy4xNjAwNzkzNDM4*_ga_334KNG3DMQ*MTYwNDMwMTk4Ni42MC4xLjE2MDQzMDM3MDIuMA..#/)[ ](https://pancakeswap.finance/voting) untuk menelusuri proposal dalam daftar. Jika Anda tidak melihat proposalnya, mungkin ada di tab "soon".

#### Baca dan pilih pilihan untuk dipilih

![halaman proposal](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-1.png)

Di halaman proposal. Anda akan menemukan:

* Konten proposal
* Pilihan untuk dipilih
* Detail proposal seperti blok snapshot dan jendela pemungutan suara
* Hasil pemungutan suara terbaru
* Daftar suara

Baca proposal dengan seksama dan klik pilihan yang ingin Anda pilih.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-2.png)

#### Konfirmasi dan berikan suara Anda

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-6.png)

Konfirmasi semua detail dan klik "Confirm Vote", kemudian konfirmasi di dompet Anda untuk menandatangani pesan.

Selesai, Anda telah berhasil memberikan suara.

{% tab title="Periksa blok snapshot" %}
**Periksa blok snapshot**

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-3.png)

Kekuatan suara dihitung berdasarkan snapshot yang diambil pada blok snapshot. Oleh karena itu, membeli atau menyetorkan lebih banyak CAKE setelah proposal diposting tidak akan meningkatkan kekuatan suara untuk proposal tersebut.

Jika Anda ingin mengetahui waktu tepat blok snapshot, cukup klik nomor blok dan cari stempel waktu di halaman BscScan.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-7.png)
