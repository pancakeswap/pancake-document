# Comment voter

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-voting-header.png)

Participer au vote de Gouvernance est simple et absolument **GRATUIT**. Vous n'avez même pas besoin de payer de frais de gaz ! Découvrez comment voter, suivez la prochaine proposition et exprimez votre vote.

### Comment voter

#### Accéder à la proposition de vote

Chaque fois que nous publions une nouvelle proposition, nous joignons toujours le lien vers la page de vote. Assurez-vous de suivre [nos canaux sociaux](../../../welcome-to-pancakeswap/contact-us/social-accounts.md) pour les actualités et mises à jour.

Vous pouvez également visiter le [portail de vote natif de PancakeSwap](https://voting.pancakeswap.finance/?_gl=1*pc8o0h*_ga*MTUzNDEzNDQxMy4xNjAwNzkzNDM4*_ga_334KNG3DMQ*MTYwNDMwMTk4Ni42MC4xLjE2MDQzMDM3MDIuMA..#/)[ ](https://pancakeswap.finance/voting) pour parcourir les propositions dans une liste. Si vous ne voyez pas la proposition, elle se trouve peut-être dans l'onglet « soon ».

#### Lire et choisir l'option de vote

![la page de proposition](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-1.png)

Sur la page de la proposition, vous trouverez :

* Le contenu de la proposition
* Les choix à voter
* Les détails de la proposition tels que le bloc de snapshot et la fenêtre de vote
* Le résultat de vote le plus récent
* La liste des votes

Lisez attentivement la proposition et cliquez sur le choix que vous souhaitez voter.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-2.png)

#### Confirmer et exprimer votre vote

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-6.png)

Confirmez tous les détails et cliquez sur « Confirm Vote », puis confirmez dans votre portefeuille pour signer le message.

Voilà, vous venez d'exprimer votre vote avec succès.

### Comment vérifier les détails

{% tabs %}
{% tab title="Vérifier le pouvoir de vote" %}
Avant d'exprimer votre vote, vous verrez une fenêtre « Confirm Vote ».

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/cc%202025-05-15T13_38_57.460Z.png" alt="" width="188"><figcaption></figcaption></figure>

Dans cette fenêtre, vous pourrez consulter les éléments suivants :

* Le choix que vous avez sélectionné
* Votre pouvoir de vote

Votre pouvoir de vote est égal à votre solde de CAKE au bloc de snapshot.
{% endtab %}

{% tab title="Vérifier le bloc de snapshot" %}
**Vérifier le bloc de snapshot**

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-3.png)

Le pouvoir de vote est calculé sur la base d'un snapshot pris au bloc de snapshot. Par conséquent, acheter ou déposer plus de CAKE après la publication de la proposition n'augmentera pas le pouvoir de vote pour cette proposition spécifique.

Si vous souhaitez connaître l'heure exacte du bloc de snapshot, cliquez simplement sur le numéro de bloc et recherchez l'horodatage sur la page BscScan.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-vote-7.png)
