# So handeln Sie an der PancakeSwap Exchange

![Image for post](https://miro.medium.com/max/1400/0*C0Ng5_d1hK28qMMh)

1. Gehen Sie [hier](https://pancakeswap.finance/swap) zur Exchange-Seite.



![Image for post](https://miro.medium.com/max/512/0*roteFKZKRqO-IWYU)

2. Entsperren Sie Ihr BNB Smart Chain Wallet \(oben rechts\).



![Image for post](https://miro.medium.com/max/1400/0*H5TedYqYQFb5oiO0)

3. Wählen Sie die Token aus, die Sie handeln möchten, und geben Sie den Betrag ein.



![Image for post](https://miro.medium.com/max/1400/0*AgCzp3NqkIudgyWQ)

4. Prüfen Sie die Details und klicken Sie auf „Swap“.



![Image for post](https://miro.medium.com/max/1400/0*qmhlA7jFOwtIKJ8t)

5. Prüfen Sie die Details und klicken Sie auf „Confirm Swap“.



![Image for post](https://miro.medium.com/max/1400/0*CMDlQd_FEWa6koea)

6. Bestätigen Sie die Transaktion in Ihrem Wallet.



![Image for post](https://miro.medium.com/max/1400/0*wHVyuL-WED_T3wiZ)

7. Fertig! Sie können auf „View on bscscan“ klicken, um die Details Ihrer Transaktion zu sehen.
