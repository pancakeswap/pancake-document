# ファーミング よくある質問 (FAQ)

### なぜAPRが複数あるのですか？

v3では、流動性を提供する際にアセットを集中させることで、利用可能な総流動性に対するシェアを増やし、より高い%の報酬を獲得できます。&#x20;

そのため、ポジションの価格レンジ設定によって、各流動性ポジションは独自のLP手数料APRと独自のファーミングAPRを持ちます。

グローバルAPRは、ファームにステーキングされているアクティブなポジション内のアセットの総額で、USD建てのCAKE報酬の総額を割って計算されます。そのため、グローバルファーミングAPRはあくまで一般的な参考値であり、各ポジションの個別APRを表すものではありません。

ご自身のファーミングAPRを確認するには、各ファームの下に表示されているポジションをご覧ください。

###

### ファームにステーキング中に流動性ポジションがレンジ外になった場合はどうなりますか？

v3では、アクティブ（レンジ内）な流動性ポジションのみがファームからCAKEを獲得できます。

価格がレンジ外になると、ポジションはCAKE報酬の受け取りを停止します。

価格がレンジ内に戻ると、ポジションはCAKE報酬の受け取りを再開します。ステーカーからの追加操作は不要です。



### ポジションが常にレンジ内に収まり手数料報酬を獲得できるように自動調整する方法はありますか？

PancakeSwap v3はZapによるワンクリック流動性預け入れをサポートしており、BNB ChainとEthereumで利用可能です。



### 小さなレンジの流動性ポジションで常にファーミングする方が良いですか？

より小さな価格レンジに流動性を提供することで、流動性を集中させ、価格レンジ内の総流動性に対する相対的なシェアを高め、潜在的により多くのCAKE報酬を獲得できます。

ただし、アクティブな流動性ポジションのみがCAKE報酬を獲得できることをご注意ください。つまり、現在の取引価格が流動性ポジションで定義された価格レンジ内にある場合のみ報酬を獲得できます。

ポジションの価格レンジを調整する必要がある場合は、アンステーキング、流動性の削除を行い、更新された価格レンジで新しいポジションを作成する必要があります。頻繁な調整は常に最適な戦略ではありません。インパーマネントロスを実現し、複数のトランザクションを完了するために一定量のガスが必要になるためです。



### 1つのファームで何ポジションまでステーキングできますか？

1つのファームでステーキングできるポジション数に上限はありません。

ただし、ポジションごとに手動でハーベストするためのガスが必要になることをご注意ください。利回り操作においては常にガスコストを考慮してください。



### 報酬はどのくらいの頻度でハーベストすればよいですか？

報酬をハーベストする頻度はご自身で決めていただけますが、ハーベストには小額の手数料が発生することを覚えておくと役立ちます。「ハーベスト」をクリックした後、ウォレットで確認する際にこの手数料を確認できます。

これはMetaMaskウォレットに表示されるハーベスト手数料の例です。ウォレットによって表示方法が若干異なる場合があります。手数料をあまり頻繁に支払わないよう、しばらく報酬を積み立てることをご検討ください。



### ファームにステーキング中にポジションを調整したい場合はどうすればいいですか？

ファームにステーキング中でも、アンステーキングなしに流動性を追加または削除できます。調整したい流動性ポジションを見つけ、そのタイトル/IDをクリックするだけで、「追加」と「削除」ボタンがあるポジション詳細ページが表示されます。

流動性ポジションの価格レンジ設定を調整したい場合は、ファームからアンステーキングし、すべての流動性を削除してから、流動性を追加して新しいポジションを再作成する必要があります。



### ファーミングAPRに影響する要因は何ですか？

Farm v3では、CAKEの報酬APRは流動性ポジション間で異なる場合があります。以下の要因に基づきます：

* ファームへのCAKEエミッションレート\
  \- より多くのCAKEはすべてのファームに対してより高い利回りを生み出します。[トークノミクスページ](https://docs.pancakeswap.finance/tokenomics/cake/cake-tokenomics)で詳細をご覧ください。
* ファームの乗数\
  \- 乗数が高いファームはすべてのファームに比例してより多くのCAKEを受け取ります。v3とv2 + stable swapファームは2つの別々の乗数セットを使用していることにご注意ください。EthereumとBNBチェーン上のファームも別々の乗数セットを使用しています。
* ポジションに預け入れられたトークン数\
  \- ポジション内のトークンが多いほど、ファームプール内の総アクティブ流動性に対する相対的なシェアが大きくなり、より多くのCAKE報酬を獲得できます。
* 選択した価格レンジ\
  \- 価格レンジが小さいほど、同量のトークン預け入れに対して高い集中度が得られ、ファームプール内の総アクティブ流動性に対する相対的なシェアが大きくなり、より多くのCAKE報酬を獲得できます。
* 現在アクティブな流動性量\
  \- ご自身と同じレンジに流動性を預け入れて集中させるユーザーが増えると、総アクティブ流動性に対する相対的なシェアが小さくなり、CAKEの報酬が少なくなります。
* 流動性ポジションがアクティブかどうか\
  \- アクティブな流動性ポジションのみがファームからCAKE報酬を獲得できます。



### 「ポジションの更新」ポップアップが表示されるのはなぜですか？

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28321%29.png)

V3ローンチ直後、シェフたちはFarmに更新を実施して報酬計算をより正確で信頼性の高いものにしました。このポップアップが表示される場合、一部のポジションで更新が必要であることを意味します。

「すべて更新」をクリックして、ウォレットのポップアップで確認してください。

なお、シェフたちはFarm V3のローンチからこの更新が実施されるまでの期間の過去のステーキングデータにもこの更新を適用しています。追加のCAKE報酬がある場合は、2023年5月1日より前にウォレットにエアドロップされます。



### v3の2倍ファームがv2の1倍ファームよりAPRが低いのはなぜですか？

まず、APRを比較する際は、2つのファーム間のステーキングされた総流動性が同等であることを確認する必要があります。

さらに、CAKEエミッションの独自のストリームを持つ複数のファームグループが存在します。各ファームグループは別々の乗数セットを共有します。

個々のファームは以下に基づいてCAKEエミッションを受け取ります：

* A = 所属するファームグループの1秒/ブロックあたりの総CAKE
* B = 所属するグループ内の乗数の総数
* C = そのファームが持つ乗数

`CAKE per block/second = C / B * A`

上記の数値は各[MasterChef](/broken/pages/-MeTWzQOSmb1ej51HT0I)コントラクトで確認できます。
