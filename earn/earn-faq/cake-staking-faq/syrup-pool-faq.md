# シロッププール よくある質問 (FAQ) & トラブルシューティング

## トラブルシューティング

### **ステーキングしていたシロッププールが見つかりません！**

シロッププールページの「終了済み」タブでシロッププールを確認できます。&#x20;

「ステーク中のみ」を選択すると、アセットを見つけやすくなります。

### **シロッププールからトークンをアンステーキングできないのはなぜですか？**

「CAKEをステーク、CAKEを獲得」プールからアンステーキングできない場合は、ウォレット内のSYRUPトークンを売却していないか確認してください。このトークンはManual CAKEプールでのCAKEに対する「所有権の証明」として機能します。&#x20;

### **ステーキング/アンステーキング後に獲得したトークンが0になったのはなぜですか？**

ご安心ください！すでにウォレットに送付されています。

シロッププールやファームでステーキングまたはアンステーキングを行うたびに、獲得したトークンはハーベストされ、同時にウォレットに送付されます。

## **一般的な質問**

### シロッププールのAPRはどのように計算されますか？

> シロッププール APR = 年換算報酬（USD）/ シロッププールにステーキングされたユーザーの資金（USD）\* 100

基本的な例として、30万USDの報酬がある60日間のプールと、300万USDのCAKEがステーキングされている場合を見てみましょう。

APRはユーザーによってより多くのCAKEがステーキングされるにつれて、またCAKEや報酬トークンの価格が変動するにつれて変動します。

|                                            | **計算**                            | 金額                                         |
| ------------------------------------------ | --------------------------------- | ------------------------------------------ |
| 配布される総報酬（USD価値）                            |                                   | 300,000 USD                                |
| 配布期間                                       |                                   | 60日                                        |
| 日次配布                                       | 300,000 / 60 =                    | 5,000 USD/日                                |
| **年換算報酬（USD価値）**                           | 5,000 \* 365 =                    | **1,825,000 USD**                          |
| **プールでユーザーがステーキングしているCAKEの価値（USD価値）** |                                   | **3,000,000 USD**                          |
| **APR**                                    | (1,825,000 / 3,000,000) \* 100 =  | <p></p><p><strong>60.833% APR</strong></p> |

### **シロッププールの「終了」番号は何を示していますか？**

そのプールの報酬配布が停止するまでの残りブロック数を示しています。プールがそのブロックに達したら、トークンをアンステーキングしてください。それ以降は報酬を受け取れなくなります。

### **シロッププールの報酬はどこから来ていますか？**

シロッププールには主に3種類があります。

1. CAKEをステーク、CAKEを獲得
2. CAKEをステーク、他のトークンを獲得。&#x20;
3. 他のトークンをステーク、CAKEを獲得

「CAKEをステーク、CAKEを獲得」シロッププールの報酬は、[CAKEエミッション](https://docs.pancakeswap.finance/tokenomics/cake/cake-tokenomics)から来ています。各ブロックで、一定数のCAKEトークンがこれらのプールの報酬として割り当てられます。

「CAKEをステーク、他のトークンを獲得」タイプの報酬は、シロッププールをスポンサーするプロジェクトチームによって提供されます。

「他のトークンをステーク、CAKEを獲得」タイプでは、PancakeSwapトレジャリーが市場からCAKEを買い戻して報酬として配布します。これらのプールはプロジェクト自体ではなく、PancakeSwapによって資金提供されます。

### SYRUPトークンとは何ですか？

PancakeSwapのSYRUPトークンは、**Manual**「CAKEをステーク、CAKEを獲得」シロッププールを操作するとウォレットに預け入れられます。&#x20;

これは基本的に、プールでステーキングしたCAKEの量を示す借用書（IOU）です。

そのプールからCAKEをアンステーキングすると、自動的に返還されます。

{% hint style="warning" %}
SYRUPトークンを売却しないでください！Manual CAKEプールからCAKEをアンステーキングするには、SYRUPを返還する必要があります。返還するSYRUPの量は、アンステーキングするCAKEの量と同じである必要があります。
{% endhint %}
