# So nehmen Sie teil – CAKE.PAD

### Zusammenfassung

**Vor dem CAKE.PAD-Event**

* [CAKE kaufen / vorbereiten](https://pancakeswap.finance/swap)

**Während des CAKE.PAD-Events**

* Während das Event aktiv ist, zahlen Sie Ihr CAKE ein, um CAKE.PAD-Partner-Token zu erhalten unter [https://pancakeswap.finance/cakepad](https://pancakeswap.finance/cakepad)

**Nach dem CAKE.PAD-Event**

1. Wenn das Event abgeschlossen ist, fordern Sie Ihre CAKE.PAD-Partner-Token an.
2. Im Falle eines [Overflows](cakepad-guide.md#overflow-sale-method) fordern Sie Ihre nicht verwendeten CAKE-Token zurück (abzüglich [gestaffelter Steuer](how-cake.pad-taxes-work-in-overflow-sales-with-example.md)).
3. Wenn das CAKE.PAD-Event Token-Vesting umfasst, kehren Sie während des Vesting-Zeitraums zurück, um freigegebene Token bis zum Ende des Vesting-Plans abzurufen.

***

## A) Vor dem CAKE.PAD-Event

Bevor Sie an einem CAKE.PAD-Event teilnehmen können, ist das Einzige, was Sie vorbereiten müssen, Ihre CAKE-Token.

### CAKE-Token erwerben

CAKE-Token werden verwendet, um die im CAKE.PAD-Event angebotenen Token zu kaufen.

* Wenn Ihr CAKE in einem Syrup Pool gestakt ist, unstaken Sie es vor dem CAKE.PAD-Event
* Andernfalls stellen Sie sicher, dass Sie im Voraus CAKE-Token kaufen und in Ihrer Wallet halten

### Wann beginnt ein CAKE.PAD-Event?

CAKE.PAD-Events sind **zeitlich begrenzt**. Verwenden Sie folgende Methoden, um sicherzustellen, dass Sie nichts verpassen:

1. Besuchen Sie die CAKE.PAD-Event-Seite: Ein **Countdown-Timer** zeigt den genauen Zeitpunkt des bevorstehenden CAKE.PAD-Events an.
2. Behalten Sie die sozialen Medien von PancakeSwap im Auge: Es gibt keinen festen Zeitpunkt, ab dem der Countdown vor dem Start eines CAKE.PAD-Events beginnt. Verfolgen Sie daher die offiziellen Accounts von PancakeSwap für Ankündigungen. Der Countdown und die Updates geben Ihnen ausreichend Zeit zur Vorbereitung.
3. Lesen Sie den Forenbeitrag zum CAKE.PAD-Event für den genauen Zeitplan.

## B) Während des CAKE.PAD-Events

Während das CAKE.PAD-Event aktiv ist, haben Sie begrenzte Zeit zur Teilnahme. Wenn Sie CAKE in Ihrer Wallet vorbereitet haben, können Sie problemlos am CAKE.PAD-Event teilnehmen!

### Prüfen, ob das CAKE.PAD-Event aktiv ist

Auf der CAKE.PAD-Event-Seite wechselt der Countdown zum Event-Start zu einem Countdown bis zum Ende des CAKE.PAD-Event-Verkaufs. So sehen Sie, wie viel Zeit noch verbleibt, um die angebotenen Token zu erwerben.

Bei jedem CAKE.PAD-Event können Teilnehmer beliebige Mengen an CAKE einsetzen. Um den CAKE-Nutzen zu steigern, gilt eine gestaffelte Teilnahmegebühr. Einzelheiten finden Sie auf der CAKE.PAD-Event-Seite oder im entsprechenden Vorschlag für das jeweilige Event.

Die endgültige Menge der CAKE.PAD-Partner-Token, die Sie erhalten, wird anhand der **Overflow-Verkaufsmethode** bestimmt.

### Overflow-Verkaufsmethode

1. Nutzer können beliebige Mengen an $CAKE einsetzen, ohne Sperrung oder Staking
2. Die Zuteilung jedes Nutzers ist proportional zu seinem eingesetzten CAKE
3. Bei Überzeichnung wird nur ein Teil des eingesetzten CAKE eines Nutzers gegen Projekt-Token getauscht
4. Je mehr Sie einsetzen → desto mehr Zuteilung erhalten Sie
5. Bei starker Überzeichnung erhalten kleine Einsätze möglicherweise 0
6. Alle nicht verwendeten $CAKE werden an Teilnehmer zurückerstattet (ggf. abzüglich Steuer)

### CAKE beim CAKE.PAD-Event einzahlen

1. Klicken Sie auf die Einzahlen-Schaltfläche auf der CAKE.PAD-Event-Verkaufskarte

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28466%29.png" alt="" width="375"><figcaption></figcaption></figure>

2. Geben Sie die Menge an CAKE ein, die Sie einsetzen möchten. Alle CAKE, die nicht zum Kauf von Token verwendet werden, werden an Sie zurückgegeben.
3.  Klicken Sie auf **Bestätigen** und genehmigen Sie die Transaktion in Ihrer Wallet<br>

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28467%29.png" alt="" width="239"><figcaption></figcaption></figure>
4. Ihr eingesetzter Betrag wird im Verkaufsbereich angezeigt.
5. Sie können während des CAKE.PAD-Events jederzeit weitere $CAKE hinzufügen.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28468%29.png" alt="" width="375"><figcaption></figcaption></figure>

**Hinweis:** Wenn das CAKE.PAD-Event überzeichnet ist, gilt eine **gestaffelte Teilnahmegebühr**. Diese Gebühr wird nur von überschüssigen Mitteln abgezogen, nicht von den CAKE, die zum Kauf von Token verwendet werden.

Siehe: [how-cake.pad-taxes-work-in-overflow-sales-with-example.md](how-cake.pad-taxes-work-in-overflow-sales-with-example.md "mention")

## C) Nach dem CAKE.PAD-Event

### Token einsammeln

* Wenn das CAKE.PAD-Event endet, können Sie Ihre neuen Token einsammeln. Einige CAKE.PAD-Events können Token-Vesting-Zeiträume umfassen.
* Die Anzahl der Token, die Sie erhalten, hängt von Ihrem CAKE-Einzahlungsbetrag im Verhältnis zum insgesamt eingesetzten Betrag ab.
* Überschüssige CAKE, die nicht für den Erwerb von CAKE.PAD-Partner-Token verwendet wurden, werden zurückerstattet (abzüglich etwaiger Teilnahmegebühren).

#### CAKE.PAD-Event **ohne Token-Vesting**

Das Einsammeln Ihrer neuen Token ist denkbar einfach. Gehen Sie einfach nach Abschluss des CAKE.PAD-Events zurück zur Event-Seite und klicken Sie unter dem Verkaufsfenster auf die Schaltfläche **Beanspruchen**. Bestätigen Sie die Aktion mit Ihrer Wallet. Sie haben nun Ihre neuen Token. Herzlichen Glückwunsch!

#### CAKE.PAD-Event **mit Token-Vesting**

Einige CAKE.PAD-Events können Vesting umfassen. Details werden stets im Vorschlag bekannt gegeben, und der Vesting-Plan wird auf der CAKE.PAD-Event-Seite angezeigt.

Die Seite zeigt:

* Insgesamt gekaufte Token
* Bereits freigegebene Token
* Token, die beansprucht werden können
* Wann das Vesting abgeschlossen sein wird

Klicken Sie auf die Schaltfläche **Beanspruchen**, um alle aktuell verfügbaren Token einzusammeln.

Während des Vesting-Zeitraums können Sie jederzeit zur CAKE.PAD-Event-Seite zurückkehren, um Token bei deren Freigabe abzurufen.
