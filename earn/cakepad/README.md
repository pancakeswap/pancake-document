# 🛍️ CAKE.PAD

Kami dengan bangga memperkenalkan **CAKE.PAD**, pengalaman akses token awal yang baru dan lebih baik di PancakeSwap, memberikan Anda akses eksklusif ke token baru sebelum mereka masuk ke bursa.

Berkembang dari IFO (Initial Farm Offering) kami, CAKE.PAD dibangun dengan mengutamakan kesederhanaan, inklusivitas, dan utilitas CAKE. Tidak ada staking, tidak ada lock-up. Cukup commit CAKE dan dapatkan akses awal ke token baru dari proyek-proyek menarik sebelum mereka masuk ke bursa.

### Apa itu CAKE.PAD?

Acara CAKE.PAD di PancakeSwap memungkinkan Anda mendapatkan akses awal ke token proyek baru tepat saat diluncurkan.

* Jadilah yang pertama memiliki token baru
* Berpotensi menikmati hadiah yang lebih tinggi dengan masuk lebih awal
* Tersedia hanya untuk **waktu yang sangat terbatas**, jadi persiapkan diri Anda terlebih dahulu!

👉 Alurnya sederhana:

* **Anda mendepositkan CAKE**
* **Proyek menerima CAKE** (hingga target penggalanan dananya)
* **PancakeSwap membakar 100% biaya partisipasi (dalam CAKE)**
* **Anda mendapatkan token mitra CAKE.PAD baru**

Sebagai bagian dari [pembaruan Tokenomics 3.0](https://pancakeswap.finance/voting/proposal/0x79ef496c9737e48d9677a6e291ff2a549dee6729c9996398e453af8ecbf0ceb3), kami telah membuat **CAKE.PAD** lebih sederhana, lebih ramping, dan lebih mudah untuk diikuti.

### Apa yang Berubah?

| Format CAKE.PAD yang Diperbarui                                                                                                                                          | Format IFO Sebelumnya                                    |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------- |
| Hanya **1 jenis** acara - Siapa pun yang memiliki CAKE dapat berpartisipasi                                                                                               | Beberapa jenis: **Basic / Private / Public**             |
| **Tidak ada persyaratan tambahan** — cukup depositkan CAKE                                                                                                               | Persyaratan meliputi **CAKE staking** + **NFT Profile** |
| **Tidak ada iCAKE / veCAKE** (tidak digunakan lagi dengan [Tokenomics 3.0](https://pancakeswap.finance/voting/proposal/0x79ef496c9737e48d9677a6e291ff2a549dee6729c9996398e453af8ecbf0ceb3)) | Menggunakan konsep **iCAKE / veCAKE**                    |
| **Pajak berjenjang** (berlaku hanya jika kelebihan langganan, berkurang seiring meningkatnya kelebihan langganan)                                                         | Biaya partisipasi tetap (misalnya, 1%)                   |

### Apa yang Tidak Berubah?

* Tidak ada batas individual — pengguna dapat meng-commit CAKE dalam jumlah berapa pun untuk berpartisipasi
* Pengguna masih dapat mengikuti **beberapa acara CAKE.PAD sekaligus** (jika lebih dari satu sedang berlangsung)
* **100% biaya acara CAKE.PAD dibakar** — menjaga mekanisme pembakaran CAKE tetap kuat

#### Tingkatan Biaya

* Berlaku **hanya jika acara CAKE.PAD kelebihan langganan**
* Pajak hanya dipotong dari kelebihan dana yang di-commit peserta, tidak ada biaya yang dibayarkan oleh mitra proyek **CAKE.PAD**
* Mitra proyek **CAKE.PAD** menerima 100% dari jumlah penggalanan dana yang ditargetkan
* PancakeSwap akan membakar 100% biaya acara **CAKE.PAD** sebagai CAKE
