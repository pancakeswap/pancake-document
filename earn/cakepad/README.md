# 🛍️ CAKE.PAD

我们很高兴地推出 **CAKE.PAD**，这是 PancakeSwap 上全新改进的代币早期访问体验，让你在新代币登陆交易所之前就能独家提前获取。

CAKE.PAD 由我们的 IFO（首次农场发行）演变而来，以简单、包容和 CAKE 实用性为设计理念。无需质押，无需锁仓。只需投入 CAKE，即可在令人兴奋的项目代币登陆交易所之前提前获取。

### 什么是 CAKE.PAD？

PancakeSwap 上的 CAKE.PAD 活动让你能够在新项目代币推出时立即提前获取。

* 成为首批拥有新代币的用户之一
* 通过提前参与，有机会享受更高的回报
* 仅在**非常有限的时间内**开放，所以请提前做好准备！

👉 流程很简单：

* **你存入 CAKE**
* **项目方收到 CAKE**（最多至其募集目标）
* **PancakeSwap 销毁 100% 的参与费用（以 CAKE 计）**
* **你获得新的 CAKE.PAD 合作伙伴代币**

作为 [Tokenomics 3.0 升级](https://pancakeswap.finance/voting/proposal/0x79ef496c9737e48d9677a6e291ff2a549dee6729c9996398e453af8ecbf0ceb3)的一部分，我们让 **CAKE.PAD** 更简单、更精简、更易于参与。

### 有哪些变化？

| 更新后的 CAKE.PAD 形式                                                                                                                                                  | 此前的 IFO 形式                                      |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------- |
| 只有**1 种**活动类型——任何持有 CAKE 的人都可以参与                                                                                                               | 多种类型：**Basic / Private / Public**             |
| **无额外要求**——只需存入 CAKE                                                                                                                            | 要求包括 **CAKE 质押** + **NFT 个人资料** |
| **无 iCAKE / veCAKE**（随 [Tokenomics 3.0](https://pancakeswap.finance/voting/proposal/0x79ef496c9737e48d9677a6e291ff2a549dee6729c9996398e453af8ecbf0ceb3) 一同弃用） | 使用 **iCAKE / veCAKE** 概念                         |
| **分级税率**（仅在超额认购时适用，并随超额认购规模增大而降低）                                                                                     | 固定参与费用（例如 1%）                        |

### 有哪些未变化？

* 无个人上限——用户可投入任意数量的 $CAKE 参与
* 用户仍可**同时参与多个 CAKE.PAD 活动**（如果同时有多个活动进行中）
* **100% 的 CAKE.PAD 活动费用将被销毁**——使 CAKE 的销毁机制保持强劲

#### 费用分级

* 仅在 **CAKE.PAD 活动超额认购时**适用
* 税费仅从参与者超额投入的资金中扣除，**CAKE.PAD** 项目合作伙伴无需支付任何费用
* **CAKE.PAD** 项目合作伙伴可获得其募集目标金额的 100%
* PancakeSwap 将以 CAKE 形式销毁 100% 的 **CAKE.PAD 活动**费用
