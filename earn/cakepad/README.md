# 🛍️ CAKE.PAD

Wir freuen uns, **CAKE.PAD** vorzustellen – das neue und verbesserte Erlebnis für frühen Token-Zugang auf PancakeSwap, das Ihnen exklusiven Frühzugang zu neuen Token bietet, bevor diese an Börsen gehandelt werden.

Als Weiterentwicklung unseres IFO (Initial Farm Offering) wurde CAKE.PAD mit Blick auf Einfachheit, Inklusivität und CAKE-Nutzen entwickelt. Kein Staking, keine Sperrzeiten. Einfach CAKE einzahlen und frühzeitigen Zugang zu neuen Token aus spannenden Projekten erhalten, bevor diese an Börsen erscheinen.

### Was ist CAKE.PAD?

Ein CAKE.PAD-Event auf PancakeSwap ermöglicht Ihnen frühzeitigen Zugang zu neuen Projekt-Token direkt bei deren Launch.

* Seien Sie unter den Ersten, die neue Token besitzen
* Profitieren Sie potenziell von höheren Rewards durch frühen Einstieg
* Nur für **sehr begrenzte Zeit** verfügbar – bereiten Sie sich im Voraus vor!

👉 Der Ablauf ist einfach:

* **Sie zahlen CAKE ein**
* **Das Projekt erhält CAKE** (bis zu seinem Fundraising-Ziel)
* **PancakeSwap verbrennt 100 % der Teilnahmegebühren (in CAKE)**
* **Sie erhalten die neuen CAKE.PAD-Partner-Token**

Im Rahmen des [Tokenomics 3.0-Upgrades](https://pancakeswap.finance/voting/proposal/0x79ef496c9737e48d9677a6e291ff2a549dee6729c9996398e453af8ecbf0ceb3) haben wir **CAKE.PAD** einfacher, schlanker und zugänglicher gestaltet.

### Was hat sich geändert?

| Aktualisiertes CAKE.PAD-Format                                                                                                                                                             | Früheres IFO-Format                                           |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| Nur **1 Art** von Event – Jeder mit CAKE kann teilnehmen                                                                                                                                   | Mehrere Typen: **Basic / Private / Public**                   |
| **Keine zusätzlichen Anforderungen** – einfach CAKE einzahlen                                                                                                                              | Anforderungen umfassten **CAKE Staking** + **NFT-Profil**     |
| **Kein iCAKE / veCAKE** (abgekündigt mit [Tokenomics 3.0](https://pancakeswap.finance/voting/proposal/0x79ef496c9737e48d9677a6e291ff2a549dee6729c9996398e453af8ecbf0ceb3))                  | Verwendete **iCAKE / veCAKE**-Konzepte                        |
| **Gestaffelte Steuer** (gilt nur bei Überzeichnung, sinkt mit zunehmender Überzeichnung)                                                                                                   | Pauschale Teilnahmegebühr (z. B. 1 %)                         |

### Was ist unverändert geblieben?

* Keine individuelle Obergrenze – Nutzer können beliebige Mengen an $CAKE einsetzen, um teilzunehmen
* Nutzer können weiterhin **gleichzeitig an mehreren CAKE.PAD-Events teilnehmen** (wenn mehr als eines aktiv ist)
* **100 % der CAKE.PAD-Event-Gebühren werden verbrannt** – der CAKE-Verbrennungsmechanismus bleibt erhalten

#### Gebührenstufen

* Gilt **nur, wenn das CAKE.PAD-Event überzeichnet ist**
* Die Steuer wird ausschließlich von den überschüssigen eingesetzten Mitteln der Teilnehmer abgezogen; die **CAKE.PAD**-Projektpartner zahlen keine Gebühren
* Der **CAKE.PAD**-Projektpartner erhält 100 % seines angestrebten Fundraising-Betrags
* PancakeSwap verbrennt 100 % der **CAKE.PAD-Event**-Gebühren als CAKE
