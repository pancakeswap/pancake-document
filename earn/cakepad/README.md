# 🛍️ CAKE.PAD

PancakeSwapにおける新しく改良された早期トークンアクセス体験、**CAKE.PAD**をご紹介します。取引所に上場する前に新しいトークンへの独占的な早期アクセスを提供します。

IFO（Initial Farm Offering）から進化したCAKE.PADは、シンプルさ、包括性、CAKEのユーティリティを念頭に置いて構築されています。ステーキングもロックアップも不要。CAKEをコミットして、取引所に上場する前にエキサイティングなプロジェクトの新しいトークンへの早期アクセスを取得するだけです。

### CAKE.PADとは？

PancakeSwap上のCAKE.PADイベントでは、ローンチ直後に新しいプロジェクトトークンへの早期アクセスを取得できます。

* 新しいトークンをいち早く保有できる
* 早期参入による高い報酬の可能性
* **非常に限られた時間**でのみ利用可能なため、事前に準備しておいてください！

👉 フローはシンプルです：

* **CAKEを預け入れる**
* **プロジェクトがCAKEを受け取る**（調達目標まで）
* **PancakeSwapが参加手数料（CAKE）の100%をバーンする**
* **CAKE.PADパートナートークンを受け取る**

[Tokenomics 3.0アップグレード](https://pancakeswap.finance/voting/proposal/0x79ef496c9737e48d9677a6e291ff2a549dee6729c9996398e453af8ecbf0ceb3)の一環として、**CAKE.PAD**はよりシンプルで、より効率的で、より参加しやすくなりました。

### 変更点

| 更新されたCAKE.PAD形式                                                                                                                                                        | 以前のIFO形式                                                |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------- |
| **1種類**のイベントのみ - CAKEを持つ誰でも参加可能                                                                                                                                       | 複数の種類：**ベーシック / プライベート / パブリック**                         |
| **追加要件なし** — CAKEを預け入れるだけ                                                                                                                                              | **CAKEステーキング** + **NFTプロファイル**が必要                         |
| **iCAKE / veCAKE不要**（[Tokenomics 3.0](https://pancakeswap.finance/voting/proposal/0x79ef496c9737e48d9677a6e291ff2a549dee6729c9996398e453af8ecbf0ceb3)で廃止）              | **iCAKE / veCAKE**の概念を使用                                 |
| **段階的な税率**（超過申込の場合のみ適用、超過申込が増えるにつれて減少）                                                                                                                               | 一律参加手数料（例：1%）                                            |

### 変更されていない点

* 個人上限なし — ユーザーは任意の量の$CAKEをコミットして参加可能
* ユーザーは**複数のCAKE.PADイベントに同時に参加**できる（複数が同時開催の場合）
* **CAKE.PADイベント手数料の100%がバーンされる** — CAKEのバーンメカニズムを強力に維持

#### 手数料ティア

* CAKE.PADイベントが**超過申込の場合のみ**適用されます
* 税金は参加者の超過コミット資金のみから控除され、**CAKE.PAD**プロジェクトパートナーは手数料を支払いません
* **CAKE.PAD**プロジェクトパートナーは調達目標額の100%を受け取ります
* PancakeSwapは**CAKE.PADイベント**手数料の100%をCAKEとしてバーンします
