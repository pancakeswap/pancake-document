# Zap

### Was ist Zap? <a href="#id-27eed32c-a46a-44f9-98ee-2a3f74e0dadd" id="id-27eed32c-a46a-44f9-98ee-2a3f74e0dadd"></a>

Zap ist eine Funktion, mit der Sie Liquidität ganz einfach hinzufügen können. Mit Zap können Sie Liquidität mit jedem Token bereitstellen, den Sie in Ihrer Wallet haben, unabhängig von den im Pool erforderlichen Token. Legen Sie einfach die Preisspanne fest, wählen Sie den bereitzustellenden Betrag und führen Sie die Transaktion aus. Ihre Token werden automatisch ausbalanciert, um die Liquiditätsposition zu bilden, während sie auf die effizienteste Weise gehandelt werden, mit geringstem Preiseinfluss und minimaler Kursabweichung.

### Unterstützte Chains

* v3 – Alle Pools auf BNB Chain, ausgewählte Pools auf Ethereum & Arbitrum
* Infinity – Alle CLAMM Pools (ohne Hook) auf BNB Chain

### Verwendung <a href="#id-438fff0f-f1da-4147-9fe3-6dc1dc2ef352" id="id-438fff0f-f1da-4147-9fe3-6dc1dc2ef352"></a>

Derzeit unterstützt Zap:

* 🆕 Jeden Token!
* Verwendung eines einzelnen Tokens
* 🆕 Verwendung von zwei Tokens
* 🆕 Oder... Verwendung mehrerer Tokens (ja, es kann wie ein Kleinstbetrags-Sammler verwendet werden)

#### Start <a href="#e43d56cd-978e-4503-8b7a-974428d4142c" id="e43d56cd-978e-4503-8b7a-974428d4142c"></a>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%283%29%20%282%29.png" alt=""><figcaption></figcaption></figure>

Um Zap zu verwenden, öffnen Sie einfach die Seite „Add Liquidity", wählen Sie das Handelspaar, für das Sie Liquidität bereitstellen möchten, das Gebührentier und die Preisspanne.

Wählen Sie dann den Token-Betrag, den Sie als Liquidität bereitstellen möchten.

Die Option zum Zapping erscheint automatisch, wenn ein oder mehrere Token nicht ausreichend vorhanden sind.

Klicken Sie auf den Link, um den Zap-Dialog aufzurufen.

#### Zap initiieren <a href="#d65281e2-90db-4280-afd0-f24157c88a9b" id="d65281e2-90db-4280-afd0-f24157c88a9b"></a>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%282%29.png" alt=""><figcaption></figcaption></figure>

Im neuen „Zap in"-Dialog finden Sie folgende Felder:

1. Das Handelspaar, für das Sie Zapping durchführen (Liquidität bereitstellen).
2. Die Einzahlungstoken und die einzuzahlenden Beträge. Sie können beliebig Token hinzufügen oder entfernen.
3. Die Preisspanne der neuen Position. Sie können auch auf die Pfeile klicken, um zwischen verschiedenen Preisanzeigen zu wechseln.
4. Eine detaillierte Aufschlüsselung, wie die Zap-Funktion Ihre Einzahlungstoken verarbeitet.
5. Eine Zusammenfassung der Statistiken, einschließlich:
   1. Geschätzter Wert in USD für die neue Liquiditätsposition.
   2. Geschätzte Token-Menge in der neuen Liquiditätsposition.
   3. Geschätzte verbleibende Mittel in USD nach dem Zapping. In den meisten Fällen sollte dieser Wert 0 sein. Falls der Liquiditätspool oder die Token sehr geringe Liquidität aufweisen, kann dieser Wert steigen.
   4. Der Preiseinfluss für die Token-Swaps und Neuausrichtungen beim Zapping.
   5. Der Preiseinfluss für das Hinzufügen von Liquidität und den Aufbau der Position.
   6. Zap-Gebühr. Je nach Liquiditätspaar kann der Gebührensatz variieren.

{% hint style="warning" %}
Bitte beachten Sie, dass Sie den Zap-Betrag möglicherweise basierend auf Ihrem verfügbaren Guthaben anpassen müssen. Wenn Sie bei einem der Token kein Guthaben haben, entfernen Sie diesen bitte.
{% endhint %}

{% hint style="info" %}
Sie werden feststellen, dass die Einstellungen aus „Add V3 Liquidity" automatisch in den Zap-Dialog übernommen werden, einschließlich des Einzahlungsbetrags und der Preisspannen-Einstellungen.
{% endhint %}

#### Zap starten <a href="#id-6cc5fa08-d336-46d9-8fdd-199bcbae8267" id="id-6cc5fa08-d336-46d9-8fdd-199bcbae8267"></a>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%282%29%20%282%29.png" alt="" width="375"><figcaption></figcaption></figure>

Klicken Sie abschließend auf „Approve" und bestätigen Sie im Wallet-Pop-up die Token-Berechtigung.

Klicken Sie dann auf „Preview", um den finalen Bestätigungsdialog aufzurufen. Bevor Sie fortfahren, überprüfen Sie bitte alle im Bestätigungsdialog angezeigten Statistiken und Schätzwerte sorgfältig. Achten Sie besonders auf die Einfluss-Kennzahlen und die maximale Kursabweichung.

Klicken Sie abschließend auf „Add Liquidity" und bestätigen Sie in Ihrem Wallet-Pop-up.

Nachdem die Transaktion bestätigt wurde, sehen Sie Ihre neue Position auf der Seite „My Position".

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%283%29%20%282%29%20%281%29.png" alt="" width="375"><figcaption></figcaption></figure>

#### Weitere Einstellungen <a href="#id-217348b6-db9d-4336-9060-d8cbd8171cd9" id="id-217348b6-db9d-4336-9060-d8cbd8171cd9"></a>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%284%29.png" alt="" width="375"><figcaption></figcaption></figure>

Wenn Sie Ihr Zap-Erlebnis weiter anpassen möchten, klicken Sie einfach auf das Zahnrad-Symbol in der oberen rechten Ecke. In den Einstellungen können Sie Folgendes konfigurieren:

* Die maximale Kursabweichung beim Zapping.
* Den Zeitraum für das Transaktionslimit.
* Ob die aggregierte Liquidität von KyberSwap für die Token-Neuausrichtung verwendet werden soll. Deaktivieren Sie diese Option, wenn Sie nur in PancakeSwap Pools handeln möchten.
* Der Degen-Modus kann für Zaps mit sehr hoher Kursabweichung verwendet werden. Nicht für normale Anwendungsfälle empfohlen – Verwendung auf eigenes Risiko.

{% hint style="warning" %}
Bitte beachten Sie, dass die Kursabweichungs- und Frist-Einstellungen unabhängig von der Swap- und Liquiditätsseite sind.
{% endhint %}

#### Zap mit zwei Tokens

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%281%29%20%281%29%20%281%29%20%281%29.png" alt="" width="375"><figcaption></figcaption></figure>

Sie können Ihre Liquidität nun auch mit zwei Tokens einzahlen (Zap in). Dies ist nützlich, wenn Ihr verfügbares Guthaben nicht mit den Preiseinstellungen und dem geforderten Token-Betrag und -Verhältnis übereinstimmt. Führen Sie einfach Zap aus, und das Verhältnis wird automatisch neu ausbalanciert.

#### Zap mit mehreren Tokens

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%282%29%20%281%29.png" alt="" width="375"><figcaption></figcaption></figure>

Ja, es funktioniert wie ein Kleinstbetrags-Sammler. Es eignet sich hervorragend, um kleine Restguthaben in Ihrer Wallet aufzuräumen und sie in eine Position umzuwandeln, mit der Sie Handelsgebühren verdienen können.&#x20;
