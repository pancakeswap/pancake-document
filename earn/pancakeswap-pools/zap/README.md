# Zap

### Что такое Zap <a href="#id-27eed32c-a46a-44f9-98ee-2a3f74e0dadd" id="id-27eed32c-a46a-44f9-98ee-2a3f74e0dadd"></a>

Zap — это функция, позволяющая легко добавлять ликвидность. С Zap ты можешь предоставлять ликвидность с помощью любого токена, который есть у тебя на балансе, независимо от того, какие токены требуются в пуле. Просто установи ценовой диапазон, выбери сумму для предоставления и выполни. Твои токены будут автоматически сбалансированы для формирования позиции ликвидности, торгуясь наиболее эффективным способом с минимальным ценовым воздействием и проскальзыванием.

### Поддерживаемые сети

* v3 — все пулы на BNB Chain, выбранные пулы в сетях Ethereum и Arbitrum
* Infinity — все пулы CLAMM (без hook) на BNB Chain

### Как использовать <a href="#id-438fff0f-f1da-4147-9fe3-6dc1dc2ef352" id="id-438fff0f-f1da-4147-9fe3-6dc1dc2ef352"></a>

На данный момент Zap поддерживает:

* 🆕 Любой токен!
* Использование одного токена
* 🆕 Использование двух токенов
* 🆕 Или... использование нескольких токенов (да, он может работать как сборщик пылевых токенов)

#### Начало работы <a href="#e43d56cd-978e-4503-8b7a-974428d4142c" id="e43d56cd-978e-4503-8b7a-974428d4142c"></a>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%283%29%20%282%29.png" alt=""><figcaption></figcaption></figure>

Чтобы использовать Zap, просто перейди на страницу добавления ликвидности, выбери торговую пару, для которой хочешь предоставить ликвидность, уровень комиссии и ценовой диапазон.

Затем выбери количество токенов, которые хочешь предоставить в ликвидность.

Опция Zap автоматически появится, когда для одного или нескольких токенов недостаточно баланса.

Нажми на ссылку, чтобы открыть модальное окно Zap.

#### Инициация Zap <a href="#d65281e2-90db-4280-afd0-f24157c88a9b" id="d65281e2-90db-4280-afd0-f24157c88a9b"></a>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%282%29.png" alt=""><figcaption></figcaption></figure>

В новом модальном окне «Zap in» ты найдёшь следующие поля:

1. Торговая пара, в которую ты осуществляешь Zap (предоставляешь ликвидность).
2. Токен(ы) для депозита и сумма(ы) для внесения. Ты можешь свободно добавлять или убирать токены для Zap.
3. Ценовой диапазон новой позиции. Ты также можешь нажать на стрелки для переключения между различными отображениями цены.
4. Подробная разбивка того, как функция Zap будет обрабатывать твои токены для депозита.
5. Сводка статистики, включающая:
   1. Расчётная стоимость в USD для новой позиции ликвидности.
   2. Расчётное количество токенов в новой позиции ликвидности.
   3. Расчётный остаток средств в USD после Zap. В большинстве случаев должно быть 0. Если у пула ликвидности или токенов очень мало ликвидности, это значение может увеличиться.
   4. Ценовое воздействие для обменов и перебалансировок токенов во время Zap.
   5. Ценовое воздействие при добавлении ликвидности и формировании позиции.
   6. Комиссия Zap. В зависимости от пары ликвидности ставка комиссии может варьироваться.

{% hint style="warning" %}
Обрати внимание, что может потребоваться перенастройка суммы для Zap в зависимости от доступного баланса. Если у тебя нет баланса одного из токенов, удали его.
{% endhint %}

{% hint style="info" %}
Ты можешь заметить, что настройки из «Add V3 Liquidity» автоматически переносятся в модальное окно Zap. Включая сумму депозита и настройки ценового диапазона.
{% endhint %}

#### Запуск Zap <a href="#id-6cc5fa08-d336-46d9-8fdd-199bcbae8267" id="id-6cc5fa08-d336-46d9-8fdd-199bcbae8267"></a>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%282%29%20%282%29.png" alt="" width="375"><figcaption></figcaption></figure>

Наконец, нажми «Approve» и подтверди во всплывающем окне кошелька разрешение токена.

Затем нажми «Preview», чтобы открыть финальное модальное окно подтверждения. Перед тем как продолжить, пожалуйста, внимательно проверь всю статистику и оценки, показанные в финальном модальном окне подтверждения. Особенно показатели воздействия и максимальное проскальзывание.

Наконец, нажми «Add Liquidity» и подтверди во всплывающем окне кошелька.

После подтверждения транзакции ты увидишь свою новую позицию на странице «My Position».

#### Дополнительные настройки <a href="#id-217348b6-db9d-4336-9060-d8cbd8171cd9" id="id-217348b6-db9d-4336-9060-d8cbd8171cd9"></a>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%284%29.png" alt="" width="375"><figcaption></figcaption></figure>

Если хочешь дополнительно настроить опыт использования Zap, просто нажми на значок шестерёнки в верхнем правом углу. В настройках ты можешь конфигурировать:

* Максимальное проскальзывание при использовании Zap.
* Временной предел для дедлайна транзакции.
* Использовать ли агрегированную ликвидность KyberSwap для перебалансировки токенов. Отключи эту опцию, если хочешь торговать только в пулах PancakeSwap.
* Режим Degen можно использовать для Zap с очень высоким проскальзыванием. Не рекомендуется для обычного использования — используй на свой страх и риск.

{% hint style="warning" %}
Обрати внимание, что настройки проскальзывания и дедлайна независимы от страниц обмена и ликвидности.
{% endhint %}

#### Zap с двумя токенами

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%281%29%20%281%29%20%281%29%20%281%29.png" alt="" width="375"><figcaption></figcaption></figure>

Теперь ты можешь добавлять ликвидность с помощью двух токенов. Это удобно, когда доступный баланс не совпадает с настройками цены и необходимым количеством и соотношением токенов. Просто используй Zap, и соотношение будет автоматически перебалансировано.

#### Zap с множеством токенов

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%282%29%20%281%29.png" alt="" width="375"><figcaption></figcaption></figure>

Да, он работает как сборщик пылевых токенов. Подходит для очистки небольших остатков в кошельке и размещения их в позицию для начала заработка от торговых комиссий.&#x20;
