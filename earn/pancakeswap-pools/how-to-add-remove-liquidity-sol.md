# So fügen Sie Liquidität hinzu / entfernen sie (SOL)

„Liquidität" ist das Herzstück der Funktionsweise von PancakeSwaps Exchange. Sie können Liquidität für jedes Token-Paar hinzufügen, indem Sie beide Token über die Liquiditätsseite einsetzen.

Als Gegenleistung für das Hinzufügen von Liquidität erhalten Sie Handelsgebühren für dieses Paar sowie Farm-Prämien (falls zutreffend).

PancakeSwap V3 ermöglicht es Ihnen, **konzentrierte Liquidität** bereitzustellen – das bedeutet, Sie wählen die Preisspanne, in der Ihre Liquidität aktiv ist. Dadurch haben Sie mehr Kontrolle und Effizienz über den Einsatz Ihres Kapitals.

{% hint style="warning" %}
**Hinweis:** Die in diesem Leitfaden gezeigten Bilder dienen nur zur Veranschaulichung und spiegeln möglicherweise keine Echtzeit-Daten oder aktuellen Pool-Statistiken wider.
{% endhint %}

## Liquidität hinzufügen

Sie können Liquidität auf zwei Arten hinzufügen:

* **Option 1:** Einem bestehenden Pool beitreten
* **Option 2:** Einer bereits erstellten Position weitere Token hinzufügen

***

### Option 1: Einem bestehenden Pool beitreten

#### Schritt 1: Zur Pool-Listenansicht navigieren

Hier sehen Sie alle aktiven V3 Pools auf Solana.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28386%29.png" alt=""><figcaption></figcaption></figure>

#### Schritt 2: Filter verwenden, um Ihren Pool zu finden

Sie können die Filter oben auf der Seite verwenden, um:

*   Nach einem bestimmten Token-Paar zu **suchen**<br>

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28387%29.png" alt=""><figcaption></figcaption></figure>
*   Die **Layoutansicht** zu wechseln (Raster/Liste)<br>

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28388%29.png" alt=""><figcaption></figcaption></figure>
*   Pools nach TVL, Volumen, Gebühren oder APR zu **sortieren**<br>

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28389%29.png" alt=""><figcaption></figcaption></figure>

{% hint style="success" %}
Falls Ihr Pool nach der Erstellung nicht sofort erscheint, warten Sie bitte bis zu 5 Minuten. TVL-, Volumen-, Gebühren- und APR-Statistiken werden etwa alle 15 Minuten aktualisiert, sobald Swaps durch den Pool fließen.
{% endhint %}

#### Schritt 3: Wählen Sie, wie Sie Liquidität hinzufügen möchten

Sie können den Prozess starten, indem Sie entweder:

*   Auf der Pool-Karte auf **„Deposit"** klicken<br>

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28390%29.png" alt=""><figcaption></figcaption></figure>
*   ODER unter „My Positions" auf **„Create New Position"** klicken<br>

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28391%29.png" alt=""><figcaption></figcaption></figure>

#### Schritt 4: Preisspanne festlegen

Da es sich um einen V3 Pool handelt, müssen Sie eine Preisspanne für Ihre Liquidität festlegen:

*   **Schnelle Voreinstellungen** verwenden (z. B. ± 25 %) oder eine benutzerdefinierte Spanne festlegen<br>

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28392%29.png" alt=""><figcaption></figcaption></figure>
*   Den **Preisrichtungs-Umschalter** verwenden, um zwischen Basis-/Notierungsansicht zu wechseln<br>

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28393%29.png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
Achten Sie auf **Warnhinweise**, wenn:

* Ihre gewählte Spanne weit vom Marktpreis entfernt ist
* Der Pool geringe Liquidität aufweist
{% endhint %}

#### Schritt 5: Einzahlungsbetrag eingeben

Geben Sie die Token-Mengen ein, die Sie bereitstellen möchten.

\*\* Der APR wird erst angezeigt, wenn Sie Beträge für beide Token eingegeben haben.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28394%29.png" alt=""><figcaption></figcaption></figure>

#### Schritt 6: Vorschau & Bestätigung

*   Klicken Sie auf **„Add Liquidity"**

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28396%29.png" alt=""><figcaption></figcaption></figure>
*   Überprüfen Sie Ihre Position im Vorschau-Dialog<br>

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28397%29.png" alt=""><figcaption></figcaption></figure>

Nach der Bestätigung wird die Transaktion eingereicht und Ihre Position wird erstellt!

## Liquidität entfernen

Sie können Liquidität aus jeder Ihrer aktiven Positionen direkt über den Tab **My Positions** entfernen.

#### 1. Zu **My Positions** navigieren

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28402%29.png" alt=""><figcaption></figcaption></figure>

#### 2. Die Position auswählen, aus der Sie Liquidität entfernen möchten

Klicken Sie auf das **„−"**-Symbol neben der Position.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28403%29.png" alt=""><figcaption></figcaption></figure>

#### 3. Den zu entfernenden Betrag eingeben

Sie können entweder:

* Die Token-Mengen manuell eingeben
* **ODER** den **Schieberegler** verwenden, um einen Prozentsatz Ihrer aktuellen Position zu wählen

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28404%29.png" alt=""><figcaption></figcaption></figure>

#### 4. (Optional) Position nach dem Entfernen von Liquidität offenhalten

Wenn Sie beim Entfernen von **100 %** Ihrer Liquidität **„Keep my position open"** auswählen:

* Ihre Token werden ausgezahlt
* Aber die Positionshistorie und Ihre ursprüngliche Preisspanne bleiben unter **My Positions** **sichtbar**

Wenn Sie die Position **vollständig schließen** möchten, einschließlich der Anzeige der Preisspanne:

* Klicken Sie auf das **„X"**-Symbol

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28408%29.png" alt=""><figcaption></figcaption></figure>

#### 5. Dieselbe Preisspanne erneut verwenden

Sie können der gleichen Preisspanne später auch **weitere Liquidität hinzufügen**, indem Sie dieselben Schritte wie beim ersten Hinzufügen von Liquidität befolgen.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28409%29.png" alt=""><figcaption></figcaption></figure>
