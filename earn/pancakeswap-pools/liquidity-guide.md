# So fügen Sie Liquidität hinzu / entfernen sie (EVM)

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-add-remove-liquidity-header.png)

„Liquidität" ist das Herzstück der Funktionsweise von PancakeSwaps Exchange. Sie können Liquidität für jedes Token-Paar hinzufügen, indem Sie beide Token über die Liquiditätsseite einsetzen.

Als Gegenleistung für das Hinzufügen von Liquidität erhalten Sie Handelsgebühren für dieses Paar sowie entweder ein NFT oder LP-Token, die Sie in [Farms](https://pancakeswap.finance/farms) einsetzen können, um CAKE-Prämien zu verdienen!

## Exchange V3

Um Liquidität bereitzustellen, müssen Sie einen Betrag eines beliebigen Token-Paares einsetzen. Ihr niedrigster Wert (in USD) der beiden Token bestimmt das Limit der Liquidität, die Sie bereitstellen können.

Sie können problemlos beliebige Token handeln, die Sie benötigen. Besuchen Sie unseren Leitfaden [So handeln Sie auf PancakeSwap](https://docs.pancakeswap.finance/get-started/trade-guide), falls Sie Hilfe benötigen.

In diesem Beispiel fügen wir V3-Liquidität mit ETH und USDC hinzu.



1 – Besuchen Sie die [Liquiditäts](https://pancakeswap.finance/liquidity)seite.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28243%29.png" alt=""><figcaption></figcaption></figure>

2 – Klicken Sie auf den Button „Add Liquidity".



3 – Wählen Sie über das Eingabefeld oben links die beiden Token des Handelspaares, für das Sie Liquidität hinzufügen möchten. Hier verwenden wir ETH und USDC als Beispiel.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28126%29.png)



4 – Die Oberfläche wählt automatisch das beliebteste Handelsgebührentier und konfiguriert die Preisspanne für Sie.



5 – Sie können die Version sowie das Gebührentier des Liquiditätspools, für den Sie Liquidität bereitstellen, anhand der Anzeige „V3 LP – x % Gebührentier" bestätigen.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2843%29.png)

* Wenn Sie das Gebührentier anpassen möchten, klicken Sie auf „More" und wählen Sie das gewünschte Gebührentier.
* Bitte beachten Sie, dass es immer empfehlenswert ist, Liquidität im beliebtesten Gebührentier bereitzustellen.



6 – Sie können die Preisspanne in den Anzeigen auf der rechten Seite überprüfen und bestätigen.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2822%29.png)

* Das Diagramm zeigt das Liquiditätsniveau über alle Preisspannen hinweg. Sie können mit den Lupensymbolen hinein- und herauszoomen. Sie können das Diagramm durch Ziehen der unteren x-Achse verschieben und navigieren.
* Wenn Sie die Preisspanne anpassen möchten, ziehen Sie einfach die Griffe, klicken Sie auf die + und – Buttons bei den beiden Preisen oder klicken Sie auf die beiden Preiszahlen und geben Sie diese manuell ein.
* Obwohl es nicht empfohlen wird, können Sie Ihre Liquidität über die gesamte Preisspanne bereitstellen, indem Sie auf den Button „Full Range" klicken.



7 – Geben Sie unter „Deposit Amount" bei einem der Token einen Betrag ein. Der andere sollte automatisch berechnet und ausgefüllt werden. Falls einer der Token kein ausreichendes Guthaben hat, wird ein Fehler angezeigt und der Button ausgegraut. Bitte geben Sie einen niedrigeren Betrag ein, um fortzufahren, oder verwenden Sie den „MAX"-Button, um den maximal verfügbaren Wert einzufügen.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2847%29.png)



8 – Klicken Sie auf den Button „Enable USDC". Falls Sie Liquidität gegen andere Token als ETH hinzufügen, müssen Sie möglicherweise zweimal auf „Enable" klicken, für jeden Token Ihres Paares. Ihre Wallet wird Sie um Bestätigung der Aktion bitten.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2898%29.png)



9 – Der „Add"-Button leuchtet dann auf. Klicken Sie, um fortzufahren.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2826%29.png)



10 – Ein neues Pop-up-Fenster erscheint mit einer Vorschau Ihrer Liquiditätsposition. Wenn alles korrekt aussieht, klicken Sie erneut auf „Add", um fortzufahren.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2838%29.png)



11 – Ihre Wallet wird Sie um Bestätigung bitten. Bestätigen Sie Ihre Transaktion aus Ihrer Wallet.



12 – Kurz darauf sehen Sie Ihre neue Liquiditätsposition auf der Seite „My Liquidity". Sie können deren Details einsehen, indem Sie auf die Position klicken.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28211%29.png" alt=""><figcaption></figcaption></figure>

### **Liquidität entfernen**

So entfernen Sie Liquidität.

1 – Besuchen Sie die [Liquiditäts](https://pancakeswap.finance/liquidity)seite**.**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28191%29.png" alt=""><figcaption></figcaption></figure>



2 – Klicken Sie unter „Your Liquidity" auf die Position, aus der Sie Liquidität entfernen möchten. Sie können den Filter verwenden, um schnell alle V3-Liquiditätspositionen anzuzeigen.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28251%29.png)



3 – Klicken Sie auf „Remove". Ein neues Fenster erscheint.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28286%29.png)



4 – Verwenden Sie die Buttons oder den Schieberegler, um festzulegen, wie viel Liquidität Sie entfernen möchten. Wählen Sie „MAX", um Ihre gesamte Liquidität aus diesem Paar zu entfernen.

5 – Klicken Sie auf „Remove", um fortzufahren.

6 – Ein Fenster erscheint und zeigt an, wie viele Token Sie erhalten werden. Klicken Sie erneut auf „Remove". Ihre Wallet wird Sie um Bestätigung der Aktion bitten.

7 – Nachdem die Transaktion bestätigt wurde, erhalten Sie die beiden Token Ihres Paares. Und falls Sie nicht die gesamte Liquidität entfernt haben, wird Ihr verbleibender Liquiditätswert auf der Liquiditätsseite aktualisiert.



## Exchange V2

### Liquidität hinzufügen

In diesem Beispiel fügen wir V2-Liquidität mit BNB und CAKE hinzu.

{% hint style="warning" %}
Bitte beachten Sie, dass dieses Beispiel nur zur Veranschaulichung dient – das CAKE/BNB-Handelspaar wurde zu V3 migriert. Bitte stellen Sie immer V3-Liquidität bereit, es sei denn, einer der zugrunde liegenden Token unterstützt Exchange V3 nicht oder der Großteil der Liquidität für das Token-Paar wurde noch nicht migriert.
{% endhint %}

1. Besuchen Sie die [Liquiditäts](https://pancakeswap.finance/liquidity)seite.
2. Klicken Sie auf den Button „Add Liquidity".
3. Wählen Sie über das Eingabefeld oben links die beiden Token des Handelspaares, für das Sie Liquidität hinzufügen möchten. Hier verwenden wir BNB und CAKE als Beispiel.
4. Die Oberfläche fügt standardmäßig V3-Liquidität hinzu, mit einigen Ausnahmen:
   1. Falls das Handelspaar eine aktive PancakeSwap V2 Farm hat, wird standardmäßig V2-Liquidität hinzugefügt.
   2. Falls das Handelspaar einen bestehenden V2-Liquiditätspool hat, wird ein Link „Add V2 Liquidity" angezeigt. Klicken Sie einfach darauf, um zu V2-Liquidität zu wechseln.
5. Bestätigen Sie, dass Sie nun V2-Liquidität hinzufügen, indem Sie nach der Anzeige „V2 LP – 0,25 Gebührentier" Ausschau halten.
6. Geben Sie unter „Deposit Amount" bei einem der Token einen Betrag ein. Der andere sollte automatisch berechnet und ausgefüllt werden. Falls einer der Token kein ausreichendes Guthaben hat, wird ein Fehler angezeigt und der Button ausgegraut. Bitte geben Sie einen niedrigeren Betrag ein, um fortzufahren, oder verwenden Sie den „MAX"-Button, um den maximal verfügbaren Wert einzufügen.
7. Klicken Sie auf den Button „Enable CAKE". Falls Sie Liquidität gegen andere Token als BNB hinzufügen, müssen Sie möglicherweise zweimal auf „Enable" klicken, für jeden Token Ihres Paares. Ihre Wallet wird Sie um Bestätigung der Aktion bitten.
8. Der „Add"-Button leuchtet dann auf. Klicken Sie, um fortzufahren.
9. Ihre Wallet wird Sie um Bestätigung bitten. Bestätigen Sie Ihre Transaktion aus Ihrer Wallet.
10. Kurz darauf sehen Sie Ihr LP-Token-Guthaben auf der Liquiditätsseite, zusammen mit anderen Liquiditätspositionen aus V3 und StableSwap.

### **Liquidität entfernen**

So entfernen Sie Liquidität.

1\. Besuchen Sie die [Liquiditäts](https://exchange.pancakeswap.finance/#/pool)seite**.**

2\. Klicken Sie unter „Your Liquidity" auf das Paar, aus dem Sie Liquidität entfernen möchten. Sie können den Filter verwenden, um schnell alle V2-Liquiditätspositionen anzuzeigen.

3\. Klicken Sie auf „Remove". Ein neuer Dialog erscheint.

4\. Verwenden Sie die Buttons oder den Schieberegler, um festzulegen, wie viel Liquidität Sie entfernen möchten. Wählen Sie „MAX", um Ihre gesamte Liquidität aus diesem Paar zu entfernen.

5\. Klicken Sie auf „Enable". Ihre Wallet wird Sie auffordern, die Aktion zu unterzeichnen**.**

6\. Der „Remove"-Button leuchtet auf. Klicken Sie, um fortzufahren.

7\. Ein Fenster erscheint und zeigt an, wie viele Token Sie erhalten werden. Klicken Sie auf „Confirm". Ihre Wallet wird Sie um Bestätigung der Aktion bitten.

8\. Nachdem die Transaktion bestätigt wurde, erhalten Sie die beiden Token Ihres Paares. Und falls Sie nicht die gesamte Liquidität entfernt haben, wird Ihr verbleibender Liquiditätswert auf der Liquiditätsseite aktualisiert.<br>
