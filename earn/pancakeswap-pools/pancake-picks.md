# ⛏️ Pancake Picks

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%281%29%20%281%29.png" alt=""><figcaption></figcaption></figure>

Dalam dunia kripto yang bergerak cepat, memisahkan kebisingan dari tren bisa menjadi hal yang sulit. Pancake Picks membantu dengan menampilkan pasangan token terbaik dari kategori yang sedang tren seperti Memecoin dan AI Agent di halaman [Pool Likuiditas](https://pancakeswap.finance/liquidity/pools) kami setiap hari kerja. Dengan menyoroti token-token ini berdasarkan data pasar dan komunitas utama, Pancake Picks memudahkan pengguna untuk menemukan tren terkini.&#x20;

### Bagaimana cara kerja Pancake Picks?

1. **Kategori Token**: Kami menggunakan API CoinGecko untuk menemukan token yang sedang tren dalam kategori seperti [Meme](https://www.coingecko.com/en/categories/meme-token) dan [AI Agent,](https://www.coingecko.com/en/categories/ai-agents) kemudian mencocokkannya dengan token di PancakeSwap di salah satu dari 8 rantai EVM yang kami dukung.
2. **Memilih Pasangan Terbaik**: Kami menganalisis Pool Likuiditas dan memilih 3 pasangan token teratas dari daftar ini berdasarkan data pasar dan komunitas yang signifikan selama 24 jam sebelumnya.
3. **Formula**: Untuk menjaga keadilan dan menghindari manipulasi sistem, kami tidak mengungkapkan formula pasti untuk cara kami memilih token. The Kitchen akan menyesuaikannya dari waktu ke waktu untuk mencerminkan tren pasar.
4. **Token yang Lulus**: Setidaknya satu dari 3 pasangan teratas akan berasal dari token yang telah lulus dari four.meme atau PancakeSwap Springboard.

### Manfaat Token yang Ditampilkan

#### Manfaat dari PancakeSwap:&#x20;

Jika pasangan token Anda dipilih untuk Pancake Picks, Anda akan menikmati:

* **Whitelisting**: Jika token Anda belum ada di daftar token kami, kami akan menambahkannya.
* **Emisi CAKE**: Token Anda akan mendapatkan emisi CAKE selama ditampilkan.
* **Visibilitas yang Meningkat**: Kami akan menampilkan token Anda secara menonjol di halaman Pool Likuiditas kami, memudahkan pengguna untuk menjelajahi token dan pasangan Likuiditasnya.

### Mengapa Pancake Picks penting?

* **Seleksi Berbasis Data**: Pancake Picks menyediakan pendekatan transparan dan berbasis kualitas untuk menyoroti token yang sedang mendapatkan momentum di pasar, memungkinkan pengguna menemukan proyek-proyek relevan yang sedang tren.
* **Menyederhanakan Dukungan**: The Kitchen menerima banyak permintaan dukungan dari proyek-proyek baru. Pancake Picks membantu menyederhanakan proses dengan berfokus pada token dengan metrik pasar dan komunitas yang kuat, sehingga lebih mudah untuk mengevaluasi proyek mana yang harus diprioritaskan.
* **Mendorong Likuiditas PancakeSwap**: Dengan menampilkan token di Pancake Picks, kami mendorong tim untuk menempatkan token mereka di PancakeSwap, sehingga mendukung lebih lanjut tujuan kami untuk menyediakan Likuiditas bagi proyek-proyek berkualitas tinggi di berbagai rantai.

### FAQ

1. Token saya berkinerja baik, tetapi mengapa tidak dipilih?
   1. Kami tidak berbagi formula pasti yang kami gunakan untuk memilih token guna mencegah manipulasi. Jika token Anda tidak terpilih, metrik pasar atau komunitas utama mungkin tidak lengkap. Teruslah membangun, dan token Anda bisa ditampilkan di masa mendatang!
2. Likuiditas token saya ada di DEX lain, apakah akan dipertimbangkan untuk Pancake Picks?
   1. Tidak. Kami hanya mempertimbangkan token yang Likuiditasnya berada di PancakeSwap, beserta metrik dari Pool Likuiditas kami. Jika Anda ingin token Anda dipertimbangkan, pastikan untuk menambahkan Likuiditas ke salah satu dari 8 rantai EVM yang kami dukung.
3. Berapa lama Pancake Picks akan berlangsung?
   1. Tidak ada tanggal akhir yang ditetapkan, tetapi jika minat menurun atau jika fitur ini tidak lagi sesuai dengan tujuan kami, kami mungkin akan menghentikannya. Kami juga akan mengadaptasi kategori token untuk mengikuti tren baru.
4. Kategori token apa yang saat ini dipertimbangkan untuk Pancake Picks?
   1. Saat ini kami melihat Memecoin dan AI Agent, sebagaimana didefinisikan oleh CoinGecko, meskipun kami mungkin memperluas atau menyesuaikan daftar ini di masa mendatang.
5. Mengapa token saya tidak dipilih, meskipun ada dalam kategori aktif?
   1. Pastikan token Anda terdaftar di CoinGecko dengan tag kategori yang benar. Jika tidak, kami tidak akan dapat menemukannya melalui API mereka.
6. Mengapa \<masukkan kategori token> tidak dipertimbangkan oleh Pancake Picks? Saat ini sedang tren dan semakin populer di komunitas kripto
   1. Kami terbuka terhadap saran! Silakan bagikan permintaan Anda di [Telegram](https://t.me/pancakeswap) atau [Discord](https://discord.com/invite/pancakeswap). Namun, untuk menjaga agar proses penyaringan tetap efisien, kami perlu membatasi jumlah kategori yang kami pertimbangkan.
7. Berapa banyak emisi CAKE yang akan diterima pasangan token yang dipilih?
   1. Posisi 1: 30 CAKE per hari
   2. Posisi 2: 20 CAKE per hari
   3. Posisi 3: 10 CAKE per hari
   4. Angka-angka ini mungkin berubah seiring perkembangan produk. Untuk saat ini, emisi berasal dari [anggaran diskresi The Kitchen,](https://pancakeswap.finance/voting/proposal/0x8eff088ca5d8c07a1a0be979533b6aa36dd098edb62714f948c06cf561817432) tanpa emisi baru. Jika fitur ini menjadi populer, kami mungkin akan memanfaatkan anggaran Pertumbuhan Ekosistem untuk meningkatkan emisi.
8. Bagaimana cara saya meningkatkan kinerja token agar dipertimbangkan untuk Pancake Picks?
   1. Meskipun kami tidak dapat berbagi formula pasti yang kami gunakan, kami mendorong proyek untuk terus menumbuhkan daya tarik token dan komunitas mereka secara organik, yang seharusnya tercermin positif saat kami melakukan evaluasi internal.
9. Seberapa sering Pancake Picks akan diperbarui?
   1. Pancake Picks akan diperbarui setiap hari kerja. Jika token Anda ditampilkan pada hari Jumat, token tersebut akan tetap aktif selama sekitar 3 hari.
10. Pukul berapa Pancake Picks akan diperbarui?
    1. Tidak ada waktu yang ditetapkan, tetapi kami bertujuan untuk memperbarui Picks setiap hari kerja sekitar pukul 09.00 UTC.
11. Kapan data token akan dipertimbangkan?
    1. Kami menggunakan data dari 24 jam terakhir, yang diperbarui pukul 00.00 UTC setiap hari kerja untuk menentukan Pancake Picks.
    2. Untuk 3 pasangan teratas per epoch, mereka akan dipilih berdasarkan frekuensi kemunculan mereka di Pancake Picks sepanjang 2 minggu. Jika ada seri, kami akan mengambil pasangan dengan skor lebih tinggi selama epoch berdasarkan formula internal kami.
