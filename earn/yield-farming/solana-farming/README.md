# Solana 파밍

## PancakeSwap SOL v3에서 파밍 이용 방법

파밍을 이용하면 적격 풀에 유동성을 공급할 때 기본 유동성 공급자(LP) 수수료에 더해 추가 보상을 받을 수 있습니다. 다음 주소에서 시작하는 방법은 아래와 같습니다: [https://solana.pancakeswap.finance/liquidity-pools/](https://solana.pancakeswap.finance/liquidity-pools/)

{% hint style="warning" %}
**참고:** 이 가이드에 표시된 이미지는 설명을 위한 것이며 실시간 데이터나 현재 파밍 통계를 반영하지 않을 수 있습니다.
{% endhint %}

***

### 1. 파밍 필터링하여 보기

*   **풀 목록(Pool List)** 페이지에서 **"Show Farm only"** 필터를 켜면 파밍 보상을 제공하는 풀만 표시됩니다.

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%281%29.png" alt=""><figcaption></figcaption></figure>

### 2. APR 상세 내역 확인

* 풀 옆에 표시된 APR 위에 **마우스를 올리거나** **클릭**하세요.
*   다음과 같은 상세 내역이 표시됩니다.

    * 거래 수수료에서 발생하는 LP 보상
    * 파밍 인센티브에서 발생하는 추가 보상
    * 해당 풀의 토큰 기준 **예상 주간 보상**

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%281%29%20%284%29.png" alt=""><figcaption></figcaption></figure>

### 3. 파밍 보상 획득 시작

* 파밍이 활성화된 풀에 **유동성을 추가**하기만 하면 됩니다.
* **활성(범위 내)** 포지션을 보유하게 되면:
  * **스왑이 발생할 때 자동으로** 파밍 보상을 획득하기 시작합니다.
  * **LP NFT를 스테이킹할 필요가 없습니다**. 보상이 포지션에 직접 누적됩니다.

### 4. 보상 확인

* **"My Positions"** 페이지로 이동하여 다음을 확인하세요.
  * 활성 LP 포지션
  * 각 포지션별로 누적된 파밍 보상

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28415%29.png" alt=""><figcaption></figcaption></figure>

### 5. 보상 수령

* 포지션에서 **"Harvest"를 클릭**하면 다음을 모두 수확합니다.
  * LP 보상(거래 수수료에서 발생)
  * 파밍 토큰 보상(해당하는 경우)
* **"Harvest All"**을 사용하면 **모든 활성 포지션**의 보상을 한 번의 트랜잭션으로 수령할 수 있습니다.
