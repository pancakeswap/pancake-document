# Solana Farming

## Anleitung zur Nutzung von Farms auf PancakeSwap SOL V3

Farming ermöglicht es Ihnen, zusätzliche Rewards auf die Standard-Liquiditätsanbieter-(LP-)Gebühren zu verdienen, wenn Sie Liquidität in berechtigten Pools bereitstellen. Hier erfahren Sie, wie Sie loslegen können: [https://solana.pancakeswap.finance/liquidity-pools/](https://solana.pancakeswap.finance/liquidity-pools/)

{% hint style="warning" %}
**Hinweis:** Die in dieser Anleitung gezeigten Abbildungen dienen nur zur Veranschaulichung und spiegeln möglicherweise keine Echtzeitdaten oder aktuelle Farming-Statistiken wider.
{% endhint %}

***

### 1. Nach Farms filtern

*   Aktivieren Sie auf der **Pool-Listenseite** den Filter **„Nur Farms anzeigen"**, um ausschließlich Pools anzuzeigen, die Farming-Rewards anbieten.

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%281%29.png" alt=""><figcaption></figcaption></figure>

### 2. APR-Aufschlüsselung anzeigen

* **Fahren Sie über** den neben einem Pool angezeigten APR oder **klicken Sie** darauf.
*   Eine Aufschlüsselung erscheint, die Folgendes anzeigt:

    * LP-Rewards aus Handelsgebühren.
    * Zusätzliche Rewards aus Farming-Incentives.
    * Eine **geschätzte wöchentliche Reward** in Token für diesen Pool.

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%281%29%20%284%29.png" alt=""><figcaption></figcaption></figure>

### 3. Farming-Rewards verdienen

* **Fügen Sie einfach Liquidität** zu einem Pool hinzu, für den Farming aktiviert ist.
* Sobald Sie eine **aktive (im Bereich befindliche)** Position halten:
  * Beginnen Sie **automatisch Farming-Rewards zu verdienen, wenn Swaps stattfinden**.
  * **Kein Staken Ihrer LP-NFT erforderlich** – Rewards werden direkt Ihrer Position gutgeschrieben.

### 4. Rewards verfolgen

* Navigieren Sie zur Seite **„Meine Positionen"**, um Folgendes anzuzeigen:
  * Aktive LP-Positionen.
  * Für jede Position angesammelte Farming-Rewards.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28415%29.png" alt=""><figcaption></figcaption></figure>

### 5. Rewards abrufen

* **Klicken Sie auf „Ernten"** bei einer Position, um sowohl Folgendes zu ernten:
  * LP-Rewards (aus Handelsgebühren)
  * Farming-Token-Rewards (falls zutreffend)
* Verwenden Sie **„Alle ernten"**, um Rewards aus **allen aktiven Positionen** in einer einzigen Transaktion einzusammeln.
