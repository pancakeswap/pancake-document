# Solana Farming

## Cara Menggunakan Farm di PancakeSwap SOL V3

Farming memungkinkan Anda mendapatkan hadiah tambahan di atas biaya penyedia likuiditas (LP) standar ketika Anda menyediakan likuiditas ke pool yang memenuhi syarat. Berikut cara memulainya melalui: [https://solana.pancakeswap.finance/liquidity-pools/](https://solana.pancakeswap.finance/liquidity-pools/)

{% hint style="warning" %}
**Catatan:** Gambar yang ditampilkan dalam panduan ini hanya untuk tujuan ilustrasi dan mungkin tidak mencerminkan data real-time atau statistik farming saat ini.
{% endhint %}

***

### 1. Filter untuk Melihat Farm

*   Di halaman **Pool List**, aktifkan filter **"Show Farm only"** untuk menampilkan hanya pool yang menawarkan hadiah farming.

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%281%29.png" alt=""><figcaption></figcaption></figure>

### 2. Lihat Rincian APR

* **Arahkan kursor** atau **klik** pada APR yang ditampilkan di samping sebuah pool.
*   Rincian akan muncul menampilkan:

    * Hadiah LP dari biaya perdagangan.
    * Hadiah tambahan dari insentif farming.
    * **Estimasi hadiah mingguan** dalam token untuk pool tersebut.

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%281%29%20%284%29.png" alt=""><figcaption></figcaption></figure>

### 3. Mulai Mendapatkan Hadiah Farming

* Cukup **tambahkan likuiditas** ke pool yang farming-nya diaktifkan.
* Setelah Anda memiliki posisi **aktif (dalam rentang)**:
  * Anda akan mulai mendapatkan hadiah farming **secara otomatis saat swap terjadi**.
  * **Tidak perlu melakukan stake LP NFT Anda**—hadiah terakumulasi langsung ke posisi Anda.

### 4. Pantau Hadiah Anda

* Navigasikan ke halaman **"My Positions"** untuk melihat:
  * Posisi LP aktif Anda.
  * Hadiah farming yang terakumulasi untuk setiap posisi.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28415%29.png" alt=""><figcaption></figcaption></figure>

### 5. Klaim Hadiah Anda

* **Klik "Harvest"** pada sebuah posisi untuk memanen keduanya:
  * Hadiah LP (dari biaya perdagangan)
  * Hadiah token farming (jika ada)
* Gunakan **"Harvest All"** untuk mengumpulkan hadiah dari **semua posisi aktif** dalam satu transaksi.
