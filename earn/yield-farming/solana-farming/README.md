# Farming sur Solana

## Comment utiliser les Farms sur PancakeSwap SOL V3

Le farming vous permet de gagner des récompenses supplémentaires en plus des frais standard des fournisseurs de Liquidité (LP) lorsque vous fournissez de la Liquidité à des pools éligibles. Voici comment démarrer via : [https://solana.pancakeswap.finance/liquidity-pools/](https://solana.pancakeswap.finance/liquidity-pools/)

{% hint style="warning" %}
**Remarque :** Les images présentées dans ce guide sont fournies à titre illustratif uniquement et peuvent ne pas refléter les données en temps réel ou les statistiques de farming actuelles.
{% endhint %}

***

### 1. Filtrer pour afficher les Farms

*   Sur la page **Liste des Pools**, activez le filtre **« Afficher les Farms uniquement »** pour n'afficher que les pools offrant des récompenses de farming.

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%281%29.png" alt=""><figcaption></figcaption></figure>

### 2. Voir la répartition de l'APR

* **Survolez** ou **cliquez** sur l'APR affiché à côté d'un pool.
*   Une répartition apparaîtra indiquant :

    * Les récompenses LP issues des frais de trading.
    * Les récompenses supplémentaires des incitations de farming.
    * Une **récompense hebdomadaire estimée** en jetons pour ce pool.

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%281%29%20%284%29.png" alt=""><figcaption></figcaption></figure>

### 3. Commencer à gagner des récompenses de farming

* **Ajoutez simplement de la Liquidité** à un pool dont le farming est activé.
* Une fois que vous détenez une position **active (dans la plage)** :
  * Vous commencerez à gagner des récompenses de farming **automatiquement lorsque des Swaps se produisent**.
  * **Pas besoin de staker votre NFT LP** — les récompenses s'accumulent directement sur votre position.

### 4. Suivre vos récompenses

* Accédez à la page **« Mes positions »** pour consulter :
  * Vos positions LP actives.
  * Les récompenses de farming accumulées pour chaque position.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28415%29.png" alt=""><figcaption></figcaption></figure>

### 5. Réclamer vos récompenses

* **Cliquez sur « Récolter »** sur une position pour récolter à la fois :
  * Les récompenses LP (issues des frais de trading)
  * Les récompenses en jetons de farming (le cas échéant)
* Utilisez **« Tout récolter »** pour collecter les récompenses de **toutes les positions actives** en une seule transaction.
