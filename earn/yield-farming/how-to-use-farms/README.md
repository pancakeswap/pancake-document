# ファームの使い方

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-yield-farms-header.png)

ファームでのYield Farmingは、PancakeSwapでCAKE報酬を獲得するための優れた方法です。

ファームでは**2つのトークン**をステーキングして流動性を提供し、流動性ポジションNFTまたはLP Tokensを受け取り、それをファームにステーキングして報酬を獲得する必要があります。これにより、他のトークンのポジションを保持しながらCAKEを獲得できます！

{% hint style="warning" %}
Yield farmingはシロッププールやシングルトークンステーキングよりも高い報酬が得られる場合がありますが、**インパーマネントロス（Impermanent Loss）**のリスクが伴います。思ったほど怖くはありませんが、始める前にこの概念を理解しておくことをお勧めします。

詳しくは、Binance Academyの[インパーマネントロスに関する記事](https://academy.binance.com/en/articles/impermanent-loss-explained)をご覧ください。
{% endhint %}

## 流動性を提供するペアを見つける

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28360%29.png" alt=""><figcaption></figcaption></figure>

ユニバーサルFarmページにより、PancakeSwapがサポートするすべてのネットワークにわたって、トークン別に流動性ペアを検索し、手数料、取引量、APRを確認できます。ウォレットでネットワークを切り替える必要はありません。

開始するには、[https://pancakeswap.finance/liquidity/pools](https://pancakeswap.finance/liquidity/pools)にアクセスしてください。

#### 機能の説明

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28361%29.png" alt=""><figcaption></figcaption></figure>

1. トレンド中、またはPancakeSwapのファームが付いているすべての流動性プール/ペア
2. ご自身のすべての流動性ポジション
3. すべてのレガシーファーム。「全プール」で以前ステーキングしていたファームが見つからない場合は、こちらを検索してください。
4. デフォルトではすべてのサポートチェーンのファームとトークンが表示されます。このドロップダウンを使用して、ネットワーク/チェーン別にプールをフィルタリングします。
5. このドロップダウンを使用して、トークン別にプールをフィルタリングします。
6. このタブを使用して、DEXタイプ別にプールをフィルタリングします。
7. APR、TVL、または24時間取引量の矢印ボタンをクリックして、選択した指標でプールを並び替えます。
8. bCAKE - ファームイールドブースターのセクション。[詳細はこちら](../../../welcome-to-pancakeswap/vecake-sunset/bcake/)
9. 新バージョンで問題が発生した場合は、このリンクを使用してレガシーファームページに戻ります。

## ポジションをステーキングして報酬を獲得する

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28363%29.png" alt=""><figcaption></figcaption></figure>

流動性が追加されると、右上のテーブルに表示されます。または「マイポジション」タブにも表示されます。

* V3の場合は、「ステーク」をクリックしてポジションをステーキングし、CAKEの獲得を開始してください。V3ではユーザーが複数のポジションを作成できるため、上記の手順を繰り返して、異なる価格レンジで複数のポジションをステーキングできます。
* V2とStableSwapの場合は、「ステーク」をクリックした後、ステーキングするLP tokensの量を指定する必要があります。収益を最大化するために、通常はLP tokensの100%をステーキングするとよいでしょう。

## ファーミング報酬のハーベスト

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28364%29.png" alt=""><figcaption></figcaption></figure>

新しいユニバーサルFarmページでは、すべてのファーミングポジションを簡単に確認できます。「マイポジション」に移動して右上の「ファームのみ」をクリックするだけで、選択中のネットワークに関わらず、すべてのファーミングポジションがフィルタリングされます。

プール/ペアのリストと同様に、ツールバーを使用してネットワーク/チェーン、トークン、DEXタイプ別にポジションをフィルタリングできます。

ステーキングされたポジションからCAKE報酬をハーベストするには、「ハーベスト」をクリックして、ウォレットのポップアップで確認してください。

複数のステーキングポジションがある場合は、それぞれ個別にハーベストする必要があります。&#x20;

## **ファームにステーキング中の流動性の追加または削除**

V3では、ファームにステーキング中でも、アンステーキングなしに流動性を追加または削除できます。

その場合は、「マイポジション」ページに戻り、調整したいポジションを見つけます。

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28365%29.png" alt="" width="280"><figcaption></figcaption></figure>

トークンペアとポジションIDが記載されたポジションタイトルをクリックして、ポジション詳細ページを開きます。

「追加」または「削除」ボタンを使用して、ステーキングされたポジションの流動性を調整します。

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28366%29.png" alt=""><figcaption></figcaption></figure>

ポジションを調整する際、未請求のCAKE報酬はすべてハーベストされてウォレットに送付されますのでご注意ください。

## **アンステーク**

いつでもポジションをアンステーキングできます。

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28367%29.png" alt=""><figcaption></figcaption></figure>

アンステーキングするには、「マイポジション」に戻り、ポジションを見つけて以下をクリックします：

* 「アンステーク」（V3ポジションの場合）&#x20;
* 「-」（V2、StableSwap LPの場合）、その後アンステーキングする量を選択する

ウォレットのポップアップで確認してください。しばらく待つと、ポジションNFTまたはLP tokensが、保留中のすべてのCAKE報酬とともにウォレットに返還されます。

## 報酬はどのくらいの頻度でハーベストすればよいですか？

報酬をハーベストする頻度はご自身で決めていただけますが、ハーベストには小額の手数料が発生することを覚えておくと役立ちます。

**ハーベスト**をクリックした後、ウォレットで確認する際にこの手数料を確認できます。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28281%29.png)

これはMetaMaskウォレットに表示されるハーベスト手数料の例です。ウォレットによって表示方法が若干異なる場合があります。手数料をあまり頻繁に支払わないよう、しばらく報酬を積み立てることをご検討ください。
