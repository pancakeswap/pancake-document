# Crosschain Farming

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2836%29.png" alt=""><figcaption></figcaption></figure>

マルチチェーン展開により、PancakeSwapはPancakeSwapファームの象徴的なイールドファーミング体験を他のブロックチェーンのユーザーにもお届けしています。Yield Farmsでは、LP Tokensをステーキングすることで、PancakeSwapをサポートしながらCAKEを獲得できます。

Yield Farmingについて詳しくは、[メインセクション](../)をご覧ください。

ファーミングを始めるには、[ファームの使い方ガイド](https://docs.pancakeswap.finance/products/yield-farming/how-to-use-farms)をご確認ください。

{% hint style="warning" %}
Yield farmingはシロッププールよりも高い報酬が得られる場合がありますが、**インパーマネントロス（Impermanent Loss）**のリスクが伴います。思ったほど怖くはありませんが、始める前にこの概念を理解しておくことをお勧めします。

詳しくは、Binance Academyの[インパーマネントロスに関する記事](https://academy.binance.com/en/articles/impermanent-loss-explained)をご覧ください。
{% endhint %}

PancakeSwap Crosschain farmingは、Celer Networkが提供するクロスチェーンメッセージングサービスによって動作しています。詳しくは、[https://www.celer.network/](https://www.celer.network/)をご覧ください。
