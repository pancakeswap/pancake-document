# 在 Aptos 上进行农场挖矿

<figure><img src="../../../.gitbook/assets/farming-on-aptos.png" alt=""><figcaption></figcaption></figure>

随着我们的多链部署，PancakeSwap 现在将标志性的农场挖矿体验带给了 Aptos 上的流动性提供者。农场允许用户通过质押 LP 代币来支持 PancakeSwap，同时赚取 CAKE。

查看[主要部分](../)以了解更多关于农场挖矿的信息。

我们将产品体验设计为在不同区块链之间保持一致。因此，如果你是 BSC 上的资深农场用户，在 Aptos 上进行农场挖矿时你会感到得心应手。如果你是流动性农场挖矿的新手，查看我们的[农场使用指南](https://docs.pancakeswap.finance/products/yield-farming/how-to-use-farms)以开始。

要了解更多关于如何在 BSC 和 Aptos 之间跨链转移你的资产和 CAKE，请查看 [CAKE 跨链桥接指南](../../../welcome-to-pancakeswap/how-to-guides/get-started-aptos/cake-bridging-guide.md)。

{% hint style="warning" %}
农场挖矿能带来比 Syrup 资金池更高的回报，但同时伴随着**无常损失**的风险。它并不像听起来那么可怕，但在开始之前值得先了解一下这个概念。

查看币安学院的这篇精彩的[无常损失解析文章](https://academy.binance.com/en/articles/impermanent-loss-explained)以了解更多。
{% endhint %}
