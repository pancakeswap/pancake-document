# Farming di Aptos

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/farming-on-aptos.png" alt=""><figcaption></figcaption></figure>

Dengan penerapan multichain kami, PancakeSwap kini menghadirkan pengalaman Yield Farming ikonik kepada penyedia likuiditas di Aptos. Yield Farms memungkinkan pengguna untuk mendapatkan CAKE sambil mendukung PancakeSwap dengan melakukan Staking LP Token.

Lihat [bagian utama](../) untuk mempelajari lebih lanjut tentang Yield Farming.

Kami merancang pengalaman produk agar konsisten di berbagai blockchain. Oleh karena itu, jika Anda adalah pengguna Farm berpengalaman di BSC, Anda akan merasa familiar ketika farming di Aptos. Jika Anda baru dalam liquidity farming, lihat [panduan Cara Menggunakan Farm](https://docs.pancakeswap.finance/products/yield-farming/how-to-use-farms) kami untuk memulai.

Untuk mempelajari lebih lanjut tentang cara melakukan Bridge aset dan CAKE antara BSC dan Aptos. Lihat [Panduan CAKE Bridging](../../../welcome-to-pancakeswap/how-to-guides/get-started-aptos/cake-bridging-guide.md).

{% hint style="warning" %}
Yield farming dapat memberikan hadiah yang lebih baik daripada Syrup Pools, tetapi mengandung risiko **Impermanent Loss**. Ini tidak semenakutkan kedengarannya, namun tetap penting untuk memahami konsep ini sebelum Anda mulai.

Lihat [artikel tentang Impermanent Loss ](https://academy.binance.com/en/articles/impermanent-loss-explained)dari Binance Academy untuk mengetahui lebih lanjut.
{% endhint %}
