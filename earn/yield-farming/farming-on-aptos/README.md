# Farming on Aptos

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/farming-on-aptos.png" alt=""><figcaption></figcaption></figure>

マルチチェーン展開により、PancakeSwapはAptosの流動性提供者に象徴的なイールドファーミング体験をお届けしています。Yield Farmsでは、LP Tokensをステーキングすることで、PancakeSwapをサポートしながらCAKEを獲得できます。

Yield Farmingについて詳しくは、[メインセクション](../)をご覧ください。

異なるブロックチェーン間で一貫した製品体験を設計しています。そのため、BSC上でFarmを長年使用されている方は、Aptosでファーミングする際も親しみやすく感じていただけるでしょう。流動性ファーミングが初めての方は、[ファームの使い方ガイド](https://docs.pancakeswap.finance/products/yield-farming/how-to-use-farms)をご確認ください。

BSCとAptos間でアセットとCAKEをブリッジする方法については、[CAKEブリッジングガイド](../../../welcome-to-pancakeswap/how-to-guides/get-started-aptos/cake-bridging-guide.md)をご覧ください。

{% hint style="warning" %}
Yield farmingはシロッププールやシングルトークンステーキングよりも高い報酬が得られる場合がありますが、**インパーマネントロス（Impermanent Loss）**のリスクが伴います。思ったほど怖くはありませんが、始める前にこの概念を理解しておくことをお勧めします。

詳しくは、Binance Academyの[インパーマネントロスに関する記事](https://academy.binance.com/en/articles/impermanent-loss-explained)をご覧ください。
{% endhint %}
