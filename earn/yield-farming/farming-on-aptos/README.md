# Farming na Aptos

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/farming-on-aptos.png" alt=""><figcaption></figcaption></figure>

Com nossa implantação multichain, a PancakeSwap está trazendo a icônica experiência de yield farming para os provedores de liquidez na Aptos. Os Yield Farms permitem que os usuários ganhem CAKE enquanto apoiam a PancakeSwap fazendo Staking de LP Tokens.

Confira a [seção principal](../) para saber mais sobre yield farming.

Projetamos a experiência do produto para ser consistente em diferentes blockchains. Portanto, se você é um usuário experiente de Farm na BSC, se sentirá em casa ao fazer farming na Aptos. Se você é novo no farming de liquidez, confira nosso [guia Como Usar os Farms](https://docs.pancakeswap.finance/products/yield-farming/how-to-use-farms) para começar.

Para saber mais sobre como fazer Bridge dos seus ativos e CAKE entre a BSC e a Aptos, confira o [Guia de Bridging de CAKE](../../../welcome-to-pancakeswap/how-to-guides/get-started-aptos/cake-bridging-guide.md).

{% hint style="warning" %}
O Yield Farming pode oferecer recompensas melhores do que os Syrup Pools, mas apresenta o risco de **Perda Impermanente**. Não é tão assustador quanto parece, mas vale a pena aprender o conceito antes de começar.

Confira este excelente [artigo sobre Perda Impermanente](https://academy.binance.com/en/articles/impermanent-loss-explained) da Binance Academy para saber mais.
{% endhint %}
