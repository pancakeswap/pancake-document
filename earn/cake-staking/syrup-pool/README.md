# 🍯 Syrup Pools – CAKE staken

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/syrup-poos-header.png)

### **Was sind Syrup Pools?**

Syrup Pools sind die einfachste Möglichkeit, kostenlose Token auf PancakeSwap zu verdienen.\
Staken Sie CAKE und verdienen Sie kostenlose Token. So einfach ist das.

Einige spezielle Pools ermöglichen es Ihnen außerdem, neben CAKE auch andere Token zu staken!
