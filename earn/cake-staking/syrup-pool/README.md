# 🍯 Syrup Pool - Stake CAKE

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/syrup-poos-header.png)

### **Cosa sono i Syrup Pool?**

I Syrup Pool sono il modo più semplice per guadagnare token gratuiti su PancakeSwap.\
Metti in Staking CAKE, guadagna token gratuiti. È davvero così semplice.

Alcuni Pool speciali ti permettono di mettere in Staking anche altri token oltre a CAKE!
