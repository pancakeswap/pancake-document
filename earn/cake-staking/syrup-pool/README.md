# 🍯 シロッププール - CAKE をステーキング

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/syrup-poos-header.png)

### **シロッププールとは何ですか？**

シロッププールはPancakeSwapで無料のトークンを獲得する最もシンプルな方法です。\
CAKEをステーキングして、無料のトークンを獲得しましょう。とても簡単です。

一部の特別なプールでは、CAKE以外のトークンをステーキングすることもできます！
