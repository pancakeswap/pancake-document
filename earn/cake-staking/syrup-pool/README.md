# 🍯 시럽 풀 - CAKE 스테이킹

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/syrup-poos-header.png)

### **시럽 풀이란 무엇인가요?**

시럽 풀은 PancakeSwap에서 무료 토큰을 얻는 가장 간단한 방법입니다.\
CAKE를 스테이킹하고 무료 토큰을 받으세요. 정말 그렇게 쉽습니다.

일부 특별한 풀에서는 CAKE 외의 다른 토큰도 스테이킹할 수 있습니다!
