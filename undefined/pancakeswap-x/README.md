# ✖️ PancakeSwap X

PancakeSwap X는 다양한 서드파티 유동성을 집계하고 인기 있는 PancakeSwap dApp에 바로 통합하여, PancakeSwap에서 좋아하는 자산을 거래하는 완전히 새로운 방식을 선보입니다. 더 많은 자산 거래, 더 깊은 유동성, 가스비 없는 스왑 등 다양한 이점을 제공합니다.

* 더 나은 가격
* 더 많은 스왑 가능 토큰
* 내장된 MEV 보호
* 가스비 없는 스왑

{% hint style="success" %}
**PancakeSwap X는 Arbitrum, Ethereum, BNB Chain, Base, Robinhood Chain에서 운영 중이며 암호화폐 토큰 스왑을 지원합니다. 실물 자산(RWA)은 BNB Chain, Ethereum, Robinhood Chain에서 추가로 지원됩니다.**
{% endhint %}
