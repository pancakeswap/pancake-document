# Smart Router로 거래하는 방법

## Smart Router에서 거래하기

Smart Router는 스왑 페이지에서 기본적으로 비활성화되어 있습니다. 사용 방법은 기존 PancakeSwap AMM과 비슷합니다.

시작하기 전에 **BNB 체인과 호환되는 지갑과 가스비로 사용할 BNB**가 필요합니다. 자세한 내용은 [지갑 가이드](../../../pancakeswap/how-to-guides/get-started/wallet-guide.md)를 확인하세요.

1. [여기](https://pancakeswap.finance/swap#/swap)에서 스왑 페이지로 이동합니다.
2. 거래하려는 토큰 페어를 선택합니다. 출시 시점에는 슬리피지 우려로 인해 Smart Router에서 정확한 입력 수량(exact input) 방식만 지원합니다.
3. 거래할 토큰 수량을 입력합니다. **"Use StableSwap for better fees"** 체크박스를 선택합니다.

4\. 하단 행의 경로 필드에 있는 아이콘을 사용해 새 경로를 확인합니다. 이제 준비가 끝났습니다! 이후의 스왑 과정은 평소와 같습니다. 처음 거래하는 경우 [여기의 가이드](../trade-guide.md)를 확인하세요.

## Smart Router 끄기

Smart Router를 비활성화하면 모든 거래가 V2 경로로 라우팅되며, 스테이블스왑 페어는 활성화되지 않습니다.

1. 스왑 메뉴 오른쪽 상단의 **Settings** 아이콘을 누릅니다.
2. 나타나는 팝업에서 **Disable Smart Router**를 선택합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Screenshot%202022-11-25%20at%202.02.11%20PM.png)

3\. 설정 페이지를 닫습니다.
