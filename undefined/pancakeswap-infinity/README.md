# ♾️ PancakeSwap Infinity

> 개발자이거나 자세한 기술 문서가 필요하시다면 이 문서를 참고하세요: [https://developer.pancakeswap.finance/](https://developer.pancakeswap.finance/)

**PancakeSwap Infinity**는 탈중앙화 거래를 더 빠르고, 더 저렴하고, 더 유연하게 만들기 위해 설계된 PancakeSwap AMM의 최신 버전입니다. 모듈식 설계를 사용하여 더 높은 커스터마이징을 가능하게 하며, 다양한 유형의 거래 풀과 가격 모델을 지원합니다.

Infinity에서 개발자는 풀 수명 주기의 주요 동작 시점에 실행되는 작은 코드 조각인 "Hooks"를 사용하여 새로운 기능을 더 쉽게 구축할 수 있습니다. 이를 통해 커스텀 오라클, 다이내믹 수수료 풀, 고급 거래 및 유동성 관리 기능 등 다양한 활용 사례를 구현할 수 있습니다.

PancakeSwap v3와 비교해 Infinity는 가스 효율이 더 높고 미래 지향적입니다. 회계 처리와 거래 로직 같은 핵심 기능을 분리하여, Hooks 기능과 함께 새로운 가격 곡선을 매끄럽게 통합할 수 있으며, 재배포 없이도 프로토콜이 진화할 수 있습니다.

### ⭐️ 주요 기능

1. Singleton
2. Flash Accounting
3. Hooks
4. 네이티브 토큰 지원
5. 커스텀 가격 곡선
6. ERC-6909
7. `donate()`
