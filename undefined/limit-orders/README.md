# 🎯 지정가 및 TWAP 주문

{% hint style="warning" %}
**지정가 주문(Orbs)은 지원이 중단되었습니다.** 대기 중인 주문이 있다면 [여기](https://pancakeswap.finance/swap/limit-v1)에서 관리하세요. 최신 지정가 주문 기능은 여기에서 이용하세요: [https://pancakeswap.finance/swap/limit](https://pancakeswap.finance/swap/limit)
{% endhint %}

{% hint style="success" %}
**수수료 수익형 지정가 주문**은 PancakeSwap에서만 이용할 수 있는 **업계 최초의 거래 기능**입니다.
{% endhint %}

#### 이 기능은 무엇인가요?

수수료 수익형 지정가 주문을 사용하면 토큰을 자동으로 매수하거나 매도할 목표 가격을 설정하면서 **수수료를 얻을 수** 있습니다. 풀 가격이 목표에 도달하면 주문이 실행되고, 원하는 출력 토큰과 수수료가 지갑으로 직접 전송됩니다.

* **지원 체인:** BNB 체인
* **최소 주문 규모:** $50

#### 왜 사용해야 하나요?

* 차트를 계속 지켜볼 필요가 없습니다.
* 실행 수수료가 없습니다. 대신 주문이 체결되면 **수수료(0.1%)를 얻습니다**.
* 매끄럽게 작동합니다. 완전한 온체인 방식이며 PancakeSwap Infinity 아키텍처로 구동됩니다.

***

TWAP(시간 가중 평균 가격)은 주문을 더 작은 거래 규모로 나누어 일정한 간격으로 실행하는 일반적인 주문 유형입니다. TWAP 주문의 주된 목적은 주문의 가격 영향을 줄이는 것입니다.

{% hint style="info" %}
TWAP 기능은 [Orbs](https://www.orbs.com/)가 개발했으며 Orbs의 [L3 기술](https://www.orbs.com/overview/)로 구동됩니다.
{% endhint %}
