# 🏦 Stableswap

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/en-stableswap.png" alt=""><figcaption></figcaption></figure>

PancakeSwap의 StableSwap은 불변 곡선 슬리피지 함수를 기반으로 스테이블 페어를 더 낮은 슬리피지로 거래할 수 있게 하는 기능입니다. USD 스테이블코인(예: HAY, BUSD, USDT)이나 유동성 스테이킹 토큰(예: stkBNB, BNBx)처럼 가격이 서로 비슷한 특정 자산을 스왑하도록 설계되었습니다.

PancakeSwap은 현재 두 가지 StableSwap 모델을 제공합니다. [**Infinity StableSwap**](infinity-stableswap.md)과 [**Classic StableSwap**](classic-stableswap.md)입니다. Infinity StableSwap은 PancakeSwap의 최신 Infinity 아키텍처를 기반으로 구축되어 향상된 유연성, 효율성, 향후 확장성을 제공합니다. Classic StableSwap은 기존 풀과 유동성을 계속 지원하는 최초의 StableSwap 구현을 말합니다.
