## TRANSLATION POLICY

- P1: Keep YAML frontmatter keys; translate only natural-language values.
- P2: Preserve heading levels, lists, tables, GitBook blocks ({% hint %}, {% tabs %}, <figure>).
- P3: Never alter URLs, relative link targets, or anchors. Translate only human-readable link text.
- P4: Every image reference must use ABSOLUTE URLs:
  Format: ![alt](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/FILENAME)
  URL-encode spaces as %20, ( as %28, ) as %29. Remove angle brackets from paths.
  Example: ![](<../../.gitbook/assets/my file (1).png>) → ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/my%20file%20%281%29.png)
- P5: Keep brand/product names in English: PancakeSwap, veCAKE, CAKE, MEV Guard, etc.
  Keep versioned names: PancakeSwap Infinity, PancakeSwap X, Tokenomics 3.0, v3/v2.
  Keep acronyms: MEV, RPC, FAQ, APR, IFO, TWAP, ALP, AMM, BSC, CEX.
- P6: Never change HTML entities, code spans/blocks, or placeholders like {Gift_Code}.
- P7: Preserve emojis in headings and titles.
- P8: File paths must match en exactly (same directory structure).
- P9: No untranslated English prose (except allowed brand/technical terms in P5).
- P10: Apply glossaries.md consistently. Register: use informal "tú", not formal "usted".
