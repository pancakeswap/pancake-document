#### Wormhole explorer

Di halaman status bridge, Anda dapat melihat tautan yang akan membawa Anda ke transaksi Anda di Wormhole Explorer. Saat transaksi rantai sumber Anda telah selesai tetapi belum diverifikasi oleh Wormhole, status transaksi Anda akan terlihat seperti ini:

Opsi find redeem adalah metode alternatif yang dapat Anda ikuti untuk menyelesaikan transaksi rantai tujuan Anda. Anda dapat menggunakan metode ini jika wormhole bridge mengalami gangguan atau gagal memperbarui status transaksi bridge Anda. Untuk menukarkan transaksi Anda, pertama klik tombol redeem

Kemudian akan menampilkan opsi ini untuk melanjutkan transaksi Anda. Klik ini untuk diarahkan ke forum (tautan ada di pertanyaan berikutnya) di mana Anda dapat menyelesaikan transaksi penukaran Anda. <br>

### T: Saya telah mengirim token ke \<rantai> - token saya tidak sampai di Dompet tujuan, tetapi sudah keluar dari Dompet asal saya. Apa yang harus saya lakukan?[​](https://portalbridge.com/docs/faqs/troubleshooting#i-have-sent-tokens-to-chain---my-tokens-did-not-arrive-in-my-target-wallet-but-have-left-my-origin-wallet-what-do-i-do) <a href="#i-have-sent-tokens-to-chain---my-tokens-did-not-arrive-in-my-target-wallet-but-have-left-my-origin-w" id="i-have-sent-tokens-to-chain---my-tokens-did-not-arrive-in-my-target-wallet-but-have-left-my-origin-w"></a>

Anda perlu a) menukarkannya, atau, jika penukaran sudah berhasil, b) menambahkannya ke Dompet Anda:

**a) Penukaran:**

* Buka [https://portalbridge.com/#/redeem](https://portalbridge.com/#/redeem)
* Anda perlu memasukkan rantai sumber dan ID transaksi yang sesuai (yang dapat Anda temukan di Dompet Anda, atau dengan alamat Anda di Penjelajah Blok blockchain)

<figure><img src="https://lh7-us.googleusercontent.com/v4gdm8TKNfhuq8cRaHWwn-EuJKCuzWSXl5zt76DDHq3N6TBqP-ntLVZNS5CMbIUBvtE2qI2eCpw_ean4hSicvrLCYhlz8TI5WxgzN3zBpo2wqInZvYuaXCcxU3k6nF6l-On05Ak4vjdZPLhJcQZXybc" alt=""><figcaption></figcaption></figure>

* Klik Recover
* Klik Redeem dan terima persetujuan Dompet

**b) Menambahkan ke Dompet Anda:**

**MetaMask:**[**​**](https://portalbridge.com/docs/faqs/troubleshooting#metamask)

* Di tab aset MetaMask, klik import tokens
* Alamat kontrak dapat ditemukan di transaksi Penjelajah Blok yang relevan dan dengan mengklik nama token. Saat Anda mengklik nama token, jendela baru akan terbuka dan alamat kontrak ada di sisi kanan di ringkasan profil.
* Anda juga memerlukan simbol - ini bisa apa saja yang ingin Anda gunakan untuk mengenali token tersebut.
* Klik add custom token

Lihat tutorial video - Cara menambahkan token ke Dompet MetaMask Anda [di sini.](https://portalbridge.com/docs/video-tutorials/how-to-manually-add-tokens-to-your-wallet#metamask)

### Saya telah mem-bridge token X tetapi sekarang tidak bisa menukarnya. Tidak ada DEX yang memiliki pasar likuid,[​](https://portalbridge.com/docs/faqs/troubleshooting#i-bridged-x-token-but-cannot-swap-it-now-no-dex-has-liquid-markets) <a href="#i-bridged-x-token-but-cannot-swap-it-now-no-dex-has-liquid-markets" id="i-bridged-x-token-but-cannot-swap-it-now-no-dex-has-liquid-markets"></a>

Anda telah mem-bridge token yang tidak memiliki Likuiditas di rantai tujuan. Anda perlu menggunakan Portal bridge untuk mem-bridge ini kembali. Anda dapat melakukan ini dengan menempelkan alamat kontrak token (yang dapat Anda temukan di Dompet Anda atau dengan alamat Anda di Penjelajah Blok blockchain) ke kolom pencarian "select a token" di Portal.

Anda dapat menemukan ikhtisar komprehensif pasar likuid [di sini](https://portalbridge.com/docs/faqs/liquid-markets).
