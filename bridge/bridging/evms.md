# Comment effectuer un Bridge – Entre des EVMs

{% hint style="success" %}
**EVMs :** Les chaînes EVM sont des blockchains qui utilisent la Machine Virtuelle Ethereum pour exécuter des contrats intelligents et des dApps compatibles avec Ethereum. Parmi les exemples, on trouve Ethereum, BNB Smart Chain, etc.
{% endhint %}

1. Accédez à [https://pancakeswap.finance/bridge](https://pancakeswap.finance/bridge)
2. Assurez-vous que votre Portefeuille est connecté

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%281%29%20%283%29.png" alt=""><figcaption></figcaption></figure>

3. Sélectionnez vos chaînes **source** et **de destination** via les sélecteurs de réseau

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%282%29%20%283%29.png" alt="" width="375"><figcaption></figcaption></figure>

4. Saisissez le montant que vous souhaitez envoyer et sélectionnez le token depuis le menu déroulant

* **Conseil :** Vérifiez toujours l'adresse du contrat du token avant d'envoyer !

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%283%29%20%283%29.png" alt="" width="374"><figcaption></figcaption></figure>

5. Sélectionnez le **token reçu** — Dans certains cas où les symboles de tokens sont identiques (par ex. USDC / USDT), des variantes apparaîtront pour que vous puissiez en choisir une

* **Conseil :** Survolez le token ou cliquez sur le lien pour vérifier le nom et l'adresse du token

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%284%29%20%282%29.png" alt="" width="375"><figcaption><p>USDC</p></figcaption></figure>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%285%29%20%282%29.png" alt="" width="375"><figcaption><p>USDC (Wormhole)</p></figcaption></figure>

6. Vérifiez la section « Vous recevez » pour confirmer que tous les détails sont corrects

* PancakeSwap sélectionne parmi plusieurs fournisseurs Bridge en fonction de vos chaînes source et de destination.
* Les fournisseurs diffèrent par leurs frais, leurs délais de traitement et leurs éventuelles restrictions — ceux-ci seront clairement indiqués.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28385%29.png" alt=""><figcaption></figcaption></figure>

* Des étiquettes vous aident à comparer les itinéraires :
  * **Best Return** = montant reçu le plus élevé
  * **Fastest** = délai de transfert le plus court

Utilisez ces étiquettes pour trouver le bon équilibre entre vitesse et valeur selon vos besoins.

{% hint style="warning" %}
Lors de votre **première transaction** avec un fournisseur Bridge, il vous sera demandé d'approuver le transfert de token (action unique)

* Pour votre **deuxième transaction**, cliquez simplement sur « Send » et votre transfert Bridge commencera
{% endhint %}

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%286%29%20%281%29.png" alt=""><figcaption></figcaption></figure>

7. Installez-vous confortablement ! La plupart des transferts Bridge se terminent en quelques minutes seulement. Une fois terminé, vos tokens apparaîtront dans votre adresse Ethereum.
