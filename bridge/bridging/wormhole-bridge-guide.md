# Wormhole 브릿지 가이드

### 안내 사항

Wormhole 브릿지를 사용하기 전에 이 가이드를 반드시 읽어 보세요. 이 가이드는 브릿지 사용법을 단계별로 설명하고, 번역 검색 및 트랜잭션 재개와 같이 기본으로 지원되는 유용한 기능도 소개합니다. 또한 문제 해결 방법도 안내합니다.

### 브릿지 진행하기

<figure><img src="https://lh7-us.googleusercontent.com/ZnR2zSNBpjyrzAs_JVlYdKCMDVYmOw4AVdJj_VIk0dmkvqTNxAC1ror2bEQlmSLeVGNV-PwhQSZdyquv-nCBPsHLjACy6LQsyM7M98dFrT9xKnZqC0aWYgUj0fjwC5pbZ9g1UwLalAU6DV-ORgPs-UY" alt=""><figcaption></figcaption></figure>

1. **PancakeSwap Wormhole 브릿지로 이동합니다 -** [**https://bridge.pancakeswap.finance/wormhole**](https://bridge.pancakeswap.finance/wormhole)
2. **출발 체인 지갑 연결** - 먼저 지갑을 연결합니다. 위젯을 사용할 때는 지갑이 브릿지를 시작할 네트워크로 미리 설정되어 있지 않아도 됩니다. Wormhole이 선택한 네트워크에 맞춰 올바른 네트워크로 자동 설정합니다. EVM 체인에서는 MetaMask만 지원됩니다.
3. **출발 체인 네트워크 선택** - PancakeSwap은 현재 Wormhole 브릿지에서 4개의 네트워크(Ethereum, Binance Smart Chain, Arbitrum, Base)를 지원합니다.
4. **출발 체인 자산 선택** - 브릿지할 토큰을 선택합니다.&#x20;
5. **4, 5, 6단계** - 도착 체인에 대해 1, 2, 3단계를 반복합니다.
6. 브릿지 수량 입력 - 브릿지할 수량을 입력하고 트랜잭션을 승인합니다. 경로와 브릿지 정보가 다음과 비슷하게 표시됩니다.

<figure><img src="https://lh7-us.googleusercontent.com/k6VhFctTcH__ojn3fMScEUUONGP_uPHk-s8OvVonboim7Cm37xCQhNiReTpUuo90_c81jg51pHVKsxhok50I6dwHWjBGZgB-yaIksikYP0aQB7uUaI1Wm6wK9uoYdZdygkViWnXWZcGnsBrPnivbij0" alt="" width="563"><figcaption></figcaption></figure>

7. 승인 후 트랜잭션이 전송되면 트랜잭션 상태 페이지가 표시됩니다.

<figure><img src="https://lh7-us.googleusercontent.com/RpERMKVOpXOJn56_-awggVO63Pl_KkkvQBzrwlD3jdEssKk7H6gznb7Np8ampHm3quG3doPGReqKFMyU1Fa4b0nlxjmSiZgSlY1WfEEAzbM_PcpZVRtESmXWol50wku4SE5oT8MgjfIwdoj8-rf-IBE" alt="" width="563"><figcaption></figcaption></figure>

브릿지 과정은 세 단계로 이루어집니다. 이 단계들은 시간이 다소 걸릴 수 있으며, 보통 출발 체인 트랜잭션에 대해 일정 수의 블록 컨펌이 필요합니다. 컨펌 기준에 도달하면 Wormhole이 트랜잭션 성공을 확인하는 증명을 생성합니다. 이 증명은 도착 체인에서 브릿지된 자산을 수령(claim)하는 데 필요합니다.

8. 검증이 완료되면 아래와 같이 표시되는 수령(claim) 버튼을 클릭하여 브릿지된 자산을 받을 수 있습니다.&#x20;
