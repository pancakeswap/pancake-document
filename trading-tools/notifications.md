### Web3 알림이란 무엇인가요?

Web3 알림은 최신 뉴스와 업데이트를 위해 플랫폼과 상호작용하는 방식의 큰 도약을 의미합니다. PancakeSwap에 매끄럽게 통합된 이 알림은 여러 가지 이점을 제공합니다. WalletConnect와 협력하여 사용자가 DeFi 뉴스, 업데이트 및 중요한 작업을 하나의 창에서 확인할 수 있도록 알림(BETA)을 출시했습니다. Web3 알림은 아직 BETA 단계이며 앞으로 몇 달 동안 추가적인 변경과 개발이 이루어질 예정입니다.

**Web3 알림의 이점:**

* 실시간 알림으로 최신 정보 확인: PancakeSwap의 주요 이벤트, 시장 동향, 제품 업데이트, 커뮤니티 소식을 놓치지 마세요.
* 중요한 정보에 우선순위 지정: 관련성에 따라 주제, 제품, 카테고리를 선택하세요. 다양한 필터로 알림을 맞춤 설정할 수 있습니다.
* 바로 실행 가능한 직접 링크: 각 알림에 직접 링크가 포함되어 있어 중요한 업데이트에 알림에서 바로 신속하게 대응할 수 있습니다.

### 알림 설정 방법:

1. 간편하게 활성화: [홈페이지](https://pancakeswap.finance/)를 방문하세요. PancakeSwap 메뉴 왼쪽 상단의 설정 아이콘을 클릭하고 "알림 허용"을 선택합니다.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/web-git-feat-web3-notifications-soft-launch.pancake.run__chain%3Dbsc%20%281%29.png" alt="" width="362"><figcaption></figcaption></figure>

2. 지갑 연결: 오른쪽 상단의 벨 아이콘을 클릭하고 지갑에서 메시지에 서명하여 알림을 승인합니다.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/web-git-feat-web3-notifications-soft-launch.pancake.run__chain%3Dbsc%20%286%29.png" alt="" width="433"><figcaption></figcaption></figure>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/web-git-feat-web3-notifications-soft-launch.pancake.run__chain%3Dbsc%20%284%29.png" alt="" width="293"><figcaption></figcaption></figure>

3. 피드 맞춤 설정: 왼쪽의 드롭다운을 선택하여 관심사와 필요에 맞게 알림 설정을 조정하세요.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/web-git-feat-web3-notifications-soft-launch.pancake.run__chain%3Dbsc%20%285%29.png" alt=""><figcaption></figcaption></figure>

4. 최신 정보 유지: 벨 아이콘을 클릭하여 드롭다운 메뉴에서 모든 알림을 편리하게 확인하세요.

### 알림 기능

현재 알림 목록은 모든 EVM 체인에서 지원되며 다음을 포함합니다.

| 알림       | 기능                                                     |
| ------------------ | ------------------------------------------------------------ |
| 유동성 포지션 | 유동성 포지션이 범위를 벗어난 경우 이동하도록 사용자에게 알림 |
| 파밍               | 파밍 APR 또는 새로운 파밍이 있는 경우 사용자에게 알림         |
| 지갑 잔액     | 가스 잔액이 부족한 경우 사용자에게 알림                   |
| 복권            | 복권 추첨에 대해 사용자에게 알림                                |
| 예측         | 예측 보상을 수령하도록 사용자에게 알림                     |
| 가격 알림       | 주요 가격 변동에 대해 사용자에게 알림                           |

### 다음 계획은?

* 향상된 필터링: 사용자가 적시에 올바른 정보를 받을 수 있도록 알림을 세밀하게 조정
* 멀티 플랫폼: 모바일 및 기타 플랫폼 지원, 잠재적인 크로스 프로토콜 기능을 통해 PancakeSwap을 DeFi 활동의 허브로 만들기
* 더 많은 알림: 다른 제품에 대한 알림과 신규 제안과 같은 거버넌스 관련 정보에 대한 알림.
