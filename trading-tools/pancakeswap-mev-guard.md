# 🛡️ PancakeSwap MEV Guard

オンチェーンでのトレードがMEVボットにフロントランニングされることを心配していますか？もう心配はいりません。PancakeSwapのMEV Guardを使用してトレードを保護しましょう。

BNB Chainで利用可能です。

### 主な特徴

1. フロントランニングやサンドイッチ攻撃なしで安全・確実・プライベートなSwapをお楽しみください。
2. Swapや取引を超えた日常的な使用に対応する、高速で信頼性の高いRPCエンドポイント。
3. あらゆる種類のSwapユーザー向けに、設定が簡単で完全に無料のソリューション。

### 使用方法

[https://pancakeswap.finance/mev](https://pancakeswap.finance/mev)にアクセスして詳細をご確認ください。

または以下の情報を使用してウォレットに手動で追加できます：

* ネットワーク名：PancakeSwap MEV Guard New&#x20;
* RPC URL：https://bscrpc.pancakeswap.finance&#x20;
* チェーンID：56&#x20;
* 通貨シンボル：BNB&#x20;
* ブロックエクスプローラーURL：https://bscscan.com
