# 🎁 Pancake Gifts

### 🎯 Pancake Giftsとは何ですか？

**Pancake Gifts**を使うと、**リンク**や**QRコード**だけを使って、友達、ユーザー、またはコミュニティにトークン（オプションのガスを含む）を送ることができます。受取人にとってシンプルで安全、ガス不要の体験です。

クリプトへのオンボーディングをメッセージを送るくらい簡単にするために作られています。ウォレットへの資金注入、ブリッジング、事前手数料は不要です。

### 🤝 なぜPancake Giftsを作ったか

Web3へのオンボーディングはまだ摩擦が多いです。新しいユーザーは始める前に諦めてしまうことが多く、その原因は：

* **ウォレットにガスがない** → オンチェーンアクションができない
* **正しいチェーンに資金がない** → dAppsを使う前にブリッジングが必要
* **始めるためだけにクリプトを購入する必要がある** → CEXへのサインアップまたは法定通貨のオンランプが必要

Pancake Giftsはこれらの障壁を次の方法で排除します：

* ✅ **ネイティブガストークンを含む**ギフトで、受取人がすぐに操作できます
* ✅ **ガス手数料を事前にスポンサー**（送信者が少額の手数料を支払う）
* ✅ **シンプルなリンクまたはQRで請求**を可能にします — 複雑なオンボーディング不要



以下の両方に役立つツールです：

* オンチェーンを始める新しいユーザー
* **導入を促進し、ユーザーに報酬を与え、より使いやすい方法でキャンペーンを実施**したいWeb3ネイティブコミュニティ

***

### ⚙️ 機能概要

| 機能                | 説明                                                      |
| ---------------------- | ---------------------------------------------------------------- |
| **チェーン対応**      | BNB Chain（初期ローンチ）                                       |
| **ギフトコードタイプ**    | リンク **または** QRコード                                              |
| **1回限りの使用**       | 各コードは1回のみ請求可能                               |
| **トークン対応**      | 最大2トークン：1 BEP-20（必須）、1ネイティブガストークン（オプション） |
| **カスタム金額**     | トークンごとに異なる金額を設定                                   |
| **ギフト請求ガス手数料** | 送信者がガスを事前支払い（BNBで約$0.05）                              |
| **ギフト履歴**       | ユーザーは送ったギフト、請求状況、有効期限をすべて確認できます              |
| **セキュリティチェック**    | 移転手数料および複雑なロジックのトークンは禁止           |

### 🚫 制限事項

1. **ギフト1つにつき1コード** — 一括ギフトはまだサポートされていません。
2. **ギフトは再開できません** — キャンセルまたは有効期限切れ後は再利用できません。
3. **サポートされていないトークンはブロックされます** — 移転手数料や特別なロジックを持つトークンは作成時にエラーが表示されます。
4. **請求失敗時はリトライされます** — バックエンドが数回リトライします。それでも失敗した場合、ギフトは**請求不可**とマークされ、資金を取り戻すにはキャンセルが必要です。
5. **ギフトは同じチェーンで請求する必要があります** — 例えばETHのギフトはEthereumで請求する必要があります。クロスチェーン請求はまだサポートされていません。

***

### 🕒 キャンセルと有効期限のロジック

ギフトはステータスと時間に基づいて定義されたライフサイクルに従います：

#### 手動キャンセル

* **作成者**は**未請求**かつ**有効期限内**のギフトをキャンセルできます。
* 初期ギフト請求ガス手数料を差し引いたトークンが送信者に返却されます。
* キャンセルされたギフトは再アクティベートまたは再使用**できません**。

#### 自動有効期限

* ギフトはユーザー定義の期間（デフォルト：7日）後に**自動的に有効期限切れ**になります。
* 未請求のトークンは送信者のウォレットに**自動返却**されます。
* 有効期限切れのギフトも再利用できません。

***

### 🔄 ギフトのステータスとその意味

| ステータス          | 説明                                                              |
| --------------- | ------------------------------------------------------------------------ |
| **保留中**     | ギフトが作成され、請求を待っています                              |
| **請求済み**     | ギフトが受取人によって正常に請求されました                             |
| **キャンセル済み**   | ギフトが送信者によって手動でキャンセルされました                                |
| **有効期限切れ**     | ギフトが請求されずに有効期限を過ぎました                        |
| **請求不可** | リトライ回数超過；資金を取り戻すにはギフトをキャンセルする必要があります |

***

### ⚠️ エラー処理とエッジケース

1. **サポートされていないトークン**
   * 移転手数料や特別なロジックを持つトークンのギフト作成はブロックされます。
2. **ガス不一致**
   * **実際の請求ガスコスト ≥** 送信者の事前支払い手数料の場合、過剰使用を防ぐために請求は自動的に失敗します。ガス手数料レベルが範囲内になったら再試行されます。
3. **請求失敗時**
   * 最初の失敗時にリトライが試みられます。
   * それでも失敗した場合：
     * 受取人には「請求不可」と表示されます
     * 送信者は手動でギフトをキャンセルして資金を取り戻す必要があり、受取人は新しいギフトコードをリクエストする必要があります。
