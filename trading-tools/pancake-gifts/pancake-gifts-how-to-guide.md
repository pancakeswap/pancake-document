# Pancake Gifts : Guide pratique

Pancake Gifts vous permet d'envoyer des tokens — y compris du gaz optionnel — à des amis, utilisateurs ou membres d'une communauté en utilisant simplement un **lien ou un code QR**. Le processus est rapide, fluide et adapté aux débutants.

Ce guide vous accompagne pour :

* ✅ Comment **créer** un Pancake Gift
* ✅ Comment **l'envoyer ou le partager**
* ✅ Comment **réclamer** un cadeau
* ✅ Comment **annuler** un cadeau (s'il n'a pas été réclamé)

***

### 🧑‍🍳 Étape 1 : Créer un cadeau

#### 1. Accédez à l'onglet de création de cadeau

Rendez-vous sur l'onglet **Cadeau** dans l'interface du Portefeuille PancakeSwap.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28418%29.png" alt="" width="306"><figcaption></figcaption></figure>

#### 2. Sélectionnez les tokens et les montants

Choisissez jusqu'à **deux tokens** à inclure dans votre cadeau :

* **Un token BEP-20** (requis) — ex. CAKE
* **Un token de gaz natif** (optionnel) — ex. BNB

Cette configuration vous permet de :

* Envoyer des tokens utilisables au destinataire
*   Couvrir leur gaz afin qu'ils puissent effectuer des transactions immédiatement

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28419%29.png" alt="" width="311"><figcaption></figcaption></figure>

#### 3. Choisissez le type de cadeau

Sélectionnez l'une des options suivantes :

* 🔗 **Lien** — Facile à copier et à partager via messagerie ou réseaux sociaux
* 📱 **Code QR** — Idéal pour les événements en personne ou les utilisateurs mobiles

> 💡 Chaque cadeau ne peut être réclamé qu'une seule fois et ne prend en charge qu'un seul format de livraison (lien ou QR).

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28420%29.png" alt="" width="316"><figcaption></figcaption></figure>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28421%29.png" alt="" width="311"><figcaption></figcaption></figure>

#### 4. Vérifiez le récapitulatif et payez

Avant de confirmer, vérifiez :

* **Montant du cadeau** — Total des tokens inclus dans le cadeau
* **Frais de gaz de réclamation** — Tokens natifs que l'expéditeur inclut pour permettre au destinataire de réclamer sans frais (\~0,05 $ en BNB)

Une fois confirmé :

* Le cadeau est créé et enregistré on-chain
* Vous recevrez un **lien ou code QR** — assurez-vous de **le sauvegarder avant de fermer la fenêtre contextuelle**

{% hint style="danger" %}
&#x20;Si vous fermez la fenêtre contextuelle sans sauvegarder, le code cadeau ne pourra pas être récupéré ultérieurement.
{% endhint %}

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28422%29.png" alt="" width="273"><figcaption></figcaption></figure>

### 📤 Étape 2 : Envoyer ou partager le cadeau

Après la création, vous recevrez soit :

* Un **lien partageable**, et / ou
* Un **code QR à scanner**

Vous pouvez le partager via :

* Applications de messagerie (Telegram, WhatsApp)
* E-mail
* Réseaux sociaux
* Message direct lors d'événements

Lien partageable

> Je viens de vous envoyer ${Gift\_Amount} ! 🎉
>
> Appuyez sur ce lien pour le réclamer : 👉 [https://pancakeswap.finance/invite/{Gift\_Code}](https://pancakeswap.finance/invite/%7BGift_Code%7D)
>
> Connectez votre portefeuille pour finaliser la réclamation.
>
> Ou saisissez le code `{Gift_Code}` manuellement dans le Portefeuille PancakeSwap.

### 🎉 Étape 3 : Réclamer un cadeau

#### 1. Après avoir connecté votre portefeuille, appuyez sur le lien ou scannez le code QR

Lorsque le destinataire :

* **Ouvre le lien** ou
* **Scanne le code QR**

L'application remplira automatiquement le code cadeau. Si le cadeau est éligible et non réclamé, l'interface de réclamation se chargera.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28424%29.png" alt="" width="341"><figcaption></figcaption></figure>

Dans le cas contraire, un message d'erreur s'affichera (ex. expiré ou déjà réclamé).

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28425%29.png" alt="" width="375"><figcaption></figcaption></figure>

***

#### 2. Approuver et recevoir les tokens

Le destinataire peut réclamer **sans payer de frais de gaz** (ils sont déjà couverts).

Une fois approuvé :

* Les tokens BEP-20 (et le token de gaz, s'il est inclus) sont déposés dans son portefeuille
*   Le cadeau est marqué comme **réclamé**

### ❌ Étape 4 : Annuler un cadeau (s'il n'a pas été réclamé)

Vous pouvez annuler un cadeau uniquement si :

* Il est encore **non réclamé**
* Il est encore **dans la fenêtre d'expiration** (par défaut : 7 jours)

Pour annuler :

1. Rendez-vous sur l'onglet **Historique des cadeaux**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28429%29.png" alt="" width="308"><figcaption></figcaption></figure>

2. Trouvez le cadeau

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28431%29.png" alt="" width="299"><figcaption></figcaption></figure>



3. Cliquez sur **Annuler**

Les tokens seront retournés dans votre portefeuille (moins les frais de parrainage de gaz).

> ⚠️ Les cadeaux annulés ne peuvent pas être réactivés ni réutilisés.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Group%201410078707.png" alt="" width="563"><figcaption></figcaption></figure>

***

### ✅ C'est tout !

Vous savez maintenant comment :

1. Créer un Pancake Gift
2. L'envoyer à quelqu'un via un lien ou un QR
3. Réclamer un cadeau qui vous a été envoyé
4. Annuler un cadeau si nécessaire

Vous souhaitez consulter l'historique complet de vos cadeaux ou vérifier les statuts ? Retournez simplement sur l'onglet **Cadeau** dans le Portefeuille PancakeSwap.
