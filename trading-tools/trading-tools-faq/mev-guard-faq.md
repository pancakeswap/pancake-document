# FAQ

## Qu'est-ce que le MEV et l'Attaque sandwich ?

Le MEV (Maximal Extractable Value) désigne le profit supplémentaire qu'il est possible de réaliser en réordonnant ou en incluant des transactions dans un bloc.

Une attaque sandwich est un type spécifique d'attaque MEV où un attaquant place une transaction avant et une après une transaction cible pour manipuler le prix d'un actif à des fins lucratives. Cela entraîne des coûts accrus ou des résultats moins favorables pour la victime.

## Qu'est-ce qu'un endpoint RPC protégé contre le MEV ?

C'est une passerelle spécialisée pour interagir avec une blockchain qui aide à protéger les utilisateurs contre l'exploitation MEV (Maximal Extractable Value), comme les attaques sandwich.

## Comment MEV Guard me protège-t-il des attaques ?

L'endpoint achemine les transactions via des relais privés, ainsi que d'autres mécanismes de protection, pour garantir que les transactions des utilisateurs sont traitées de manière sécurisée et sans interférence, réduisant ainsi le risque de Glissement, de manipulation de prix ou de perte de valeur.

## Comment installer MEV Guard ?

Suivez les instructions de la page pour changer ou ajouter l'endpoint protégé MEV à votre portefeuille.

Si vous utilisez MetaMask, cela peut se faire en cliquant sur le bouton. Si vous utilisez d'autres portefeuilles, veuillez consulter les guides détaillés pour ajouter le réseau manuellement.

## Comment désactiver ou supprimer MEV Guard ?

Si vous utilisez MetaMask, repassez simplement votre endpoint RPC aux nœuds publics habituels. Si vous utilisez d'autres portefeuilles, veuillez consulter les guides détaillés pour revenir manuellement aux nœuds publics.
