# 자주 묻는 질문 (FAQ)

## MEV와 샌드위치 공격이란 무엇인가요?

MEV(Maximal Extractable Value, 최대 추출 가능 가치)는 블록 내에서 거래의 순서를 바꾸거나 거래를 포함시켜 얻을 수 있는 추가 수익을 의미합니다.

샌드위치 공격은 공격자가 대상 거래의 앞과 뒤에 각각 하나의 거래를 배치하여 자산 가격을 조작하고 이익을 얻는 특정 유형의 MEV 공격입니다. 이로 인해 피해자는 비용이 늘어나거나 더 나쁜 결과를 얻게 됩니다.

## MEV 보호 RPC 엔드포인트란 무엇인가요?

샌드위치 공격과 같은 MEV(최대 추출 가능 가치) 착취로부터 사용자를 보호하는 데 도움이 되는, 블록체인과 상호작용하기 위한 전용 게이트웨이입니다.

## MEV Guard는 공격으로부터 어떻게 나를 보호하나요?

이 엔드포인트는 프라이빗 릴레이와 기타 보호 메커니즘을 통해 거래를 전달하여 사용자의 거래가 간섭 없이 안전하게 처리되도록 하며, 슬리피지, 가격 조작 또는 가치 손실의 위험을 줄입니다.

## MEV Guard는 어떻게 설치하나요?

페이지의 안내에 따라 MEV 보호 엔드포인트로 전환하거나 지갑에 추가하세요.

MetaMask를 사용하는 경우 버튼을 클릭하여 설정할 수 있습니다. 다른 지갑을 사용하는 경우 상세 가이드를 참고하여 네트워크를 수동으로 추가하세요.

## MEV Guard는 어떻게 비활성화하거나 제거하나요?

MetaMask를 사용하는 경우 RPC 엔드포인트를 일반 퍼블릭 노드로 다시 전환하면 됩니다. 다른 지갑을 사용하는 경우 상세 가이드를 참고하여 네트워크를 퍼블릭 노드로 수동으로 되돌리세요.
