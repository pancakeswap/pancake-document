# 🎯 PancakeSwap Auto Slippage

PancakeSwapはAuto Slippageを導入し、取引をより簡単かつ効率的にしました。Auto Slippageは現在の市場状況に基づいてスリッページを自動的に調整し、取引の失敗を防ぎ、スリッページのエラーによる損失リスクを軽減します。

## スリッページとは何ですか？

**スリッページ**とは、取引で期待する価格と実際に取引が完了した価格との差異のことです。これはいくつかの理由で発生することがあります：

* 市場の変動性 – 注文を確定してから実行されるまでの間に価格が大きく動く場合があります
* 流動性の低さ – 期待する価格で十分なトークンが用意されていない場合
* ブロックチェーンの遅延 – 確認処理に時間がかかり、取引完了前に価格が変わる場合があります

{% hint style="info" %}
例：

100 CAKEをBNBにスワップしようとしたとき、1 CAKE = 0.01 BNBを期待していたとします。しかし取引が処理された時点で価格が変わり、1 CAKEあたり0.0098 BNBしか受け取れなかった場合、この小さな差異がスリッページです。
{% endhint %}

## スリッページ許容範囲とは何ですか？

**スリッページ許容範囲**とは、取引がキャンセルされる前に許容できる最大の価格差です。価格が設定した許容範囲を超えて変動した場合、予期せぬ損失を防ぐためにトランザクションが失敗します。

{% hint style="info" %}
例：

スリッページ許容範囲を1%に設定した場合、取引が完了する前に価格が1%以上変動した場合、取引は実行されません。
{% endhint %}

## スリッページ許容範囲が低すぎるとどうなりますか？

スリッページ許容範囲が**低すぎる設定**の場合、特に以下のような状況でトランザクションが失敗する可能性が高くなります：

* 市場が不安定な場合
* 流動性の低いトークンをスワップする場合
* 税金や複雑なメカニズムを持つトークンを使用する場合

{% hint style="warning" %}
重要：トランザクションが失敗した場合でも、試みに対するガス手数料は消費されます。
{% endhint %}

## Auto Slippageの紹介 — なぜAuto Slippageが役立つのですか？

Auto Slippageは現在の市場状況に基づいてスリッページを自動的に調整し、時間を節約し、取引失敗のリスクを軽減します。

**Auto Slippage**を使用することで、スリッページ許容範囲を手動で調整する必要がなくなります。これにより、以下のような一般的な問題を防ぎます：

* **スリッページを低く設定しすぎる**ことで、実行中のわずかな価格変動によりトランザクションが失敗する問題。
* **スリッページを高く設定しすぎる**ことで、より広い価格範囲を許容することにより受け取るトークン数が少なくなる問題。

{% hint style="info" %}
最高の取引体験を確保するため、Auto Slippageは**自動的にオンに設定**されています。手動でスリッページ許容範囲が設定されている場合は、新しいスリッページ設定が適用されます。
{% endhint %}



## Auto Slippageはどのように機能しますか？

<pre class="language-html"><code class="lang-html"><strong>Auto Slippage (%) = (Gas Cost in USD / Output Token Value in USD) * 100%
</strong></code></pre>

* ガスコストが出力トークンの価値に比べて高い場合、Auto Slippageは取引が確実に通るようにスリッページを高めに設定します。
* ガスが安く出力トークンの価値が大きい場合、より小さいスリッページが使用されます。

Auto Slippageはトークンとネットワークの状況に応じて、**0.5%**から**5.0%**の間の値を選択します。



## Auto SlippageはすべてのネットワークでAuto Slippageは使用できますか？

いいえ — Auto SlippageはBNBチェーン、Ethereumなどのレイヤー1（L1）チェーンでのみサポートされています。

レイヤー2（L2）チェーンではサポートされていません。その理由は：

* Auto Slippageの計算式は有用なスリッページ設定を算出するために意味のあるガスコスト値に依存しているためです
* L2のガス手数料は非常に低いため、L2にAuto Slippageを適用しても取引成功率は改善しません

{% hint style="success" %}
&#x20;Auto Slippageがネットワークで**サポートされていない**場合：

* 以前に使用したスリッページ設定が適用されます
* 以前に設定したことがない場合は、デフォルトで0.5%になります
{% endhint %}
