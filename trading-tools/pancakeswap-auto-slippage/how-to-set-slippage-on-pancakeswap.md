# PancakeSwap에서 슬리피지를 설정하는 방법

#### PancakeSwap에서 슬리피지를 설정하는 방법

PancakeSwap은 슬리피지를 설정하는 두 가지 옵션을 제공합니다.

* 자동 슬리피지: 토큰과 시장 상황에 따라 자동으로 조정됩니다.
* 고정 슬리피지: 더 세밀한 제어를 위해 특정 슬리피지 비율을 직접 설정할 수 있습니다.



다음 위치에서 이 설정에 접근할 수 있습니다.

1. 설정 아이콘 클릭(스왑 화면 오른쪽 상단 패널)
2. 스왑 상세 정보의 편집 아이콘 -> 슬리피지 허용치
