# Comment définir le Glissement sur PancakeSwap

#### Comment définir le Glissement sur PancakeSwap

PancakeSwap propose deux options pour définir le Glissement :

* Glissement automatique : s'ajuste automatiquement en fonction du token et des conditions du marché.
* Glissement fixe : vous permet de définir un pourcentage de Glissement spécifique pour plus de contrôle.



Vous pouvez accéder à ces paramètres depuis :

1. En cliquant sur l'icône des paramètres (panneau supérieur droit du Swap)
2. L'icône de modification dans les détails du Swap -> Tolérance au Glissement
