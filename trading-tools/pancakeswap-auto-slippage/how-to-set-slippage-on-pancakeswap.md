# PancakeSwapでスリッページを設定する方法

#### PancakeSwapでスリッページを設定する方法

PancakeSwapではスリッページの設定に2つのオプションがあります：

* Auto Slippage：トークンと市場状況に基づいて自動的に調整されます。
* Fixed Slippage：より細かくコントロールするために特定のスリッページ率を設定できます。



これらの設定には以下からアクセスできます：

1. 設定アイコンをクリックする（Swapの右上パネル）
2. Swapの詳細にある編集アイコン → スリッページ許容範囲
