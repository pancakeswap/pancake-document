# 如何在 PancakeSwap 上设置滑点

#### 如何在 PancakeSwap 上设置滑点

PancakeSwap 提供两种设置滑点的方式：

* 自动滑点：根据代币和市场状况自动调整。
* 固定滑点：允许您设置特定的滑点百分比，以获得更多控制权。



您可以通过以下方式访问这些设置：

1. 点击设置图标（兑换面板右上角）
2. 兑换详情中的编辑图标 -> 滑点容差
