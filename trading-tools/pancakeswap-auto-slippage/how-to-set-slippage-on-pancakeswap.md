#### So legen Sie die Kursabweichung auf PancakeSwap fest

PancakeSwap bietet zwei Optionen zur Festlegung der Kursabweichung:

* Automatische Kursabweichung: Passt sich automatisch basierend auf Token und Marktbedingungen an.
* Feste Kursabweichung: Ermöglicht Ihnen, einen bestimmten Kursabweichungsprozentsatz für mehr Kontrolle festzulegen.



Sie können auf diese Einstellungen zugreifen über:

1. Klick auf das Einstellungssymbol (oberes rechtes Panel des Swap)
2. Bearbeitungssymbol in den Swap-Details -> Kursabweichungstoleranz
