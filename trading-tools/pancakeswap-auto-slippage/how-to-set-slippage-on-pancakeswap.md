# PancakeSwap'ta Kayma Nasıl Ayarlanır?

#### PancakeSwap'ta Kayma Nasıl Ayarlanır?

PancakeSwap, Kayma ayarı için iki seçenek sunar:

* Auto Slippage: Token ve piyasa koşullarına göre otomatik olarak ayarlanır.
* Sabit Kayma: Daha fazla kontrol için belirli bir Kayma yüzdesi belirlemenizi sağlar.



Bu ayarlara şuradan erişebilirsin:

1. Ayarlar simgesine tıklayarak (Swap'ın sağ üst paneli)
2. Swap detaylarındaki düzenleme simgesinden -> Kayma Toleransı
