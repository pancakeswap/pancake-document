## PancakeSwap NFTマーケットプレイスからNFTを引き出す方法

PancakeSwap NFTマーケットプレイスのページは現在ご利用いただけませんが、マーケットプレイスのスマートコントラクトは引き続き稼働しています。NFTを出品して売れなかった場合、そのNFTは今もマーケットプレイスのコントラクトに保管されています。BscScan上で直接出品をキャンセルすることで、ご自身でNFTを取り戻すことができます。

NFT 1つあたり数分で完了し、ガス代としてわずかなBNBが必要になるだけです。

### 始める前に

以下が必要です。

* **NFTを出品したときと同じウォレット。** 出品を作成したウォレットだけが、その出品をキャンセルできます。
* **ブラウザウォレット**（例：MetaMask、Trust Walletの拡張機能、Binance Walletの拡張機能）。**BNB Smart Chain**に接続してください。
* ガス代を支払うための**少額のBNB**。NFTの引き出しは1つずつ個別のトランザクションで行います。

以下のアドレスを手元に控えておいてください。

| 項目                         | アドレス                                         |
| -------------------------- | -------------------------------------------- |
| マーケットプレイスコントラクト            | `0x17539cCa21C7933Df5c980172d22659B8C345C5A` |
| Pancake Squad コレクション      | `0x0a8901b0E25DEb55A87524f0cC164E9644020EBA` |
| Pancake Bunnies コレクション    | `0xDf7952B35f24aCF7fC0487D01c8d5690a60DBa07` |

> **安全のために**
>
> * 操作するのはマーケットプレイスコントラクト `0x17539cCa21C7933Df5c980172d22659B8C345C5A` のみにしてください。BscScanのURLに含まれるアドレスを必ず確認してください。
> * NFTの引き出しにBNBやトークンの送信が必要になることは**一切ありません**。また、承認（`approve` や `setApprovalForAll`）への署名も必要ありません。ウェブサイトや人物からこれを求められた場合は、詐欺です。
> * PancakeSwapがDMを送ったり、シードフレーズを尋ねたりすることは決してありません。

### ステップ1：出品中のNFTを確認する

引き出したいNFTごとに、**コレクションアドレス**と**トークンID**の2つの情報が必要です。

1. BscScan上のマーケットプレイスコントラクトの[Read Contractページ](https://bscscan.com/address/0x17539cCa21C7933Df5c980172d22659B8C345C5A#readContract)を開きます。
2. **`viewAsksByCollectionAndSeller`** を見つけて展開します。
3. 各フィールドを入力します。
   * `collection`：上の表にあるコレクションアドレス（例：Pancake Squadの場合は `0x0a8901b0E25DEb55A87524f0cC164E9644020EBA`）
   * `seller`：ご自身のウォレットアドレス
   * `cursor`：`0`
   * `size`：`100`
4. **Query** をクリックします。
5. `tokenIds` の結果を確認します。これらはそのコレクションで現在も出品中のトークンIDであり、引き出し可能なNFTです。
6. 複数のコレクションでNFTを出品していた場合は、コレクションごとに手順3〜5を繰り返します。

**`tokenIds` が空（`[]`）の場合**、そのコレクションにはアクティブな出品がありません。NFTはすでに売却された（この場合、BNBは受け取り済みです）か、以前に出品をキャンセルした（この場合、すでにウォレットに戻っています）かのどちらかです。

**1つのコレクションで出品が100件を超える場合**、結果の最後の数値が次のcursorです。その数値を `cursor` に指定して再度クエリを実行すると、残りを確認できます。

**NFTがPancake SquadまたはPancake Bunnies以外のコレクションのものである場合**は、同じページで **`viewCollections`** を展開し、`cursor = 0`、`size = 100` を入力して **Query** をクリックすると、マーケットプレイスが対応しているすべてのコレクションを確認できます。

### ステップ2：NFTを引き出す

1. BscScan上のマーケットプレイスコントラクトの[Write Contractページ](https://bscscan.com/address/0x17539cCa21C7933Df5c980172d22659B8C345C5A#writeContract)を開きます。
2. **Connect to Web3** をクリックし、NFTを出品したときと同じウォレットを接続します。ウォレットがBNB Smart Chainに接続されていることを確認してください。
3. **`cancelAskOrder`** を見つけて展開します。
4. 各フィールドを入力します。
   * `_collection`：ステップ1で確認したコレクションアドレス
   * `_tokenId`：ステップ1で確認したトークンID（数字のみ。例：`1234`）
5. **Write** をクリックし、ウォレットでトランザクションを承認します。BNBを送る必要はなく、ガス代のみをお支払いいただきます。
6. トランザクションが成功すると、NFTはウォレットに戻ります。
7. 引き出したいNFTごとに繰り返します。

正常に完了したかを確認するには、もう一度ステップ1を実行してください。該当のトークンIDがリストに表示されなくなっているはずです。

### トラブルシューティング

| 問題                                  | 内容と対処方法                                                                                                         |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| エラー：`Order: Token not listed`        | 接続中のウォレットがこのコレクションのこのトークンIDを出品していないか、NFTがすでに売却または引き出し済みです。元のウォレットと、正しいコレクションアドレスおよびトークンIDを使用しているか確認してください。 |
| Writeボタンを押しても何も起こらない                | ウォレットのネットワークが間違っている可能性があります。BNB Smart Chainに切り替えて、再接続してください。                                                    |
| ガス不足または残高不足                         | ガス代を支払うため、ウォレットに少額のBNBを追加してください。                                                                                |
| NFTを出品したウォレットにアクセスできなくなった           | 出品をキャンセルできるのは元のウォレットのみです。PancakeSwapを含め、誰もあなたに代わって引き出すことはできません。                                                 |
