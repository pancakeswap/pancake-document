# 🧙 Page 1

## Как вывести свой NFT с PancakeSwap NFT Marketplace

Страницы PancakeSwap NFT Marketplace больше недоступны, но смарт-контракт маркетплейса всё ещё работает. Если ты выставил NFT на продажу, а он так и не продался, он по-прежнему находится в контракте маркетплейса. Ты можешь вернуть его сам, отменив листинг напрямую на BscScan.

Это занимает несколько минут на каждый NFT и стоит лишь небольшую сумму BNB за газ.

### Перед началом

Тебе понадобится:

* **Тот же кошелёк, с которого ты выставлял NFT.** Отменить листинг может только кошелёк, создавший его.
* **Браузерный кошелёк** (например, MetaMask, расширение Trust Wallet или расширение Binance Wallet), настроенный на **BNB Smart Chain**.
* **Небольшое количество BNB** для оплаты газа. Каждый NFT выводится отдельной транзакцией.

Держи под рукой эти адреса:

| Элемент                    | Адрес                                        |
| -------------------------- | -------------------------------------------- |
| Контракт маркетплейса      | `0x17539cCa21C7933Df5c980172d22659B8C345C5A` |
| Коллекция Pancake Squad    | `0x0a8901b0E25DEb55A87524f0cC164E9644020EBA` |
| Коллекция Pancake Bunnies  | `0xDf7952B35f24aCF7fC0487D01c8d5690a60DBa07` |

> **Безопасность**
>
> * Взаимодействуй только с контрактом маркетплейса `0x17539cCa21C7933Df5c980172d22659B8C345C5A`. Всегда проверяй адрес в URL BscScan.
> * Для вывода NFT **никогда** не нужно отправлять BNB или токены и никогда не нужно подписывать разрешение (`approve` или `setApprovalForAll`). Если сайт или человек просит тебя об этом, это мошенничество.
> * PancakeSwap никогда не напишет тебе в личные сообщения и не попросит твою сид-фразу.

### Шаг 1: Найди NFT, которые у тебя всё ещё выставлены

Для каждого NFT, который хочешь вывести, тебе нужны две вещи: **адрес коллекции** и **token ID**.

1. Открой [страницу Read Contract](https://bscscan.com/address/0x17539cCa21C7933Df5c980172d22659B8C345C5A#readContract) контракта маркетплейса на BscScan.
2. Найди и разверни **`viewAsksByCollectionAndSeller`**.
3. Заполни поля:
   * `collection`: адрес коллекции из таблицы выше (например, для Pancake Squad это `0x0a8901b0E25DEb55A87524f0cC164E9644020EBA`)
   * `seller`: адрес твоего кошелька
   * `cursor`: `0`
   * `size`: `100`
4. Нажми **Query**.
5. Посмотри на результат `tokenIds`. Это token ID, которые у тебя всё ещё выставлены в этой коллекции, и именно эти NFT ты можешь вывести.
6. Если ты выставлял NFT из нескольких коллекций, повтори шаги с 3 по 5 для каждой коллекции.

**Если `tokenIds` пуст (`[]`)**, у тебя нет активных листингов в этой коллекции. Твой NFT либо был продан (и тогда ты уже получил BNB), либо ты ранее отменил листинг (и тогда он уже вернулся в твой кошелёк).

**Если у тебя больше 100 листингов** в одной коллекции, последнее число в результате — это следующий курсор. Выполни запрос снова, указав это число в качестве `cursor`, чтобы увидеть остальные.

**Если твой NFT из коллекции, отличной от Pancake Squad или Pancake Bunnies**, разверни **`viewCollections`** на той же странице, введи `cursor = 0` и `size = 100` и нажми **Query**, чтобы увидеть все коллекции, которые поддерживает маркетплейс.

### Шаг 2: Выведи свой NFT

1. Открой [страницу Write Contract](https://bscscan.com/address/0x17539cCa21C7933Df5c980172d22659B8C345C5A#writeContract) контракта маркетплейса на BscScan.
2. Нажми **Connect to Web3** и подключи тот же кошелёк, с которого выставлялся NFT. Убедись, что твой кошелёк подключён к BNB Smart Chain.
3. Найди и разверни **`cancelAskOrder`**.
4. Заполни поля:
   * `_collection`: адрес коллекции из шага 1
   * `_tokenId`: token ID из шага 1, обычным числом (например, `1234`)
5. Нажми **Write** и подтверди транзакцию в кошельке. BNB ты не отправляешь, а платишь только за газ.
6. Когда транзакция пройдёт успешно, NFT вернётся в твой кошелёк.
7. Повтори для каждого NFT, который хочешь вывести.

Чтобы убедиться, что всё сработало, выполни шаг 1 ещё раз. Token ID больше не должен появляться в списке.

### Устранение неполадок

| Проблема                                                  | Что это значит и что делать                                                                                                                                                                                 |
| --------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Ошибка: `Order: Token not listed`                         | Подключённый кошелёк не выставлял этот token ID в этой коллекции, либо NFT уже был продан или выведен. Проверь, что ты используешь исходный кошелёк, а также правильные адрес коллекции и token ID.            |
| Кнопка Write ничего не делает                             | Скорее всего, твой кошелёк подключён не к той сети. Переключись на BNB Smart Chain и подключись заново.                                                                                                      |
| Не хватает газа или недостаточно средств                  | Пополни кошелёк небольшим количеством BNB для оплаты газа.                                                                                                                                                  |
| У меня больше нет доступа к кошельку, с которого выставлялся NFT | Отменить листинг может только исходный кошелёк. Никто, включая PancakeSwap, не может вывести его за тебя.                                                                                           |
