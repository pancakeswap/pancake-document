# Social Login

{% hint style="danger" %}
Social Login으로 생성된 스마트 지갑은 현재 [제한된 네트워크](https://docs.pancakeswap.finance/trading-tools/social-login/social-login-faq#general-overview)만 지원합니다.\
스마트 지갑 UI 또는 기반 지갑 제공업체에서 _지원하지 않는_ 체인으로 자산을 전송하면 자금에 일시적으로 접근할 수 없게 될 수 있습니다.
{% endhint %}

### Social Login이란 무엇인가요?

PancakeSwap의 **Social Login**을 사용하면 Google, X (Twitter), Discord 또는 Telegram 계정으로 안전한 자기 수탁형 지갑을 만들 수 있습니다. 브라우저 확장 프로그램, 시드 구문, 복잡한 설정이 필요 없습니다.

특히 초보자이거나 빠르게 시작하려는 분들이 DeFi를 가장 빠르게 탐색할 수 있는 방법입니다. 지갑은 백그라운드에서 자동으로 생성되며 PancakeSwap이 지원하는 모든 체인에서 원활하게 작동합니다.

#### 🚀 Social Login + Pancake Gifts: 매끄러운 DeFi 온보딩

**PancakeSwap Gifts**와 함께 사용하면 Social Login은 초보자에게 최적화된 경험을 제공합니다.

* 간단한 링크로 **선물(토큰 또는 NFT) 받기**
* 소셜 계정으로 **즉시 로그인**
* **자산 수령 및 사용** — 지갑 설정이나 기술 지식이 필요 없습니다

이 흐름은 암호화폐를 시작할 때 흔히 겪는 장벽을 없애 주며, PancakeSwap 생태계에 온보딩하는 것을 그 어느 때보다 쉽게 만들어 줍니다.
