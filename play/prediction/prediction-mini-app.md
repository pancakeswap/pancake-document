# Mini application Prediction

### Qu'est-ce que la mini application ?

La mini application Telegram vous permet d'accéder rapidement aux fonctionnalités de PancakeSwap au sein de Telegram.

### Comment connecter mon portefeuille ?

{% tabs %}
{% tab title="Desktop" %}
**Utiliser MetaMask**

Vous pouvez connecter votre portefeuille MetaMask mobile à la mini application Telegram de bureau via un code QR. Pour vous connecter, choisissez « MetaMask », cliquez sur « Mobile » et scannez le code QR avec MetaMask sur votre téléphone.

**Utiliser WalletConnect**

Vous pouvez connecter n'importe quel portefeuille mobile à la mini application Telegram de bureau via un code QR. Pour vous connecter, choisissez « WalletConnect », cliquez sur le code QR et scannez-le avec votre téléphone mobile.

{% hint style="warning" %}
L'option « Desktop » pour MetaMask n'est pas fonctionnelle. Vous ne pouvez connecter que MetaMask mobile à la mini application Telegram de bureau.
{% endhint %}
{% endtab %}

{% tab title="iPhone" %}
**Utiliser MetaMask**

Vous pouvez connecter votre portefeuille MetaMask à votre mini application Telegram. Pour vous connecter, choisissez « MetaMask ». Si une invite vous demande si vous souhaitez être redirigé vers l'application MetaMask, cliquez sur Ouvrir. Suivez ensuite les instructions dans l'application MetaMask pour vous connecter.

**Utiliser WalletConnect**

Vous pouvez connecter n'importe quel portefeuille mobile pris en charge à votre mini application Telegram. Pour vous connecter, choisissez « WalletConnect », cliquez sur « Voir tout » et sélectionnez votre portefeuille. Si une invite vous demande si vous souhaitez être redirigé vers l'application du portefeuille, cliquez sur Ouvrir. Suivez ensuite les instructions dans l'application du portefeuille pour vous connecter.
{% endtab %}

{% tab title="Android" %}
**Utiliser MetaMask**

Vous pouvez connecter votre portefeuille MetaMask à votre mini application Telegram. Pour vous connecter, choisissez « MetaMask ». Vous serez redirigé vers MetaMask, puis suivez simplement les instructions dans l'application MetaMask pour vous connecter.

**Utiliser WalletConnect**

Vous pouvez connecter n'importe quel portefeuille mobile pris en charge à votre mini application Telegram. Pour vous connecter, choisissez « WalletConnect », cliquez sur « Voir tout » et sélectionnez votre portefeuille. Vous serez redirigé vers l'application du portefeuille, puis suivez les instructions pour vous connecter.

{% hint style="warning" %}
WalletConnect peut ne pas fonctionner sur certains téléphones Android. Dans ce cas, veuillez vous connecter via d'autres méthodes.
{% endhint %}
{% endtab %}
{% endtabs %}

### Quel marché PancakeSwap est pris en charge ?

Actuellement, la mini application prend en charge le marché BNBUSD sur BNB Chain.

### Comment signer et confirmer les transactions dans la mini application ?

Vous devrez signer et exécuter les transactions dans votre application de portefeuille connecté.

{% hint style="warning" %}
Sur iPhone, il peut être nécessaire de basculer manuellement entre les applications de portefeuille et Telegram. Veuillez suivre les instructions à l'écran.
{% endhint %}

### Puis-je utiliser mes portefeuilles d'extension sur l'ordinateur de bureau ?

Malheureusement, la mini application Telegram ne prend en charge que les portefeuilles mobiles pour l'instant.
