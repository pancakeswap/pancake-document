# Prognose Mini App

### Was ist eine Mini App?

Die Telegram Mini App ermöglicht Ihnen schnellen Zugriff auf PancakeSwap-Funktionen innerhalb von Telegram.

### Wie verbinde ich meine Wallet?

{% tabs %}
{% tab title="Desktop" %}
**MetaMask verwenden**

Sie können Ihre mobile MetaMask-Wallet über einen QR-Code mit der Desktop-Telegram-Mini-App verbinden. Wählen Sie zur Verbindung „MetaMask", klicken Sie auf „Mobil" und scannen Sie den QR-Code mit MetaMask auf Ihrem Telefon.

**WalletConnect verwenden**

Sie können jede mobile Wallet über einen QR-Code mit der Desktop-Telegram-Mini-App verbinden. Wählen Sie zur Verbindung „WalletConnect", klicken Sie auf QR-Code und scannen Sie den QR-Code mit dem Mobiltelefon.

{% hint style="warning" %}
Die Option „Desktop" für MetaMask ist nicht funktionsfähig. Sie können nur mobiles MetaMask mit der Desktop-Telegram-Mini-App verbinden.
{% endhint %}
{% endtab %}

{% tab title="iPhone" %}
**MetaMask verwenden**

Sie können Ihre MetaMask-Wallet mit Ihrer Telegram-Mini-App verbinden. Wählen Sie zur Verbindung „MetaMask". Wenn eine Eingabeaufforderung erscheint, ob Sie zur MetaMask-App weitergeleitet werden möchten, klicken Sie auf Öffnen. Folgen Sie dann den Anweisungen in der MetaMask-App zum Verbinden.

**WalletConnect verwenden**

Sie können jede unterstützte mobile Wallet mit Ihrer Telegram-Mini-App verbinden. Wählen Sie zur Verbindung „WalletConnect", klicken Sie auf „Alle anzeigen" und wählen Sie Ihre Wallet aus. Wenn eine Eingabeaufforderung erscheint, ob Sie zur Wallet-App weitergeleitet werden möchten, klicken Sie auf Öffnen. Folgen Sie dann den Anweisungen in der Wallet-App zum Verbinden.
{% endtab %}

{% tab title="Android" %}
**MetaMask verwenden**

Sie können Ihre MetaMask-Wallet mit Ihrer Telegram-Mini-App verbinden. Wählen Sie zur Verbindung „MetaMask". Sie werden zu MetaMask weitergeleitet; folgen Sie dann einfach den Anweisungen in der MetaMask-App zum Verbinden.

**WalletConnect verwenden**

Sie können jede unterstützte mobile Wallet mit Ihrer Telegram-Mini-App verbinden. Wählen Sie zur Verbindung „WalletConnect", klicken Sie auf „Alle anzeigen" und wählen Sie Ihre Wallet aus. Sie werden zur Wallet-App weitergeleitet; folgen Sie dann den Anweisungen in der Wallet-App zum Verbinden.

{% hint style="warning" %}
WalletConnect funktioniert möglicherweise nicht auf einigen Android-Telefonen. Verbinden Sie sich in diesem Fall über andere Methoden.
{% endhint %}
{% endtab %}
{% endtabs %}

### Welcher PancakeSwap-Markt wird unterstützt?

Derzeit unterstützt die Mini App den BNBUSD-Markt auf BNB Chain.

### Wie unterzeichne und bestätige ich Transaktionen für die Mini App?

Sie müssen Transaktionen in Ihrer verbundenen Wallet-App unterzeichnen und ausführen.

{% hint style="warning" %}
Auf dem iPhone müssen Sie möglicherweise manuell zwischen Wallet-Apps und Telegram wechseln. Bitte folgen Sie den Anweisungen auf dem Bildschirm.
{% endhint %}

### Kann ich meine Browser-Erweiterungs-Wallets auf dem Desktop verwenden?

Leider unterstützt die Telegram-Mini-App derzeit nur mobile Wallets.
