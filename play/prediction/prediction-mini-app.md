# Prediction Mini App

### Apa itu mini app?

Telegram mini app memungkinkan Anda mengakses fitur PancakeSwap dengan cepat di dalam Telegram.

### Bagaimana cara menghubungkan dompet saya?

{% tabs %}
{% tab title="Desktop" %}
**Menggunakan MetaMask**

Anda dapat menghubungkan dompet MetaMask mobile Anda ke desktop Telegram mini app menggunakan kode QR. Untuk terhubung, pilih "MetaMask", klik "Mobile", dan pindai kode QR menggunakan MetaMask di ponsel Anda.

**Menggunakan WalletConnect**

Anda dapat menghubungkan dompet mobile apa pun ke desktop Telegram mini app menggunakan kode QR. Untuk terhubung, pilih "WalletConnect", klik kode QR, dan pindai kode QR menggunakan ponsel Anda.

{% hint style="warning" %}
Opsi "Desktop" untuk MetaMask tidak berfungsi. Anda hanya dapat menghubungkan MetaMask mobile ke desktop Telegram mini app.
{% endhint %}
{% endtab %}

{% tab title="iPhone" %}
**Menggunakan MetaMask**

Anda dapat menghubungkan dompet MetaMask Anda ke Telegram mini app. Untuk terhubung, pilih "MetaMask". Jika muncul permintaan apakah Anda ingin dibawa ke aplikasi MetaMask, klik Buka. Kemudian ikuti instruksi di aplikasi MetaMask untuk terhubung.

**Menggunakan WalletConnect**

Anda dapat menghubungkan dompet mobile yang didukung ke Telegram mini app. Untuk terhubung, pilih "WalletConnect", klik "View All", dan pilih dompet Anda. Jika muncul permintaan apakah Anda ingin dibawa ke aplikasi dompet, klik Buka. Kemudian ikuti instruksi di aplikasi dompet untuk terhubung.
{% endtab %}

{% tab title="Android" %}
**Menggunakan MetaMask**

Anda dapat menghubungkan dompet MetaMask Anda ke Telegram mini app. Untuk terhubung, pilih "MetaMask". Anda akan diarahkan ke MetaMask, kemudian cukup ikuti instruksi di aplikasi MetaMask untuk terhubung.

**Menggunakan WalletConnect**

Anda dapat menghubungkan dompet mobile yang didukung ke Telegram mini app. Untuk terhubung, pilih "WalletConnect", klik "View All", dan pilih dompet Anda. Anda akan diarahkan ke aplikasi dompet, kemudian ikuti instruksi di aplikasi dompet untuk terhubung.

{% hint style="warning" %}
Wallet Connect mungkin tidak berfungsi di beberapa ponsel Android. Dalam hal itu, silakan hubungkan melalui metode lain.
{% endhint %}
{% endtab %}
{% endtabs %}

### Pasar PancakeSwap mana yang didukung?

Saat ini mini app mendukung pasar BNBUSD di BNB Chain.

### Bagaimana cara menandatangani dan mengonfirmasi transaksi untuk mini app?

Anda perlu menandatangani dan mengeksekusi transaksi di aplikasi dompet yang terhubung.

{% hint style="warning" %}
Di iPhone, Anda mungkin perlu beralih secara manual antara aplikasi dompet dan Telegram. Silakan ikuti instruksi di layar.
{% endhint %}

### Bisakah saya menggunakan dompet ekstensi di Desktop?

Sayangnya Telegram mini app saat ini hanya mendukung dompet mobile.
