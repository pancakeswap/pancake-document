# 지갑 만들기

PancakeSwap을 시작하려면 가장 먼저 BNB Smart Chain(BSC)을 지원하는 지갑을 설정해야 합니다. 지갑은 데스크톱 컴퓨터와 스마트폰 기기 모두에서 사용할 수 있습니다. 본인에게 가장 적합한 지갑을 선택하세요.

{% hint style="danger" %}
**지갑을 설정할 때는 반드시 다음을 지켜 주세요.**

* ✅ **공식 출처에서 최신 버전만 다운로드하여 설치하세요.**
* ✅ **설정 가이드를 꼼꼼히 따르세요.**
* ✅ **복구 구문을 안전하게 백업하세요.**
* ❌ **어떤 상황에서도 복구 구문을 다른 사람과 절대 공유하지 마세요.**
* ❌ **지갑 앱 외의 웹사이트나 앱에 복구 구문을 절대 입력하지 마세요.**
{% endhint %}

## 스마트폰/모바일 지갑 vs 데스크톱 지갑?

모바일 기기 지갑과 데스크톱 기반 지갑은 각각 장단점이 다릅니다. 어떤 유형이 본인에게 더 적합한지 고려해 지갑 유형을 결정해 보세요.

|              | 모바일 | 데스크톱 |
| ------------ | --- | ---- |
| 어디서나 사용      | ✅   | ➖    |
| 사용하기 쉬움      | ✅   | ➖    |
| 더 안전함        | ➖   | ✅    |
| 접근성 친화적      | ➖   | ✅    |
| 파손/분실/도난에 강함 | ➖   | ✅    |
| 전원/연결 장애에 강함 | ✅   | ➖    |

### **스마트폰/모바일 지갑**

스마트폰/모바일 지갑을 사용하면 거의 어디서나 암호화폐에 접근할 수 있습니다. Android와 iOS 기기 모두에서 지갑을 사용할 수 있습니다.

{% tab title="MetaMask" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20\(33\)%20\(3\).png)

MetaMask는 ERC20(Ethereum 네트워크)과 BEP2 및 BEP20(Binance Chain 및 BNB Smart Chain 네트워크)을 지원하는 매우 인기 있는 브라우저 기반 지갑 플러그인입니다.

​**장점:**

* 감사 가능성을 위한 오픈 소스
* BscScan에서 WEB3 사용 가능
* 보안과 신뢰성 측면에서 탄탄한 이력
* 온라인에 풍부한 이용 가이드와 자료
* 다양한 도구와 사용자 설정
* Transak을 통한 ETH 구매 지원
* 매우 많은 언어 지원
* 데스크톱 기기용 브라우저 플러그인으로도 제공

**단점:**

* 다른 옵션보다 설정 시간이 오래 걸림
* BNB Smart Chain 및 PancakeSwap과 함께 사용하려면 추가 단계가 필요함
* 추가 정보와 설정이 초보자에게 혼란을 줄 수 있음

[**MetaMask 다운로드**](https://metamask.io/download.html) (기기를 자동으로 감지)\
[**MetaMask 설정 가이드**](https://academy.binance.com/en/articles/connecting-metamask-to-binance-smart-chain)

{% tab title="Coinbase Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/coinbase_wallet_wordmark_blue.png)

수백만 명의 사용자가 Coinbase Wallet을 통해 DeFi로 수익을 얻고, 5,500개가 넘는 자산을 스왑하고, NFT 컬렉션을 보관합니다. Coinbase Wallet은 BEP2 및 BEP20(Binance Chain 및 BNB Smart Chain 네트워크)을 지원합니다.

**주요 특징:**

* 미국에서 가장 많이 다운로드된 모바일 dapp 지갑으로, 활성 지갑 사용자 1,200만 명 이상.
* BNB Smart Chain 및 PancakeSwap과 함께 사용하기 위한 추가 단계가 필요하지 않음.
* 프리미엄 사용자층: web3를 탐색하기 시작하면서 Coinbase Wallet으로 유입될 수 있는 Coinbase 리테일 앱 사용자 최대 8,900만 명 이상.
* Coinbase 리테일 앱에서 자산을 쉽게 이전 가능.
* 법정화폐 온램프: 이제 Coinbase가 운영되는 86개국 모두에서 지갑을 벗어나지 않고 법정화폐로 직접 암호화폐를 구매할 수 있습니다.
* 안전한 클라우드 백업을 갖춘 업계 최고 수준의 보안.

[**Coinbase Wallet 다운로드**](https://coinbase-wallet.onelink.me/q5Sx/fdb9b250) **(기기를 자동으로 감지)**

[**Coinbase Wallet 설정 가이드**](https://www.coinbase.com/wallet/getting-started-mobile)

_Coinbase Wallet은 Coinbase Wallet_ [_서비스 약관_](https://wallet.coinbase.com/terms-of-service) _및_ [_개인정보 처리방침_](https://wallet.coinbase.com/privacy-policy)_에 따라 소프트웨어 서비스를 제공하는 자기 수탁(self-custody) 지갑입니다. Coinbase Wallet은 Coinbase.com과_ [_별개_](https://help.coinbase.com/en/wallet/getting-started/what-s-the-difference-between-coinbase-com-and-wallet) _이며, Coinbase Wallet의 개인 키는 Coinbase가 아닌 사용자가 직접 보관합니다. 수수료가 적용될 수 있습니다. Coinbase Wallet을 사용하기 위해 Coinbase.com 계정은 필요하지 않습니다._

Trust Wallet은 스마트 기기용으로 인기 있는 지갑입니다. DApp, NFT 수집품(Opensea.io 지원), 지갑 내 스테이킹을 지원합니다.

**장점:**

* 감사 가능성을 위한 오픈 소스
* Binance 암호화폐 거래소의 후원
* 여러 암호화폐 네트워크 간 손쉬운 전환
* 기본적으로 네트워크 포함
* 지갑 내 스테이킹 옵션 포함
* NFT 컬렉션, BNB 스테이킹, 지갑 내 DApp 접속 등 추가 기능 제공

**단점:**

* 언어가 휴대폰 설정에 종속됨
* DApp이 제한적임
* 트랜잭션 알림이 지연될 수 있음

[**Trust Wallet 다운로드**](https://trustwallet.com) (기기를 자동으로 감지)\

​**장점:**

**단점:**

* 중국어와 영어만 지원
* 영어 번역에 일부 문제가 있음
* 더 오래된 지갑보다 온라인 자료가 적음

{% tab title="MetaMask" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20\(33\)%20\(3\).png)

MetaMask는 기본적으로 ERC20(Ethereum 네트워크)을 지원하고, 약간의 설정을 거치면 BEP2 및 BEP20(Binance Chain 및 BNB Smart Chain 네트워크)도 지원하는 매우 인기 있는 브라우저 기반 지갑 플러그인입니다.

​**장점:**

* 감사 가능성을 위한 오픈 소스
* BscScan에서 WEB3 사용 가능
* 보안과 신뢰성 측면에서 탄탄한 이력
* 온라인에 풍부한 이용 가이드와 자료
* 다양한 도구와 사용자 설정
* 매우 많은 언어 지원
* 모바일 기기에서도 사용 가능

**단점:**

* 다른 옵션보다 설정 시간이 오래 걸림
* BNB Smart Chain 및 PancakeSwap과 함께 사용하려면 추가 단계가 필요함
* 추가 정보와 설정이 초보자에게 혼란을 줄 수 있음

[**MetaMask 다운로드**](https://metamask.io/download.html) (브라우저를 자동으로 감지)\
[**MetaMask 설정 가이드**](https://academy.binance.com/en/articles/connecting-metamask-to-binance-smart-chain)
{% endtab %}

{% tab title="Binance Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20\(255\).png)

Binance Wallet은 Binance Chain(BEP2)과 BNB Smart Chain(BEP20) 네트워크를 기본적으로 지원하는 브라우저 플러그인 지갑입니다. Binance Wallet은 Binance 암호화폐 거래소에서 개발했습니다.

​**장점:**

* 감사 가능성을 위한 오픈 소스
* Binance 암호화폐 거래소의 후원
* Binance 또는 Gmail 계정과 직접 연결 가능
* 간소화된 사용자 경험
* 기본적으로 BNB Smart Chain을 지원하여 PancakeSwap을 쉽게 사용 가능
* 다수의 언어 지원
* 하드웨어 지갑 호환

**단점:**

* 다른 지갑의 일부 사용자 설정이 없음
* 추가 도구가 없어 다른 지갑에서 가능한 일부 작업을 할 수 없음
* 더 오래된 지갑보다 온라인 자료가 적음

[**Binance Wallet 다운로드**](https://www.binance.org/en) (브라우저를 자동으로 감지)\
[**Binance Wallet 설정 가이드**](https://docs.binance.org/smart-chain/wallet/binance.html)
{% endtab %}

{% tab title="Coinbase Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/coinbase_wallet_wordmark_blue.png)

수백만 명의 사용자가 Coinbase Wallet을 통해 DeFi로 수익을 얻고, 5,500개가 넘는 자산을 스왑하고, NFT 컬렉션을 보관합니다. Coinbase Wallet은 ERC20(Ethereum 네트워크)과 BEP2 및 BEP20(Binance Chain 및 BNB Smart Chain 네트워크)을 지원합니다.

**주요 특징:**

* 활성 지갑 사용자 1,200만 명 이상.
* BNB Smart Chain 및 PancakeSwap과 함께 사용하기 위한 추가 단계가 필요하지 않음.
* 프리미엄 사용자층: web3를 탐색하기 시작하면서 Coinbase Wallet으로 유입될 수 있는 Coinbase 리테일 앱 사용자 최대 8,900만 명 이상.
* Coinbase 리테일 앱에서 자산을 쉽게 이전 가능.
* 법정화폐 온램프: 이제 Coinbase가 운영되는 86개국 모두에서 지갑을 벗어나지 않고 법정화폐로 직접 암호화폐를 구매할 수 있습니다.
* 안전한 클라우드 백업을 갖춘 업계 최고 수준의 보안
* 모바일 기기에서도 사용 가능

**참고:**

* 현재 Chrome에서만 사용 가능

[**Coinbase Wallet 다운로드**](https://chrome.google.com/webstore/detail/coinbase-wallet-extension/hnfanknocfeofbddgcijnmhnfnkdnaad?hl=en\&authuser=0)[ ](https://chrome.google.com/webstore/detail/coinbase-wallet-extension/hnfanknocfeofbddgcijnmhnfnkdnaad?hl=en\&authuser=0)(Chrome 전용)

[**Coinbase Wallet 설정 가이드**](https://www.coinbase.com/wallet/getting-started-extension)

_Coinbase Wallet은 Coinbase Wallet_ [_서비스 약관_](https://wallet.coinbase.com/terms-of-service) _및_ [_개인정보 처리방침_](https://wallet.coinbase.com/privacy-policy)_에 따라 소프트웨어 서비스를 제공하는 자기 수탁(self-custody) 지갑입니다. Coinbase Wallet은 Coinbase.com과_ [_별개_](https://help.coinbase.com/en/wallet/getting-started/what-s-the-difference-between-coinbase-com-and-wallet) _이며, Coinbase Wallet의 개인 키는 Coinbase가 아닌 사용자가 직접 보관합니다. 수수료가 적용될 수 있습니다. Coinbase Wallet을 사용하기 위해 Coinbase.com 계정은 필요하지 않습니다._

{% tab title="Token Pocket" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20\(125\)%20\(3\).png)

Token Pocket은 Mac OS와 Win64 기기 모두에서 사용할 수 있는 독립 실행형 애플리케이션입니다. Token Pocket을 사용하면 브라우저와 독립된 소프트웨어에서 암호화폐를 관리할 수 있습니다.

​**장점:**

* 감사 가능성을 위한 오픈 소스
* 브라우저 및 브라우저 권한과 독립적
* 여러 암호화폐 네트워크 간 손쉬운 전환 가능
* 기본적으로 다양한 네트워크 지원
* 브라우저 플러그인 지갑보다 덜 답답한 사용자 경험
* 모바일 기기에서도 사용 가능

**단점:**

* 데스크톱 설정 과정에서 개인 키 입력을 요구함
* 중국어와 영어만 지원
* 영어 번역에 일부 문제가 있음
* 더 오래된 지갑보다 온라인 자료가 적음

[**Token Pocket 데스크톱 지갑 다운로드**](https://www.tokenpocket.pro/en/download/pc) (MacOS 또는 Win64)

**Token Pocket 데스크톱 설정 가이드**

Token Pocket 데스크톱 버전은 개인 키를 가져오도록(import) 요구합니다. 진행하기 전에 개인 키에 대해 잘 알고 그 중요성을 이해하고 있는지 확인하세요.

Token Pocket은 오픈 소스 프로젝트이므로 코드가 공개되어 있으며 일반적으로 안전하다고 여겨집니다. 그렇더라도 개인 키는 본인의 책임이므로 신뢰할 수 있고 확인할 수 있는 애플리케이션에서만 사용하세요.

1. PC에서 Token Pocket 웹사이트를 방문하여 **Desktop** 버튼을 클릭합니다.

![](https://lh3.googleusercontent.com/8BvpBrdR19cHhjJq0_xOFQwpTDLaYUxqLAM03JPFzBPz93SHl3n84Dw_kICcfOR80iVZFS1QfYsexEUMNnchMLGSH11lHKMqBQWAJUZy7yd0LM6jaFrwRGt5EluBRo_uDqJBqbg2)

1. 다음 페이지에서 사용 중인 운영체제용 버튼을 클릭하고 다운로드가 완료될 때까지 기다립니다. 이 가이드는 Windows를 기준으로 하지만 Mac OS에서도 과정은 대체로 같습니다.

![](https://lh3.googleusercontent.com/SrYkM-cFg_tO3RcTlYv2Rq4pViUzRSw5el_JR8SnQYDmvVYupjJveTUXHr8QPeo30Ooc4EHBKEuYjxM1JbtirRHitGJtZ-2ET_Xk5a5DRbhqwyJToToii-s6Ch195p5o3Eo4Ajnm)

1. 설치 파일을 실행합니다. Token Pocket을 컴퓨터의 모든 사용자에게 제공할지, 현재 사용자에게만 제공할지 선택하라는 안내가 표시됩니다. 보안을 위해 현재 사용자만 선택하는 것을 권장합니다.

![](https://lh3.googleusercontent.com/EnmEle5PcVenTxE7jEtEHhQxeXwKjhzlOkZH67ByFLAIo4RMife2u4n36uDDGjTB8h64KxS0wmlI8FKAbxB6KvjvhD-WgCqdKpyUP1YM4tmxqTzjLGPuqDmf5ABTyY_5-wG7ppgG)

1. 설치할 대상 폴더를 입력하고 **Install**을 클릭합니다.

![](https://lh6.googleusercontent.com/ED7cl2_ZGBkUvM-A7CpE_bRNfdLQ8DcD2qmq6KaGAUIZTi_06f7BA_m-xBhoFzrczfTZQENsYji2Xlh_DNh0zWpmRnuo45HKX2r8zJxrBtqXkuPgxfCd4jAIvMytHu6iT_ZPRxmI)

1. 설치가 끝나면 **Finish**를 클릭하고 Token Pocket을 실행합니다.
2. Token Pocket이 열리면 중국어 인터페이스가 표시될 수 있습니다. 왼쪽 하단의 EN을 클릭하면 영어로 변경할 수 있습니다.

![](https://lh6.googleusercontent.com/V3VS6TaN0rJtfqjzCo5QEtS1ywJn_bmmB2hKWLbUGRy_-Pk83kGfu9feB35VAi4TC7BHKTqkApDagBuWP7XS3tVNzhcMPmANGqLlsOecumQpMMisvUBiABqi05351e7cNUgktWsO)

![](https://lh5.googleusercontent.com/GQqBU7OEK7BQuJc4NiOHEqt3kjO-B6jM6AAv3PFD6DoYuXywuOz6365Z5rPmNtkigWSg3f1_zzvoHfWAUvqIpEKaAajkDxVwlaWAljIW1ZGdgSwqECVa2CwgtS_vOOcX8faW19gB)

1. 다음 페이지에서 Token Pocket이 개인 키를 가져오도록(import) 요구합니다. 부담스러울 수 있지만 Token Pocket은 기존 지갑의 인터페이스 역할을 할 뿐입니다. 사용하려는 기존 지갑에서 개인 키를 가져와야 합니다.

[MetaMask에서 개인 키를 가져오는 방법에 대한 가이드](https://metamask.zendesk.com/hc/en-us/articles/360015289632-How-to-Export-an-Account-Private-Key)가 있습니다. Token Pocket 모바일 버전에서 개인 키를 가져오려면 이 페이지 위쪽의 모바일 Token Pocket 탭을 참고하세요. 다른 지갑을 사용 중이고 개인 키를 가져오는 방법을 모른다면 관련 가이드를 찾아봐야 합니다.
