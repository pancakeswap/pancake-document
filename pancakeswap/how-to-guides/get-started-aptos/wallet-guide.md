# 지갑 만들기

Aptos에서 PancakeSwap 여정을 시작하려면 가장 먼저 Aptos 체인을 지원하는 지갑을 설정해야 합니다. 지갑은 데스크톱 컴퓨터와 스마트폰 모두에서 사용할 수 있습니다. 자신에게 가장 잘 맞는 지갑을 선택하세요.

{% hint style="danger" %}
**지갑을 설정할 때는 반드시 다음을 지켜주세요.**

* ✅ **공식 출처에서 최신 버전만 다운로드하여 설치하세요.**
* ✅ **설정 가이드를 꼼꼼히 따라 하세요.**
* ✅ **복구 구문을 안전하게 백업하세요.**
* ❌ **어떤 상황에서도 복구 구문을 다른 사람과 절대 공유하지 마세요.**
* ❌ **지갑 앱 이외의 웹사이트나 앱에 복구 구문을 절대 입력하지 마세요.**
{% endhint %}

## 스마트폰/모바일 지갑과 데스크톱 지갑 중 무엇을 선택할까요?

{% hint style="warning" %}
작성 시점 기준으로 Aptos를 지원하는 모바일 지갑은 많지 않습니다. 더 많은 지갑이 준비되면 Chef 팀이 튜토리얼에 추가할 예정입니다.

**더 많은 모바일 지갑이 준비될 때까지는** [**데스크톱 지갑**](wallet-guide.md#desktop-web-browser-wallets)**을 사용하시기를 권장합니다.**
{% endhint %}

모바일 기기 지갑과 데스크톱 기반 지갑은 각기 장단점이 다릅니다. 어떤 쪽이 자신에게 더 잘 맞는지 고려하여 지갑 유형을 결정하세요.

|              | 모바일 | 데스크톱 |
| ------------ | --- | ---- |
| 어디서나 사용 가능   | ✅   | ➖    |
| 사용하기 쉬움      | ✅   | ➖    |
| 더 높은 보안      | ➖   | ✅    |
| 접근성 친화적      | ➖   | ✅    |
| 파손/분실/도난에 강함 | ➖   | ✅    |
| 정전/연결 끊김에 강함 | ✅   | ➖    |

**Blocto 지갑 설정 가이드**

1 - 지갑 연결 창에서 "Blocto"를 선택하면 로그인 창이 표시됩니다. 이메일 주소를 입력하고 "Register"(등록)를 클릭하세요. 이전에 Blocto 계정을 설정한 적이 있다면 이메일 주소를 입력하고 "sign in"(로그인)을 클릭하세요.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/blocto-setup-desktop-1%20\(1\).png)

2 - 그다음 이메일로 받은 일회용 비밀번호를 입력하세요.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/blocto-setup-desktop-2.png)

3 - "Create Aptos wallet"(Aptos 지갑 만들기)을 클릭한 다음 "Confirm"(확인)을 클릭하여 연결하세요.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/blocto-setup-desktop-3.png) ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/blocto-setup-desktop-4.png)

4 - 완료되었습니다! Aptos에서 PancakeSwap을 사용하려면 Aptos 주소에 APT를 입금해야 합니다. 다른 기기에서 같은 계정에 접근하려면 동일한 이메일 주소로 로그인하기만 하면 됩니다.
