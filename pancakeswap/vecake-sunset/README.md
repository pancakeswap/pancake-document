# veCAKE 종료

[Tokenomics 3.0 업그레이드](https://pancakeswap.finance/voting/proposal/0x79ef496c9737e48d9677a6e291ff2a549dee6729c9996398e453af8ecbf0ceb3)의 일환으로 veCAKE와 연결된 제품들이 종료됩니다. 영향을 받는 **주요 제품 영역**과 변경 사항이 적용되는 시점은 다음과 같습니다.

## 어떤 제품이 영향을 받나요?

1. **veCAKE 및 게이지 투표**

* **2025년 4월 23일 00:00 UTC**부터 veCAKE와 모든 게이지 투표가 종료됩니다.
* 마지막 게이지 투표는 \*\*2025년 4월 23일 00:00 UTC (Epoch 37)\*\*에 종료됩니다.
* Epoch 37의 결과는 \*\*Epoch 38 (4월 25일 \~ 5월 6일)\*\*에 실행됩니다.
* veCAKE 풀 APR과 뇌물(Bribe) APR을 포함한 **게이지 보상**은 **2025년 5월 7일까지** 계속 적립됩니다.

2. **일드 파밍**

veCAKE를 통한 부스트는 **2025년 4월 24일부터 5월 7일 사이**에 포지션 매니저, 시럽 풀, 파밍 활동 전반에서 단계적으로 폐지됩니다.

3. 수익 공유

거래 수수료의 **5% 수익 공유**는 **2025년 5월 7일 00:00 UTC**에 종료됩니다. 기존에 수익 공유에 할당되던 자금은 **CAKE 소각 메커니즘**으로 전환되며, 해당 풀의 소각 비율이 \*\*10%에서 15%\*\*로 높아집니다.

{% hint style="info" %}
🧭 **참고**: veCAKE 관련 기능이 플랫폼 전반에서 완전히 종료됨에 따라 PancakeSwap 웹사이트도 순차적으로 업데이트됩니다.
{% endhint %}

## 어떤 조치를 취해야 하나요?

{% hint style="info" %}
CAKE 상환 가이드: [staked-cake-redemption.md](staked-cake-redemption.md "mention")
{% endhint %}

1. **보상 수령**: 마지막 **Epoch 38** (2025년 4월 25일 \~ 5월 7일)의 보상을 받으려면 **2025년 5월 7일 00:00 UTC 이전에는 CAKE를 출금하지 마세요**.
2.  **CAKE/veCAKE 상환:** PancakeSwap 인터페이스를 통해 CAKE를 직접 스테이킹한 사용자는 스테이킹한 CAKE와 veCAKE를 상환할 수 있는 기간이 6개월이며, 상환 **마감일은 2025년 10월 23일**입니다.<br>

    \*\*veCAKE 매니저(예: Aster, StakeDAO, CakePie)\*\*에 연결된 veCAKE의 경우, PancakeSwap은 1:1 상환을 지원하는 락커 프로토콜의 위임자 주소를 화이트리스트에 등록합니다. 해당 프로토콜들은 자체 인터페이스에 상환 페이지를 열 예정이며, 해당 프로토콜에 스테이킹한 사용자는 xCAKE를 **1:1 비율**로 CAKE로 상환할 수 있습니다. **자세한 내용은 각 veCAKE 매니저의 공지를 참고해 주세요** .
