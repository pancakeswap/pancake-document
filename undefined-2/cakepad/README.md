# 🛍️ CAKE.PAD

PancakeSwap의 새롭게 개선된 초기 토큰 액세스 경험인 **CAKE.PAD**를 소개하게 되어 기쁩니다. 새로운 토큰이 거래소에 상장되기 전에 독점적으로 먼저 만나볼 수 있습니다.

IFO(Initial Farm Offering)에서 발전한 CAKE.PAD는 단순함, 포용성, 그리고 CAKE 활용성을 염두에 두고 만들어졌습니다. 스테이킹도, 락업도 없습니다. CAKE를 커밋하기만 하면 거래소에 상장되기 전에 흥미로운 프로젝트의 새로운 토큰을 먼저 얻을 수 있습니다.

### CAKE.PAD란 무엇인가요?

PancakeSwap의 CAKE.PAD 이벤트에서는 새로운 프로젝트 토큰이 출시되는 즉시 얼리 액세스를 받을 수 있습니다.

* 새로운 토큰을 가장 먼저 보유하는 사람 중 하나가 되세요
* 일찍 참여하여 더 높은 보상을 누릴 수 있습니다
* **매우 제한된 시간** 동안에만 이용할 수 있으므로 미리 준비하세요!

👉 흐름은 간단합니다.

* **CAKE를 예치합니다**
* **프로젝트가 CAKE를 받습니다** (모금 목표까지)
* **PancakeSwap이 참여 수수료(CAKE)의 100%를 소각합니다**
* **새로운 CAKE.PAD 파트너 토큰을 받습니다**

[Tokenomics 3.0 업그레이드](https://pancakeswap.finance/voting/proposal/0x79ef496c9737e48d9677a6e291ff2a549dee6729c9996398e453af8ecbf0ceb3)의 일환으로 **CAKE.PAD**를 더 단순하고 간결하며 참여하기 쉽게 개선했습니다.

### 무엇이 달라졌나요?

| 업데이트된 CAKE.PAD 형식                                                                                                                                             | 이전 IFO 형식                           |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------- |
| 이벤트 유형은 **1가지**뿐 - CAKE를 보유한 누구나 참여 가능                                                                                                                        | 여러 유형: **Basic / Private / Public** |
| **추가 요건 없음** — CAKE만 예치하면 됩니다                                                                                                                                 | 요건에 **CAKE 스테이킹** + **NFT 프로필** 포함  |
| **iCAKE / veCAKE 없음** ([Tokenomics 3.0](https://pancakeswap.finance/voting/proposal/0x79ef496c9737e48d9677a6e291ff2a549dee6729c9996398e453af8ecbf0ceb3)으로 폐지) | **iCAKE / veCAKE** 개념 사용            |
| **단계별 세금** (초과 청약 시에만 적용되며, 초과 청약이 커질수록 감소)                                                                                                                   | 고정 참여 수수료 (예: 1%)                   |

### 변하지 않은 점

* 개인별 한도 없음 — 사용자는 원하는 만큼의 $CAKE를 커밋하여 참여할 수 있습니다
* 사용자는 여전히 **여러 CAKE.PAD 이벤트에 동시에 참여**할 수 있습니다 (둘 이상 진행 중인 경우)
* **CAKE.PAD 이벤트 수수료의 100%가 소각됩니다** — CAKE의 소각 메커니즘을 강력하게 유지합니다

#### 수수료 등급

* **CAKE.PAD 이벤트가 초과 청약된 경우에만** 적용됩니다
* 세금은 참가자가 초과로 커밋한 자금에서만 차감되며, **CAKE.PAD** 프로젝트 파트너는 어떠한 수수료도 지불하지 않습니다
* **CAKE.PAD** 프로젝트 파트너는 목표 모금액의 100%를 받습니다
* PancakeSwap은 **CAKE.PAD 이벤트** 수수료의 100%를 CAKE로 소각합니다
