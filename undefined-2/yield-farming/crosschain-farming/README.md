# 크로스체인 파밍

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20(36).png" alt=""><figcaption></figcaption></figure>

멀티체인 배포를 통해 PancakeSwap은 이제 PancakeSwap 파밍의 대표적인 일드 파밍 경험을 다른 블록체인의 사용자에게도 제공합니다. 파밍에서는 LP 토큰을 스테이킹하여 PancakeSwap을 지원하면서 CAKE를 획득할 수 있습니다.

일드 파밍에 대해 더 알아보려면 [메인 섹션](../)을 확인하세요.

파밍을 시작하려면 [파밍 이용 방법 가이드](https://docs.pancakeswap.finance/earn/yield-farming/how-to-use-farms/how-to-use-farms)를 확인하세요.

{% hint style="warning" %}
일드 파밍은 시럽 풀보다 더 높은 보상을 제공할 수 있지만, **비영구적 손실(Impermanent Loss)** 위험이 따릅니다. 이름처럼 그렇게 무서운 것은 아니지만, 시작하기 전에 개념을 알아 두는 것이 좋습니다.

자세한 내용은 Binance Academy의 [비영구적 손실에 대한 훌륭한 글](https://academy.binance.com/en/articles/impermanent-loss-explained)을 확인하세요.
{% endhint %}

PancakeSwap 크로스체인 파밍은 Celer Network가 제공하는 크로스체인 메시징 서비스를 기반으로 합니다. 자세한 내용은 [https://www.celer.network/](https://www.celer.network/)에서 확인하세요.
