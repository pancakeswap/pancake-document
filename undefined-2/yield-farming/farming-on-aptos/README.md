# Aptos 파밍

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/farming-on-aptos.png" alt=""><figcaption></figcaption></figure>

멀티체인 배포를 통해 PancakeSwap은 이제 Aptos의 유동성 공급자에게도 PancakeSwap 파밍의 대표적인 일드 파밍 경험을 제공합니다. 파밍에서는 LP 토큰을 스테이킹하여 PancakeSwap을 지원하면서 CAKE를 획득할 수 있습니다.

일드 파밍에 대해 더 알아보려면 [메인 섹션](../)을 확인하세요.

저희는 여러 블록체인에서 일관된 제품 경험을 제공하도록 설계했습니다. 따라서 BSC에서 파밍을 자주 이용하셨다면 Aptos에서 파밍할 때도 익숙하게 느끼실 것입니다. 유동성 파밍이 처음이라면 [파밍 이용 방법 가이드](https://docs.pancakeswap.finance/earn/yield-farming/how-to-use-farms/how-to-use-farms)를 확인하여 시작하세요.

BSC와 Aptos 간에 자산과 CAKE를 브릿지하는 방법은 [CAKE 브릿징 가이드](../../../pancakeswap/how-to-guides/get-started-aptos/cake-bridging-guide.md)를 확인하세요.

{% hint style="warning" %}
일드 파밍은 시럽 풀보다 더 높은 보상을 제공할 수 있지만, **비영구적 손실(Impermanent Loss)** 위험이 따릅니다. 이름처럼 그렇게 무서운 것은 아니지만, 시작하기 전에 개념을 알아 두는 것이 좋습니다.

자세한 내용은 Binance Academy의 [비영구적 손실에 대한 훌륭한 글](https://academy.binance.com/en/articles/impermanent-loss-explained)을 확인하세요.
{% endhint %}
