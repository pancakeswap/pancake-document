# 🔷 \[存档] veCAKE

<figure><img src="../../../.gitbook/assets/image (339).png" alt=""><figcaption></figcaption></figure>

{% hint style="danger" %}
\[已存档] veCAKE
{% endhint %}

veCAKE 代表投票托管 CAKE（vote-escrowed CAKE）。veCAKE 代币在 PancakeSwap 的治理中发挥着关键作用，使你能够积极参与 [PancakeSwap 的治理提案](https://pancakeswap.finance/voting)和 Gauges 投票系统。这让你可以对更广泛的治理提案进行投票，并影响流动性池内 CAKE 排放的分配。

Gauges 投票赋予 veCAKE 持有者能力，在推出之初即可塑造 CAKE 排放在 BNB Chain、Ethereum 和 Arbitrum 上的农场（Farms）等核心产品间的分配。通过运用 veCAKE，用户直接影响 CAKE 排放在每个池中的分配方式，从而影响特定的流动性池和项目。一个池通过 Gauges 投票累积的 veCAKE 越多，分配的 CAKE 排放就越高，从而在随后的 14 天 epoch 中为流动性提供者（LP）带来更多奖励。

锁定 CAKE 从 1 周到 4 年的任意时长，即可获得 veCAKE。你的 veCAKE 数量基于你锁定的 CAKE 数量以及你锁定它们的时长。
