# 🔷 \[Archive] veCAKE

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28339%29.png" alt=""><figcaption></figcaption></figure>

{% hint style="danger" %}
\[ARCHIVED] veCAKE
{% endhint %}

veCAKE は vote-escrowed CAKE（投票エスクロー型 CAKE）の略です。veCAKE トークンは PancakeSwap のガバナンスにおいて重要な役割を果たし、[PancakeSwap のガバナンスプロポーザル](https://pancakeswap.finance/voting)および Gauges Voting システムへの積極的な参加を可能にします。これにより、広範なガバナンスプロポーザルへの投票や、流動性プール内の CAKE エミッションの配分に影響を与えることができます。

Gauges Voting は、veCAKE ホルダーが BNB Chain、Ethereum、Arbitrum 上のファームなど、必須プロダクトへの CAKE エミッション配分を形成できる仕組みです。veCAKE を活用することで、ユーザーは各プール内における CAKE エミッションの配分に直接影響を与え、特定の流動性プールやプロジェクトに作用します。Gauges Voting を通じてプールが多くの veCAKE を獲得するほど、割り当てられる CAKE エミッションが増加し、続く14日間のエポック期間において流動性プロバイダー（LP）への報酬が向上します。

1週間から4年の間で任意の期間 CAKE をロックすることで veCAKE を取得できます。veCAKE の量は、ロックした CAKE の数量とロック期間に基づいて決まります。
