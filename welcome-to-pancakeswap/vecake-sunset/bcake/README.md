# bCAKE

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2825%29.png" alt=""><figcaption></figcaption></figure>

bCAKE - Farm Booster es un multiplicador de impulso generado automáticamente que te permite aumentar tu rendimiento de CAKE de farms seleccionadas hasta 2.5x, aprovechando al máximo la combinación del Staking de veCAKE y el farming de liquidez.

{% hint style="info" %}
**¡bCAKE NO es un nuevo token y NO puede ser transferido!**
{% endhint %}
