# bCAKE

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2825%29.png" alt=""><figcaption></figcaption></figure>

bCAKE - Farm Booster est un multiplicateur de boost généré automatiquement qui vous permet de booster votre rendement en CAKE sur des farms sélectionnées jusqu'à 2,5x, en combinant pleinement le Staking veCAKE et le farming de Liquidité.

{% hint style="info" %}
**bCAKE N'est PAS un nouveau token et NE peut PAS être transféré !**
{% endhint %}
