# bCAKE

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2825%29.png" alt=""><figcaption></figcaption></figure>

bCAKE - Farm Booster, adalah pengganda boost yang dibuat secara otomatis yang memungkinkan Anda meningkatkan hasil CAKE dari farm pilihan hingga 2,5x, dengan memanfaatkan sepenuhnya kombinasi Staking veCAKE dan liquidity farming.

{% hint style="info" %}
**bCAKE BUKAN token baru dan TIDAK dapat ditransfer!**
{% endhint %}
