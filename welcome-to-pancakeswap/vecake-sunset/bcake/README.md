# bCAKE

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2825%29.png" alt=""><figcaption></figcaption></figure>

bCAKE - 파밍 부스터는 자동으로 생성되는 부스트 배수로, 선택한 파밍에서 CAKE 수익을 최대 2.5배까지 높여 주며 veCAKE 스테이킹과 유동성 파밍을 결합한 이점을 최대한 활용할 수 있게 해 줍니다.

{% hint style="info" %}
**bCAKE는 새로운 토큰이 아니며 전송할 수 없습니다!**
{% endhint %}

bCAKE에 대해 자세히 알아보고 이를 사용해 파밍 수익을 부스트하는 방법을 확인하세요.
