# bCAKE

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2825%29.png" alt=""><figcaption></figcaption></figure>

bCAKE - Farm Booster, è un moltiplicatore di boost generato automaticamente che ti permette di aumentare il tuo rendimento di CAKE dalle Farm selezionate fino a 2,5x, sfruttando appieno la combinazione di Staking veCAKE e farming di Liquidità.

{% hint style="info" %}
**bCAKE NON è un nuovo token e NON può essere trasferito!**
{% endhint %}
