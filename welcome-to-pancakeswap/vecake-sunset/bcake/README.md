# bCAKE

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2825%29.png" alt=""><figcaption></figcaption></figure>

bCAKE - Farm Booster は自動生成されるブースト倍率で、veCAKE ステーキングと流動性ファーミングを組み合わせることで、選択したファームからの CAKE 収益を最大2.5倍にブーストできます。

{% hint style="info" %}
**bCAKE は新しいトークンではなく、譲渡もできません！**
{% endhint %}
