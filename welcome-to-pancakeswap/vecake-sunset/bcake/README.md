# bCAKE

<figure><img src="../../../.gitbook/assets/image (25).png" alt=""><figcaption></figcaption></figure>

bCAKE - 农场加成器是一种自动生成的加成倍数，让你能够将选定农场的 CAKE 收益最高提升至 2.5 倍，充分发挥 veCAKE 质押与流动性农场相结合的优势。

{% hint style="info" %}
**bCAKE 不是一种新代币，也无法转移！**
{% endhint %}
