# 如何使用全新的 bCAKE

<figure><img src="../../../.gitbook/assets/image (87).png" alt=""><figcaption></figcaption></figure>

与 iCAKE 和 vCAKE 一样，bCAKE 是一项为我们忠实的 CAKE 持有者设计的 veCAKE 质押福利。通过锁定 CAKE，你会获得 veCAKE，而 veCAKE 会自动赋予你 bCAKE。你可以将选定农场的收益最高提升至 2.5 倍。

加成倍数是根据你的 veCAKE 余额，以及你想要加成的农场中的流动性数量来计算的。

## 准备工作 <a href="#id-9ad80126-6efe-49c2-b203-3590093b92d6" id="id-9ad80126-6efe-49c2-b203-3590093b92d6"></a>

#### **建立一个固定期限的 veCAKE 质押仓位** <a href="#id-3e485cf0-a9c5-408d-ab19-3ad2a7852589" id="id-3e485cf0-a9c5-408d-ab19-3ad2a7852589"></a>

![](<../../../.gitbook/assets/image (78).png>)

如果你尚未在 veCAKE 池中锁定任何 CAKE，请点击"前往池子"并按照指引建立一个固定期限的质押仓位。

要了解更多关于如何建立 veCAKE 质押仓位的信息，请阅读[此处](https://docs.pancakeswap.finance/products/syrup-pool/new-cake-pool#fixed-term-staking)。

#### 找到你想要加成的农场和仓位 <a href="#cf04ee3e-9678-4fc4-bf79-dcc5620a83fd" id="cf04ee3e-9678-4fc4-bf79-dcc5620a83fd"></a>

你只能为启用了 bCAKE 的农场收益进行加成。要查找这些农场，请查看 APR 部分，寻找带有绿色火箭图标的绿色 APR 数字。

![](<../../../.gitbook/assets/image (83).png>)

或者，使用"农场类型"选择器中的"可用加成器"筛选条件，快速筛选出所有启用了 bCAKE 的农场。

![](<../../../.gitbook/assets/image (76).png>)

#### 质押你的仓位

为了激活 bCAKE，你的仓位必须正在农场中质押。

* 对于 V3：点击"质押"来质押你的 LP 仓位。
* 对于 V2 和 StableSwap：点击"添加 LP"来质押你的 LP 代币。
* 对于仓位管理器：点击"添加流动性"来添加流动性。

要了解更多关于农场的信息，请查看[此](https://docs.pancakeswap.finance/products/yield-farming/how-to-use-farms)教程。

#### 激活 bCAKE <a href="#b3a80f22-5043-4e4b-afae-93b4abec504e" id="b3a80f22-5043-4e4b-afae-93b4abec504e"></a>

bCAKE 激活现在已完全自动化。&#x20;

<figure><img src="../../../.gitbook/assets/Frame 883379190.png" alt="" width="174"><figcaption><p>V3 农场</p></figcaption></figure>

<figure><img src="../../../.gitbook/assets/Connected - Has LP - Has veCAKE - Boosted automatically.png" alt="" width="174"><figcaption><p>V2、StableSwap</p></figcaption></figure>

<figure><img src="../../../.gitbook/assets/Connected - Has liquidity - Has veCAKE - Boosted automatically.png" alt="" width="174"><figcaption><p>仓位管理器</p></figcaption></figure>

质押后，你应该会看到当前正在质押的农场所应用的加成倍数。要了解更多关于 bCAKE 倍数如何计算的信息，请阅读[此处](https://docs.pancakeswap.finance/products/yield-farming/bcake/faq#why-do-my-multipliers-change-even-after-activation)。

{% hint style="info" %}
请注意，任何对农场仓位或 veCAKE 质押的用户操作都会根据农场和 CAKE 质押池的最新数据和统计信息自动更新你的加成倍数。

在[此处](https://docs.pancakeswap.finance/products/yield-farming/bcake/faq#why-do-my-multipliers-change-even-after-activation)了解更多。
{% endhint %}

可同时进行加成的农场仓位数量已不再有限制。只要 veCAKE 质押仓位处于活跃状态，你就可以加成无限数量的农场以及仓位管理器仓位。

#### 取消设置 bCAKE <a href="#id-6fa438f5-eea6-4d66-9b56-24780cedd273" id="id-6fa438f5-eea6-4d66-9b56-24780cedd273"></a>

bCAKE 取消设置现在也已完全自动化。

要取消 bCAKE 加成，只需移除你的流动性即可。

* 对于 V3：点击"取消质押"来取消质押你的 LP 仓位。
* 对于 V2 和 StableSwap：点击"-"减号按钮来取消质押你的 LP 代币。
* 对于仓位管理器：点击"-"减号按钮来移除流动性。
