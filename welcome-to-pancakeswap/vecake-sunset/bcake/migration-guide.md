# Guide de Migration

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-guide.png" alt=""><figcaption></figcaption></figure>

Pour commencer à booster votre Liquidité V2, StableSwap ou de gestionnaire de positions via bCAKE, vous devez effectuer une migration en dé-stakant votre LP depuis l'ancien contrat, puis en le restakant dans le nouveau.

### Accéder à l'assistant de migration

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Group%201410076909.png" alt="" width="189"><figcaption></figcaption></figure>

Localisez la bannière en haut de la page Farm ou Gestionnaire de positions, cliquez sur « Proceed » pour démarrer le processus de migration.

[Accéder aux Farms](https://pancakeswap.finance/farms)

[Accéder au Gestionnaire de positions](https://pancakeswap.finance/position-managers)

### Dé-staker vos tokens LP des anciens contrats

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/step1.png" alt=""><figcaption></figcaption></figure>

Dans la première étape, vous verrez la liste complète des farms V2, StableSwap et des gestionnaires de positions nécessitant une migration pour profiter du boost bCAKE.

Cliquez sur les boutons « Unstake All » à droite et confirmez la transaction dans votre application Portefeuille pour dé-staker TOUS les tokens LP des anciens contrats.

Vous devrez les dé-staker individuellement.

Après avoir dé-staké tous les LP, cliquez sur « Go to Stake » pour passer à l'étape suivante.

### Restaker vos tokens LP dans les nouveaux contrats

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/step2.png" alt=""><figcaption></figcaption></figure>

Dans la deuxième étape, vous verrez la liste complète des farms V2, StableSwap et des gestionnaires de positions disponibles pour le restaking.

Commencez par cliquer sur les boutons « Enable » pour autoriser les dépôts.

Ensuite, cliquez sur les boutons « Restake » pour restaker les tokens LP dans le nouveau contrat.

*   Pour les farms V2 et StableSwap, vous devez définir le nombre de tokens LP à restaker dans la nouvelle fenêtre modale.<br>

    Nous recommandons de restaker l'ensemble de vos tokens LP pour vous assurer de percevoir le rendement maximum disponible.
*   Pour les gestionnaires de positions, il vous suffit de confirmer la transaction dans votre Portefeuille ; tous vos LP de gestionnaires de positions seront restakés dans les nouveaux contrats.<br>

    Étant donné que les LP des gestionnaires de positions ne peuvent pas être traités séparément, nous recommandons vivement de restaker TOUS les LP des gestionnaires de positions dans les nouveaux contrats.

Après le restaking, les boutons afficheront « Staked ».

Vous devrez les restaker individuellement.

Après avoir restaké tous les LP, cliquez sur « Finish » pour revenir à la page Farm.
