# Panduan Migrasi

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-guide.png" alt=""><figcaption></figcaption></figure>

Untuk mulai meningkatkan likuiditas V2, StableSwap, atau Position Manager Anda melalui bCAKE, Anda perlu melakukan migrasi dengan melakukan unstake LP dari kontrak lama, dan melakukan restake ke kontrak baru.

### Navigasi ke wizard migrasi

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Group%201410076909.png" alt="" width="189"><figcaption></figcaption></figure>

Temukan banner di bagian atas halaman Farm atau Position Manager, klik "Proceed" untuk memulai proses migrasi.

[Buka Farm](https://pancakeswap.finance/farms)

[Buka Position Manager](https://pancakeswap.finance/position-managers)

### Unstake token LP Anda dari kontrak lama

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/step1.png" alt=""><figcaption></figcaption></figure>

Pada langkah pertama, Anda akan melihat daftar lengkap farm V2, StableSwap, dan position manager yang memerlukan migrasi untuk menikmati boost bCAKE.

Klik tombol "Unstake All" di sebelah kanan, dan konfirmasi transaksi di aplikasi dompet Anda, untuk melakukan unstake SEMUA token LP dari kontrak lama.

Anda perlu melakukan unstake masing-masing secara individual.

Setelah melakukan unstake semua LP, klik "Go to Stake" untuk melanjutkan ke langkah berikutnya.

### Restake token LP Anda ke kontrak baru

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/step2.png" alt=""><figcaption></figcaption></figure>

Pada langkah kedua, Anda akan melihat daftar lengkap farm V2, StableSwap, dan position manager yang tersedia untuk restake.

Pertama, klik tombol "Enable" untuk mengaktifkan setoran.

Kemudian, klik tombol "Restake" untuk melakukan restake token LP ke kontrak baru.

*   Untuk farm V2 dan StableSwap, Anda perlu menentukan jumlah token LP yang ingin Anda restake di modal pop-up baru.<br>

    Kami menyarankan untuk melakukan restake semua token LP Anda untuk memastikan Anda mendapatkan hasil maksimum yang tersedia.
*   Untuk Position Manager, cukup konfirmasi transaksi di dompet Anda, semua LP Position Manager Anda akan di-restake ke kontrak baru.<br>

    Karena LP Position Manager tidak dapat diproses secara terpisah, kami sangat menyarankan untuk melakukan restake SEMUA LP position manager ke kontrak baru.

Setelah restake, tombol akan berubah menjadi "Staked"

Anda perlu melakukan restake masing-masing secara individual.

Setelah melakukan restake semua LP, klik "Finish", untuk kembali ke halaman Farm.
