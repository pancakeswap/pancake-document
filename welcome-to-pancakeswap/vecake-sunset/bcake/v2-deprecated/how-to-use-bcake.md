# Comment utiliser bCAKE ?

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-use-bCAKE.png)

Comme iCAKE et vCAKE, bCAKE est également un avantage conçu pour les utilisateurs qui verrouillent leurs CAKE dans le pool de Staking CAKE à terme fixe. Le multiplicateur de boost est calculé en fonction du montant de CAKE que vous stakez, de la durée de Staking, ainsi que du nombre de tokens LP que vous stakez dans la farm que vous souhaitez booster.

## Préparations

### Initier une position de Staking CAKE à terme fixe

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/bCAKE-no-cake-locked.png)

Si vous n'avez pas encore verrouillé de CAKE dans le pool de Staking CAKE, cliquez sur « Go to Pool » et suivez les instructions pour initier une position de Staking à terme fixe.

Pour en savoir plus sur le Staking CAKE à terme fixe, lisez [ici](../../../../archive/legacy-products/new-cake-pool/#fixed-term-staking).

### Activer les Farm boosters

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/bCAKE-enable-booster.png)

Pour activer les Farm boosters, vous devez effectuer une configuration unique. Pour procéder, cliquez simplement sur « Enable » et confirmez la transaction depuis votre Portefeuille.

### Migrer vos Stakings

{% hint style="info" %}
Si vous ne stakez pas actuellement dans la farm pour laquelle vous souhaitez activer bCAKE, vous pouvez ignorer cette étape et commencer directement par staker des tokens LP dans la farm.
{% endhint %}

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/bCAKE-staking-migration-needed.png)

Si vous stakez déjà dans la farm pour laquelle vous souhaitez activer le Farm booster, une migration unique de Staking est également requise.

Cliquez sur « Migrate » et suivez le guide étape par étape pour effectuer les migrations. Vos récompenses CAKE seront automatiquement récoltées et envoyées dans votre Portefeuille.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/bCAKE-migration-inprogress.png)

## Activer les Boosters

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/bCAKE-pending-activation%20%281%29.png)

Une fois prêt, vous devriez voir le multiplicateur de boost disponible et l'APR boosté pour la farm dans laquelle vous stakez actuellement. Pour en savoir plus sur le calcul du multiplicateur bCAKE, lisez [ici](../faq.md#how-are-the-bcake-multipliers-calculated).

Pour activer le boost, cliquez sur le bouton « Boost » et confirmez la transaction depuis votre Portefeuille.

{% hint style="info" %}
Veuillez noter que toute action d'un utilisateur sur les farms ou le pool de Staking CAKE mettra automatiquement à jour votre multiplicateur de boost en fonction des données et statistiques les plus récentes des farms et du pool de Staking CAKE.

En savoir plus [ici](../faq.md#why-do-my-multipliers-change-even-after-activation).
{% endhint %}

### ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/bCAKE-farm-number-limit.png)

Le nombre de farms pouvant être boostées simultanément est limité. Pour vérifier le nombre de boosters restants, consultez le panneau en haut.

Vous devrez désactiver un booster actif pour pouvoir activer des boosters sur d'autres farms.

## Désactiver les Boosters

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/bCAKE-pending-unset%20%281%29.png)

Pour désactiver un Farm booster, cliquez simplement sur le bouton « Unset » et confirmez la transaction depuis votre Portefeuille.

Veuillez noter qu'à la désactivation, les CAKE gagnés seront récoltés vers le contrat Farm booster et seront automatiquement envoyés dans votre Portefeuille lors de la prochaine récolte, du prochain dépôt ou retrait. En savoir plus [ici](../faq.md#where-are-my-cake-rewards-after-activating-or-unsetting-the-booster).
