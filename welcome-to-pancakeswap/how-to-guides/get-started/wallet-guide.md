# Membuat Dompet

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

Untuk memulai di PancakeSwap, hal pertama yang Anda butuhkan adalah menyiapkan Dompet yang mendukung BNB Smart Chain (BSC). Dompet tersedia baik di komputer desktop maupun perangkat smartphone. Anda perlu memilih Dompet yang paling sesuai dengan kebutuhan Anda.

{% hint style="danger" %}
**Saat menyiapkan Dompet, pastikan untuk:**

* ✅ **Mengunduh dan memasang hanya versi terbaru dari sumber resmi.**
* ✅ **Mengikuti panduan penyiapan dengan saksama.**
* ✅ **Membuat cadangan frasa pemulihan Anda dengan aman.**
* ❌ **JANGAN PERNAH membagikan frasa pemulihan Anda kepada siapa pun, dalam kondisi apa pun.**
* ❌ **JANGAN PERNAH memasukkan frasa pemulihan Anda ke situs web atau aplikasi mana pun, selain aplikasi Dompet Anda.**
{% endhint %}

## Dompet Smartphone/Mobile atau Desktop?

Dompet perangkat mobile dan Dompet berbasis desktop memiliki kelebihan dan kekurangan yang berbeda. Pertimbangkan mana yang lebih sesuai dengan kebutuhan Anda untuk membantu menentukan jenis Dompet yang akan digunakan.

|                                   | Mobile | Desktop |
| --------------------------------- | ------ | ------- |
| Dapat digunakan di mana saja      | ✅      | ➖       |
| Mudah digunakan                   | ✅      | ➖       |
| Lebih aman                        | ➖      | ✅       |
| Ramah aksesibilitas               | ➖      | ✅       |
| Tahan terhadap kerusakan/kehilangan/pencurian | ➖      | ✅       |
| Tahan terhadap gangguan daya/koneksi | ✅      | ➖       |

### **Dompet Smartphone/Mobile**

Dompet Smartphone/Mobile memungkinkan Anda mengakses kripto hampir di mana saja. Dompet tersedia di perangkat Android maupun iOS.

{% tab title="MetaMask" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2833%29%20%283%29.png)

MetaMask adalah plugin Dompet berbasis browser yang sangat populer dan mendukung ERC20 (jaringan Ethereum) serta BEP2 & BEP20 (jaringan Binance Chain dan BNB Smart Chain).

​**Kelebihan:**

* Open source untuk kemampuan audit
* Mendukung WEB3 di BscScan
* Riwayat keamanan dan keandalan yang kuat
* Banyak panduan cara penggunaan dan sumber daya online
* Banyak alat dan pengaturan khusus
* Menawarkan pembelian ETH dengan Transak
* Mendukung jumlah bahasa yang sangat banyak
* Juga tersedia sebagai plugin browser untuk perangkat desktop

**Kekurangan:**

* Waktu penyiapan lebih lama dibandingkan opsi lain
* Langkah tambahan diperlukan untuk digunakan dengan BNB Smart Chain dan PancakeSwap
* Informasi dan pengaturan tambahan dapat membingungkan pemula

{% tab title="Coinbase Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/coinbase_wallet_wordmark_blue.png)

Jutaan pengguna memilih Coinbase Wallet untuk mendapatkan imbal hasil dengan DeFi, melakukan Swap lebih dari 5.500 aset, dan menyimpan koleksi NFT mereka. Coinbase Wallet mendukung BEP2 & BEP20 (jaringan Binance Chain dan BNB Smart Chain).

**Keunggulan:**

* Dompet dapp mobile paling banyak diunduh di Amerika Serikat dengan 12M+ pengguna Dompet aktif.
* Tidak ada langkah tambahan yang diperlukan untuk digunakan dengan BNB Smart Chain dan PancakeSwap.
* Audiens utama: Hingga 89M+ pengguna aplikasi ritel Coinbase yang dapat bergabung ke Coinbase Wallet saat mereka mulai menjelajahi web3.
* Mudah untuk mentransfer aset dari aplikasi ritel Coinbase.
* Fiat On-ramp: Pengguna sekarang dapat langsung membeli kripto dengan fiat di semua 86 negara tempat Coinbase beroperasi, tanpa meninggalkan Dompet.
* Keamanan terdepan di industri dengan pencadangan cloud yang aman.

[**Unduh Coinbase Wallet**](https://coinbase-wallet.onelink.me/q5Sx/fdb9b250) **(Mendeteksi perangkat secara otomatis)**

Coinbase Wallet_ [_berbeda_](https://help.coinbase.com/en/wallet/getting-started/what-s-the-difference-between-coinbase-com-and-wallet) _dari Coinbase.com, dan kunci privat untuk Coinbase Wallet disimpan langsung oleh pengguna dan bukan oleh Coinbase. Biaya mungkin berlaku. Anda tidak memerlukan akun Coinbase.com untuk menggunakan Coinbase Wallet._
