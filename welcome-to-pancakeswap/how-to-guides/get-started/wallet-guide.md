# Crea un Portafoglio

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

Per iniziare su PancakeSwap, la prima cosa di cui hai bisogno è configurare un portafoglio che supporti BNB Smart Chain (BSC). I portafogli sono disponibili sia su computer desktop che su smartphone. Dovrai scegliere il portafoglio che meglio si adatta alle tue esigenze.

{% hint style="danger" %}
**Quando configuri un portafoglio, assicurati di:**

* ✅ **Scaricare e installare solo la versione più recente da una fonte ufficiale.**
* ✅ **Seguire attentamente la guida alla configurazione.**
* ✅ **Effettuare un backup sicuro delle tue frasi di recupero.**
* ❌ **NON condividere MAI le tue frasi di recupero con nessuno, in nessuna circostanza.**
* ❌ **NON inserire MAI la tua frase di recupero su un sito web o app, a eccezione dell'app del tuo portafoglio.**
{% endhint %}

## Portafoglio Smartphone/Mobile o Desktop?

I portafogli per dispositivi mobile e quelli desktop hanno punti di forza e debolezze diversi. Considera quale si adatta meglio alle tue esigenze per decidere quale tipo di portafoglio utilizzare.

|                                         | Mobile | Desktop |
| --------------------------------------- | ------ | ------- |
| Utilizzabile ovunque                    | ✅      | ➖       |
| Facile da usare                         | ✅      | ➖       |
| Più sicuro                              | ➖      | ✅       |
| Accessibile                             | ➖      | ✅       |
| Resistente a danni/smarrimento/furto    | ➖      | ✅       |
| Resistente a interruzioni di corrente/connessione | ✅      | ➖       |

### **Portafogli Smartphone/Mobile**

I portafogli Smartphone/Mobile ti permettono di accedere alle tue criptovalute quasi ovunque. I portafogli sono disponibili sia su dispositivi Android che iOS.
