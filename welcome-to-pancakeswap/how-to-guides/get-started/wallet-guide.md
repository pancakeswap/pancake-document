# ウォレットを作成する

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

PancakeSwap を始めるには、まず BNB Smart Chain (BSC) に対応したウォレットを用意する必要があります。ウォレットはデスクトップとスマートフォンの両方で利用できます。ご自身のニーズに合ったウォレットをお選びください。

{% hint style="danger" %}
**ウォレットのセットアップ時は、必ず以下の点を守ってください。**

* ✅ **公式ソースから最新バージョンのみダウンロード・インストールする。**
* ✅ **セットアップガイドをよく確認しながら進める。**
* ✅ **リカバリーフレーズを安全にバックアップする。**
* ❌ **いかなる状況でも、リカバリーフレーズを他人に教えない。**
* ❌ **ウォレットアプリ以外のウェブサイトやアプリにリカバリーフレーズを入力しない。**
{% endhint %}

## スマートフォン / モバイル と デスクトップ、どちらを使う？

モバイルウォレットとデスクトップウォレットにはそれぞれ長所・短所があります。どちらがご自身のニーズに合っているかを考えてウォレットの種類を選んでください。

|                                   | モバイル | デスクトップ |
| --------------------------------- | ------ | ------- |
| どこでも使える                      | ✅      | ➖       |
| 使いやすい                          | ✅      | ➖       |
| セキュリティが高い                   | ➖      | ✅       |
| アクセシビリティに優れている          | ➖      | ✅       |
| 破損・紛失・盗難に強い               | ➖      | ✅       |
| 電源・接続障害に強い                 | ✅      | ➖       |

### **スマートフォン / モバイル ウォレット**

スマートフォン / モバイルウォレットを使えば、ほぼどこからでも暗号資産にアクセスできます。Android と iOS の両方に対応しています。

{% tab title="MetaMask" %}

MetaMask は非常に人気の高いブラウザベースのウォレットプラグインで、ERC20（Ethereum ネットワーク）および BEP2・BEP20（Binance Chain および BNB Smart Chain ネットワーク）に対応しています。

* BNB Smart Chain および PancakeSwap で使用するために追加の設定手順が必要

{% endhint %}

{% tab title="Token Pocket" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28125%29%20%283%29.png)

Token Pocket は Mac OS および Win64 デバイス向けのスタンドアロンアプリケーションです。ブラウザに依存せず、独立したソフトウェアで暗号資産を管理できます。

​**メリット：**

* オープンソースで監査可能
* ブラウザおよびその権限から独立している
* 多くの暗号資産ネットワーク間を簡単に切り替えられる
* デフォルトで多数のネットワークをサポート
* ブラウザプラグインウォレットより画面が広く使いやすい
* モバイル版も利用可能

**デメリット：**

* デスクトップセットアップ時に秘密鍵の入力を求められる
* 中国語と英語のみ対応
* 英語翻訳に一部問題がある
* 確立されたウォレットと比べてオンラインリソースが少ない

[**Token Pocket デスクトップウォレットをダウンロード**](https://www.tokenpocket.pro/en/download/pc)（MacOS または Win64）

**Token Pocket デスクトップセットアップガイド**

Token Pocket のデスクトップ版では秘密鍵のインポートが求められます。続行する前に、秘密鍵の重要性をよく理解しておいてください。

Token Pocket はオープンソースプロジェクトであり、コードは公開されており一般的に安全とされています。それでも、秘密鍵の管理はご自身の責任となりますので、信頼性を確認できるアプリケーションにのみ使用してください。

1. PC で Token Pocket のウェブサイトにアクセスして **Desktop** ボタンをクリックします。

![](https://lh3.googleusercontent.com/8BvpBrdR19cHhjJq0_xOFQwpTDLaYUxqLAM03JPFzBPz93SHl3n84Dw_kICcfOR80iVZFS1QfYsexEUMNnchMLGSH11lHKMqBQWAJUZy7yd0LM6jaFrwRGt5EluBRo_uDqJBqbg2)

1. 次のページでお使いの OS のボタンをクリックし、ダウンロードが完了するまで待ちます。このガイドは Windows 版を使用していますが、Mac OS でも手順はほぼ同じです。

![](https://lh3.googleusercontent.com/SrYkM-cFg_tO3RcTlYv2Rq4pViUzRSw5el_JR8SnQYDmvVYupjJveTUXHr8QPeo30Ooc4EHBKEuYjxM1JbtirRHitGJtZ-2ET_Xk5a5DRbhqwyJToToii-s6Ch195p5o3Eo4Ajnm)

1. インストールファイルを実行します。Token Pocket をコンピューター上の全ユーザーに対して利用可能にするか、現在のユーザーのみに限定するかを選択する画面が表示されます。セキュリティのため、現在のユーザーのみを推奨します。

![](https://lh3.googleusercontent.com/EnmEle5PcVenTxE7jEtEHhQxeXwKjhzlOkZH67ByFLAIo4RMife2u4n36uDDGjTB8h64KxS0wmlI8FKAbxB6KvjvhD-WgCqdKpyUP1YM4tmxqTzjLGPuqDmf5ABTyY_5-wG7ppgG)

1. インストール先のフォルダを指定して **Install** をクリックします。

![](https://lh6.googleusercontent.com/ED7cl2_ZGBkUvM-A7CpE_bRNfdLQ8DcD2qmq6KaGAUIZTi_06f7BA_m-xBhoFzrczfTZQENsYji2Xlh_DNh0zWpmRnuo45HKX2r8zJxrBtqXkuPgxfCd4jAIvMytHu6iT_ZPRxmI)

2. Token Pocket を開くと、中国語インターフェースが表示される場合があります。左下の EN をクリックすると英語に切り替えられます。

![](https://lh6.googleusercontent.com/V3VS6TaN0rJtfqjzCo5QEtS1ywJn_bmmB2hKWLbUGRy_-Pk83kGfu9feB35VAi4TC7BHKTqkApDagBuWP7XS3tVNzhcMPmANGqLlsOecumQpMMisvUBiABqi05351e7cNUgktWsO)

![](https://lh5.googleusercontent.com/GQqBU7OEK7BQuJc4NiOHEqt3kjO-B6jM6AAv3PFD6DoYuXywuOz6365Z5rPmNtkigWSg3f1_zzvoHfWAUvqIpEKaAajkDxVwlaWAljIW1ZGdgSwqECVa2CwgtS_vOOcX8faW19gB)

1. 次のページで、Token Pocket から秘密鍵のインポートを求められます。難しく感じるかもしれませんが、Token Pocket は既存ウォレットのインターフェースとして機能します。現在使用しているウォレットから秘密鍵を取得する必要があります。

[MetaMask から秘密鍵を取得するガイドはこちら](https://metamask.zendesk.com/hc/en-us/articles/360015289632-How-to-Export-an-Account-Private-Key)をご参照ください。Token Pocket モバイル版から秘密鍵をインポートする方法は、このページ上部の「Token Pocket モバイル」タブをご確認ください。他のウォレットをお使いで秘密鍵の取得方法が分からない場合は、別途ガイドをお探しください。
