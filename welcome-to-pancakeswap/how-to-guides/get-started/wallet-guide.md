# Créer un Portefeuille

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

Pour commencer sur PancakeSwap, vous devez d'abord configurer un portefeuille compatible avec BNB Smart Chain (BSC). Les portefeuilles sont disponibles aussi bien sur ordinateur que sur smartphone. Choisissez celui qui correspond le mieux à vos besoins.

{% hint style="danger" %}
**Lors de la configuration de votre portefeuille, veillez à :**

* ✅ **Télécharger et installer uniquement la dernière version depuis une source officielle.**
* ✅ **Suivre attentivement le guide de configuration.**
* ✅ **Sauvegarder en toute sécurité vos phrases de récupération.**
* ❌ **NE JAMAIS partager vos phrases de récupération avec qui que ce soit, en aucune circonstance.**
* ❌ **NE JAMAIS saisir votre phrase de récupération sur un site web ou une application autre que votre application de portefeuille.**
{% endhint %}

## Portefeuille Smartphone/Mobile ou Bureau ?

Les portefeuilles mobiles et les portefeuilles bureau présentent des avantages et des inconvénients différents. Réfléchissez à celui qui correspond le mieux à vos besoins pour choisir le type de portefeuille à utiliser.

|                                            | Mobile | Bureau |
| ------------------------------------------ | ------ | ------ |
| Utilisable partout                         | ✅      | ➖      |
| Facile à utiliser                          | ✅      | ➖      |
| Plus sécurisé                              | ➖      | ✅      |
| Accessible                                 | ➖      | ✅      |
| Résistant aux dommages/pertes/vols         | ➖      | ✅      |
| Résistant aux coupures d'alimentation/connexion | ✅  | ➖      |

### **Portefeuilles Smartphone/Mobile**

Les portefeuilles smartphone/mobiles vous permettent d'accéder à vos cryptomonnaies presque partout. Ils sont disponibles sur les appareils Android et iOS.

{% tab title="MetaMask" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2833%29%20%283%29.png)

MetaMask est une extension de portefeuille très populaire qui prend en charge les tokens ERC20 (réseau Ethereum) ainsi que BEP2 et BEP20 (réseaux Binance Chain et BNB Smart Chain).

​**Avantages :**

* Open source pour l'auditabilité
* Compatible WEB3 sur BscScan
* Un solide historique de sécurité et de fiabilité
* De nombreux guides et ressources disponibles en ligne
* De nombreux outils et paramètres personnalisables
* Permet l'achat d'ETH via Transak
* Prend en charge un très grand nombre de langues
* Disponible également en tant qu'extension de navigateur pour les appareils de bureau

**Inconvénients :**

* Temps de configuration plus long que les autres options
* Étapes supplémentaires nécessaires pour l'utilisation avec BNB Smart Chain et PancakeSwap
* Les informations et paramètres supplémentaires peuvent dérouter les débutants
