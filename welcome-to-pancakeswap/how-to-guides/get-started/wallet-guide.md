# Crear una billetera

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

Para comenzar con PancakeSwap, lo primero que necesitas es configurar una billetera compatible con BNB Smart Chain (BSC). Las billeteras están disponibles tanto en computadoras de escritorio como en dispositivos móviles. Deberás elegir la que mejor se adapte a tus necesidades.

{% hint style="danger" %}
**Al configurar una billetera, asegúrate de:**

* ✅ **Descargar e instalar solo la versión más reciente desde una fuente oficial.**
* ✅ **Seguir cuidadosamente la guía de configuración.**
* ✅ **Hacer una copia de seguridad segura de tus frases de recuperación.**
* ❌ **NUNCA compartas tus frases de recuperación con nadie, bajo ninguna circunstancia.**
* ❌ **NUNCA ingreses tu frase de recuperación en un sitio web o aplicación que no sea tu billetera.**
{% endhint %}

## ¿Billetera móvil o de escritorio?

Las billeteras para dispositivos móviles y las de escritorio tienen diferentes fortalezas y debilidades. Considera cuál se adapta mejor a tus necesidades para decidir qué tipo de billetera usar.

|                                   | Móvil | Escritorio |
| --------------------------------- | ------ | ------- |
| Úsala en cualquier lugar          | ✅      | ➖       |
| Fácil de usar                     | ✅      | ➖       |
| Más segura                        | ➖      | ✅       |
| Accesibilidad                     | ➖      | ✅       |
| Resistente a daños/pérdidas/robo  | ➖      | ✅       |
| Resistente a cortes de corriente/conexión | ✅ | ➖    |

### **Billeteras para smartphone/móvil**

Las billeteras para smartphone/móvil te permiten acceder a tus criptomonedas casi en cualquier lugar. Están disponibles tanto en dispositivos Android como iOS.
