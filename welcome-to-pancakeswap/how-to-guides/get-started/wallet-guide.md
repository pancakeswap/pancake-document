# Создание кошелька

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

Чтобы начать работу с PancakeSwap, первым делом нужно настроить кошелёк с поддержкой BNB Smart Chain (BSC). Кошельки доступны как для настольных компьютеров, так и для смартфонов. Тебе нужно выбрать тот, который лучше всего подходит именно тебе.

{% hint style="danger" %}
**При настройке кошелька обязательно:**

* ✅ **Скачивай и устанавливай только последнюю версию из официального источника.**
* ✅ **Внимательно следуй руководству по настройке.**
* ✅ **Надёжно сохрани свои фразы для восстановления.**
* ❌ **НИКОГДА не сообщай свои фразы для восстановления кому-либо, ни при каких обстоятельствах.**
* ❌ **НИКОГДА не вводи свою фразу для восстановления на сайтах или в приложениях, кроме твоего приложения-кошелька.**
{% endhint %}

## Смартфон/Мобильный или Десктопный кошелёк?

Мобильные и десктопные кошельки имеют разные преимущества и недостатки. Подумай, что подходит тебе лучше, чтобы выбрать подходящий тип кошелька.

|                                   | Мобильный | Десктопный |
| --------------------------------- | --------- | ---------- |
| Использование везде               | ✅         | ➖          |
| Простота использования            | ✅         | ➖          |
| Более надёжный                    | ➖         | ✅          |
| Удобство доступа                  | ➖         | ✅          |
| Защита от повреждения/утраты/кражи | ➖        | ✅          |
| Работа без питания/подключения    | ✅         | ➖          |

### **Мобильные кошельки**

Мобильные кошельки позволяют получать доступ к криптовалюте практически в любом месте. Кошельки доступны как для Android, так и для iOS.

{% tab title="MetaMask" %}
![](<https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2833%29%20%283%29.png>)

MetaMask — очень популярный плагин-кошелёк для браузера, поддерживающий ERC20 (сеть Ethereum) и BEP2 & BEP20 (сети Binance Chain и BNB Smart Chain).

​**Преимущества:**

* Открытый исходный код для аудитируемости
* Поддержка WEB3 на BscScan
* Надёжная история безопасности и стабильности
* Большое количество руководств и ресурсов онлайн
* Много инструментов и настроек
* Покупка ETH через Transak
* Поддержка очень большого числа языков
* Также доступен как плагин для браузера на десктопе

**Недостатки:**

* Более долгая настройка по сравнению с другими вариантами
* Нужны дополнительные шаги для работы с BNB Smart Chain и PancakeSwap
* Дополнительная информация и настройки могут запутать начинающих пользователей

{% tab title="Coinbase Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/coinbase_wallet_wordmark_blue.png)

* Простой перевод активов из розничного приложения Coinbase.
* Fiat On-ramp: пользователи могут напрямую покупать крипту за фиат в 86 странах, где работает Coinbase, не выходя из кошелька.
* Ведущая в отрасли безопасность с защищённым облачным резервным копированием.

**Получение приватного ключа с мобильного устройства для импорта на десктоп**

Token Pocket позволяет использовать и десктопный, и мобильный кошелёк. В этом разделе описано, как получить приватный ключ с мобильного кошелька для импорта в его десктопную версию.

{% hint style="warning" %}
Обращайся со своими приватными ключами крайне осторожно. Передав приватный ключ кому-либо, ты даёшь им полный доступ к своим монетам! Token Pocket — это проект с открытым исходным кодом, который будет использовать твой приватный ключ для импорта кошелька. Тем не менее используй приватный ключ только в тех приложениях, которым доверяешь и которые можешь проверить как легитимные!
{% endhint %}

1. Нажми вкладку **Me** на нижней панели и нажми **Manage Wallets**.

![](https://lh3.googleusercontent.com/_DE3EO8bsI5wKZlkTeJv3zZ77LR8SVQYOwB4EXbY_GhKzz4PSZpo3MdlvrU8sLoLyPcRQjdjOA24VPjAa_UZdt-JaiRgPMk67uBs7JIi5gp9gV1_wDB7fW7FQoFogTMZ_EQJYxcQ)

1. На следующей странице нажми на запись **BNB Smart Chain**. Будь осторожен — не нажимай на часть с адресом, иначе скопируешь только его.

![](https://lh4.googleusercontent.com/jLhXL03uhZHBKbHaPvy3ZrD1EmYCR8ECqwMxQIzTKnUtxMNntaDA8Dx4oVlXSadoFhhJqZACsYWVPfvITBEpWfkCfwntcQY3Fw5EYgGH-tmva8PZbvYbBRCy_c5V7E1yQHvXiU0F)

1. Когда появится меню, найди и нажми опцию **Export Private Key**. Введи пароль, чтобы получить приватный ключ.

{% hint style="danger" %}
\*\*НИКОГДА, ни при каких обстоятельствах, не сообщай кому-либо свой приватный ключ или фразу для восстановления («сид-фраза»). Это даст кому-то полный доступ к твоей криптовалюте!

Настоящий сайт PancakeSwap и его сотрудники никогда не попросят тебя вводить свою сид-фразу.\*\*
{% endhint %}

Теперь твой приватный ключ готов для импорта кошелька в десктопную версию Token Pocket.

Token Pocket — самостоятельное приложение, доступное как для Mac OS, так и для Win64. Token Pocket позволяет управлять криптовалютой в программе, независимой от браузера.

​**Преимущества:**

* Открытый исходный код для аудитируемости
* Не зависит от браузера и его разрешений
* Позволяет легко переключаться между многими криптосетями
* Поддержка многих сетей по умолчанию
* Менее загроможденный интерфейс по сравнению с плагинами-кошельками для браузера
* Также доступен на мобильных устройствах

**Недостатки:**

* Требует ввода приватного ключа в процессе настройки на десктопе
* Поддерживает только китайский и английский языки
* Есть проблемы с английским переводом
* Меньше онлайн-ресурсов по сравнению с более известными кошельками

[**Скачать Token Pocket Desktop Wallet**](https://www.tokenpocket.pro/en/download/pc) (MacOS или Win64)

**Руководство по настройке Token Pocket Desktop**

Token Pocket — это проект с открытым исходным кодом, поэтому код общедоступен и считается безопасным. Тем не менее твои приватные ключи — твоя ответственность, поэтому используй их только в приложениях, которым доверяешь и которые можешь проверить.
