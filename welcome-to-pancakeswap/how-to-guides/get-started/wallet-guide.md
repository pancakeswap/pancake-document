# Wallet erstellen

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

Um mit PancakeSwap zu beginnen, müssen Sie zunächst ein Wallet einrichten, das BNB Smart Chain (BSC) unterstützt. Wallets sind sowohl auf Desktop-Computern als auch auf Smartphones verfügbar. Sie müssen das Wallet wählen, das Ihren Anforderungen am besten entspricht.

{% hint style="danger" %}
**Beim Einrichten eines Wallets sollten Sie unbedingt:**

* ✅ **Nur die neueste Version aus einer offiziellen Quelle herunterladen und installieren.**
* ✅ **Der Einrichtungsanleitung sorgfältig folgen.**
* ✅ **Ihre Wiederherstellungsphrasen sicher sichern.**
* ❌ **Ihre Wiederherstellungsphrasen NIEMALS mit jemandem teilen, unter keinen Umständen.**
* ❌ **Ihre Wiederherstellungsphrase NIEMALS auf einer Website oder in einer App eingeben, außer in Ihrer Wallet-App.**
{% endhint %}

## Smartphone/Mobil oder Desktop-Wallet?

Mobile Wallets und Desktop-Wallets haben unterschiedliche Stärken und Schwächen. Überlegen Sie, welches besser zu Ihren Anforderungen passt, um zu entscheiden, welchen Wallet-Typ Sie verwenden möchten.

|                                      | Mobil | Desktop |
| ------------------------------------ | ----- | ------- |
| Überall nutzbar                      | ✅     | ➖       |
| Einfach zu bedienen                  | ✅     | ➖       |
| Sicherer                             | ➖     | ✅       |
| Barrierefreiheit                     | ➖     | ✅       |
| Resistent gegen Beschädigung/Verlust/Diebstahl | ➖ | ✅    |
| Resistent gegen Strom-/Verbindungsausfall | ✅ | ➖      |

### **Smartphone/Mobile Wallets**

Smartphone/Mobile Wallets ermöglichen es Ihnen, nahezu überall auf Ihre Krypto-Assets zuzugreifen. Wallets sind sowohl für Android als auch für iOS-Geräte verfügbar.

{% hint style="warning" %}
