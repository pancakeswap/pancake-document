# Использование PancakeSwap без централизованных бирж

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-pancakeswap-without-cex-header.png)

PancakeSwap — децентрализованное приложение. Это означает, что в отличие от Binance или других централизованных платформ, тебе не нужно регистрировать аккаунт для его использования... нужен только криптокошелёк. Как же получить криптовалюту в PancakeSwap без использования централизованной биржи?

В этом руководстве мы покажем тебе процесс использования «межсетевых мостов» для перевода активов на кошелёк BNB Smart Chain и начала работы с PancakeSwap.

### **Перевод активов из других блокчейнов в BNB Smart Chain**

Ты можешь использовать различные межсетевые мосты для перевода токенов из Ethereum или других сетей в BNB Smart Chain.

В следующих руководствах мы покажем перевод USDT из различных блокчейнов в BNB Smart Chain с использованием трёх разных межсетевых мостов.

{% tabs %}
{% tab title="🥞🌉 Pancake Bridge (рекомендуется)" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28168%29.png)

[**PancakeSwap Bridge**](http://bridge.pancakeswap.finance) — нативный межсетевой мост активов, работающий на базе Stargate.

Этот мост позволяет легко перевести стейблкоины в BNB Chain и участвовать в активном сообществе PancakeSwap и более широкой экосистеме BNB!

📖 [Узнать, как использовать](https://medium.com/pancakeswap/launching-pancakeswap-bridge-a-partnership-with-stargate-21c1c9f491a8)
{% endtab %}

{% tab title="AnySwap" %}
Попробуем перевести USDT из блокчейна Polygon (MATIC) в BSC с помощью AnySwap.

1. Подготовь кошелёк Polygon (MATIC) с USDT и небольшим количеством MATIC для газа.
2. Поскольку AnySwap поддерживает только MetaMask, OKEx Wallet и Coin98 Wallet. Если ты используешь другие приложения-кошельки, рекомендуем импортировать кошелёк в MetaMask.
3. Перейди на [https://anyswap.exchange/#/router](https://anyswap.exchange/#/router)
4. Подключи кошелёк и переключи сеть на Polygon (MATIC) Mainnet.
5.  Выбери USDT в сети MATIC mainnet как «From» и USDT в сети BSC mainnet как «To». Введи сумму USDT, которую хочешь перевести.

    <img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/MBP3-2021.10.19-055554AM-Google%20Chrome_AnySwap%20-%20Cross%20Chain%20Protocol.png" alt="" data-size="original">
6. Нажми «Approve USDT» для подтверждения USDT.
7. Дополнительно: если ты хочешь, чтобы AnySwap отправил USDT на другой адрес BSC, используй кнопку «+ Send To».
8. Нажми «Swap» и завершите финальные межсетевые транзакции.
9. Весь процесс займёт около 10–30 минут в зависимости от загруженности сети.
10. После завершения ты должен получить средства в кошельке BSC. Теперь можешь начать использовать PancakeSwap для обмена токенов в BNB Smart Chain!
{% endtab %}

{% tab title="O3 Hub" %}
⚠️ **O3 Swap находится в бета-версии. Торгуй на свой страх и риск.**

Попробуем использовать O3 Hub для перевода USDT из блокчейна ERC-20 в BNB Smart Chain.

1. Подготовь кошелёк ERC-20 (Ethereum Mainnet) с USDT и небольшим количеством ETH для газа.
2. Поскольку O3 Hub поддерживает только MetaMask и O3 Wallet. Если ты используешь другие приложения-кошельки, рекомендуем импортировать кошелёк в MetaMask.
3. Перейди на [https://o3swap.com/hub](https://o3swap.com/hub)
4.  Подключи MetaMask или O3 кошелёк для ETH и BSC. Переключи сеть в MetaMask на Ethereum Mainnet.

    <img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/MBP3-2021.10.19-054852AM-Google%20Chrome_O3swap.png" alt="" data-size="original">
5.  Выбери ERC-20 USDT как «You pay» и BEP-20 USDT как «You will receive». Введи сумму USDT, которую хочешь перевести.

    <img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/MBP3-2021.10.19-053358AM-Google%20Chrome_O3swap.png" alt="" data-size="original">
6.  Дважды проверь, что в поле «To» указан правильный адрес кошелька BNB Smart Chain, который ты подключил.

    <img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/MBP3-2021.10.19-053441AM-Google%20Chrome_O3swap.png" alt="" data-size="original">
7. Убедись, что всё верно. Нажми «Swap».
8. Следуй инструкциям на экране для подтверждения USDT и завершения финальной межсетевой транзакции.
9.  Весь процесс займёт около 10–30 минут в зависимости от загруженности сети. Ход выполнения можно отслеживать на вкладке history.

    <img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/MBP3-2021.10.19-054520AM-Google%20Chrome_O3swap.png" alt="" data-size="original">
10. После завершения ты должен получить средства в кошельке BSC. Теперь можешь начать использовать PancakeSwap для обмена токенов в BNB Smart Chain!

Дополнительно ты можешь ознакомиться с [этим руководством пользователя](https://docs.o3swap.com/o3-swap-user-guide/hub#2.-hub-swap) от O3 Swap.
