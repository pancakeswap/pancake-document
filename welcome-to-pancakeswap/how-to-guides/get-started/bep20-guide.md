# Mendapatkan Token BEP20

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-get-bep20-tokens-header.png)

Token asli BNB Smart Chain (BSC) adalah **BEP20**.

Untuk melakukan sebagian besar hal di BSC, Anda perlu membayar biaya gas, yang berbentuk BEP20 BNB.

Anda juga memerlukan versi BEP20 dari setiap token yang ingin Anda perdagangkan, Staking, dan lainnya di BSC.

Ada beberapa cara untuk mengonversi token Anda ke BEP20, namun berikut adalah yang kami rekomendasikan:

{% tabs %}
{% tab title="🥞🌉 Pancake Bridge" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28168%29.png)

[**PancakeSwap Bridge**](http://bridge.pancakeswap.finance) — jembatan cross-chain aset asli, didukung oleh Stargate.

Bridge ini memungkinkan Anda memindahkan stablecoin dengan mudah ke BNB Chain, dan berpartisipasi dalam Komunitas PancakeSwap yang aktif serta Ekosistem BNB yang lebih luas!

📖 [Pelajari cara menggunakannya](https://medium.com/pancakeswap/launching-pancakeswap-bridge-a-partnership-with-stargate-21c1c9f491a8)
{% endtab %}

{% tab title="💰 Binance" %}
[**Binance.com**](https://github.com/pancakeswap/pancake-document/tree/255db0c7af28df2f9c1209daa5cdbd774490a666/get-started/www.binance.com)

Anda dapat menarik token sebagai BEP20 melalui akun Binance Anda (jika Anda memilikinya). Harap diingat bahwa Anda memerlukan akun untuk melakukan ini.

📖 [Berikut panduan singkat yang mereka buat untuk membantu Anda.](https://www.binance.com/en/support/faq/85a1c394ac1d489fb0bfac0ef2fceafd)
{% endtab %}

{% tab title="🔒 SafePal" %}
[**SafePal**](https://safepal.io/download)

Anda tidak perlu akun atau registrasi apa pun. Lakukan Swap lintas rantai langsung dari Dompet Anda.

📖 [Berikut panduan singkat yang mereka buat untuk membantu Anda.](https://docs.safepal.io/safepal-app/cross-chain-swap-tutorial)
{% endtab %}
