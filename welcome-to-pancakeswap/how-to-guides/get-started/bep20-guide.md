# Obtenir des tokens BEP20

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-get-bep20-tokens-header.png)

Les tokens natifs de BNB Smart Chain (BSC) sont les **BEP20**.

Pour effectuer la plupart des opérations sur BSC, vous devrez payer des frais de gas, qui se présentent sous la forme de BNB BEP20.

Vous aurez également besoin de la version BEP20 de tout token que vous souhaitez échanger, mettre en Staking, etc. sur BSC.

Plusieurs méthodes permettent de convertir vos tokens en BEP20 ; voici celles que nous recommandons :

{% tabs %}
{% tab title="🥞🌉 Pancake Bridge" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28168%29.png)

[**PancakeSwap Bridge**](http://bridge.pancakeswap.finance) — un Bridge natif cross-chain, propulsé par Stargate.

Ce Bridge vous permet de transférer facilement vos stablecoins vers BNB Chain et de rejoindre la communauté PancakeSwap ainsi que l'écosystème BNB !

📖 [Apprendre à l'utiliser](https://medium.com/pancakeswap/launching-pancakeswap-bridge-a-partnership-with-stargate-21c1c9f491a8)
{% endtab %}

{% tab title="💰 Binance" %}
[**Binance.com**](https://github.com/pancakeswap/pancake-document/tree/255db0c7af28df2f9c1209daa5cdbd774490a666/get-started/www.binance.com)

Vous pouvez retirer des tokens en BEP20 depuis votre compte Binance (si vous en possédez un). Veuillez noter qu'un compte est nécessaire pour ce faire.

📖 [Voici un guide rapide pour vous aider.](https://www.binance.com/en/support/faq/85a1c394ac1d489fb0bfac0ef2fceafd)
{% endtab %}

{% tab title="🔒 SafePal" %}
[**SafePal**](https://safepal.io/download)

Aucun compte ni inscription nécessaire. Effectuez des Swaps cross-chain directement depuis votre portefeuille.

📖 [Voici un guide rapide pour vous aider.](https://docs.safepal.io/safepal-app/cross-chain-swap-tutorial)
{% endtab %}
