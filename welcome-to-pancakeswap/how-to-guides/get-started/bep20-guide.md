# BEP20 トークンを入手する

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-get-bep20-tokens-header.png)

BNB Smart Chain (BSC) のネイティブトークンは **BEP20** 形式です。

BSC 上でほとんどの操作を行うには、BEP20 形式の BNB でガス代を支払う必要があります。

また、BSC 上で取引・ステーキングなどを行いたいトークンも、BEP20 バージョンが必要です。

トークンを BEP20 形式に変換する方法はいくつかありますが、以下の方法をおすすめします。

{% tabs %}
{% tab title="🥞🌉 Pancake Bridge" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28168%29.png)

[**PancakeSwap Bridge**](http://bridge.pancakeswap.finance) — Stargate を利用したネイティブアセットのクロスチェーンブリッジです。

このブリッジを使うと、ステーブルコインをシームレスに BNBチェーン へ移動させ、活発な PancakeSwap コミュニティや BNB エコシステム全体に参加することができます。

📖 [使い方を見る](https://medium.com/pancakeswap/launching-pancakeswap-bridge-a-partnership-with-stargate-21c1c9f491a8)
{% endtab %}

{% tab title="💰 Binance" %}
[**Binance.com**](https://github.com/pancakeswap/pancake-document/tree/255db0c7af28df2f9c1209daa5cdbd774490a666/get-started/www.binance.com)

Binance アカウントをお持ちの方は、アカウントから BEP20 形式でトークンを出金できます。利用にはアカウントが必要です。

📖 [Binance による詳細ガイドはこちら](https://www.binance.com/en/support/faq/85a1c394ac1d489fb0bfac0ef2fceafd)
{% endtab %}

{% tab title="🔒 SafePal" %}
[**SafePal**](https://safepal.io/download)

アカウント登録は不要です。ウォレットから直接クロスチェーンスワップを実行できます。

📖 [SafePal による詳細ガイドはこちら](https://docs.safepal.io/safepal-app/cross-chain-swap-tutorial)
{% endtab %}
