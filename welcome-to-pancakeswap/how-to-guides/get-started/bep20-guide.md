# Получение BEP20 токенов

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-get-bep20-tokens-header.png)

Нативные токены BNB Smart Chain (BSC) — это **BEP20**.

Для большинства действий на BSC нужно платить за газ в виде BEP20 BNB.

Тебе также понадобится версия BEP20 любого токена, который ты хочешь торговать, стейкировать и т. д. на BSC.

Есть несколько способов конвертировать токены в BEP20, и вот те, которые мы рекомендуем:

{% tabs %}
{% tab title="🥞🌉 Pancake Bridge" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28168%29.png)

[**PancakeSwap Bridge**](http://bridge.pancakeswap.finance) — нативный межсетевой мост активов, работающий на базе Stargate.

Этот мост позволяет легко перевести стейблкоины в BNB Chain и участвовать в активном сообществе PancakeSwap и более широкой экосистеме BNB!

📖 [Узнать, как использовать](https://medium.com/pancakeswap/launching-pancakeswap-bridge-a-partnership-with-stargate-21c1c9f491a8)
{% endtab %}

{% tab title="💰 Binance" %}
[**Binance.com**](https://github.com/pancakeswap/pancake-document/tree/255db0c7af28df2f9c1209daa5cdbd774490a666/get-started/www.binance.com)

Ты можешь выводить токены как BEP20 через свой аккаунт Binance (если он есть). Имей в виду, что для этого нужен аккаунт.

📖 [Вот краткое руководство от них.](https://www.binance.com/en/support/faq/85a1c394ac1d489fb0bfac0ef2fceafd)
{% endtab %}

{% tab title="🔒 SafePal" %}
[**SafePal**](https://safepal.io/download)

Аккаунт или регистрация не нужны. Выполняй межсетевые обмены прямо из кошелька.

📖 [Вот краткое руководство от них.](https://docs.safepal.io/safepal-app/cross-chain-swap-tutorial)
{% endtab %}
