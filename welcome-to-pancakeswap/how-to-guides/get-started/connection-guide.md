# Menghubungkan Dompet Anda ke PancakeSwap

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-connect-wallet-header.png)

Anda telah membuat Dompet dan mendapatkan token BEP20, sekarang Anda hanya perlu menghubungkan Dompet Anda dengan PancakeSwap dan Anda siap untuk memulai!

Lihat langkah-langkah di bawah ini tentang cara menghubungkan setiap Dompet yang kami rekomendasikan ke PancakeSwap.

## Smartphone/Mobile

{% tabs %}
{% tab title="Trust Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2867%29.png)

Untuk menghubungkan Trust Wallet, ikuti langkah-langkah di bawah ini. Perlu diperhatikan bahwa perangkat Android dan iOS menggunakan langkah yang berbeda!

**Android**

1. Buka Trust Wallet dan ketuk tombol **DApps** di bagian bawah layar.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28174%29.png)

1. Gulir ke bawah ke "Popular" dan ketuk "PancakeSwap". Anda juga dapat menemukannya di "Exchanges".

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28121%29.png)

1. Halaman baru akan terbuka dengan logo PancakeSwap dan beberapa informasi. Ketuk tombol **Connect**.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2824%29.png)

1. PancakeSwap akan terbuka. Jika Anda melihat tombol **Connect** di pojok kanan atas, ketuk tombol tersebut dan ketuk **Trust Wallet** dari daftar.

{% hint style="warning" %}
Jika Anda tidak dapat terhubung pada langkah 4, kembali ke menu DApps dan cari "PancakeSwap" lagi. Menggunakan "Pancake Swap" dari bagian "History" dapat mengakibatkan masalah yang sama.
{% endhint %}

**iOS**

Untuk terhubung ke PancakeSwap melalui iOS, Trust Wallet telah menyiapkan panduan terperinci tentang penggunaan WalletConnect.

Baca [panduan Trust Wallet untuk terhubung ke PancakeSwap melalui WalletConnect](https://community.trustwallet.com/t/using-walletconnect-to-access-pancakeswap/212307).

**Sumber Daya**

[**Unduh Trust Wallet**](https://trustwallet.com) (Mendeteksi perangkat secara otomatis)\
[**Panduan Penyiapan Trust Wallet**](https://www.binance.com/en/blog/421499824684901157/how-to-set-up-and-use-trust-wallet-for-binance-smart-chain)
{% endtab %}

{% tab title="MetaMask" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2833%29%20%283%29.png)

Untuk menghubungkan MetaMask ke PancakeSwap, ikuti langkah-langkah di bawah ini.

**Android dan iOS**

1. Buka MetaMask dan ketuk **ikon menu hamburger** di pojok kiri atas.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2865%29.png)

1. Ketuk **Settings** pada menu.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28318%29.png)

1. Di menu Settings, ketuk **Network**.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2828%29.png)

1. Ketuk tombol **Add Network** di bagian bawah.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2863%29.png)

1. Pada halaman yang terbuka, ketikkan detail berikut:

**Network Name:** BNB Smart Chain\
**RPC Url:** [https://bsc-dataseed.binance.org](https://bsc-dataseed.binance.org)\
**Chain ID:** 56\
**Symbol:** BNB\
**Block Explorer URL:** [http://bscscan.com](http://bscscan.com)

1. Setelah Anda mengonfirmasi penambahan jaringan baru, kembali ke menu hamburger dan ketuk **Browser**.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28153%29.png)

1. Ketikkan "PancakeSwap" di kolom pencarian dan mulai pencarian. Hasil teratas akan menjadi bursa PancakeSwap. Ketuk untuk masuk.
2. Dompet Anda akan meminta Anda untuk terhubung. Ketuk **Connect** untuk terhubung ke PancakeSwap.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28184%29.png)

**Sumber Daya**

[**Unduh MetaMask**](https://metamask.io/download.html) (Mendeteksi perangkat secara otomatis)\
[**Panduan Penyiapan MetaMask**](https://academy.binance.com/en/articles/connecting-metamask-to-binance-smart-chain\))
{% endtab %}

{% tab title="Coinbase Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/coinbase_wallet_wordmark_blue.png)

1. Buka Coinbase Wallet dan ketuk **ikon pengaturan** di pojok kanan bawah.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p1.png)\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p1_5.png)
2. Di menu Settings, ketuk **Default Network**.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p2.png)
3. Pilih **Binance Smart Chain** dari daftar opsi jaringan.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p3.png)
4. Setelah memilih jaringan Binance Smart Chain, klik **Ikon Browser** di bagian tengah bawah aplikasi Anda.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p4.png)\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p5.png)
5. Ketikkan "PancakeSwap.finance" di kolom pencarian dan mulai pencarian.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p6.png)
6. Klik **Connect** **Wallet** untuk terhubung ke Coinbase Wallet.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p7.png)

**Sumber Daya**

[**Unduh Coinbase Wallet**](https://coinbase-wallet.onelink.me/q5Sx/fdb9b250) **(Mendeteksi perangkat secara otomatis)**

{% tab title="Token Pocket" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28125%29%20%283%29.png)

Token Pocket adalah aplikasi manajemen mata uang kripto yang secara bawaan mendukung banyak jaringan mata uang kripto. Aplikasi ini juga tersedia sebagai aplikasi desktop.

**Android dan iOS**

1. Ketuk tombol **Discover** di bagian bawah layar utama.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28170%29.png)

1. Anda akan melihat halaman browser DApp terbuka. Di bawah "Recommended", cari dan ketuk tombol **PancakeSwap**. Jika Anda tidak dapat melihat PancakeSwap di bawah Recommended, Anda juga dapat menemukannya di bawah "BSC".

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28250%29.png)

1. Jendela akan terbuka yang menyatakan bahwa Anda akan membuka DApp pihak ketiga. Ketuk **I got it** dan Anda akan dibawa ke situs web PancakeSwap yang terhubung ke Dompet Anda.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28320%29.png)

**Sumber Daya**\
[**Unduh Aplikasi Token Pocket**](https://www.tokenpocket.pro/en/download/app) (Mendeteksi perangkat secara otomatis)\
**Panduan Penyiapan Token Pocket Mobile**
{% endtab %}

{% tab title="SafePal" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2897%29.png)

SafePal tersedia sebagai Dompet perangkat lunak maupun perangkat keras. Dompet ini mudah dipasang dan dibuat, serta langsung siap mendukung BEP2 (Binance Chain) dan BEP20 (BNB Smart Chain).

**Android dan iOS**

1. Ketuk tombol ikon **4 kotak** di bagian bawah layar utama.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28150%29.png)

1. Anda akan melihat halaman browser DApp terbuka. Di bawah "DeFi", cari dan ketuk tombol **PancakeSwap**. Jika Anda tidak dapat melihat PancakeSwap di bawah DeFi, Anda juga dapat menemukannya di bawah "BSC".

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28167%29.png)

1. Jendela akan terbuka yang menyatakan bahwa Anda akan membuka DApp pihak ketiga. Ketuk **Confirm** dan Anda akan dibawa ke situs web PancakeSwap yang terhubung ke Dompet Anda.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28223%29.png)

**Sumber Daya**\
​[**Unduh SafePal**](https://safepal.io/download) (Mendeteksi perangkat secara otomatis)\
[**Panduan Penyiapan SafePal**](https://blog.safepal.io/binance-smart-chain-x-safepal/)
{% endtab %}

## **Dompet Desktop/Browser Web**

{% tabs %}
{% tab title="MetaMask" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2833%29%20%283%29.png)

**Chrome dan Firefox**

1. Buka MetaMask dan klik **pemilih jaringan** di bagian atas. Secara default, akan menampilkan "Ethereum Mainnet". Gulir ke bawah dan klik **Custom RPC**.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28115%29.png)

1. Sebuah jendela akan terbuka. Ketikkan detail di bawah ini.

**Network Name:** BNB Smart Chain\
**New RPC URL:** [https://bsc-dataseed.binance.org](https://bsc-dataseed.binance.org)\
**Chain ID:** 56\
**Currency Symbol (optional):** BNB\
**Block Explorer URL (optional):** [http://bscscan.com](http://bscscan.com)

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28246%29.png)

1. Pastikan Anda telah mengetikkan semuanya dengan benar dan klik **Save**. BNB Smart Chain sekarang akan menjadi salah satu opsi jaringan Anda.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28130%29.png)

1. Kunjungi [situs web PancakeSwap](https://pancakeswap.finance). Di pojok kanan atas Anda akan melihat tombol **Connect**. Klik tombol tersebut.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28164%29%20%281%29.png)

1. Sebuah jendela akan muncul meminta Anda memilih Dompet untuk dihubungkan. Klik **MetaMask** (ini adalah opsi teratas dalam daftar).

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28270%29.png)

**Sumber Daya**

[**Unduh MetaMask**](https://metamask.io/download.html) (Mendeteksi browser secara otomatis)\
[**Panduan Penyiapan MetaMask**](https://academy.binance.com/en/articles/connecting-metamask-to-binance-smart-chain)
{% endtab %}

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/coinbase_wallet_wordmark_blue.png)

1. Buka Coinbase Wallet dan klik ikon **Settings** di pojok kanan atas. Secara default, akan menampilkan "Ethereum Mainnet" sebagai Default Network.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/cb-desktop-1.png)

5. Sebuah jendela akan muncul meminta Anda memilih Dompet untuk dihubungkan. Klik **Coinbase Wallet** (ini adalah opsi teratas dalam daftar).\

{% tab title="Token Pocket" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28125%29%20%283%29.png)

**Aplikasi Desktop**

1. Ketika Anda membuka aplikasi, DApps seharusnya menjadi halaman default (jika tidak, klik ke halaman DApps).
2. Di tengah halaman Anda akan melihat daftar jaringan untuk dipilih. Klik **BSC**.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28260%29.png)

1. Pada daftar DApp BSC, Anda akan menemukan tautan PancakeSwap. Klik tautan **PancakeSwap**.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28290%29.png)

{% hint style="warning" %}
Pastikan Anda tidak memilih opsi "PancakeSwap data analysis". Jika Anda melakukannya, Anda tidak akan dapat terhubung.
{% endhint %}

1. Browser Anda akan membuka tab PancakeSwap dan mencoba terhubung ke Token Pocket.

{% hint style="warning" %}
Anda tidak akan dapat menggunakan MetaMask dan TokenPocket secara bersamaan melalui browser web yang sama. Pastikan Anda menggunakan browser web tanpa plugin MetaMask yang terpasang jika Anda menggunakan TokenPocket di komputer desktop Anda.
{% endhint %}
