# Ihr Wallet mit PancakeSwap verbinden

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-connect-wallet-header.png)

Sie haben ein Wallet erstellt und Ihre BEP20-Token erhalten – jetzt müssen Sie Ihr Wallet nur noch mit PancakeSwap verbinden, und schon kann es losgehen!

Lesen Sie die folgenden Schritte, um zu erfahren, wie Sie jedes unserer empfohlenen Wallets mit PancakeSwap verbinden.

## Smartphone/Mobil

{% tabs %}
{% tab title="Trust Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2867%29.png)

Um Trust Wallet zu verbinden, folgen Sie den nachstehenden Schritten. Beachten Sie, dass Android und iOS unterschiedliche Schritte erfordern!

**Android**

1. Öffnen Sie Trust Wallet und tippen Sie auf die Schaltfläche **DApps** am unteren Bildschirmrand.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28174%29.png)

1. Scrollen Sie nach unten zu „Popular" und tippen Sie auf „PancakeSwap". Sie finden es auch unter „Exchanges".

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28121%29.png)

1. Eine neue Seite mit dem PancakeSwap-Logo und einigen Informationen wird geöffnet. Tippen Sie auf die Schaltfläche **Connect**.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2824%29.png)

1. PancakeSwap wird geöffnet. Wenn Sie oben rechts eine Schaltfläche **Connect** sehen, tippen Sie darauf und wählen Sie **Trust Wallet** aus der Liste.

{% hint style="warning" %}
Falls Sie in Schritt 4 keine Verbindung herstellen können, kehren Sie zum DApps-Menü zurück und suchen Sie erneut nach „PancakeSwap". Die Verwendung von „Pancake Swap" aus dem Bereich „History" kann zum gleichen Problem führen.
{% endhint %}

**iOS**

Um sich über iOS mit PancakeSwap zu verbinden, hat Trust Wallet eine detaillierte Anleitung zur Nutzung von WalletConnect erstellt.

Lesen Sie die [Trust Wallet-Anleitung zur Verbindung mit PancakeSwap über WalletConnect](https://community.trustwallet.com/t/using-walletconnect-to-access-pancakeswap/212307).

**Ressourcen**

[**Trust Wallet herunterladen**](https://trustwallet.com) (Erkennt Gerät automatisch)\
[**Trust Wallet Einrichtungsanleitung**](https://www.binance.com/en/blog/421499824684901157/how-to-set-up-and-use-trust-wallet-for-binance-smart-chain)
{% endtab %}

{% tab title="MetaMask" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2833%29%20%283%29.png)

Um MetaMask mit PancakeSwap zu verbinden, folgen Sie den nachstehenden Schritten.

**Android und iOS**

1. Öffnen Sie MetaMask und tippen Sie auf das **Burger-Symbol** oben links.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2865%29.png)

1. Tippen Sie im Menü auf **Settings**.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28318%29.png)

1. Im Einstellungsmenü tippen Sie auf **Network**.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2828%29.png)

1. Tippen Sie unten auf die Schaltfläche **Add Network**.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2863%29.png)

1. Geben Sie auf der sich öffnenden Seite die folgenden Details ein:

**Network Name:** BNB Smart Chain\
**RPC Url:** [https://bsc-dataseed.binance.org](https://bsc-dataseed.binance.org)\
**Chain ID:** 56\
**Symbol:** BNB\
**Block Explorer URL:** [http://bscscan.com](http://bscscan.com)

1. Nachdem Sie die Eingabe des neuen Netzwerks bestätigt haben, kehren Sie zum Burger-Menü zurück und tippen Sie auf **Browser**.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28153%29.png)

1. Geben Sie „PancakeSwap" in das Suchfeld ein und starten Sie die Suche. Das erste Ergebnis ist die PancakeSwap-Börse. Tippen Sie darauf, um sie aufzurufen.
2. Ihr Wallet fordert Sie auf, eine Verbindung herzustellen. Tippen Sie auf **Connect**, um sich mit PancakeSwap zu verbinden.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28184%29.png)

**Ressourcen**

[**MetaMask herunterladen**](https://metamask.io/download.html) (Erkennt Gerät automatisch)\
[**MetaMask Einrichtungsanleitung**](https://academy.binance.com/en/articles/connecting-metamask-to-binance-smart-chain\))
{% endtab %}

{% tab title="Coinbase Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/coinbase_wallet_wordmark_blue.png)

1. Öffnen Sie Coinbase Wallet und tippen Sie unten rechts auf das **Einstellungssymbol**.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p1.png)\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p1_5.png)
2. Tippen Sie im Einstellungsmenü auf **Default Network**.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p2.png)
3. Wählen Sie **Binance Smart Chain** aus der Liste der Netzwerkoptionen.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p3.png)
4. Nachdem Sie das Binance Smart Chain-Netzwerk ausgewählt haben, klicken Sie unten in der Mitte Ihrer App auf das **Browser-Symbol**.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p4.png)\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p5.png)
5. Geben Sie „PancakeSwap.finance" in das Suchfeld ein und starten Sie die Suche.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p6.png)
6. Klicken Sie auf **Connect** **Wallet**, um sich mit Coinbase Wallet zu verbinden.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p7.png)

{% tab title="Token Pocket" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28125%29%20%283%29.png)

Token Pocket ist eine Kryptowährungsverwaltungs-App, die nativ viele Kryptowährungsnetzwerke unterstützt. Es ist auch eine Desktop-Anwendung verfügbar.

**Android und iOS**

1. Tippen Sie auf die Schaltfläche **Discover** am unteren Rand des Hauptbildschirms.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28170%29.png)

1. Es öffnet sich eine DApp-Browserseite. Suchen Sie unter „Recommended" die Schaltfläche **PancakeSwap** und tippen Sie darauf. Falls Sie PancakeSwap unter „Recommended" nicht sehen, finden Sie es auch unter „BSC".

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28250%29.png)

1. Ein Fenster öffnet sich mit dem Hinweis, dass Sie eine DApp eines Drittanbieters öffnen werden. Tippen Sie auf **I got it** und Sie werden zur PancakeSwap-Website weitergeleitet, die mit Ihrem Wallet verbunden ist.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28320%29.png)

**Ressourcen**\
[**Token Pocket App herunterladen**](https://www.tokenpocket.pro/en/download/app) (Erkennt Gerät automatisch)\
**Token Pocket Mobile Einrichtungsanleitung**
{% endtab %}

{% tab title="SafePal" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2897%29.png)

SafePal ist sowohl als Software- als auch als Hardware-Wallet erhältlich. Das Wallet ist einfach zu installieren und einzurichten und unterstützt von Anfang an BEP2 (Binance Chain) und BEP20 (BNB Smart Chain).

**Android und iOS**

1. Tippen Sie auf das Symbol mit den **4 Quadraten** am unteren Rand des Hauptbildschirms.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28150%29.png)

1. Es öffnet sich eine DApp-Browserseite. Suchen Sie unter „DeFi" die Schaltfläche **PancakeSwap** und tippen Sie darauf. Falls Sie PancakeSwap unter „DeFi" nicht sehen, finden Sie es auch unter „BSC".

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28167%29.png)

1. Ein Fenster öffnet sich mit dem Hinweis, dass Sie eine DApp eines Drittanbieters öffnen werden. Tippen Sie auf **Confirm** und Sie werden zur PancakeSwap-Website weitergeleitet, die mit Ihrem Wallet verbunden ist.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28223%29.png)

**Ressourcen**\
​[**SafePal herunterladen**](https://safepal.io/download) (Erkennt Gerät automatisch)\
[**SafePal Einrichtungsanleitung**](https://blog.safepal.io/binance-smart-chain-x-safepal/)
{% endtab %}

## **Desktop/Webbrowser-Wallets**

{% tabs %}
{% tab title="MetaMask" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2833%29%20%283%29.png)

**Chrome und Firefox**

1. Öffnen Sie MetaMask und klicken Sie oben auf den **Netzwerkauswähler**. Standardmäßig wird „Ethereum Mainnet" angezeigt. Scrollen Sie nach unten und klicken Sie auf **Custom RPC**.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28115%29.png)

1. Ein Fenster öffnet sich. Geben Sie die folgenden Details ein.

**Network Name:** BNB Smart Chain\
**New RPC URL:** [https://bsc-dataseed.binance.org](https://bsc-dataseed.binance.org)\
**Chain ID:** 56\
**Currency Symbol (optional):** BNB\
**Block Explorer URL (optional):** [http://bscscan.com](http://bscscan.com)

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28246%29.png)

1. Vergewissern Sie sich, dass Sie alles korrekt eingegeben haben, und klicken Sie auf **Save**. BNB Smart Chain ist nun eine Ihrer Netzwerkoptionen.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28130%29.png)

1. Besuchen Sie die [PancakeSwap-Website](https://pancakeswap.finance). In der oberen rechten Ecke sehen Sie die Schaltfläche **Connect**. Klicken Sie darauf.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28164%29%20%281%29.png)

1. Ein Fenster erscheint, in dem Sie aufgefordert werden, ein Wallet für die Verbindung auszuwählen. Klicken Sie auf **MetaMask** (es ist die oberste Option in der Liste).

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28270%29.png)

**Ressourcen**

[**MetaMask herunterladen**](https://metamask.io/download.html) (Erkennt Browser automatisch)\

{% tab title="Token Pocket" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28125%29%20%283%29.png)

**Desktop-Anwendung**

1. Wenn Sie die Anwendung öffnen, sollte DApps die Standardseite sein (falls nicht, navigieren Sie zur DApps-Seite).
2. In der Mitte der Seite sehen Sie eine Liste von Netzwerken zur Auswahl. Klicken Sie auf **BSC**.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28260%29.png)

1. In der Liste der BSC-DApps finden Sie PancakeSwap-Links. Klicken Sie auf einen **PancakeSwap**-Link.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28290%29.png)

{% hint style="warning" %}
Achten Sie darauf, die Option „PancakeSwap data analysis" nicht auszuwählen. Andernfalls können Sie keine Verbindung herstellen.
{% endhint %}

1. Ihr Browser öffnet einen PancakeSwap-Tab und versucht, eine Verbindung zu Token Pocket herzustellen.

{% hint style="warning" %}
Sie können MetaMask und TokenPocket nicht gleichzeitig im selben Webbrowser verwenden. Stellen Sie sicher, dass Sie einen Webbrowser ohne installiertes MetaMask-Plugin verwenden, wenn Sie TokenPocket auf Ihrem Desktop-Computer nutzen.
{% endhint %}
