# ウォレットを PancakeSwap に接続する

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-connect-wallet-header.png)

ウォレットを作成して BEP20 トークンを入手できたら、あとはウォレットを PancakeSwap に接続するだけです。準備完了です！

推奨ウォレットごとの接続手順を以下にご確認ください。

## スマートフォン / モバイル

{% tabs %}
{% tab title="Trust Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2867%29.png)

Trust Wallet を接続するには、以下の手順に従ってください。Android と iOS では手順が異なりますのでご注意ください。

**Android**

1. Trust Wallet を開き、画面下部の **DApps** ボタンをタップします。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28174%29.png)

1. 「Popular」までスクロールして「PancakeSwap」をタップします。「Exchanges」セクションでも見つけられます。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28121%29.png)

1. PancakeSwap のロゴと情報が表示された新しいページが開きます。**Connect** ボタンをタップします。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2824%29.png)

1. PancakeSwap が開きます。右上に **Connect** ボタンが表示されている場合はタップし、一覧から **Trust Wallet** を選択します。

{% hint style="warning" %}
手順 4 で接続できない場合は、DApps メニューに戻って「PancakeSwap」を再度検索してください。「History」セクションの「Pancake Swap」を使用すると、同様の問題が発生することがあります。
{% endhint %}

**iOS**

iOS で PancakeSwap に接続するには、Trust Wallet が WalletConnect を使用した詳細ガイドを用意しています。

[Trust Wallet の WalletConnect を使った PancakeSwap 接続ガイド](https://community.trustwallet.com/t/using-walletconnect-to-access-pancakeswap/212307)をご参照ください。

**参考リンク**

[**Trust Wallet をダウンロード**](https://trustwallet.com)（デバイスを自動検出）\
[**Trust Wallet セットアップガイド**](https://www.binance.com/en/blog/421499824684901157/how-to-set-up-and-use-trust-wallet-for-binance-smart-chain)
{% endtab %}

{% tab title="MetaMask" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2833%29%20%283%29.png)

MetaMask を PancakeSwap に接続するには、以下の手順に従ってください。

**Android および iOS**

1. MetaMask を開き、左上の**ハンバーガーアイコン**をタップします。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2865%29.png)

1. メニューの **Settings** をタップします。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28318%29.png)

1. 設定メニューで **Network** をタップします。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2828%29.png)

1. 下部の **Add Network** ボタンをタップします。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2863%29.png)

1. 開いたページに以下の情報を入力します。

**Network Name:** BNB Smart Chain\
**RPC Url:** [https://bsc-dataseed.binance.org](https://bsc-dataseed.binance.org)\
**Chain ID:** 56\
**Symbol:** BNB\
**Block Explorer URL:** [http://bscscan.com](http://bscscan.com)

1. 新しいネットワークの追加を確認したら、ハンバーガーメニューに戻り **Browser** をタップします。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28153%29.png)

1. 検索フィールドに「PancakeSwap」と入力して検索します。最上位の結果が PancakeSwap の取引所です。タップして開きます。
2. ウォレットから接続の確認が求められます。**Connect** をタップして PancakeSwap に接続します。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28184%29.png)

**参考リンク**

[**MetaMask をダウンロード**](https://metamask.io/download.html)（デバイスを自動検出）\
[**MetaMask セットアップガイド**](https://academy.binance.com/en/articles/connecting-metamask-to-binance-smart-chain\))

{% tab title="Coinbase Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/coinbase_wallet_wordmark_blue.png)

1. Coinbase Wallet を開き、右下の**設定アイコン**をタップします。\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p1.png)\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p1_5.png)
2. 設定メニューで **Default Network** をタップします。\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p2.png)
3. ネットワーク一覧から **Binance Smart Chain** を選択します。\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p3.png)
4. Binance Smart Chain ネットワークを選択したら、アプリ下部中央の**ブラウザアイコン**をタップします。\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p4.png)\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p5.png)
5. 検索フィールドに「PancakeSwap.finance」と入力して検索します。\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p6.png)
6. **Connect** **Wallet** をクリックして Coinbase Wallet に接続します。\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p7.png)

{% tab title="Token Pocket" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28125%29%20%283%29.png)

Token Pocket は、多くの暗号通貨ネットワークをネイティブにサポートする暗号資産管理アプリです。デスクトップアプリ版もあります。

**Android および iOS**

1. メイン画面下部の **Discover** ボタンをタップします。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28170%29.png)

1. DApp ブラウザページが開きます。「Recommended」から **PancakeSwap** ボタンを見つけてタップします。Recommended に表示されていない場合は「BSC」セクションでも見つけられます。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28250%29.png)

1. サードパーティ DApp を開く旨の確認ウィンドウが表示されます。**I got it** をタップすると、ウォレットに接続された状態で PancakeSwap のウェブサイトが開きます。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28320%29.png)

**参考リンク**\
[**Token Pocket アプリをダウンロード**](https://www.tokenpocket.pro/en/download/app)（デバイスを自動検出）\
**Token Pocket モバイルセットアップガイド**
{% endtab %}

{% tab title="SafePal" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2897%29.png)

SafePal はソフトウェアウォレットとハードウェアウォレットの両方として利用できます。インストールと作成が簡単で、BEP2 (Binance Chain) および BEP20 (BNB Smart Chain) をすぐにサポートしています。

**Android および iOS**

1. メイン画面下部の **4 つの四角**アイコンボタンをタップします。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28150%29.png)

1. DApp ブラウザページが開きます。「DeFi」セクションから **PancakeSwap** ボタンを見つけてタップします。DeFi に表示されていない場合は「BSC」セクションでも見つけられます。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28167%29.png)

1. サードパーティ DApp を開く旨の確認ウィンドウが表示されます。**Confirm** をタップすると、ウォレットに接続された状態で PancakeSwap のウェブサイトが開きます。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28223%29.png)

**参考リンク**\
​[**SafePal をダウンロード**](https://safepal.io/download)（デバイスを自動検出）\
[**SafePal セットアップガイド**](https://blog.safepal.io/binance-smart-chain-x-safepal/)
{% endtab %}

## **デスクトップ / ウェブブラウザ ウォレット**

{% tabs %}
{% tab title="MetaMask" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2833%29%20%283%29.png)

**Chrome および Firefox**

1. MetaMask を開き、上部の**ネットワーク選択**をクリックします。デフォルトでは「Ethereum Mainnet」と表示されています。下にスクロールして **Custom RPC** をクリックします。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28115%29.png)

1. ウィンドウが開きます。以下の情報を入力します。

**Network Name:** BNB Smart Chain\
**New RPC URL:** [https://bsc-dataseed.binance.org](https://bsc-dataseed.binance.org)\
**Chain ID:** 56\
**Currency Symbol (optional):** BNB\
**Block Explorer URL (optional):** [http://bscscan.com](http://bscscan.com)

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28246%29.png)

1. すべて正しく入力されていることを確認して **Save** をクリックします。BNB Smart Chain がネットワーク選択肢に追加されます。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28130%29.png)

1. [PancakeSwap ウェブサイト](https://pancakeswap.finance)にアクセスします。右上に **Connect** ボタンが表示されますので、クリックします。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28164%29%20%281%29.png)

1. 接続するウォレットを選択するウィンドウが表示されます。**MetaMask**（リストの最上部）をクリックします。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28270%29.png)

**参考リンク**

[**MetaMask をダウンロード**](https://metamask.io/download.html)（ブラウザを自動検出）\

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28125%29%20%283%29.png)

**デスクトップアプリ**

1. アプリを開くと、デフォルトで DApps ページが表示されます（表示されない場合は DApps ページに移動してください）。
2. ページ中央付近にネットワーク一覧が表示されます。**BSC** をクリックします。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28260%29.png)

{% hint style="warning" %}
「PancakeSwap data analysis」オプションは選択しないようにしてください。選択すると接続できなくなります。
{% endhint %}

1. ブラウザで PancakeSwap のタブが開き、Token Pocket への接続が試みられます。

{% hint style="warning" %}
MetaMask と TokenPocket を同じウェブブラウザで同時に接続することはできません。デスクトップで TokenPocket を使用する場合は、MetaMask プラグインがインストールされていないブラウザをご使用ください。
{% endhint %}
