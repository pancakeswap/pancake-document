# 지갑을 PancakeSwap에 연결하기

지갑을 만들고 BEP20 토큰도 받았다면, 이제 지갑을 PancakeSwap에 연결하기만 하면 준비가 끝납니다!

아래 단계에서 추천 지갑별로 PancakeSwap에 연결하는 방법을 확인해 보세요.

## 스마트폰/모바일

{% tabs %}
{% tab title="Trust Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2867%29.png)

Trust Wallet을 연결하려면 아래 단계를 따르세요. Android와 iOS 기기는 단계가 서로 다르다는 점에 유의하세요!

**Android**

1. Trust Wallet을 열고 화면 하단의 **DApps** 버튼을 탭합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28174%29.png)

1. "Popular"까지 스크롤한 후 "PancakeSwap"을 탭합니다. "Exchanges"에서도 찾을 수 있습니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28121%29.png)

1. PancakeSwap 로고와 몇 가지 정보가 있는 새 페이지가 열립니다. **Connect** 버튼을 탭합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2824%29.png)

1. PancakeSwap이 열립니다. 오른쪽 상단에 **Connect** 버튼이 보이면 탭한 후 목록에서 **Trust Wallet**을 탭합니다.

{% hint style="warning" %}
4단계에서 연결할 수 없다면 DApps 메뉴로 돌아가 "PancakeSwap"을 다시 찾아보세요. "History" 섹션의 "Pancake Swap"을 사용하면 같은 문제가 발생할 수 있습니다.
{% endhint %}

**iOS**

iOS에서 PancakeSwap에 연결하기 위해, Trust Wallet은 WalletConnect 사용에 대한 상세 가이드를 준비했습니다.

[WalletConnect를 통해 PancakeSwap에 연결하는 Trust Wallet 가이드](https://community.trustwallet.com/t/using-walletconnect-to-access-pancakeswap/212307)를 읽어 보세요.

**참고 자료**

[**Trust Wallet 다운로드**](https://trustwallet.com) (기기를 자동으로 감지)\
[**Trust Wallet 설정 가이드**](https://www.binance.com/en/blog/421499824684901157/how-to-set-up-and-use-trust-wallet-for-binance-smart-chain)
{% endtab %}

{% tab title="MetaMask" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2833%29%20%283%29.png)

MetaMask를 PancakeSwap에 연결하려면 아래 단계를 따르세요.

**Android 및 iOS**

1. MetaMask를 열고 왼쪽 상단의 **햄버거 아이콘**을 탭합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2865%29.png)

1. 메뉴에서 **Settings**를 탭합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28318%29.png)

1. Settings 메뉴에서 **Network**를 탭합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2828%29.png)

1. 하단의 **Add Network** 버튼을 탭합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2863%29.png)

1. 열린 페이지에 다음 정보를 입력합니다.

**네트워크 이름(Network Name):** BNB Smart Chain\
**RPC Url:** [https://bsc-dataseed.binance.org](https://bsc-dataseed.binance.org)\
**체인 ID(Chain ID):** 56\
**심볼(Symbol):** BNB\
**블록 탐색기 URL(Block Explorer URL):** [http://bscscan.com](http://bscscan.com)

1. 새 네트워크 입력을 확인했다면 햄버거 메뉴로 돌아가 **Browser**를 탭합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28153%29.png)

1. 검색창에 "PancakeSwap"을 입력하고 검색을 시작합니다. 최상단 결과가 PancakeSwap 거래소입니다. 탭하여 들어갑니다.
2. 지갑에서 연결을 요청합니다. **Connect**를 탭하여 PancakeSwap에 연결합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28184%29.png)

**참고 자료**

[**MetaMask 다운로드**](https://metamask.io/download.html) (기기를 자동으로 감지)\
[**MetaMask 설정 가이드**](https://academy.binance.com/en/articles/connecting-metamask-to-binance-smart-chain\))
{% endtab %}

{% tab title="Coinbase Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/coinbase_wallet_wordmark_blue.png)

1. Coinbase Wallet을 열고 오른쪽 하단의 **설정 아이콘**을 탭합니다.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p1.png)\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p1_5.png)
2. Settings 메뉴에서 **Default Network**를 탭합니다.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p2.png)
3. 네트워크 옵션 목록에서 **Binance Smart Chain**을 선택합니다.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p3.png)
4. Binance Smart Chain 네트워크를 선택했다면 앱 하단 중앙의 **브라우저 아이콘**을 클릭합니다.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p4.png)\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p5.png)
5. 검색창에 "PancakeSwap.finance"를 입력하고 검색을 시작합니다.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p6.png)
6. **Connect** **Wallet**을 클릭하여 Coinbase Wallet에 연결합니다.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/CB-M-p7.png)

**참고 자료**

[**Coinbase Wallet 다운로드**](https://coinbase-wallet.onelink.me/q5Sx/fdb9b250) **(기기를 자동으로 감지)**

[**Coinbase Wallet 설정 가이드**](https://www.coinbase.com/wallet/getting-started-mobile)
{% endtab %}

{% tab title="Token Pocket" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28125%29%20%283%29.png)

Token Pocket은 다양한 암호화폐 네트워크를 기본적으로 지원하는 암호화폐 관리 앱입니다. 데스크톱 애플리케이션도 제공됩니다.

**Android 및 iOS**

1. 메인 화면 하단의 **Discover** 버튼을 탭합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28170%29.png)

1. DApp 브라우저 페이지가 열립니다. "Recommended" 아래에서 **PancakeSwap** 버튼을 찾아 탭합니다. Recommended에서 PancakeSwap이 보이지 않으면 "BSC"에서도 찾을 수 있습니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28250%29.png)

1. 서드파티 DApp을 연다는 안내 창이 열립니다. **I got it**을 탭하면 지갑이 연결된 상태로 PancakeSwap 웹사이트로 이동합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28320%29.png)

**참고 자료**\
[**Token Pocket 앱 다운로드**](https://www.tokenpocket.pro/en/download/app) (기기를 자동으로 감지)\
**Token Pocket 모바일 설정 가이드**
{% endtab %}

{% tab title="SafePal" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2897%29.png)

SafePal은 소프트웨어 지갑과 하드웨어 지갑으로 모두 제공됩니다. 설치와 생성이 쉬우며 BEP2(Binance Chain)와 BEP20(BNB Smart Chain)을 바로 지원합니다.

**Android 및 iOS**

1. 메인 화면 하단의 **4개의 사각형** 아이콘 버튼을 탭합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28150%29.png)

1. DApp 브라우저 페이지가 열립니다. "DeFi" 아래에서 **PancakeSwap** 버튼을 찾아 탭합니다. DeFi에서 PancakeSwap이 보이지 않으면 "BSC"에서도 찾을 수 있습니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28167%29.png)

1. 서드파티 DApp을 연다는 안내 창이 열립니다. **Confirm**을 탭하면 지갑이 연결된 상태로 PancakeSwap 웹사이트로 이동합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28223%29.png)

**참고 자료**\
[**SafePal 다운로드**](https://safepal.io/download) (기기를 자동으로 감지)\
[**SafePal 설정 가이드**](https://blog.safepal.io/binance-smart-chain-x-safepal/)
{% endtab %}

## **데스크톱/웹 브라우저 지갑**

{% tabs %}
{% tab title="MetaMask" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2833%29%20%283%29.png)

**Chrome 및 Firefox**

1. MetaMask를 열고 상단의 **네트워크 선택기**를 클릭합니다. 기본적으로 "Ethereum Mainnet"이 표시됩니다. 아래로 스크롤하여 **Custom RPC**를 클릭합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28115%29.png)

1. 창이 열립니다. 아래 정보를 입력합니다.

**네트워크 이름(Network Name):** BNB Smart Chain\
**새 RPC URL(New RPC URL):** [https://bsc-dataseed.binance.org](https://bsc-dataseed.binance.org)\
**체인 ID(Chain ID):** 56\
**통화 심볼(Currency Symbol, 선택):** BNB\
**블록 탐색기 URL(Block Explorer URL, 선택):** [http://bscscan.com](http://bscscan.com)

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28246%29.png)

1. 모든 내용을 올바르게 입력했는지 확인한 후 **Save**를 클릭합니다. 이제 BNB Smart Chain이 네트워크 옵션 중 하나로 추가됩니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28130%29.png)

1. [PancakeSwap 웹사이트](https://pancakeswap.finance)를 방문합니다. 오른쪽 상단에 **Connect** 버튼이 보입니다. 클릭하세요.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28164%29%20%281%29.png)

1. 연결할 지갑을 선택하라는 창이 나타납니다. **MetaMask**를 클릭합니다 (목록 최상단 옵션입니다).

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28270%29.png)

**참고 자료**

[**MetaMask 다운로드**](https://metamask.io/download.html) (브라우저를 자동으로 감지)\
[**MetaMask 설정 가이드**](https://academy.binance.com/en/articles/connecting-metamask-to-binance-smart-chain)
{% endtab %}

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28255%29.png)

**Chrome 및 Firefox**

1. Binance Chain Wallet을 열고 상단의 네트워크 선택기를 클릭합니다. 기본 네트워크는 Binance Chain입니다. 목록에서 **BNB Smart Chain**을 선택합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2854%29.png)

1. PancakeSwap 웹사이트를 방문합니다. 오른쪽 상단에서 **Connect**를 클릭합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28164%29%20%281%29.png)

1. 연결할 지갑을 선택하라는 창이 나타납니다. **Binance Chain Wallet**을 클릭합니다 (목록 아래쪽에 있습니다).

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28117%29.png)

**참고 자료**

[**Binance Wallet 다운로드**](https://www.binance.org/en) (브라우저를 자동으로 감지)\
**Binance Wallet 설정 가이드**
{% endtab %}

{% tab title="Coinbase Wallet" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/coinbase_wallet_wordmark_blue.png)

1. Coinbase Wallet을 열고 오른쪽 상단의 **Settings** 아이콘을 클릭합니다. 기본적으로 Default Network로 "Ethereum Mainnet"이 표시됩니다.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/cb-desktop-1.png)
2. **Default Network**를 클릭하고 **Binance Smart Chain**을 선택합니다.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/cb-desktop-2.png)
3. 이제 Binance Smart Chain이 Default Network로 설정됩니다.
4. [ ](https://pancakeswap.finance)[pancakeswap.finance](https://pancakeswap.finance)를 방문합니다. 오른쪽 상단에 **Connect** 버튼이 보입니다. 클릭하세요.\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/cb-desktop-3.png)
5. 연결할 지갑을 선택하라는 창이 나타납니다. **Coinbase Wallet**을 클릭합니다 (목록 최상단 옵션입니다).\
   ![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/cb-desktop-4.png)

{% tab title="Token Pocket" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28125%29%20%283%29.png)

**데스크톱 애플리케이션**

1. 애플리케이션을 열면 DApps가 기본 페이지로 표시됩니다 (그렇지 않다면 DApps 페이지로 이동하세요).
2. 페이지 중간쯤에 선택할 수 있는 네트워크 목록이 보입니다. **BSC**를 클릭합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28260%29.png)

1. BSC DApp 목록에서 PancakeSwap 링크를 찾을 수 있습니다. **PancakeSwap** 링크를 클릭합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28290%29.png)

{% hint style="warning" %}
"PancakeSwap data analysis" 옵션은 선택하지 않도록 주의하세요. 선택하면 연결할 수 없습니다.
{% endhint %}

1. 브라우저에서 PancakeSwap 탭이 열리고 Token Pocket에 연결을 시도합니다.

{% hint style="warning" %}
동일한 웹 브라우저에서 MetaMask와 TokenPocket을 동시에 사용해 연결할 수 없습니다. 데스크톱 컴퓨터에서 TokenPocket을 사용하는 경우 MetaMask 플러그인이 설치되지 않은 웹 브라우저를 사용하세요.
{% endhint %}
