# Mulai Menggunakan PancakeSwap (BSC)

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/get-started-header.png)

Menggunakan hal baru memang bisa terasa sedikit menantang. Namun jangan khawatir, kami telah menyiapkan berbagai panduan untuk membantu Anda merasa nyaman menggunakan PancakeSwap!

## Menyiapkan PancakeSwap

Ikuti panduan-panduan ini untuk menyiapkan semua yang diperlukan dalam menggunakan PancakeSwap, atau langsung saja buka panduan yang Anda butuhkan jika Anda sudah mulai tetapi merasa kebingungan.

[Membuat Dompet](https://docs.pancakeswap.finance/get-started/wallet-guide)\
[Mendapatkan Token BEP20](https://docs.pancakeswap.finance/get-started/bep20-guide)\
[Menghubungkan Dompet Anda ke PancakeSwap](https://docs.pancakeswap.finance/get-started/connection-guide)
