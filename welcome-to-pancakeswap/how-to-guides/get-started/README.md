# Get Started (BSC)

Пользоваться чем-то новым бывает непросто. Но не переживай: мы подготовили ряд руководств, которые помогут тебе освоиться с PancakeSwap!

## Настройка PancakeSwap

Следуй этим руководствам, чтобы всё настроить для использования PancakeSwap, или переходи сразу к нужному руководству, если у тебя всё шло хорошо, но ты потерялся.

[Создание кошелька](https://docs.pancakeswap.finance/get-started/wallet-guide)\

[Подключение кошелька к PancakeSwap](https://docs.pancakeswap.finance/get-started/connection-guide)
