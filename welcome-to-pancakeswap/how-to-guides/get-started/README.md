Usar algo nuevo puede ser un poco desafiante. ¡No te preocupes! Hemos creado una serie de guías para ayudarte a familiarizarte con PancakeSwap.

## Configurar PancakeSwap

Sigue estas guías para tener todo listo y comenzar a usar PancakeSwap, o salta directamente a la guía que necesites si ya llevas un tiempo pero te has perdido.

[Conectar tu billetera a PancakeSwap](https://docs.pancakeswap.finance/get-started/connection-guide)
