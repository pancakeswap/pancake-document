# はじめに(BSC)

新しいものを使い始めるのは、少し大変に感じることがあります。でもご安心ください。PancakeSwapに慣れていただけるよう、さまざまなガイドをご用意しています。

## PancakeSwapのセットアップ

PancakeSwapを使うための準備を整えるには、以下のガイドに沿って進めてください。すでに使い始めていて途中でわからなくなった場合は、必要なガイドに直接移動していただいても構いません。

[ウォレットを作成する](https://docs.pancakeswap.finance/get-started/wallet-guide)\
[BEP20トークンを入手する](https://docs.pancakeswap.finance/welcome-to-pancakeswap/how-to-guides/get-started/bep20-guide)\
[ウォレットをPancakeSwapに接続する](https://docs.pancakeswap.finance/get-started/connection-guide)

## PancakeSwapの機能の使い方ガイド

ウォレットの準備とPancakeSwapへの接続が完了したら、以下のその他のハウツーガイドもご覧ください。

[取引の方法](https://docs.pancakeswap.finance/trade/pancakeswap-exchange/trade-guide)\
[流動性の追加/削除の方法](https://docs.pancakeswap.finance/earn/pancakeswap-pools/liquidity-guide)\
[ファームの使い方](https://docs.pancakeswap.finance/earn/yield-farming/how-to-use-farms/how-to-use-farms)\
[シロッププールでのステーキング方法](https://docs.pancakeswap.finance/earn/cake-staking/syrup-pool/syrup-pool-guide)\
[宝くじの遊び方](https://docs.pancakeswap.finance/play/lottery/lottery-guide)\
[予測の使い方](https://docs.pancakeswap.finance/play/prediction/prediction-guide)\
[IFOへの参加方法](https://docs.pancakeswap.finance/products/ifo-initial-farm-offering/ifo-guide)\
[NFTプロフィールの設定方法](https://docs.pancakeswap.finance/products/nft-profile-system/profile-guide)\
[投票の方法](https://docs.pancakeswap.finance/protocol/voting/voting-guide)

PancakeSwapの機能やサービスに関するその他のドキュメント(より高度なガイドを含む)は、メニューからご確認ください。

必要な情報が見つからない場合は、[PancakeSwap Telegram](../../contact-us/social-accounts.md)にお気軽にお越しいただき、そちらでご質問ください。
