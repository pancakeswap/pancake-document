# 지갑을 PancakeSwap에 연결하기

## 지갑 연결하기

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/wallet-connection-aptos.png" alt=""><figcaption></figcaption></figure>

1. 오른쪽 상단의 "지갑 연결(Connect Wallet)"을 클릭하세요.
2. 대부분의 브라우저 확장 프로그램 지갑은 해당 아이콘을 선택한 뒤 팝업 창의 안내를 따르면 됩니다.
3. Blocto의 경우 이메일 주소로 가입하거나 로그인하세요. 자세한 내용은 [여기](wallet-guide.md)를 확인하세요.

{% hint style="danger" %}
**기억하세요. 어떤 상황에서도 절대로 다른 사람에게 개인 키나 복구 구문을 알려주어서는 안 됩니다.**
{% endhint %}

## **Aptos 메인넷에 연결하기**
