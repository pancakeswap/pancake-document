# Подключение кошелька к PancakeSwap

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-connect-wallet-header.png)

## Подключи кошелёк

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/wallet-connection-aptos.png" alt=""><figcaption></figcaption></figure>

1. Нажми «Connect Wallet» в правом верхнем углу.
2. Для большинства расширений-кошельков для браузера просто выбери их значок и следуй инструкциям во всплывающем окне.
3. Для Blocto используй свой адрес электронной почты для регистрации или входа. Подробнее об этом читай [здесь](wallet-guide.md).

{% hint style="danger" %}
**Помни — НИКОГДА, ни при каких обстоятельствах не сообщай кому-либо свой приватный ключ или фразы для восстановления.**
{% endhint %}
