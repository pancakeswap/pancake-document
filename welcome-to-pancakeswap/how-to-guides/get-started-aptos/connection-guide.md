# Conectar tu billetera a PancakeSwap

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-connect-wallet-header.png)

## Conectar tu billetera

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/wallet-connection-aptos.png" alt=""><figcaption></figcaption></figure>

1. Haz clic en "Connect Wallet" en la esquina superior derecha.
2. Para la mayoría de las billeteras de extensión de navegador, simplemente selecciona su ícono y sigue las instrucciones de la ventana emergente.
3. Para Blocto, usa tu dirección de correo electrónico para registrarte o iniciar sesión. Para obtener más información, consulta [aquí](wallet-guide.md).

{% hint style="danger" %}
**Recuerda: NUNCA, bajo ninguna circunstancia, debes darle a alguien tu clave privada o frases de recuperación.**
{% endhint %}
