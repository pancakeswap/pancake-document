# Mendapatkan Aptos Coins

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-get-aptos-coins-header.png)

{% hint style="info" %}
Panduan ini mencakup layanan Bridging Aptos utama untuk token-token mainstream. Untuk melakukan Bridge CAKE antara Aptos dan BNB Smart Chain, gunakan [PancakeSwap Aptos Bridge](https://bridge.pancakeswap.finance/aptos).
{% endhint %}

Token asli dari Aptos Chain adalah **Aptos Coin (APT)**.

Untuk melakukan sebagian besar hal di Aptos Chain, Anda perlu membayar biaya gas yang berbentuk APT.

Anda juga memerlukan token yang ingin Anda perdagangkan atau Staking di Aptos Chain. Ada beberapa cara untuk membawa aset Anda ke Aptos Chain, berikut adalah cara yang kami rekomendasikan:

{% tabs %}
{% tab title="🌉 Aptos Bridge" %}
[**Aptos Bridge - LayerZero**](https://theaptosbridge.com/bridge)

* Aptos Bridge memungkinkan Anda melakukan bridge untuk token-token mainstream dan stablecoin ke Aptos
* Mendukung "gas on destination" - terima sejumlah kecil Aptos Coin (APT) untuk gas agar dapat memulai petualangan di Aptos Chain
* **⚠️ Catatan: untuk saat ini aset dibungkus saat di-bridge.** **(ditandai sebagai "LayerZero")**\
  Sebelum melakukan bridge token Anda, pastikan untuk memeriksa ulang daftar token guna mengetahui versi token yang dibungkus mana yang sedang Anda perdagangkan.
{% endtab %}

{% tab title="🌉 cBridge" %}
[**cBridge**](https://cbridge.celer.network/1/12360001/)

* cBridge memungkinkan Anda melakukan bridge untuk token-token mainstream dan stablecoin ke Aptos
* **⚠️ Catatan: untuk saat ini aset dibungkus saat di-bridge.** **(ditandai sebagai "Celer")**\
  Sebelum melakukan bridge token Anda, pastikan untuk memeriksa ulang daftar token guna mengetahui versi token yang dibungkus mana yang sedang Anda perdagangkan.

**📖** [**Tutorial cBridge yang Disediakan oleh Celer**](https://cbridge-docs.celer.network/tutorial/cross-chain-transfer)
{% endtab %}

{% tab title="🌉 Wormhole" %}
[**Wormhole - Portal Token Bridge**](https://www.portalbridge.com/#/transfer)

* Portal Token Bridge memungkinkan Anda melakukan bridge untuk token-token mainstream dan stablecoin ke Aptos
* **⚠️ Catatan: aset dibungkus saat di-bridge.** **(ditandai sebagai "Wormhole")**\
  Sebelum melakukan bridge token Anda, pastikan untuk memeriksa ulang daftar token guna mengetahui versi token yang dibungkus mana yang sedang Anda perdagangkan.

[**📖 Tutorial yang disediakan oleh Wormhole**](https://docs.wormhole.com/wormhole/video-tutorial-how-to-use-portal)
{% endtab %}

{% tab title="🥞 CAKE Bridging" %}
Untuk melakukan Bridge token CAKE antara Aptos dan BNB Smart Chain, gunakan [PancakeSwap Aptos Bridge](https://bridge.pancakeswap.finance/aptos). Lihat [panduan](cake-bridging-guide.md) untuk mempelajari cara menggunakannya.
{% endtab %}

{% tab title="💰 Binance.com" %}
[**Binance.com**](https://www.binance.com/en/)

* Anda dapat menarik Aptos Coin (APT) di Aptos Chain melalui akun Binance Anda.&#x20;
* **⚠️ Saat ini hanya Aptos Coin (APT) yang didukung. Untuk melakukan bridge aset lainnya, lihat opsi bridging lain yang tersedia di atas.**
* **⚠️ Anda memerlukan akun untuk melakukan hal ini.**

📖 [Berikut adalah panduan singkat yang mereka buat untuk membantu Anda.](https://www.binance.com/en/support/faq/85a1c394ac1d489fb0bfac0ef2fceafd)
