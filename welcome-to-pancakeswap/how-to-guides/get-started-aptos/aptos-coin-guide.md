# Aptos Coins erhalten

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-get-aptos-coins-header.png)

{% hint style="info" %}
Diese Anleitung behandelt die wichtigsten Aptos Bridging-Dienste für gängige Token. Um CAKE zwischen Aptos und der BNB Smart Chain zu bridgen, verwenden Sie die [PancakeSwap Aptos Bridge](https://bridge.pancakeswap.finance/aptos).
{% endhint %}

Der native Token der Aptos Chain ist **Aptos Coin (APT)**.

Für die meisten Aktionen auf der Aptos Chain benötigen Sie Gas in Form von APT.

Sie benötigen außerdem die Token, die Sie auf der Aptos Chain handeln oder staken möchten. Es gibt mehrere Möglichkeiten, Ihre Assets auf die Aptos Chain zu übertragen. Wir empfehlen folgende:

{% tabs %}
{% tab title="🌉 Aptos Bridge" %}
[**Aptos Bridge - LayerZero**](https://theaptosbridge.com/bridge)

* Die Aptos Bridge ermöglicht es Ihnen, gängige Token und Stablecoins zu Aptos zu bridgen
* Unterstützt „Gas on Destination" – erhalten Sie eine kleine Menge Aptos Coin (APT) für Gas, um Ihr Aptos-Chain-Abenteuer zu starten
* **⚠️ Hinweis: Derzeit werden Assets beim Bridging eingewickelt.** **(markiert als „LayerZero")**\
  Überprüfen Sie vor dem Bridging Ihrer Token die Token-Liste, um zu sehen, welche eingewickelte Version der Token Sie handeln.
{% endtab %}

{% tab title="🌉 cBridge" %}
[**cBridge**](https://cbridge.celer.network/1/12360001/)

* Die cBridge ermöglicht es Ihnen, gängige Token und Stablecoins zu Aptos zu bridgen
* **⚠️ Hinweis: Derzeit werden Assets beim Bridging eingewickelt.** **(markiert als „Celer")**\
  Überprüfen Sie vor dem Bridging Ihrer Token die Token-Liste, um zu sehen, welche eingewickelte Version der Token Sie handeln.

**📖** [**cBridge-Tutorial von Celer**](https://cbridge-docs.celer.network/tutorial/cross-chain-transfer)
{% endtab %}

{% tab title="🌉 Wormhole" %}
[**Wormhole - Portal Token Bridge**](https://www.portalbridge.com/#/transfer)

* Die Portal Token Bridge ermöglicht es Ihnen, gängige Token und Stablecoins zu Aptos zu bridgen
* **⚠️ Hinweis: Assets werden beim Bridging eingewickelt.** **(markiert als „Wormhole")**\
  Überprüfen Sie vor dem Bridging Ihrer Token die Token-Liste, um zu sehen, welche eingewickelte Version der Token Sie handeln.

[**📖 Tutorial von Wormhole**](https://docs.wormhole.com/wormhole/video-tutorial-how-to-use-portal)
{% endtab %}

{% tab title="🥞 CAKE Bridging" %}
Um CAKE-Token zwischen Aptos und der BNB Smart Chain zu bridgen, verwenden Sie die [PancakeSwap Aptos Bridge](https://bridge.pancakeswap.finance/aptos). Lesen Sie die [Anleitung](cake-bridging-guide.md), um mehr über die Nutzung zu erfahren.
{% endtab %}

{% tab title="💰 Binance.com" %}
[**Binance.com**](https://www.binance.com/en/)

* Sie können Aptos Coin (APT) auf der Aptos Chain über Ihr Binance-Konto abheben.&#x20;
* **⚠️ Derzeit wird nur Aptos Coin (APT) unterstützt. Um andere Assets zu bridgen, lesen Sie bitte die anderen verfügbaren Bridging-Optionen oben.**
* **⚠️ Hierfür benötigen Sie ein Konto.**

📖 [Hier finden Sie eine kurze Anleitung, die Ihnen weiterhelfen kann.](https://www.binance.com/en/support/faq/85a1c394ac1d489fb0bfac0ef2fceafd)
{% endtab %}
