# Obtenir des Aptos Coins

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-get-aptos-coins-header.png)

{% hint style="info" %}
Ce guide présente les principaux services de Bridging sur Aptos pour les tokens courants. Pour effectuer un Bridge de CAKE entre Aptos et BNB Smart Chain, utilisez le [PancakeSwap Aptos Bridge](https://bridge.pancakeswap.finance/aptos).
{% endhint %}

Le token natif de la chaîne Aptos est l'**Aptos Coin (APT)**.

Pour effectuer la plupart des opérations sur la chaîne Aptos, vous devrez payer des frais de réseau (gas), réglés en APT.

Vous aurez également besoin des tokens que vous souhaitez échanger ou staker sur la chaîne Aptos. Il existe plusieurs façons de transférer vos actifs vers Aptos, mais voici celles que nous recommandons :

{% tabs %}
{% tab title="🌉 Aptos Bridge" %}
[**Aptos Bridge - LayerZero**](https://theaptosbridge.com/bridge)

* L'Aptos Bridge vous permet de transférer des tokens courants et des stablecoins vers Aptos
* Prend en charge le "gas on destination" — recevez une petite quantité d'Aptos Coin (APT) pour couvrir vos premiers frais de réseau sur Aptos
* **⚠️ Remarque : pour l'instant, les actifs sont wrappés lors du Bridge.** **(marqués comme "LayerZero")**\
  Avant de transférer vos tokens, vérifiez bien la liste des tokens pour identifier la version wrappée que vous allez échanger.
{% endtab %}

{% tab title="🌉 cBridge" %}
[**cBridge**](https://cbridge.celer.network/1/12360001/)

* Le cBridge vous permet de transférer des tokens courants et des stablecoins vers Aptos
* **⚠️ Remarque : pour l'instant, les actifs sont wrappés lors du Bridge.** **(marqués comme "Celer")**\
  Avant de transférer vos tokens, vérifiez bien la liste des tokens pour identifier la version wrappée que vous allez échanger.

**📖** [**Tutoriel cBridge fourni par Celer**](https://cbridge-docs.celer.network/tutorial/cross-chain-transfer)
{% endtab %}

{% tab title="🌉 Wormhole" %}
[**Wormhole - Portal Token Bridge**](https://www.portalbridge.com/#/transfer)

* Le Portal Token Bridge vous permet de transférer des tokens courants et des stablecoins vers Aptos
* **⚠️ Remarque : les actifs sont wrappés lors du Bridge.** **(marqués comme "Wormhole")**\
  Avant de transférer vos tokens, vérifiez bien la liste des tokens pour identifier la version wrappée que vous allez échanger.

[**📖 Tutoriel fourni par Wormhole**](https://docs.wormhole.com/wormhole/video-tutorial-how-to-use-portal)
{% endtab %}

{% tab title="🥞 CAKE Bridging" %}
Pour effectuer un Bridge du token CAKE entre Aptos et BNB Smart Chain, utilisez le [PancakeSwap Aptos Bridge](https://bridge.pancakeswap.finance/aptos). Consultez le [guide](cake-bridging-guide.md) pour apprendre à l'utiliser.
{% endtab %}

{% tab title="💰 Binance.com" %}
[**Binance.com**](https://www.binance.com/en/)

* Vous pouvez retirer des Aptos Coin (APT) sur la chaîne Aptos via votre compte Binance.&#x20;
* **⚠️ Seul l'Aptos Coin (APT) est actuellement pris en charge. Pour transférer d'autres actifs, consultez les autres options de Bridging disponibles ci-dessus.**
* **⚠️ Un compte est nécessaire pour effectuer cette opération.**

📖 [Voici un guide rapide pour vous aider.](https://www.binance.com/en/support/faq/85a1c394ac1d489fb0bfac0ef2fceafd)
{% endtab %}
