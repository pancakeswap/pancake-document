# Obtener Aptos Coins

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-get-aptos-coins-header.png)

{% hint style="info" %}
Esta guía cubre los principales servicios de puenteo de Aptos para tokens convencionales. Para puentear CAKE entre Aptos y BNB Smart Chain, usa el [PancakeSwap Aptos Bridge](https://bridge.pancakeswap.finance/aptos).
{% endhint %}

El token nativo de Aptos Chain es **Aptos Coin (APT)**.

Para hacer la mayoría de las cosas en Aptos Chain, necesitarás pagar gas, que viene en forma de APT.

También necesitarás los tokens que quieras intercambiar o hacer Staking en Aptos Chain. Hay varias formas de llevar tus activos a Aptos Chain, pero aquí están las que recomendamos:

{% tabs %}
{% tab title="🌉 Aptos Bridge" %}
[**Aptos Bridge - LayerZero**](https://theaptosbridge.com/bridge)

* El Aptos Bridge te permite puentear tokens convencionales y stablecoins a Aptos
* Compatible con "gas en destino": recibe una pequeña cantidad de Aptos Coin (APT) para gas y empieza tu aventura en Aptos Chain
* **⚠️ Nota: por ahora, los activos se envuelven al puentearlos.** **(marcados como "LayerZero")**\
  Antes de puentear tus tokens, asegúrate de revisar la lista de tokens para ver qué versión envuelta de los tokens estás intercambiando.
{% endtab %}

{% tab title="🌉 cBridge" %}
[**cBridge**](https://cbridge.celer.network/1/12360001/)

* cBridge te permite puentear tokens convencionales y stablecoins a Aptos
* **⚠️ Nota: por ahora, los activos se envuelven al puentearlos.** **(marcados como "Celer")**\
  Antes de puentear tus tokens, asegúrate de revisar la lista de tokens para ver qué versión envuelta de los tokens estás intercambiando.

**📖** [**Tutorial de cBridge proporcionado por Celer**](https://cbridge-docs.celer.network/tutorial/cross-chain-transfer)
{% endtab %}

{% tab title="🌉 Wormhole" %}
[**Wormhole - Portal Token Bridge**](https://www.portalbridge.com/#/transfer)

* El Portal Token Bridge te permite puentear tokens convencionales y stablecoins a Aptos
* **⚠️ Nota: los activos se envuelven al puentearlos.** **(marcados como "Wormhole")**\
  Antes de puentear tus tokens, asegúrate de revisar la lista de tokens para ver qué versión envuelta de los tokens estás intercambiando.

[**📖 Tutorial proporcionado por Wormhole**](https://docs.wormhole.com/wormhole/video-tutorial-how-to-use-portal)
{% endtab %}

{% tab title="🥞 CAKE Bridging" %}
Para puentear el token CAKE entre Aptos y BNB Smart Chain, usa el [PancakeSwap Aptos Bridge](https://bridge.pancakeswap.finance/aptos). Consulta la [guía](cake-bridging-guide.md) para aprender cómo usarlo.
{% endtab %}

{% tab title="💰 Binance.com" %}
[**Binance.com**](https://www.binance.com/en/)

* Puedes retirar Aptos Coin (APT) en Aptos Chain desde tu cuenta de Binance.&#x20;
* **⚠️ Por el momento, solo se admite Aptos Coin (APT). Para puentear otros activos, consulta las otras opciones de puenteo disponibles arriba.**
* **⚠️ Necesitas una cuenta para hacerlo.**

📖 [Aquí hay una guía rápida que han creado para ayudarte.](https://www.binance.com/en/support/faq/85a1c394ac1d489fb0bfac0ef2fceafd)
{% endtab %}
