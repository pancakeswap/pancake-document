# Obter Aptos Coins

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-get-aptos-coins-header.png)

{% hint style="info" %}
Este guia abrange os principais serviços de bridging da Aptos para tokens principais. Para fazer Bridge de CAKE entre Aptos e BNB Smart Chain, use a [PancakeSwap Aptos Bridge](https://bridge.pancakeswap.finance/aptos).
{% endhint %}

O token nativo da Aptos Chain é o **Aptos Coin (APT)**.

Para fazer a maioria das coisas na Aptos Chain, você precisará pagar gas, que vem na forma de APT.

Você também precisará dos tokens que deseja negociar ou fazer Staking na Aptos Chain. Existem algumas maneiras de trazer seus ativos para a Aptos Chain, mas aqui estão as que recomendamos:

{% tabs %}
{% tab title="🌉 Aptos Bridge" %}
[**Aptos Bridge - LayerZero**](https://theaptosbridge.com/bridge)

* A Aptos Bridge permite fazer bridge de tokens principais e stablecoins para a Aptos
* Suporta "gas on destination" - receba uma pequena quantidade de Aptos Coin (APT) para gas para iniciar sua aventura na Aptos Chain
* **⚠️ Nota: por enquanto, os ativos são embrulhados quando bridgeados.** **(marcados como "LayerZero")**\
  Antes de fazer bridge dos seus tokens, verifique a lista de tokens para ver qual versão embrulhada dos tokens você está negociando.
{% endtab %}

{% tab title="🌉 cBridge" %}
[**cBridge**](https://cbridge.celer.network/1/12360001/)

* A cBridge permite fazer bridge de tokens principais e stablecoins para a Aptos
* **⚠️ Nota: por enquanto, os ativos são embrulhados quando bridgeados.** **(marcados como "Celer")**\
  Antes de fazer bridge dos seus tokens, verifique a lista de tokens para ver qual versão embrulhada dos tokens você está negociando.

**📖** [**Tutorial da cBridge fornecido pela Celer**](https://cbridge-docs.celer.network/tutorial/cross-chain-transfer)
{% endtab %}

{% tab title="🌉 Wormhole" %}
[**Wormhole - Portal Token Bridge**](https://www.portalbridge.com/#/transfer)

* A Portal Token Bridge permite fazer bridge de tokens principais e stablecoins para a Aptos
* **⚠️ Nota: os ativos são embrulhados quando bridgeados.** **(marcados como "Wormhole")**\
  Antes de fazer bridge dos seus tokens, verifique a lista de tokens para ver qual versão embrulhada dos tokens você está negociando.

[**📖 Tutorial fornecido pelo Wormhole**](https://docs.wormhole.com/wormhole/video-tutorial-how-to-use-portal)
{% endtab %}

{% tab title="🥞 CAKE Bridging" %}
Para fazer Bridge do token CAKE entre Aptos e BNB Smart Chain, use a [PancakeSwap Aptos Bridge](https://bridge.pancakeswap.finance/aptos). Confira o [guia](cake-bridging-guide.md) para aprender como usá-la.
{% endtab %}

{% tab title="💰 Binance.com" %}
[**Binance.com**](https://www.binance.com/en/)

* Você pode sacar Aptos Coin (APT) na Aptos Chain por meio da sua conta Binance.&#x20;
* **⚠️ Atualmente, apenas Aptos Coin (APT) é suportado. Para fazer bridge de outros ativos, confira as outras opções de bridging disponíveis acima.**
* **⚠️ Você precisa de uma conta para fazer isso.**

📖 [Aqui está um guia rápido que eles criaram para ajudar você.](https://www.binance.com/en/support/faq/85a1c394ac1d489fb0bfac0ef2fceafd)
{% endtab %}
{% endtabs %}
