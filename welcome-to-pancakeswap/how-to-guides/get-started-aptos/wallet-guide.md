# Crear una billetera

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

Para comenzar tu aventura con PancakeSwap en Aptos, lo primero que necesitas es configurar una billetera compatible con Aptos Chain. Las billeteras están disponibles tanto en computadoras de escritorio como en dispositivos móviles. Deberás elegir la que mejor se adapte a tus necesidades.

{% hint style="danger" %}
**Al configurar una billetera, asegúrate de:**

* ✅ **Descargar e instalar solo la versión más reciente desde una fuente oficial.**
* ✅ **Seguir cuidadosamente la guía de configuración.**
* ✅ **Hacer una copia de seguridad segura de tus frases de recuperación.**
* ❌ **NUNCA compartas tus frases de recuperación con nadie, bajo ninguna circunstancia.**
* ❌ **NUNCA ingreses tu frase de recuperación en un sitio web o aplicación que no sea tu billetera.**
{% endhint %}

## ¿Billetera móvil o de escritorio?

{% hint style="warning" %}
Al momento de escribir esto, hay un número limitado de billeteras móviles con soporte para Aptos. Los Chefs incluirán más billeteras en el tutorial cuando estén disponibles.

**Recomendamos usar** [**billeteras de escritorio**](wallet-guide.md#desktop-web-browser-wallets) **hasta que haya más billeteras móviles disponibles.**
{% endhint %}

Las billeteras para dispositivos móviles y las de escritorio tienen diferentes fortalezas y debilidades. Considera cuál se adapta mejor a tus necesidades para decidir qué tipo de billetera usar.

|                                   | Móvil | Escritorio |
| --------------------------------- | ------ | ------- |
| Úsala en cualquier lugar          | ✅      | ➖       |
| Fácil de usar                     | ✅      | ➖       |
| Más segura                        | ➖      | ✅       |
| Accesibilidad                     | ➖      | ✅       |
| Resistente a daños/pérdidas/robo  | ➖      | ✅       |
| Resistente a cortes de corriente/conexión | ✅ | ➖    |

[**Descargar FewCha Wallet**](https://fewcha.app/)

**Guía de configuración de Fewcha wallet**

1\. Una vez que la extensión Fewcha Wallet termine de descargarse, aparecerá una pestaña de bienvenida. Aquí puedes seleccionar "Create a new wallet" (o "Use an existing wallet" si ya tienes una).

3\. Para la frase de recuperación, escríbela o cópiala y guárdala en un lugar que puedas recordar.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28108%29.png" alt=""><figcaption></figcaption></figure>

> * **NUNCA** compartas tus frases de recuperación con nadie, bajo ninguna circunstancia.
> * **NUNCA** ingreses tu frase de recuperación en un sitio web o aplicación que no sea tu billetera.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28203%29.png" alt=""><figcaption></figcaption></figure>
