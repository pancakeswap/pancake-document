# 创建钱包

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

要在 Aptos 上开启你的 PancakeSwap 之旅，你首先需要设置一个支持 Aptos 链的钱包。钱包既有桌面电脑版本，也有智能手机设备版本。你需要选择最适合你需求的钱包。

{% hint style="danger" %}
**在设置钱包时，请务必：**

* ✅ **只从官方来源下载并安装最新版本。**
* ✅ **仔细按照设置指南操作。**
* ✅ **安全地备份你的助记词。**
* ❌ **在任何情况下，都绝不要与任何人分享你的助记词。**
* ❌ **绝不要在钱包应用以外的任何网站或应用中输入你的助记词。**
{% endhint %}

## 智能手机/移动钱包还是桌面钱包？

{% hint style="warning" %}
在撰写本文时，支持 Aptos 的移动钱包数量有限。当更多钱包可用时，Chefs 会在教程中加入它们。

**我们建议使用**[**桌面钱包**](wallet-guide.md#desktop-web-browser-wallets)**，直到有更多移动钱包准备就绪。**
{% endhint %}

移动设备钱包和桌面钱包各有优势和劣势。请考虑哪种更适合你的需求，以帮助决定使用哪种类型的钱包。

|                                   | 移动端 | 桌面端 |
| --------------------------------- | ------ | ------- |
| 随处可用                      | ✅      | ➖       |
| 易于使用                       | ✅      | ➖       |
| 更安全                       | ➖      | ✅       |
| 无障碍友好            | ➖      | ✅       |
| 抗损坏/丢失/盗窃       | ➖      | ✅       |
| 抗断电/断网 | ✅      | ➖       |
