# Cüzdan Oluştur

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

Aptos'ta PancakeSwap yolculuğuna başlamak için öncelikle Aptos Chain'i destekleyen bir cüzdan kurman gerekiyor. Cüzdanlar hem masaüstü bilgisayarlar hem de akıllı telefonlar için mevcuttur. İhtiyaçlarına en uygun cüzdanı seçmen gerekiyor.

{% hint style="danger" %}
**Cüzdan kurarken şunlara dikkat et:**

* ✅ **Yalnızca resmi kaynaktan en güncel sürümü indirip kur.**
* ✅ **Kurulum rehberini dikkatlice takip et.**
* ✅ **Kurtarma ifadelerini güvenli bir şekilde yedekle.**
* ❌ **Kurtarma ifadelerini hiçbir koşulda hiç kimseyle PAYLAŞMA.**
* ❌ **Kurtarma ifadeni cüzdan uygulamasının dışında hiçbir web sitesine veya uygulamaya GİRME.**
{% endhint %}

## Akıllı Telefon/Mobil mi Masaüstü Cüzdanı mı?

{% hint style="warning" %}
Bu yazının hazırlandığı sırada Aptos desteği olan sınırlı sayıda mobil cüzdan bulunmaktadır. Daha fazla mobil cüzdan hazır olduğunda Chefs bunları eğitime ekleyecektir.

Daha fazla mobil cüzdan hazır olana kadar [**masaüstü cüzdanlarını**](wallet-guide.md#desktop-web-browser-wallets) **kullanmanı öneririz.**
{% endhint %}

Mobil cihaz cüzdanları ile masaüstü tabanlı cüzdanların farklı güçlü ve zayıf yönleri vardır. Hangi cüzdan türünü kullanacağına karar vermek için hangisinin ihtiyaçlarına daha uygun olduğunu değerlendir.

|                                   | Mobil | Masaüstü |
| --------------------------------- | ------ | ------- |
| Her yerden kullanım               | ✅      | ➖       |
| Kullanım kolaylığı                | ✅      | ➖       |
| Daha güvenli                      | ➖      | ✅       |
| Erişilebilirlik                   | ➖      | ✅       |
| Hasar/kayıp/hırsızlığa dayanıklı  | ➖      | ✅       |
| Güç/bağlantı kesintisine dayanıklı| ✅      | ➖       |
