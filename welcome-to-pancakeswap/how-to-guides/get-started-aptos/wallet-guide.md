# Eine Wallet erstellen

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

Um Ihre PancakeSwap-Reise auf Aptos zu beginnen, müssen Sie zunächst eine Wallet einrichten, die die Aptos Chain unterstützt. Wallets sind sowohl für Desktop-Computer als auch für Smartphones verfügbar. Sie müssen die Wallet auswählen, die Ihren Anforderungen am besten entspricht.

{% hint style="danger" %}
**Beim Einrichten einer Wallet sollten Sie Folgendes beachten:**

* ✅ **Laden Sie nur die neueste Version von einer offiziellen Quelle herunter und installieren Sie diese.**
* ✅ **Folgen Sie der Einrichtungsanleitung sorgfältig.**
* ✅ **Sichern Sie Ihre Wiederherstellungsphrasen sicher.**
* ❌ **Geben Sie Ihre Wiederherstellungsphrasen NIEMALS an jemanden weiter, unter keinen Umständen.**
* ❌ **Geben Sie Ihre Wiederherstellungsphrase NIEMALS auf einer Website oder in einer App ein, außer in Ihrer Wallet-App.**
{% endhint %}

## Smartphone-/Mobile- oder Desktop-Wallet?

{% hint style="warning" %}
Zum Zeitpunkt der Erstellung dieser Anleitung gibt es eine begrenzte Anzahl von mobilen Wallets mit Aptos-Unterstützung. Die Chefs werden weitere Wallets in das Tutorial aufnehmen, sobald diese verfügbar sind.

**Wir empfehlen die Verwendung von** [**Desktop-Wallets**](wallet-guide.md#desktop-web-browser-wallets) **bis mehr mobile Wallets verfügbar sind.**
{% endhint %}

Mobile Wallets und Desktop-Wallets haben unterschiedliche Stärken und Schwächen. Überlegen Sie, welche Variante Ihren Anforderungen besser entspricht, um zu entscheiden, welchen Wallet-Typ Sie verwenden möchten.

|                                         | Mobil | Desktop |
| --------------------------------------- | ----- | ------- |
| Überall verwendbar                      | ✅     | ➖       |
| Einfach zu verwenden                    | ✅     | ➖       |
| Sicherer                                | ➖     | ✅       |
| Barrierefreiheit                        | ➖     | ✅       |
| Schutz vor Beschädigung/Verlust/Diebstahl | ➖   | ✅       |
| Schutz bei Strom-/Verbindungsausfall    | ✅     | ➖       |
