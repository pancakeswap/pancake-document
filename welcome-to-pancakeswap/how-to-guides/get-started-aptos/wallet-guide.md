# Crea un Portafoglio

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

Per iniziare il tuo percorso su PancakeSwap su Aptos, la prima cosa di cui hai bisogno è configurare un Portafoglio che supporti Aptos Chain. I Portafogli sono disponibili sia su computer desktop che su dispositivi smartphone. Dovrai scegliere il Portafoglio più adatto alle tue esigenze.

{% hint style="danger" %}
**Quando configuri un Portafoglio, assicurati di:**

* ✅ **Scaricare e installare solo l'ultima versione da una fonte ufficiale.**
* ✅ **Seguire attentamente la guida di configurazione.**
* ✅ **Fare un backup sicuro delle tue frasi di recupero.**
* ❌ **NON condividere MAI le tue frasi di recupero con nessuno, in nessuna circostanza.**
* ❌ **NON inserire MAI la tua Frase seed su un sito web o un'app, tranne che sulla tua app Portafoglio.**
{% endhint %}

## Portafoglio smartphone/mobile o desktop?

{% hint style="warning" %}
Al momento della stesura, c'è un numero limitato di Portafogli mobile con supporto per Aptos. I Chefs includeranno più Portafogli nel tutorial non appena saranno disponibili.

**Consigliamo di usare i** [**Portafogli desktop**](wallet-guide.md#desktop-web-browser-wallets) **finché non saranno pronti più Portafogli mobile.**
{% endhint %}

I Portafogli su dispositivi mobile e quelli su desktop hanno punti di forza e debolezze diverse. Considera quale si adatta meglio alle tue esigenze per decidere quale tipo di Portafoglio usare.

|                                   | Mobile | Desktop |
| --------------------------------- | ------ | ------- |
| Utilizzo ovunque                  | ✅      | ➖       |
| Facile da usare                   | ✅      | ➖       |
| Più sicuro                        | ➖      | ✅       |
| Accessibilità                     | ➖      | ✅       |
| Resistente a danni/perdita/furto  | ➖      | ✅       |
| Resistente a interruzioni di corrente/connessione | ✅      | ➖       |
