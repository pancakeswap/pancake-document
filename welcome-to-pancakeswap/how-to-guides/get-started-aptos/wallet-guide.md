# ウォレットを作成する

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

AptosでPancakeSwapの旅を始めるには、まずAptosチェーンに対応したウォレットをセットアップする必要があります。ウォレットはデスクトップパソコンとスマートフォンの両方でご利用いただけます。ご自身のニーズに最適なウォレットをお選びください。

{% hint style="danger" %}
**ウォレットのセットアップ時には、必ず以下の点にご注意ください。**

* ✅ **公式ソースから最新バージョンのみをダウンロードしてインストールする。**
* ✅ **セットアップガイドを注意深く読んで従う。**
* ✅ **リカバリーフレーズを安全にバックアップする。**
* ❌ **いかなる状況においても、リカバリーフレーズを絶対に他人と共有しない。**
* ❌ **ウォレットアプリ以外のウェブサイトやアプリにリカバリーフレーズを入力しない。**
{% endhint %}

## スマートフォン/モバイルまたはデスクトップウォレット？

{% hint style="warning" %}
執筆時点では、Aptosに対応したモバイルウォレットの数は限られています。より多くのモバイルウォレットが利用可能になった際には、チェフがチュートリアルに追加する予定です。

**より多くのモバイルウォレットが準備されるまでは、[デスクトップウォレット](wallet-guide.md#desktop-web-browser-wallets)のご利用を推奨します。**
{% endhint %}

モバイルウォレットとデスクトップウォレットはそれぞれ異なる長所と短所があります。どちらのタイプのウォレットを使用するか決める際の参考にしてください。

|                                   | モバイル | デスクトップ |
| --------------------------------- | ------ | ------- |
| どこでも使える                      | ✅      | ➖       |
| 使いやすい                         | ✅      | ➖       |
| よりセキュア                        | ➖      | ✅       |
| アクセシビリティに配慮                | ➖      | ✅       |
| 破損・紛失・盗難への耐性              | ➖      | ✅       |
| 電源/接続障害への耐性                | ✅      | ➖       |
