# Buat Dompet

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-make-a-crypto-wallet-header.png)

Untuk memulai perjalanan PancakeSwap Anda di Aptos, hal pertama yang perlu Anda lakukan adalah menyiapkan dompet yang mendukung Aptos Chain. Dompet tersedia baik di komputer desktop maupun perangkat smartphone. Anda perlu memilih dompet yang paling sesuai dengan kebutuhan Anda.

{% hint style="danger" %}
**Saat menyiapkan dompet, pastikan untuk:**

* ✅ **Unduh dan instal hanya versi terbaru dari sumber resmi.**
* ✅ **Ikuti panduan pengaturan dengan cermat.**
* ✅ **Cadangkan frasa pemulihan Anda dengan aman.**
* ❌ **JANGAN PERNAH membagikan frasa pemulihan Anda kepada siapa pun, dalam keadaan apa pun.**
* ❌ **JANGAN PERNAH memasukkan frasa pemulihan Anda ke situs web atau aplikasi mana pun, selain aplikasi dompet Anda.**
{% endhint %}

## Dompet Smartphone/Mobile atau Desktop?

{% hint style="warning" %}
Pada saat penulisan ini, jumlah dompet mobile yang mendukung Aptos masih terbatas. Para Chef akan menambahkan lebih banyak dompet dalam tutorial ini ketika tersedia.

**Kami merekomendasikan penggunaan** [**dompet desktop**](wallet-guide.md#desktop-web-browser-wallets) **sampai lebih banyak dompet mobile siap digunakan.**
{% endhint %}

Dompet perangkat mobile dan dompet berbasis desktop memiliki kelebihan dan kekurangan masing-masing. Pertimbangkan mana yang lebih sesuai dengan kebutuhan Anda untuk membantu menentukan jenis dompet yang akan digunakan.

|                                   | Mobile | Desktop |
| --------------------------------- | ------ | ------- |
| Dapat digunakan di mana saja      | ✅      | ➖       |
| Mudah digunakan                   | ✅      | ➖       |
| Lebih aman                        | ➖      | ✅       |
| Ramah aksesibilitas               | ➖      | ✅       |
| Tahan terhadap kerusakan/kehilangan/pencurian | ➖      | ✅       |
| Tahan terhadap gangguan daya/koneksi | ✅      | ➖       |

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28196%29.png" alt=""><figcaption></figcaption></figure>

Fewcha adalah dompet kripto terpercaya yang dioptimalkan untuk ekosistem Aptos dan SUI yang membuka berbagai aplikasi di web3.

**Keunggulan:**

* Mendukung Blockchain Aptos dan Sui
* Dompet pertama yang mendukung blockchain murni menggunakan bahasa Move
* UX/UI yang ramah pengguna
* Sederhana, elegan, dan mudah digunakan
* Swapper dalam aplikasi
* Stake dalam aplikasi
* Berbagai bahasa
* Protokol EBCI - protokol yang mencegah beberapa pop-up saat berinteraksi dengan dApp, membantu pengguna mengelola dApp mana yang sedang mereka tandatangani untuk sebuah transaksi.
* Mendukung Koneksi Hardware Wallet (Keystone Wallet)

[**Unduh FewCha Wallet**](https://fewcha.app/)

**Panduan pengaturan Fewcha wallet**

1\. Setelah ekstensi Fewcha Wallet selesai diunduh, tab sambutan akan muncul. Di sini Anda dapat memilih "Create a new wallet" (atau "Use an existing wallet" jika Anda sudah memilikinya.)

<figure><img src="https://lh5.googleusercontent.com/xzkPxptL1JdM_IcX3jEH8J1JpEC9uWabA5QUJzKBRIqszgGeOUh67QuQx7Y6BCzv1UIXshZuxrCCgZe6wYhxCZ4JbjcbtYIdP_zO9A6VDiQgypsbr2wlvqUjhioyPsRDVOYTBJv_smcjhODx3zHnqrTvxiJzWMhZa3e4TvG3lfAqFtE6-47N08s" alt=""><figcaption></figcaption></figure>

3\. Untuk Frasa Pemulihan, tuliskan atau salin untuk disimpan di tempat yang dapat Anda ingat.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28108%29.png" alt=""><figcaption></figcaption></figure>

> * Cadangkan frasa pemulihan Anda dengan aman. Jika Anda kehilangan frasa pemulihan, Anda mungkin kehilangan akses ke dompet dan kripto di dalamnya selamanya.
> * **JANGAN PERNAH** membagikan frasa pemulihan Anda kepada siapa pun, dalam keadaan apa pun.
> * **JANGAN PERNAH** memasukkan frasa pemulihan Anda ke situs web atau aplikasi mana pun, selain aplikasi dompet Anda**.**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28203%29.png" alt=""><figcaption></figcaption></figure>

4\. Klik Finish untuk menyelesaikan proses pengaturan ini. Selesai! Setelah dompet Anda dibuat, Anda dapat mengaksesnya kapan saja dengan mengklik ikon Fewcha Wallet di bilah ekstensi.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28324%29.png" alt=""><figcaption></figcaption></figure>
