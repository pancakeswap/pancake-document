# 스테이킹 마이그레이션하기

![ICYDK: you are currently reading the "tutorial" mentioned in this banner](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration%20pre%20heat.png)

스테이킹 보상을 계속 받으려면 파밍 및 풀 스테이킹을 새로운 MasterChef로 마이그레이션해야 합니다. 걱정하지 마세요. 어렵지 않습니다.

{% hint style="info" %}
**잠깐! 마이그레이션이 필요한가요?**

다음에 해당하면 마이그레이션이 필요합니다.

* PancakeSwap **파밍**에서 파밍 중인 경우
* PancakeSwap **CAKE 시럽 풀**(Manual, Auto, IFO)에 스테이킹 중인 경우

\*다른 시럽 풀은 영향을 받지 않습니다
{% endhint %}

## 마이그레이션 방법

![At the time of the migration, Chefs will deploy a step-by-step helper to walk you through the process ](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-overview.png)

### 1. 마이그레이션 도우미로 이동하기

[https://pancakeswap.finance/migration](https://pancakeswap.finance/migration)로 이동하여 지갑을 연결하세요.

### 2. 이전 파밍에서 언스테이킹하기

마이그레이션 도우미에는 두 단계가 있습니다. 첫 번째 단계에서는 현재 스테이킹 중인 세 개의 CAKE 시럽 풀과 파밍 목록이 표시됩니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-3.png)

각 파밍과 풀에서 "**Unstake All**"(모두 언스테이킹)을 클릭하여 모든 자산을 언스테이킹하세요.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-4%20%281%29.png)

언스테이킹이 끝나면 "**Go to Stake**"(스테이킹으로 이동)를 클릭하여 2단계로 진행하세요.

### 3. LP 토큰과 CAKE를 새로운 파밍 및 풀에 스테이킹하기

여기에서 새로운 CAKE 시럽 풀과 새로운 파밍이 표시됩니다. 스테이킹하기 전에 먼저 활성화해야 합니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-5%20%281%29.png)

"**Enable**"(활성화)을 클릭하여 각 파밍과 CAKE 시럽 풀에서 스테이킹을 활성화하세요. 모바일 기기를 사용 중이라면 "**Enable**" 버튼을 찾을 때 "**v**"(아래쪽 화살표)를 클릭하여 카드를 펼치세요.

활성화한 후에는 풀과 파밍에서 스테이킹을 시작할 수 있습니다.

{% tabs %}
{% tab title="CAKE 시럽 풀" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-7%20%282%29.png)

CAKE 시럽 풀의 경우 다음과 같이 하세요.

1. "Stake CAKE" 섹션에서 "**Flexible**"(유연형)을 클릭하세요.
2. 스테이킹할 CAKE 수량을 입력하세요.
3. "**Confirm**"(확인)을 클릭하세요.



{% hint style="info" %}
락업(고정 기간) 스테이킹 옵션은 마이그레이션 며칠 후에 제공될 예정입니다. 유연형 스테이킹 포지션을 락업형으로 전환할 수 있게 됩니다. 고정 기간 스테이킹이 포함된 새로운 CAKE 시럽 풀에 대해 자세히 알아보려면 [이 문서](../../../../archive/legacy-products/new-cake-pool/)를 확인하세요.
{% endhint %}
{% endtab %}

{% tab title="파밍" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-8.png)

파밍의 경우 다음과 같이 하세요.

1. "**Stake**"(스테이킹)를 클릭하세요.
2. 스테이킹할 LP 토큰 수량을 입력하세요.
3. "**Confirm**"(확인)을 클릭하세요
{% endtab %}
{% endtabs %}

### 4. 완료!

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-9%20%281%29.png)

이제 새로운 MasterChef에 스테이킹 중이며 계속해서 CAKE 보상을 받습니다! "**Finish**"(완료)를 클릭하여 돌아가 PancakeSwap이 제공하는 다른 훌륭한 상품들도 둘러보세요.

## 자주 묻는 질문 (FAQ)

#### **언제 끝나나요?**

마이그레이션에는 몇 시간이 소요되지만, 마이그레이션 도우미 페이지가 출시되는 시점에는 완전히 끝나 있을 것입니다. 최신 소식은 [Twitter](https://twitter.com/pancakeswap/) 또는 [Telegram](https://t.me/PancakeSwapAnn) 공지 채널을 팔로우하세요!

#### **언제까지 마이그레이션해야 하나요?**

1. 언제든지 마이그레이션할 수 있습니다. 기한은 없습니다.&#x20;
2. 파밍과 풀에서 계속 보상을 받으려면 가능한 한 빨리 마이그레이션하는 것이 좋습니다.

#### 마이그레이션 도우미가 보이지 않습니다!

스마트 컨트랙트 배포와 설정이 완료된 후에야 배포됩니다. 몇 시간이 걸릴 수 있습니다. 최신 소식은 [Twitter](https://twitter.com/pancakeswap/) 또는 [Telegram](https://t.me/PancakeSwapAnn) 공지 채널을 팔로우하세요!

#### 락업 스테이킹을 사용할 수 없는 이유는 무엇인가요?

곧 제공됩니다! 원활한 마이그레이션을 위해 락업(고정 기간) 스테이킹은 마이그레이션 며칠 후에 활성화됩니다.

#### 마이그레이션 도우미에서 내 파밍을 찾을 수 없습니다!

마이그레이션 이전에 해당 파밍이 종료되었기 때문일 수 있습니다. 다음과 같이 하세요.

1. **Farms**로 이동하세요.
2. 파밍 목록 상단에서 "**Finished**"(종료됨)를 선택하세요.
3. "**Check out v1 farms**"(v1 파밍 확인)를 클릭하여 파밍을 찾으세요.
