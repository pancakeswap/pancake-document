# 迁移你的质押

![ICYDK：你现在阅读的正是此横幅中提到的“教程”](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration%20pre%20heat.png)

为了继续赚取质押奖励，你需要将你的农场和矿池质押迁移到新的 MasterChef。放轻松，这会很简单。

{% hint style="info" %}
**但等等！我需要迁移吗？**

如果你属于以下情况，则需要迁移：

* 在 PancakeSwap **Farms**（农场）中耕作。
* 在 PancakeSwap **CAKE 糖浆池**（手动、自动、IFO）中质押。

\*其他糖浆池不受影响
{% endhint %}

## 如何迁移？

![在迁移时，Chefs 会部署一个分步助手，引导你完成整个过程 ](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-overview.png)

### 1. 前往迁移助手

前往 [https://pancakeswap.finance/migration](https://pancakeswap.finance/migration)，并连接你的钱包。

### 2. 从旧农场取消质押

迁移助手中有两个步骤。在第一步中，你应该会看到一个列表，列出你当前正在质押的三个 CAKE 糖浆池和农场。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-3.png)

点击每个农场和矿池上的“**Unstake All**”（全部取消质押）来取消质押你的所有资产。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-4%20%281%29.png)

取消质押后，点击“**Go to Stake**”（前往质押）继续到第 2 步。

### 3. 将你的 LP 代币和 CAKE 质押到新的农场和矿池中。

在这里你应该会看到全新的 CAKE 糖浆池和新农场。在质押之前，你需要先启用它们。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-5%20%281%29.png)

点击“**Enable**”（启用）以在每个农场和 CAKE 糖浆池上启用质押。如果你使用的是移动设备，请在查找“**Enable**”（启用）按钮时点击“**v**”（向下箭头）展开卡片。

启用后，你将能够开始在矿池和农场中质押。

{% tabs %}
{% tab title="CAKE 糖浆池" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-7%20%282%29.png)

对于 CAKE 糖浆池。请：

1. 在“Stake CAKE”（质押 CAKE）部分下点击“**Flexible**”（灵活）。
2. 输入你想要质押的 CAKE 数量。
3. 点击“**Confirm**”（确认）。



{% hint style="info" %}
锁定（固定期限）质押选项将在迁移后几天内开放。你将能够把你的灵活质押头寸转换为锁定头寸。要了解更多关于带固定期限质押的新 CAKE 糖浆池的信息，请查看[此文档](../../../../archive/legacy-products/new-cake-pool/)。
{% endhint %}
{% endtab %}

{% tab title="Farms" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-8.png)

对于农场，请：

1. 点击“**Stake**”（质押）。
2. 输入你想要质押的 LP 代币数量。
3. 点击“**Confirm**”（确认）
{% endtab %}
{% endtabs %}

### 4. 完成！

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-9%20%281%29.png)

你现在已经在新的 MasterChef 中质押，并继续赚取 CAKE 奖励了！点击“**Finish**”（完成）返回并探索 PancakeSwap 提供的其他优质产品。

## FAQ

#### **它什么时候会完成？**

迁移将需要数小时，但在迁移助手页面上线时应该就已完全完成。关注我们的 [Twitter](https://twitter.com/pancakeswap/) 或 [Telegram](https://t.me/PancakeSwapAnn) 公告频道，获取最新更新！

#### **我必须什么时候迁移？**

1. 你可以随时迁移。没有时间限制。&#x20;
2. 尽早迁移更好，这样你就可以继续从农场和矿池赚取奖励。

#### 我没有看到迁移助手！

它只会在智能合约部署和配置完成后才部署。这可能需要数小时。关注我们的 [Twitter](https://twitter.com/pancakeswap/) 或 [Telegram](https://t.me/PancakeSwapAnn) 公告频道，获取最新更新！

#### 为什么锁定质押不可用？

敬请期待！为了实现平稳迁移，锁定（固定期限）质押将在迁移后几天内启用。

#### 我在迁移助手中找不到我的农场！

这可能是由于该农场在迁移前已停止运营。请：

1. 前往 **Farms**（农场）。
2. 在农场列表顶部选择“**Finished**”（已结束）。
3. 点击“**Check out v1 farms**”（查看 v1 农场）来查找你的农场。
