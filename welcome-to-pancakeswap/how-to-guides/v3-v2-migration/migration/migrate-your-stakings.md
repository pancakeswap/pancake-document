# Migrasikan Staking Anda

![ICYDK: Anda sedang membaca "tutorial" yang disebutkan dalam banner ini](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration%20pre%20heat.png)

Agar tetap mendapatkan hadiah staking, Anda perlu memigrasikan staking farm dan pool ke MasterChef yang baru. Tenang, prosesnya mudah.

{% hint style="info" %}
**Tapi tunggu! Apakah saya perlu bermigrasi?**

Anda perlu bermigrasi jika Anda:

* Melakukan Farming di **Farms** PancakeSwap.
* Melakukan Staking di **CAKE Syrup Pools** PancakeSwap (Manual, Auto, IFO).

\*Syrup Pool lainnya tidak terpengaruh
{% endhint %}

## Bagaimana cara bermigrasi?

![Pada saat migrasi, para Chef akan menerapkan helper langkah demi langkah untuk memandu Anda melalui prosesnya ](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-overview.png)

### 1. Navigasikan ke migration helper

Buka [https://pancakeswap.finance/migration](https://pancakeswap.finance/migration), dan hubungkan dompet Anda.

### 2. Unstake dari farm lama

Ada dua langkah dalam migration helper. Pada langkah pertama, Anda akan melihat daftar tiga CAKE syrup pool dan farm yang sedang Anda stake.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-3.png)

Klik "**Unstake All**" pada setiap farm dan pool untuk melakukan unstake semua aset Anda.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-4%20%281%29.png)

Setelah melakukan unstake, klik "**Go to Stake**" untuk melanjutkan ke langkah 2.

### 3. Stake token LP dan CAKE Anda ke farm dan pool baru.

Di sini Anda akan melihat CAKE syrup pool baru dan farm baru. Sebelum melakukan staking, Anda perlu mengaktifkannya.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-5%20%281%29.png)

Klik "**Enable**" untuk mengaktifkan staking pada setiap farm dan CAKE syrup pool. Jika menggunakan perangkat mobile, klik "**v**" (panah bawah) untuk memperluas kartu saat mencari tombol "**Enable**".

Setelah diaktifkan, Anda dapat mulai melakukan staking di pool dan farm.

{% tabs %}
{% tab title="CAKE Syrup Pool" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-7%20%282%29.png)

Untuk CAKE syrup pool. Lakukan:

1. Klik "**Flexible**" di bawah bagian "Stake CAKE".
2. Masukkan jumlah CAKE yang ingin Anda stake.
3. Klik "**Confirm**".



{% hint style="info" %}
Opsi staking terkunci (jangka tetap) akan tersedia beberapa hari setelah migrasi. Anda akan dapat mengonversi posisi staking fleksibel ke posisi terkunci. Untuk mempelajari lebih lanjut tentang CAKE syrup pool baru dengan staking jangka tetap, lihat [dokumen ini](../../../../archive/legacy-products/new-cake-pool/).
{% endhint %}
{% endtab %}

{% tab title="Farms" %}
![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-8.png)

Untuk farm, lakukan:

1. Klik "**Stake**".
2. Masukkan jumlah token LP yang ingin Anda stake.
3. Klik "**Confirm**"
{% endtab %}
{% endtabs %}

### 4. Selesai!

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/migration-helper-steps-guide-9%20%281%29.png)

Anda sekarang melakukan staking di MasterChef baru dan terus mendapatkan hadiah CAKE! Klik "**Finish**" untuk kembali dan menjelajahi produk-produk luar biasa lainnya yang ditawarkan PancakeSwap.

## FAQ

#### **Kapan akan selesai?**

Migrasi akan berlangsung beberapa jam, tetapi seharusnya sudah sepenuhnya selesai saat halaman migration helper diluncurkan. Ikuti saluran pengumuman [Twitter](https://twitter.com/pancakeswap/) atau [Telegram](https://t.me/PancakeSwapAnn) kami untuk pembaruan terkini!

#### **Kapan saya harus bermigrasi?**

1. Anda dapat bermigrasi kapan saja. Tidak ada batas waktu.&#x20;
2. Sebaiknya bermigrasi lebih cepat agar dapat terus mendapatkan hadiah dari farm dan pool.

#### Saya tidak melihat migration helper!

Helper tersebut hanya akan diterapkan setelah deployment dan konfigurasi smart contract selesai. Prosesnya mungkin memakan waktu beberapa jam. Ikuti saluran pengumuman [Twitter](https://twitter.com/pancakeswap/) atau [Telegram](https://t.me/PancakeSwapAnn) kami untuk pembaruan terkini!

#### Mengapa staking terkunci tidak tersedia?

SEGERA! Untuk memastikan migrasi yang lancar. Staking terkunci (jangka tetap) akan diaktifkan beberapa hari setelah migrasi.

#### Saya tidak dapat menemukan farm saya di migration helper!

Mungkin karena farm tersebut telah dihentikan sebelum migrasi. Lakukan:

1. Buka **Farms**.
2. Pilih "**Finished**" di bagian atas daftar farm.
3. Klik "**Check out v1 farms**" untuk mencari farm Anda.
