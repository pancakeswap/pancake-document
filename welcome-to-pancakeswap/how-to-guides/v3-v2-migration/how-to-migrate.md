# Comment migrer

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28133%29.png" alt=""><figcaption></figcaption></figure>

En avril 2023, PancakeSwap a annoncé v3 pour l'Exchange et les Farms. Certaines paires de Yield Farming devront être migrées pour continuer à percevoir des récompenses de Staking. Pas d'inquiétude, comme la dernière fois, cela devrait se passer en douceur.

### Mais attendez ! Dois-je migrer ? <a href="#id-4b9e0260-9dee-493b-b0ad-6bdba084cea6" id="id-4b9e0260-9dee-493b-b0ad-6bdba084cea6"></a>

Vous devez migrer si vous remplissez les conditions suivantes :

**Yield Farming sur les Farms v2 PancakeSwap suivants :**

* BNB Chain :
  * CAKE-BNB
  * CAKE-BUSD
  * CAKE-USDT
  * BUSD-BNB
  * USDT-BNB
  * BTCB-BUSD
  * BTCB-USDT
  * BTCB-ETH
  * BTCB-BNB
  * ETH-BNB
  * ETH-USDC
  * USDC-USDT
  * BUSD-USDC
  * BUSD-USDT
* Ethereum :
  * ETH-USDC
  * ETH-USDT
  * WBTC-ETH

La liste s'étoffera probablement au fil du temps. Le moyen le plus simple de consulter la liste à jour est de visiter [https://pancakeswap.finance/migration](https://pancakeswap.finance/migration) et de connecter votre Portefeuille.

**Fournir de la Liquidité v2 tout en remplissant les conditions suivantes :**

* La majorité de la Liquidité pour la paire de tokens a été migrée vers v3 — Veuillez consulter la page PancakeSwap Info, ou le site web ou les réseaux sociaux du projet token concerné pour plus de détails.
* L'équipe du projet de ce token a annoncé que la Liquidité serait migrée vers v3 — Veuillez consulter les sites web ou réseaux sociaux des projets individuels pour plus de détails.

### Comment migrer <a href="#c7d7b407-268c-460c-a4f1-be1b771db5e7" id="c7d7b407-268c-460c-a4f1-be1b771db5e7"></a>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28283%29.png" alt=""><figcaption></figcaption></figure>

Repérez la bannière de migration v3 sur la page Liquidity ou Farm, puis cliquez sur "Proceed" pour accéder à la page de l'assistant de migration.



**Étape 1 - Retirer ses mises des Farms v2 et/ou StableSwap**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28119%29.png" alt=""><figcaption></figcaption></figure>

À l'étape 1, l'assistant liste tous les Farms PancakeSwap v2 ou StableSwap qui nécessitent une migration.

Cliquez sur chacun des boutons "Unstake All" pour retirer tous vos LP tokens stakés dans les Farms. Votre Portefeuille vous demandera une confirmation.

Une fois tous les Farms listés déstakés, cliquez sur "Next Steps" pour continuer.



**Étape 2 - Retirer la Liquidité de l'Exchange v2 ou StableSwap**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28315%29.png" alt=""><figcaption></figcaption></figure>

À l'étape 2, l'assistant liste toutes les positions de Liquidité pouvant être migrées vers v3 avec le Yield Farming CAKE.

Cliquez sur chacun des boutons "Remove" pour afficher la fenêtre de retrait de Liquidité avec 100% sélectionné.&#x20;

Cliquez ensuite sur "Enable", signez la transaction dans votre Portefeuille, puis cliquez sur "Remove". Votre Portefeuille vous demandera une confirmation.

{% hint style="info" %}
Bien que certains tokens de projets tiers migrent également vers v3, ils n'apparaîtront pas dans la liste. Veuillez consulter les sites web ou réseaux sociaux des projets individuels pour plus de détails. Utilisez la page [Liquidity](https://pancakeswap.finance/liquidity) pour migrer manuellement.
{% endhint %}



**Étape 3 - Se préparer pour v3**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28186%29.png" alt=""><figcaption></figcaption></figure>

Aucune action n'est requise. Lisez simplement et assurez-vous de comprendre le fonctionnement de v3 et la manière de fournir de la Liquidité en v3.



**Étape 4 - Ajouter de la Liquidité v3**

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28325%29.png)

À cette étape, vous allez ajouter votre Liquidité au nouvel Exchange v3.

Cliquez sur "Add Liquidity". Votre Liquidité v2 précédemment retirée apparaîtra dans la liste ; cliquez sur "Add" pour afficher l'interface d'ajout de Liquidité v3.

Si vous ne trouvez pas la paire souhaitée, cliquez plutôt sur "Add Other Pairs" et choisissez manuellement les deux tokens.

Pour un tutoriel plus détaillé sur la fourniture de Liquidité en v3, consultez [cette page](../../../earn/pancakeswap-pools/liquidity-guide.md).

Si vous avez des questions lors de la fourniture de Liquidité en v3, consultez la [FAQ](../../../trade/trading-faq/swap-faq.md).

{% hint style="warning" %}
Veuillez noter que dans Exchange v3, seules les positions de Liquidité actives (dans la plage de prix) percevront des récompenses de frais de trading.

Soyez attentif lors de la définition de la plage de prix pour la position de Liquidité.
{% endhint %}



**Étape 5 - Staker dans les Farms v3**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2835%29.png" alt=""><figcaption></figcaption></figure>

À cette étape, vous allez staker vos nouvelles positions de Liquidité v3 dans les nouveaux Farms v3 pour commencer à percevoir des récompenses CAKE !

Cliquez sur chacun des boutons "Stake" sur la position pour la staker dans les Farms. Votre Portefeuille vous demandera une confirmation.

Pour un tutoriel plus détaillé sur le Yield Farming en v3, consultez [cette page](../../../earn/yield-farming/how-to-use-farms/#farm-v3).

Si vous avez des questions lors du Staking de Liquidité dans les Farms v3, consultez la [FAQ](../../../earn/earn-faq/farming-faq.md).

{% hint style="warning" %}
Veuillez noter que dans Farm v3, seules les positions de Liquidité actives (dans la plage de prix) percevront des récompenses CAKE.

Soyez attentif lors de la définition de la plage de prix pour la position de Liquidité.
{% endhint %}



**Terminé**

C'est tout. Vous avez migré vos mises dans les Farms et votre Liquidité vers le nouveau PancakeSwap v3 !
