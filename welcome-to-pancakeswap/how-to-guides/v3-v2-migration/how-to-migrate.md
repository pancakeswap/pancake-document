# Cara bermigrasi

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28133%29.png" alt=""><figcaption></figcaption></figure>

Pada April 2023, PancakeSwap mengumumkan v3 untuk Exchange dan Farm. Beberapa pasangan farming perlu dimigrasi agar tetap mendapatkan hadiah staking. Tenang, seperti kali sebelumnya, prosesnya seharusnya berjalan lancar.

### Tapi tunggu! Apakah saya perlu bermigrasi? <a href="#id-4b9e0260-9dee-493b-b0ad-6bdba084cea6" id="id-4b9e0260-9dee-493b-b0ad-6bdba084cea6"></a>

Anda perlu bermigrasi jika memenuhi kondisi berikut:

**Farming di Farm PancakeSwap v2 berikut:**

* BNB Chain:
  * CAKE-BNB
  * CAKE-BUSD
  * CAKE-USDT
  * BUSD-BNB
  * USDT-BNB
  * BTCB-BUSD
  * BTCB-USDT
  * BTCB-ETH
  * BTCB-BNB
  * ETH-BNB
  * ETH-USDC
  * USDC-USDT
  * BUSD-USDC
  * BUSD-USDT
* Ethereum:
  * ETH-USDC
  * ETH-USDT
  * WBTC-ETH

Daftar ini kemungkinan akan bertambah seiring waktu. Cara termudah untuk memeriksa daftar terbaru adalah dengan mengunjungi [https://pancakeswap.finance/migration](https://pancakeswap.finance/migration) dan menghubungkan dompet Anda

**Menyediakan Likuiditas v2, dan memenuhi kondisi berikut:**

* Sebagian besar Likuiditas untuk pasangan token tersebut telah dimigrasi ke v3 - Silakan periksa halaman Info PancakeSwap, atau situs web atau saluran sosial proyek token tersebut untuk informasi lebih lanjut.
* Tim proyek token tersebut telah mengumumkan bahwa Likuiditas akan dimigrasi ke v3 - Silakan periksa situs web atau saluran sosial proyek individual untuk informasi lebih lanjut.

### Cara bermigrasi <a href="#c7d7b407-268c-460c-a4f1-be1b771db5e7" id="c7d7b407-268c-460c-a4f1-be1b771db5e7"></a>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28283%29.png" alt=""><figcaption></figcaption></figure>

Cari banner migrasi v3 di halaman Liquidity atau Farm. Kemudian klik "Proceed" untuk masuk ke halaman migration helper.



**Langkah 1 - Unstake dari farm v2 dan/atau StableSwap**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28119%29.png" alt=""><figcaption></figcaption></figure>

Di langkah 1, helper akan menampilkan semua farm PancakeSwap v2 atau StableSwap yang memerlukan migrasi.

Klik setiap tombol "Unstake All" untuk melakukan unstake semua token LP yang di-stake dari farm. Dompet Anda akan meminta konfirmasi.

Ketika semua farm yang terdaftar telah di-unstake, klik "Next Steps" untuk melanjutkan.



**Langkah 2 - Hapus Likuiditas dari Exchange v2 atau StableSwap**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28315%29.png" alt=""><figcaption></figcaption></figure>

Di langkah 2, helper akan menampilkan semua posisi Likuiditas yang dapat dimigrasi ke v3 dengan Yield Farming CAKE.

Klik setiap tombol "Remove" untuk membuka modal hapus Likuiditas dengan 100% dipilih.&#x20;

Kemudian klik "Enable", tanda tangani transaksi di dompet Anda, dan klik "Remove". Dompet Anda akan meminta konfirmasi.

{% hint style="info" %}
Meskipun beberapa token proyek lain juga sedang bermigrasi ke v3, mereka tidak akan muncul dalam daftar. Silakan periksa situs web atau saluran sosial proyek individual untuk informasi lebih lanjut. Dan gunakan halaman [Liquidity](https://pancakeswap.finance/liquidity) untuk bermigrasi secara manual.
{% endhint %}



**Langkah 3 - Bersiap untuk v3**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28186%29.png" alt=""><figcaption></figcaption></figure>

Tidak ada tindakan yang diperlukan. Cukup baca dan pastikan Anda familiar dengan cara kerja v3 dan cara menyediakan Likuiditas di v3.



**Langkah 4 - Tambahkan Likuiditas v3**

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28325%29.png)

Pada langkah ini, Anda akan menambahkan Likuiditas ke Exchange v3 yang baru.

Klik "Add Liquidity". Likuiditas v2 yang sebelumnya Anda hapus akan muncul dalam daftar, klik "Add" untuk membuka antarmuka penambahan Likuiditas v3.

Jika Anda tidak melihat pasangan yang ingin ditambahkan, klik "Add Other Pairs" dan pilih dua token secara manual.

Untuk tutorial lebih terperinci tentang cara menyediakan Likuiditas di v3, baca [di sini](../../../earn/pancakeswap-pools/liquidity-guide.md).

Jika ada pertanyaan saat menyediakan Likuiditas di v3, lihat [FAQ](../../../trade/trading-faq/swap-faq.md) di sini.

{% hint style="warning" %}
Harap diperhatikan bahwa di Exchange v3, hanya posisi Likuiditas yang aktif (dalam rentang harga) yang akan mendapatkan hadiah biaya Trading.

Harap berhati-hati saat menetapkan rentang harga untuk posisi Likuiditas.
{% endhint %}



**Langkah 5 - Stake di farm v3**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2835%29.png" alt=""><figcaption></figcaption></figure>

Pada langkah ini, Anda akan melakukan staking posisi Likuiditas v3 yang baru ditambahkan ke farm v3 yang baru untuk mulai mendapatkan hadiah CAKE!

Klik setiap tombol "Stake" pada posisi untuk men-stake-nya ke farm. Dompet Anda akan meminta konfirmasi.

Untuk tutorial lebih terperinci tentang cara melakukan Farm di v3, baca [di sini](../../../earn/yield-farming/how-to-use-farms/#farm-v3).

Jika ada pertanyaan saat melakukan staking Likuiditas di farm v3, lihat [FAQ](../../../earn/earn-faq/farming-faq.md) di sini.

{% hint style="warning" %}
Harap diperhatikan bahwa di Farm v3, hanya posisi Likuiditas yang aktif (dalam rentang harga) yang akan mendapatkan hadiah CAKE.

Harap berhati-hati saat menetapkan rentang harga untuk posisi Likuiditas.
{% endhint %}



**Selesai**

Selesai. Anda telah berhasil memigrasikan farm staking dan Likuiditas Anda ke PancakeSwap v3 yang baru!
