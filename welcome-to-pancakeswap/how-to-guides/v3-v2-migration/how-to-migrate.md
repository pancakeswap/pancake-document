# 如何迁移

<figure><img src="../../../.gitbook/assets/image (133).png" alt=""><figcaption></figcaption></figure>

2023 年 4 月，PancakeSwap 宣布推出 Exchange 和 Farm 的 V3。一些农场代币对需要迁移才能继续赚取质押奖励。放轻松，就像上次一样，过程应该会很顺畅。

### 但等等！我需要迁移吗？ <a href="#id-4b9e0260-9dee-493b-b0ad-6bdba084cea6" id="id-4b9e0260-9dee-493b-b0ad-6bdba084cea6"></a>

如果你符合以下条件，则需要迁移：

**在以下 V2 PancakeSwap 农场中耕作：**

* BNB Chain：
  * CAKE-BNB
  * CAKE-BUSD
  * CAKE-USDT
  * BUSD-BNB
  * USDT-BNB
  * BTCB-BUSD
  * BTCB-USDT
  * BTCB-ETH
  * BTCB-BNB
  * ETH-BNB
  * ETH-USDC
  * USDC-USDT
  * BUSD-USDC
  * BUSD-USDT
* Ethereum：
  * ETH-USDC
  * ETH-USDT
  * WBTC-ETH

该列表最终很可能会扩充。检查更新后列表的最简单方法是访问 [https://pancakeswap.finance/migration](https://pancakeswap.finance/migration) 并连接你的钱包

**提供 V2 流动性，并符合以下条件：**

* 该代币对的大部分流动性已迁移到 V3——请查看 PancakeSwap Info 页面，或代币项目的网站或社交渠道了解更多详情。
* 该代币的项目团队已宣布流动性将迁移到 V3——请查看各个项目的网站或社交渠道了解更多详情。

### 如何迁移 <a href="#c7d7b407-268c-460c-a4f1-be1b771db5e7" id="c7d7b407-268c-460c-a4f1-be1b771db5e7"></a>

<figure><img src="../../../.gitbook/assets/image (283).png" alt=""><figcaption></figcaption></figure>

在 Liquidity（流动性）或 Farm（农场）页面上查找 V3 迁移横幅。然后点击“Proceed”（继续）进入迁移助手页面。



**第 1 步 - 从 V2 和/或 StableSwap 农场取消质押**

<figure><img src="../../../.gitbook/assets/image (119).png" alt=""><figcaption></figcaption></figure>

在第 1 步中，助手会列出所有需要迁移的 PancakeSwap V2 或 StableSwap 农场。

点击每个“Unstake All”（全部取消质押）按钮，从农场取消质押所有已质押的 LP 代币。你的钱包会要求确认。

当所有列出的农场都已取消质押后，点击“Next Steps”（下一步）继续。



**第 2 步 - 从 Exchange V2 或 StableSwap 移除流动性**

<figure><img src="../../../.gitbook/assets/image (315).png" alt=""><figcaption></figcaption></figure>

在第 2 步中，助手会列出所有可以迁移到带 CAKE 流动性挖矿的 V3 的流动性头寸。

点击每个“Remove”（移除）按钮，调出已选择 100% 的移除流动性弹窗。&#x20;

然后点击“Enable”（启用），在你的钱包中签署交易，并点击“Remove”（移除）。你的钱包会要求确认。

{% hint style="info" %}
即使其他一些项目代币也在迁移到 V3，它们也不会出现在列表中。请查看各个项目的网站或社交渠道了解更多详情。并使用 [Liquidity](https://pancakeswap.finance/liquidity)（流动性）页面手动迁移。
{% endhint %}



**第 3 步 - 为 V3 做好准备**

<figure><img src="../../../.gitbook/assets/image (186).png" alt=""><figcaption></figcaption></figure>

无需任何操作。只需阅读并确保你熟悉 V3 的工作原理以及如何在 V3 中提供流动性。



**第 4 步 - 添加 V3 流动性**

![](<../../../.gitbook/assets/image (325).png>)

在这一步中，你将把你的流动性添加到新的 Exchange V3。

点击“Add Liquidity”（添加流动性）。你之前移除的 V2 流动性会显示在列表中，点击“Add”（添加）调出添加 V3 流动性的界面。

如果你没有看到想要添加的代币对，请改为点击“Add Other Pairs”（添加其他代币对）并手动选择这两种代币。

如需了解如何在 V3 中提供流动性的更详细教程，请阅读[此处](../../../earn/pancakeswap-pools/liquidity-guide.md)。

如果你在 V3 中提供流动性时有疑问，请在此处查看 [FAQ](../../../trade/trading-faq/swap-faq.md)。

{% hint style="warning" %}
请注意，在 Exchange V3 中，只有活跃（在价格区间内）的流动性头寸才能赚取交易手续费奖励。

在为流动性头寸设置价格区间时，请务必谨慎。
{% endhint %}



**第 5 步 - 在 V3 农场中质押**

<figure><img src="../../../.gitbook/assets/image (35).png" alt=""><figcaption></figcaption></figure>

在这一步中，你将把你新添加的 V3 流动性头寸质押到新的 V3 农场，开始赚取 CAKE 奖励！

点击头寸上的每个“Stake”（质押）按钮，将它们质押到农场中。你的钱包会要求确认。

如需了解如何在 V3 中进行农场耕作的更详细教程，请阅读[此处](../../../earn/yield-farming/how-to-use-farms/#farm-v3)。

如果你在 V3 农场中质押流动性时有疑问，请在此处查看 [FAQ](../../../earn/earn-faq/farming-faq.md)。

{% hint style="warning" %}
请注意，在 Farm V3 中，只有活跃（在价格区间内）的流动性头寸才能赚取 CAKE 奖励。

在为流动性头寸设置价格区间时，请务必谨慎。
{% endhint %}



**完成**

就是这样。你已经把你的农场质押和流动性迁移到新的 PancakeSwap V3 了！
