# Как мигрировать

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28133%29.png" alt=""><figcaption></figcaption></figure>

В апреле 2023 года PancakeSwap анонсировал V3 для Exchange и Farms. Некоторые фермерские пары потребуют миграции для продолжения получения наград за стейкинг. Расслабься — как и в прошлый раз, всё должно пройти гладко.

### Но подожди! Нужно ли мне мигрировать? <a href="#id-4b9e0260-9dee-493b-b0ad-6bdba084cea6" id="id-4b9e0260-9dee-493b-b0ad-6bdba084cea6"></a>

Тебе нужно мигрировать, если выполняется одно из следующих условий:

**Yield Farming на следующих фермах PancakeSwap V2:**

* BNB Chain:
  * CAKE-BNB
  * CAKE-BUSD
  * CAKE-USDT
  * BUSD-BNB
  * USDT-BNB
  * BTCB-BUSD
  * BTCB-USDT
  * BTCB-ETH
  * BTCB-BNB
  * ETH-BNB
  * ETH-USDC
  * USDC-USDT
  * BUSD-USDC
  * BUSD-USDT
* Ethereum:
  * ETH-USDC
  * ETH-USDT
  * WBTC-ETH

Список, вероятно, будет расширяться. Самый простой способ проверить актуальный список — посетить [https://pancakeswap.finance/migration](https://pancakeswap.finance/migration) и подключить кошелёк.

**Предоставление ликвидности V2 при выполнении следующих условий:**

* Большинство ликвидности для данной пары токенов мигрировало в V3 — проверь страницу PancakeSwap Info или сайт и социальные сети проекта токена.
* Команда проекта токена объявила о миграции ликвидности в V3 — проверь соответствующие сайты и социальные каналы проекта.

### Как мигрировать <a href="#c7d7b407-268c-460c-a4f1-be1b771db5e7" id="c7d7b407-268c-460c-a4f1-be1b771db5e7"></a>

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28283%29.png" alt=""><figcaption></figcaption></figure>

Найди баннер миграции V3 на странице Liquidity или Farm. Затем нажми «Proceed» для перехода на страницу помощника по миграции.



**Шаг 1 — Снять стейкинг с ферм V2 и/или StableSwap**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28119%29.png" alt=""><figcaption></figcaption></figure>

На шаге 1 помощник покажет список всех ферм PancakeSwap V2 или StableSwap, требующих миграции.

Нажми каждую кнопку «Unstake All», чтобы снять все LP токены из стейкинга ферм. Кошелёк попросит подтверждения.

Когда все перечисленные фермы выведены из стейкинга, нажми «Next Steps» для продолжения.



**Шаг 2 — Убрать ликвидность из Exchange V2 или StableSwap**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28315%29.png" alt=""><figcaption></figcaption></figure>

На шаге 2 помощник покажет список всех позиций ликвидности, которые можно мигрировать в V3 с Yield Farming в CAKE.

Нажми каждую кнопку «Remove», чтобы открыть модальное окно удаления ликвидности с выбранными 100%.&#x20;

Затем нажми «Enable», подпиши транзакцию в кошельке и нажми «Remove». Кошелёк попросит подтверждения.

{% hint style="info" %}
Несмотря на то что некоторые другие токены проектов также мигрируют в V3, они не будут отображаться в списке. Проверь соответствующие сайты и социальные каналы проекта. Используй страницу [Liquidity](https://pancakeswap.finance/liquidity) для ручной миграции.
{% endhint %}



**Шаг 3 — Подготовься к V3**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28186%29.png" alt=""><figcaption></figcaption></figure>

Никаких действий не требуется. Просто прочитай и убедись, что понимаешь, как работает V3 и как предоставлять ликвидность в V3.



**Шаг 4 — Добавить ликвидность V3**

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28325%29.png)

На этом шаге ты добавляешь ликвидность в новый Exchange V3.

Нажми «Add Liquidity». В списке появится твоя ранее удалённая ликвидность V2 — нажми «Add», чтобы открыть интерфейс добавления ликвидности V3.

Если ты не видишь нужную пару, нажми «Add Other Pairs» и выбери два токена вручную.

Более подробное руководство по предоставлению ликвидности в V3 читай [здесь](../../../earn/pancakeswap-pools/liquidity-guide.md).

Если у тебя есть вопросы при предоставлении ликвидности в V3, смотри [FAQ](../../../trade/trading-faq/swap-faq.md).

{% hint style="warning" %}
Обрати внимание: в Exchange V3 награды за торговые комиссии получают только активные (в диапазоне) позиции ликвидности.

Будь внимателен при установке ценового диапазона для позиции ликвидности.
{% endhint %}



**Шаг 5 — Поставить в стейкинг на фермах V3**

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2835%29.png" alt=""><figcaption></figcaption></figure>

На этом шаге ты размещаешь свои только что добавленные позиции ликвидности V3 в стейкинг на новых фермах V3, чтобы начать зарабатывать награды CAKE!

Нажми каждую кнопку «Stake» на позиции, чтобы поставить её в стейкинг на ферме. Кошелёк попросит подтверждения.

Более подробное руководство по Yield Farming в V3 читай [здесь](../../../earn/yield-farming/how-to-use-farms/#farm-v3).

Если у тебя есть вопросы при размещении ликвидности в стейкинг на фермах V3, смотри [FAQ](../../../earn/earn-faq/farming-faq.md).

{% hint style="warning" %}
Обрати внимание: в Farm V3 награды CAKE получают только активные (в диапазоне) позиции ликвидности.

Будь внимателен при установке ценового диапазона для позиции ликвидности.
{% endhint %}



**Завершено**

Вот и всё. Ты мигрировал стейкинг ферм и ликвидность на новый PancakeSwap V3!
