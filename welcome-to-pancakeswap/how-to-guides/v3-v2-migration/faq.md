### **Gibt es eine Frist für die Migration?**

Nein

Sie können Ihre V2 Farms jederzeit entstaken.

Sie können Liquidität aus V2 jederzeit entfernen.

Die Chefs werden die CAKE-Reward-Emissionen von den ausgewählten V2 Farms jedoch schrittweise auf die entsprechenden V3 Farms migrieren. Um weiterhin CAKE-Rewards zu erhalten, empfehlen wir Ihnen, die Migration so früh wie möglich abzuschließen.

Für weitere Neuigkeiten und Updates zum Migrationszeitplan [folgen Sie bitte unseren Social-Media-Kanälen auf Twitter oder dem Telegram-Ankündigungskanal.](../../contact-us/social-accounts.md)

### Wann kann ich mit der Migration beginnen?

Wenn Sie dies lesen, hat die Migration wahrscheinlich bereits begonnen. Besuchen Sie [https://pancakeswap.finance/migration](https://pancakeswap.finance/migration) für weitere Details.

### Ich kann das Paar, in dem ich stake, nicht finden

Einige V2 Farms und Liquidität werden weiterhin parallel zu V3 betrieben.

Einige V2 Farms werden nicht am ersten Tag migriert. Wenn Ihre gestakten Farms nicht in „Schritt 1" erscheinen, müssen sie derzeit nicht migriert werden.

Wenn Ihre V2-Liquiditätspositionen nicht in „Schritt 2" erscheinen, liegt das wahrscheinlich daran, dass V2 Farms aktiv sind und derzeit keine Migration erforderlich ist.

Sie können Ihre Farm-Stakings und Liquidität manuell migrieren. Lesen Sie weiter.

### Kann ich meine Farm-Stakings oder Liquidität manuell migrieren, ohne den Migrations-Assistenten zu verwenden?

Ja.

Sie können LP-Token aus V2 Farms entstaken, indem Sie auf die Seite „Farms" gehen und nach Farms mit dem Tag „V2" suchen. Sie können den Schalter „Nur gestakte" verwenden, um Farms zu filtern, in denen Sie derzeit staken.

Sie können V2-Liquidität entfernen, indem Sie auf die Seite „Liquidität" gehen und nach Positionen mit dem Tag „V2" suchen. Sie können die V2-Registerkarte verwenden, um nur V2-Positionen anzuzeigen.

Befolgen Sie zum Hinzufügen Ihrer Liquidität zu V3 und zum Staking von LP-Positionen in V3 die standardmäßigen V3-Schritte.&#x20;

Eine detaillierte Anleitung zum Hinzufügen von Liquidität in V3 finden Sie [hier](../../../earn/pancakeswap-pools/liquidity-guide.md).&#x20;

Eine Anleitung zum Farming in V3 finden Sie [hier](../../../earn/yield-farming/how-to-use-farms/).
