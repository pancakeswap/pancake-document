# Wallet erstellen (SOL)

### 1. **Warum Sie ein Wallet benötigen**

Um **PancakeSwap auf Solana** zu nutzen, benötigen Sie ein **Krypto-Wallet** – es ist Ihr persönlicher Tresor für digitale Assets und Ihr Zugang zu DeFi. Ohne ein Wallet können Sie nicht:

* **Token swappen** auf Solana
* **Liquidität bereitstellen** für PancakeSwaps **V3 Pools** (unser kapitaleffizientes Modell mit konzentrierter Liquidität)
* Mit einer dApp interagieren oder Token auf Solana speichern

***

### 2. **Grundlagen der Wallet-Einrichtung (Sicherheit geht vor!)**

Krypto-Wallets geben Ihnen die volle Kontrolle über Ihre Assets – aber mit großer Macht kommt große Verantwortung. Halten Sie Ihr Wallet sicher, indem Sie diese bewährten Methoden befolgen:

| ✅ Empfehlungen                                                                      | ❌ Verbote                                                           |
| ----------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| ✅ **Aus offiziellen Quellen herunterladen** (App Stores, verifizierte Websites)     | ❌ Nicht über zufällige Links oder Direktnachrichten installieren    |
| ✅ **Den Einrichtungsanweisungen** sorgfältig folgen                                 | ❌ Den Sicherungsprozess nicht überstürzen oder überspringen         |
| ✅ **Ihre Wiederherstellungsphrase sichern** und offline aufbewahren                 | ❌ Keinen Screenshot machen oder auf Ihrem Telefon/Computer speichern |
| ✅ **Ihre Phrase privat halten** – sie ist Ihr einziger Weg zur Wiederherstellung    | ❌ Niemals teilen, auch nicht wenn jemand behauptet, „Support" zu sein |
| ✅ Ihre Wiederherstellungsphrase nur **innerhalb der Wallet-App** eingeben           | ❌ Niemals auf Websites, in Popups oder anderen Apps eingeben        |

> 🧠 Ihre Wiederherstellungsphrase = Zugang zu Ihrem Wallet

***

### 3. **Wallet wählen: Mobil oder Desktop**

Nicht sicher, welchen Wallet-Typ Sie verwenden sollen? Hier ist ein kurzer Überblick über Mobile- und Desktop/Web-Wallets, damit Sie das Richtige für Ihren Stil wählen können:

| Merkmal             | **Mobile Wallets**                     | **Browser/Desktop Wallets**              |
| ------------------- | -------------------------------------- | ---------------------------------------- |
| **Verwendungszweck** | Swappen & unterwegs verfolgen          | Ideal für Multitasking oder intensives DApp-Nutzung |
| **Benutzerfreundlichkeit** | Intuitiv, einsteigerfreundlich    | Leichte Erweiterungen, schneller Zugriff |
| **Sicherheit**      | Abhängig von der Gerätesicherheit      | Einfachere Hardware-Wallet-Integration   |
| **Komfort**         | All-in-one-App                         | Mehr manuell, aber leistungsstark        |
| **Am besten für...** | Gelegenheitsnutzer, mobile Händler    | Desktop-Nutzer, fortgeschrittene Anwendungsfälle |

> 📱 Mobile Wallets bieten oft ein komfortableres Erlebnis für Trading, Portfolio-Verwaltung und das Durchsuchen von NFTs – alles von Ihrem Telefon aus.

### 5. **Allgemeine Wallet-Einrichtungsschritte (Kurzanleitung)**

Unabhängig davon, welches Wallet Sie wählen, ist der Prozess in der Regel ähnlich:

1. **Laden Sie** die Wallet-App oder Browser-Erweiterung aus der **offiziellen Quelle** herunter
2. Starten Sie die App und tippen Sie auf **„Create a new wallet"** (Neues Wallet erstellen)
   * (Oder wählen Sie **„Import"**, wenn Sie bereits eines haben)
3. Legen Sie ein starkes **Passwort oder eine PIN** fest (falls erforderlich)
4.  Ihnen wird eine **Wiederherstellungsphrase** (12 oder 24 Wörter) angezeigt –

    → **Schreiben Sie diese auf und bewahren Sie sie an einem sicheren, offline zugänglichen Ort auf**
5. **Bestätigen Sie Ihre Wiederherstellungsphrase**, um die Einrichtung abzuschließen
6.  **Laden Sie Ihr Wallet mit SOL auf**

    → Sie benötigen **SOL**, um Gasgebühren beim Swappen oder Bereitstellen von Liquidität auf PancakeSwap zu bezahlen

***

> Warum SOL?
>
> SOL ist das **native Token der Solana-Blockchain** – es wird zur Bezahlung von Transaktionsgebühren verwendet.
>
> Bevor Sie mit PancakeSwap interagieren können, müssen Sie etwas SOL in Ihrem Wallet halten.

Sie können:

* SOL an einer zentralisierten Börse kaufen und übertragen
* Oder Assets über eine Cross-Chain Bridge zu Solana übertragen unter [pancakeswap.finance/bridge](https://pancakeswap.finance/bridge)

Sehen Sie hier, wie Sie [SOL erhalten](https://docs.pancakeswap.finance/welcome-to-pancakeswap/how-to-guides/get-started-sol/get-sol)
