# はじめに (Monad)

新しいサービスを使い始めるのは、最初は戸惑うこともあるかもしれません。でもご安心ください。Monad上のPancakeSwapを快適にお使いいただけるよう、さまざまなガイドをご用意しています。

## PancakeSwapのセットアップ

以下のガイドに沿って、Monad上でPancakeSwapを使うための準備を整えましょう。すでにある程度お使いで途中で迷ってしまった方は、必要なガイドに直接ジャンプしていただいても構いません。

* [ウォレットを作成する (MON)](https://docs.pancakeswap.finance/welcome-to-pancakeswap/how-to-guides/get-started-monad/create-a-wallet-monad)

お探しの情報が見つからない場合は、[PancakeSwap Telegram](../../contact-us/social-accounts.md)にお気軽にご参加いただき、サポートをお求めください。
