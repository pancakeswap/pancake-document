Usar algo nuevo puede ser un poco desafiante. ¡No te preocupes! Hemos creado una serie de guías para ayudarte a familiarizarte con PancakeSwap en Monad.

Sigue estas guías para tener todo listo y comenzar a usar PancakeSwap en Monad, o salta directamente a la guía que necesites si ya llevas un tiempo pero te has perdido.

* [Crear una billetera (MON)](https://docs.pancakeswap.finance/welcome-to-pancakeswap/how-to-guides/get-started-monad/create-a-wallet-monad)
* [FAQ de Monad](https://docs.pancakeswap.finance/welcome-to-pancakeswap/how-to-guides/get-started-monad/monad-faq)

Si no encuentras lo que necesitas, visita el [Telegram de PancakeSwap](../../contact-us/social-accounts.md) y pide ayuda allí.
