# Démarrer (Monad)

Prendre en main un nouvel outil peut sembler intimidant. Pas d'inquiétude, nous avons élaboré une série de guides pour vous aider à vous familiariser avec PancakeSwap sur Monad !

## Configuration de PancakeSwap

Suivez ces guides pour tout configurer et utiliser PancakeSwap sur Monad, ou accédez directement au guide dont vous avez besoin si vous vous êtes perdu en chemin.

* [Créer un portefeuille (MON)](https://docs.pancakeswap.finance/welcome-to-pancakeswap/how-to-guides/get-started-monad/create-a-wallet-monad)
* [FAQ Monad](https://docs.pancakeswap.finance/welcome-to-pancakeswap/how-to-guides/get-started-monad/monad-faq)

Si vous ne trouvez pas ce dont vous avez besoin, n'hésitez pas à visiter le [Telegram PancakeSwap](../../contact-us/social-accounts.md) et à y poser vos questions !
