# Get Started (Monad)

Utiliser quelque chose de nouveau peut être un peu difficile. Pas d'inquiétude, nous avons créé une série de guides pour vous aider à prendre en main PancakeSwap sur Monad !

## Configurer PancakeSwap

Suivez ces guides pour tout préparer afin d'utiliser PancakeSwap sur Monad, ou rendez-vous directement au guide dont vous avez besoin si vous vous en sortiez bien mais que vous vous êtes perdu(e).

* [Create a wallet (MON)](https://docs.pancakeswap.finance/welcome-to-pancakeswap/how-to-guides/get-started-monad/create-a-wallet-monad)
* [Monad FAQ](https://docs.pancakeswap.finance/welcome-to-pancakeswap/how-to-guides/get-started-monad/monad-faq)

Si vous ne trouvez pas ce dont vous avez besoin, n'hésitez pas à visiter le [Telegram de PancakeSwap](../../contact-us/social-accounts.md) pour y demander de l'aide !
