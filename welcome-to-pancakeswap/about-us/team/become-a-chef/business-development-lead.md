# ビジネスデベロップメントリード

PancakeSwap は、BNB Chain におけるトップ AMM DEX から、ネイティブ AMM プール・機関投資家向け資本・外部流通チャネルからの流動性を集約・管理するフル流動性ハブへと移行しています。本ポジションは、その構築における 3 つの専門 BD 部門のエンドツーエンドを統括します。

### ポジション概要

当社では BD チームを、チェーン別ではなく 3 つの流動性ソース別に再編します。BD リードとして Traditional AMM、機関投資家向け流動性 + RWA、新製品の流通という 3 部門全体のエンドツーエンドを担当します。担当領域のパートナーシップ、KPI、パイプラインの最初のコンタクトからライブ統合まで、社内の専門家として機能します。

これはオペレーター型の役割であり、リレーションシップ型ではありません。創出された取引量（CAKE エミッションあたり）、機関投資家向け取引量、集約 API インテグレーションの出荷数など、アウトカムで評価されます。初日から Q2 2026 の具体的な優先リストに対して週次で進捗を示すことが期待されます。



1. **Traditional AMM**

* BNB Chain、Base、SOL における CAKE エミッション効率、プロジェクトのオンボーディング（V2/V3/Infinity CLAMM）、クロスチェーンローンチパッドのパイプラインを担当する。&#x20;
* 主要指標：CAKE エミッション単位あたりの取引量。&#x20;
* 副次指標：四半期ごとの新規アクティブプール数、各チェーンでの初回ローンチプロジェクト数。
* **現在の優先事項：** Base + SOL エコシステムファンドとの関係構築 · Infinity CLAMM プロジェクトパイプライン



2. **機関投資家向け流動性 + RWA**

* トークン化株式・RWA 発行体のオンボーディング（xStocks/Backed Finance/Ondo/Robinhood）、マーケットメーカーのオンボーディング（Wintermute、Jump、GSR）、PancakeSwap X RFQ の Kraken、Bybit、OKX への流通を担当する。&#x20;
* PropAMM の機関投資家向けパイプラインを構築する。主要指標：PancakeSwap X の月次取引量、オンボードされた RWA 発行体数。
* **現在の優先事項：** BNB + Base 上の xStocks プール · Backed Finance / Kraken パートナーシップ



3. **新製品の流通**

* 1inch をウォレット（OKX、Binance、MetaMask、Trust）および DeFi プロトコル（Aave、Venus、Morpho）のデフォルト集約 API として置き換える。&#x20;
* レベニューシェアプログラムの設計、ホワイトラベル API パッケージング、競合切り替え分析を担当する。副次業務：無期限取引の機関投資家向けオンボーディング（役割の約 20%）。&#x20;
* 主要指標：四半期ごとの API インテグレーション出荷数、集約経由の月次取引量。
* **現在の優先事項：** 1inch、LiFi、Liquid Mesh の詳細競合分析 · ターゲットリストの構築

### 担当業務

* パートナーシップの全ライフサイクルを担当：ソーシング、交渉、統合、継続的な健全性指標の管理\
  パイプライン状況と部門 KPI を CEO に週次で報告し、問題だけでなく解決策の提案とともにブロッカーを共有する
* 週次の部門間 BD シンクに参加し、パイプラインの重複を把握して共同アプローチを調整する
* 担当部門のドメインに特化した継続的な競合調査を実施し、知見を実行可能な差別化戦略に変換する
* 部門が成熟するにつれて、配下の小規模な BD マネージャーチームを構築・指導する
