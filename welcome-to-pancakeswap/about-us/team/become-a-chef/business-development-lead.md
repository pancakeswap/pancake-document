# 商务拓展负责人

PancakeSwap 正在从 BNB 链上领先的 AMM DEX 转型为完整的 Liquidity Hub——聚合并管理来自原生 AMM 资金池、机构资金和外部分发渠道的流动性。该职位将领导这一建设过程中三个专业化 BD 部门之一。

### 关于该职位

我们正在围绕三类流动性来源（而非区块链）重组 BD 团队。作为 BD 负责人，你将端到端负责：传统 AMM、机构流动性 + RWA、新产品分发。你将成为内部的领域专家，负责合作伙伴关系、KPI，以及从首次接触到正式上线集成的整条业务管线。

这是一个操盘手型职位，而不是关系维护型职位。我们衡量的是成果：每释放一枚 CAKE 所产生的交易量、机构交易量、已交付的聚合器 API 集成数量。从入职第一天起，我们就期望你针对具体的 2026 年第二季度优先事项清单每周汇报进展。

#### 1. 传统 AMM

* 负责 CAKE 释放效率、项目接入（V2/V3/Infinity CLAMM），以及覆盖 BNB 链、Base 和 SOL 的跨链启动平台业务管线。
* **核心指标：** 每单位 CAKE 释放所产生的交易量。
* **次要指标：** 每季度新增活跃资金池数量、每条链上的首发项目数量。
* **当前紧急事项：** Base + SOL 生态基金关系 · Infinity CLAMM 项目管线

#### 2. 机构流动性 + RWA

* 负责代币化股票和 RWA 发行方的接入（xStocks/Backed Finance/Ondo/Robinhood）、做市商的接入（Wintermute、Jump、GSR），以及将 PancakeSwap X RFQ 分发到 Kraken、Bybit、OKX。
* 构建 PropAMM 机构业务管线。
* **核心指标：** PancakeSwap X 月交易量、已接入的 RWA 发行方数量。
* **当前紧急事项：** BNB + Base 上的 xStocks 资金池 · Backed Finance / Kraken 合作

#### 3. 新产品分发

* 取代 1inch，成为钱包（OKX、Binance、MetaMask、Trust）和 DeFi 协议（Aave、Venus、Morpho）默认使用的聚合器 API。
* 负责收益分成计划设计、白标 API 打包，以及竞品切换分析。
* **次要职责：** 永续合约机构接入（约占职位的 \~20%）。
* **核心指标：** 每季度交付的 API 集成数量、每月聚合器路由交易量。
* **当前紧急事项：** 对 1inch、LiFi、Liquid Mesh 进行深入的竞品分析 · 构建目标名单

### 你将负责

* 负责完整的合作伙伴生命周期：寻源、谈判、集成以及持续的健康度指标。
* 每周向 CEO 汇报业务管线状态和部门 KPI；提出阻碍因素时附上建议的解决方案，而不仅仅是指出问题。
* 参加每周的跨部门 BD 同步会，发现业务管线的重叠之处并协调联合推进方式。
* 持续开展针对你所在业务领域的竞品情报研究，并将发现转化为可落地的差异化策略。
* 随着部门逐步成熟，在你名下组建并指导一支小型 BD 经理团队。

### 我们在寻找

#### 必备条件

* 在 DeFi、加密货币或金融科技领域拥有 3 年以上的 BD、合作伙伴或增长经验——且有已签约交易的业绩记录，而不仅仅是业务管线
* 量化思维：能够熟练阅读链上数据、TVL/交易量看板，并从第一性原理出发自行设定 KPI 目标
* 在你目标业务领域拥有深厚的既有人脉（AMM 项目 / 机构/RWA 发行方 / 钱包或协议生态团队）
* 自主且有条理：能够在无需手把手指导的情况下同时管理多个并行的交易，并及早沟通阻碍因素
* 主人翁心态

#### 加分项

* 曾在 DEX、AMM、聚合器或 RWA 平台工作过
* 能够独立阅读智能合约交互或解读 Dune 看板
* 有从零开始组建或管理 BD 团队的经验
