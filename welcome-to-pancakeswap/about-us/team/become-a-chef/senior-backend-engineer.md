# 高级后端工程师

### 基本信息

* 薪资范围：具有竞争力，可协商
* 职位类型：全职
* 工作地点：远程
* 时区偏好：不限

### 职位概述

我们正在寻找一位经验丰富的后端工程师，热爱加密货币和 DeFi，并对微服务架构有深入的理解。你将与多元化的工程师团队紧密合作，设计、开发和维护支撑我们加密平台的后端服务。

### 你的职责

* 设计、开发和维护可扩展的后端服务和微服务。
* 与跨职能团队合作，与 DeFi 协议及其他区块链解决方案进行集成。
* 实现安全、高效、可靠的 API，为我们的加密服务提供支持。
* 在云环境中开发和部署基础设施，以确保可扩展性和性能。
* 分析并优化系统性能和稳定性。
* 紧跟区块链、DeFi 和后端技术的最新发展。

### 技能与资格

* 5 年以上后端开发经验。
* 精通现代后端编程语言，例如 Typescript
* &#x20;（必备），Rust（加分项）。
* 具有智能合约以及基于以太坊 / 基于 Solana 的应用的相关经验。
* 具有微服务和分布式系统的相关经验。
* 深入理解区块链、加密货币和 DeFi 概念。
* 具有构建 API 和集成第三方服务的实战经验。
* 具有云平台（例如 AWS、DigitalOcean）使用经验。
* 出色的问题解决能力，注重细节。
* 出色的沟通能力和协作心态。

### 加分项

* 了解 Kubernetes 等容器编排技术。
* 熟悉 PostgreSQL、Redis 或类似的数据库技术。
* 有在初创公司或快节奏环境中工作的经验。
* 具有 TheGraph 或 Subsquid 等索引解决方案的经验。

### 为什么加入我们？

* 在令人兴奋的区块链和 DeFi 领域，从事前沿技术工作。
* 加入一支充满热情、知识渊博且乐于互相支持的团队。
* 在快速发展的加密领域拥有成长和发展的机会
