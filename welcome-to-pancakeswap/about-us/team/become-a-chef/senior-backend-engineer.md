# シニアバックエンドエンジニア

### 基本情報

* 給与レンジ：競争力のある水準、交渉可能
* ポジション：フルタイム
* 勤務地：リモート
* タイムゾーン：問わず

### ポジション概要

暗号資産と DeFi への情熱を持ち、マイクロサービスアーキテクチャへの深い理解がある経験豊富なバックエンドエンジニアを募集しています。多様なエンジニアチームと緊密に連携し、当社の暗号資産プラットフォームをサポートするバックエンドサービスの設計・開発・維持を担当します。

### 担当業務

* スケーラブルなバックエンドサービスおよびマイクロサービスを設計・開発・維持する。
* DeFi プロトコルおよびその他のブロックチェーンソリューションとの統合のために部門横断チームと連携する。
* 暗号資産サービスを支える安全で効率的かつ信頼性の高い API を実装する。
* スケーラビリティとパフォーマンスを確保するためのクラウド環境へのインフラの開発・デプロイを行う。
* システムのパフォーマンスと安定性を分析・最適化する。
* ブロックチェーン、DeFi、バックエンド技術の最新動向を常に把握する。

### スキルと資格

* バックエンド開発の経験 5 年以上。
* Typescript（必須）、Rust（あると望ましい）等の最新バックエンドプログラミング言語への深い知識。&#x20;
* スマートコントラクトおよび Ethereum ベース / Solana ベースのアプリケーションの経験。
* マイクロサービスおよび分散システムの経験。
* ブロックチェーン、暗号資産、DeFi のコンセプトへの深い理解。
* API の構築とサードパーティサービスとの統合の実務経験。
* クラウドプラットフォーム（AWS、DigitalOcean など）の経験。
* 強い問題解決スキルと細部への注意力。
* 優れたコミュニケーションスキルと協調的なマインドセット。

### あると望ましいこと

* Kubernetes 等のコンテナオーケストレーション技術の知識。

* TheGraph や Subsquid 等のインデックスソリューションの経験。
