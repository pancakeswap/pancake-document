# शेफ बनें

क्या आप PancakeSwap टीम में शामिल होने में रुचि रखते हैं? यदि आप उत्साही, समर्पित हैं, और हर उस चीज़ के प्रशंसक हैं जो मुलायम, मीठी और सुनहरी-भूरी है, तो हम आपसे सुनना चाहेंगे!
