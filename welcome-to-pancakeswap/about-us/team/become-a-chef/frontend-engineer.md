# シニアフロントエンドエンジニア

### 基本情報

* 給与レンジ：競争力のある水準、交渉可能
* ポジション：フルタイム
* 勤務地：リモート
* タイムゾーン：問わず

### 担当業務

* 複雑なフロントエンド製品・アップグレードを設計、スコープ設定、見積もりする。
* PancakeSwap の成長を助ける機能を構想・開発する。
* 小規模なチームと積極的に連携し、タスクレベルでプロジェクトを計画する。
* 製品開発のあらゆる面で部門横断的なパートナーと協力する。
* チーム全体の改善点とベストプラクティスを特定・推進する。

### スキルと資格

* TypeScript、React.js、Node.js の確かな経験。
* レスポンシブ / アダプティブ Web アプリケーション構築のプロフェッショナル経験 5 年以上。
* クリーンで保守性が高く構造化されたコードを書く強い能力。
* JavaScript テストフレームワークの経験。
* 最新のフロントエンドビルドパイプラインとツールへの習熟。
* スケーラブルなフロントエンドソリューションのアーキテクチャ設計と提供の経験。
* viem、wagmi 等の最新 Web3 ライブラリへの知見を含む、Web3 および分散型アプリケーションフロントエンドの実務経験。
* GraphQL の経験。

### 主要な特性

* **学習意欲：** 新しいツールや技術を積極的に探求する姿勢。
* **自律性：** 自らリサーチを行い、知見を実践的なソリューションに変換できること。
* **習得の速さ：** 変化する要件や環境に迅速に適応できること。
* **革新的思考：** 製品とワークフローを改善する方法を積極的に模索する姿勢。
