# 前端工程师（合同制）

### 基本信息

* 薪资范围：具有竞争力，可协商
* **期限：1 - 2 个季度**
* 职位类型：全职 / 兼职
* 工作地点：远程
* 时区偏好：不限

### 你的职责

* 根据我们的需求，为 PancakeSwap 设计并构建 iOS / Android 应用。
* 构想并开发有助于应用增长的功能。
* 积极与小型团队协作，在任务层面规划项目。
* 与跨职能合作伙伴在产品开发的各个方面开展协作。

### 技能与资质

* 3-5 年构建去中心化应用的经验
* 扎实的 Typescript 和 React JS 经验。
* 能够编写结构化、整洁的代码。
* 具有 Javascript 测试工具的使用经验。
* 具有现代前端构建流水线和工具的使用经验。
* 具有定义和交付可扩展前端架构的经验。
* 有一定的 GraphQL 经验。
* 具有 Web3 及去中心化应用前端的工作经验。
* 能够独立工作并勇于创新。

### 加分项

* 了解 Solidity 和 AMM
* 了解 PancakeSwap 的产品

### 如何申请：

请将你的简历发送至 hiring@pancakeswap.com！
