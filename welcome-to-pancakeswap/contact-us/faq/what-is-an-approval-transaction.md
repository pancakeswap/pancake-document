# ¿Qué es una Transacción de Aprobación?

**La primera vez que intercambias o agregas liquidez, debes aprobar el token que estás intercambiando. Esto le da al contrato inteligente de PancakeSwap permiso para intercambiar ese token desde tu billetera.**



La transacción de aprobación le permite a PancakeSwap el permiso de intercambiar el token desde tu billetera. Debes completar una transacción de aprobación para cada token que quieras intercambiar usando PancakeSwap.



Aquí hay una guía sobre cómo completar una transacción de aprobación:

1.  Ingresa los detalles de tu intercambio.&#x20;

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/step1%20%281%29%20%281%29.png" alt=""><figcaption></figcaption></figure>
2.  Selecciona "Confirmar intercambio" después de revisar los detalles del intercambio.&#x20;

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/4536.png" alt=""><figcaption></figcaption></figure>
3. En la aplicación de billetera o extensión de billetera, aprueba el gasto del token que estás intercambiando.

Permite que el token sea usado para intercambiar en tu billetera.

_Tu billetera puede requerirte ingresar el número de tokens que quieres aprobar. Por favor, ingresa un número mayor o igual al número de tokens que estás intercambiando._&#x20;

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/1%20%281%29.png" alt=""><figcaption></figcaption></figure>

4.  Después de la aprobación, aparecerá otra transacción que te pedirá confirmar el intercambio.&#x20;

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/3.png" alt=""><figcaption></figcaption></figure>
5.  Una vez confirmado el intercambio, la transacción se envía a la blockchain (pendiente).&#x20;

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/step%2004.png" alt=""><figcaption></figcaption></figure>
6. Verás "Éxito" y una marca de verificación verde en la pantalla cuando la transacción se complete exitosamente.&#x20;

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/5.png" alt=""><figcaption></figcaption></figure>

La aprobación del token dura un período de tiempo determinado; el token deberá ser aprobado nuevamente más tarde con una solicitud de firma. Una firma de aprobación no requiere una tarifa de red.
