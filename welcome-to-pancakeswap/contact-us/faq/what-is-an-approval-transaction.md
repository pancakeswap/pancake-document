# Was ist eine Genehmigungstransaktion?

**Beim ersten Swap oder beim ersten Hinzufügen von Liquidität müssen Sie den Token, den Sie tauschen, genehmigen. Dadurch erhält der PancakeSwap-Smart-Contract die Berechtigung, diesen Token aus Ihrer Wallet zu tauschen.**



Die Genehmigungstransaktion erteilt PancakeSwap die Berechtigung, den Token aus Ihrer Wallet zu tauschen. Sie müssen für jeden Token, den Sie über PancakeSwap tauschen möchten, eine Genehmigungstransaktion durchführen.



Hier ist eine Anleitung zur Durchführung einer Genehmigungstransaktion:

1.  Geben Sie Ihre Swap-Details ein.&#x20;

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/step1%20%281%29%20%281%29.png" alt=""><figcaption></figcaption></figure>
2.  Wählen Sie nach Überprüfung der Swap-Details „Swap bestätigen" aus.&#x20;

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/4536.png" alt=""><figcaption></figcaption></figure>
3. Genehmigen Sie in Ihrer Wallet-App oder Wallet-Erweiterung die Ausgabe für den Token, den Sie tauschen.

Erlauben Sie, dass der Token zum Tauschen in Ihrer Wallet verwendet werden darf.

_Ihre Wallet fordert Sie möglicherweise auf, die Anzahl der Token einzugeben, die Sie genehmigen möchten. Bitte geben Sie eine Zahl ein, die größer oder gleich der Anzahl der Token ist, die Sie tauschen._&#x20;

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/1%20%281%29.png" alt=""><figcaption></figcaption></figure>

4.  Nach der Genehmigung erscheint eine weitere Transaktion, die Sie auffordert, den Swap zu bestätigen.&#x20;

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/3.png" alt=""><figcaption></figcaption></figure>
5.  Sobald der Swap bestätigt ist, wird die Transaktion an die Blockchain übermittelt (ausstehend).&#x20;

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/step%2004.png" alt=""><figcaption></figcaption></figure>
6. Sie sehen „Erfolg" und ein grünes Häkchen auf dem Bildschirm, wenn die Transaktion erfolgreich abgeschlossen wurde.&#x20;

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/5.png" alt=""><figcaption></figcaption></figure>

Die Token-Genehmigung ist für einen bestimmten Zeitraum gültig; danach muss der Token mit einer Signaturanfrage erneut genehmigt werden. Eine Genehmigungssignatur erfordert keine Netzwerkgebühr.
