# Ich benötige Hilfe



![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/help-area-header.png)

Wenn Sie nicht weiterkommen, etwas nicht wie erwartet funktioniert oder Sie sich nicht sicher sind, ob etwas funktioniert hat oder nicht, kann Ihnen dieser Hilfebereich weiterhelfen.

## Hilfebereiche

Wir haben die Hilfethemen in Abschnitte unterteilt, damit Sie schnell finden, was Sie suchen. Im Folgenden erhalten Sie einen Überblick darüber, was Sie erwartet.

### Fehlerbehebung

Die [Seite zur Fehlerbehebung](https://docs.pancakeswap.finance/help/troubleshooting) enthält eine Sammlung von Fehlern, auf die Nutzer bei der Verwendung von PancakeSwap stoßen können. Sie zeigt das Problem zusammen mit einer Lösung und einer Erklärung, warum das Problem aufgetreten ist.

### Allgemeine FAQ

Die [allgemeine FAQ-Seite](https://docs.pancakeswap.finance/help/faq) beantwortet häufig gestellte Fragen von PancakeSwap-Nutzern. Die Antworten bieten Ratschläge, Erklärungen oder Links zu nützlichen Ressourcen.

### Weitere Anleitungen

Im Hilfebereich finden Sie außerdem eine Reihe von Anleitungen, die Sie durch technische Probleme führen. Wir fügen Anleitungen hinzu, wenn ein Problem, das schwer zu lösen sein könnte, häufig auftritt. Falls Sie Schwierigkeiten haben, schauen Sie hier nach einer Anleitung zu Ihrem Problem.

## Support erhalten

PancakeSwap verfügt über keinen dedizierten Support-Service. Falls Sie jedoch auf ein Problem stoßen, das hier keine Antwort findet, können Sie im [Telegram-Kanal von PancakeSwap](https://t.me/pancakeswap) um Hilfe bitten. Lesen Sie zu Ihrer eigenen Sicherheit den Hinweis zu Betrugsversuchen, wenn Sie zum ersten Mal in unserem Telegram sind.
