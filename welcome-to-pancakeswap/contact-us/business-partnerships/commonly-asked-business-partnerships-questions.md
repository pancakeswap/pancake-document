# ❓ Häufig gestellte Fragen zu Geschäftspartnerschaften

#### Wie lange dauert es, bis ich eine Antwort erhalte?

Wir bemühen uns, innerhalb einer Woche auf Bewerbungen zu antworten. Aufgrund der großen Anzahl von Anfragen können wir jedoch nicht jeden einzelnen Bewerber beantworten. Wenn Sie innerhalb von zwei Wochen nach Ihrer Bewerbung keine Rückmeldung erhalten haben, wenden Sie sich bitte über Telegram an [ @PancakeSwapBD](https://t.me/PancakeSwapBD) mit dem Namen Ihres Projekts, der Website Ihres Projekts und dem Datum Ihrer Bewerbung.

#### Kann ich meinen Syrup Pool verlängern?

Wenn Sie bereits einen laufenden Syrup Pool haben, können Sie den Zeitraum durch zusätzliche Token-Freigaben verlängern. Wenden Sie sich über Ihre bestehenden PancakeSwap-Kommunikationskanäle an uns für Anfragen.

### Listing auf der Exchange

#### Wie kann ich meinen Token auf der Exchange listen?

Jeder kann beliebige ERC-20/BEP-20-Netzwerk-Token auf PancakeSwap listen. Sie müssen uns weder kontaktieren noch eine Genehmigung einholen. Sie müssen lediglich [Liquidität zu einem Liquiditätspool hinzufügen](https://docs.pancakeswap.finance/products/pancakeswap-exchange/pancakeswap-pools) – das ist alles. Händler können Ihren Token dann durch Eingabe der Contract-Adresse Ihres Tokens handeln.

#### Wie kann ich meinen Token zur Standard-Liste hinzufügen?

Projekte, die Farms betreiben, werden in der Regel zur erweiterten Token-Liste hinzugefügt, und andere Token, die vom PancakeSwap-Kernteam ausgewählt wurden, können ebenfalls hinzugefügt werden.

Wir nehmen keine Bewerbungen für die Liste entgegen. Nutzer können Ihren Token weiterhin manuell durch Eingabe der Contract-Adresse hinzufügen.

#### Wie kann ich das Logo/Symbol meines Tokens hinzufügen?

Bitte fügen Sie Ihr Symbol zum Assets-Repository von Trust Wallet hinzu, auf das PancakeSwap verweist:[ https://github.com/trustwallet/assets](https://github.com/trustwallet/assets)

#### Jemand hat eine gefälschte Kopie meines Tokens erstellt! Können Sie diese sperren?

Aufgrund der Natur von PancakeSwap als AMM-basierte DEX ist es uns nicht möglich, den Handel mit einem Token zu verhindern. Wir empfehlen, sicherzustellen, dass Ihr Token-Contract auf Ihrer Website klar sichtbar und verifizierbar ist, und Ihre Nutzer darüber zu informieren, wie sie Ihren Token sicher handeln können.

#### Nutzer erhalten beim Handel mit meinem Token eine Fehlermeldung. Was kann ich tun?

Sehen Sie sich unsere [Fehlerbehebungsseite](https://docs.pancakeswap.finance/readme/help/troubleshooting) für eine Liste häufiger Fehler auf der Exchange und deren Lösungen an.

#### Warum werden einige Statistiken meiner Token auf der Info-Seite nicht angezeigt?

Token müssen mit einem „gängigen" Token gepaart sein und eine Mindestliquiditätsmenge in diesem „gängigen" Token aufweisen, damit die Info-Seite das Token-Paar zu indizieren beginnt. Die Statistiken des zugrunde liegenden Tokens werden angezeigt, sobald das Token-Paar indiziert ist.&#x20;
