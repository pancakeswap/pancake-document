# ❓ Pertanyaan Kemitraan Bisnis yang Sering Diajukan

#### Berapa lama waktu yang dibutuhkan untuk mendapat respons?

Kami berusaha merespons aplikasi dalam waktu satu minggu, tetapi karena banyaknya permintaan, kami tidak dapat merespons setiap pemohon. Jika Anda tidak mendengar kabar dari kami dalam dua minggu setelah mendaftar, coba hubungi [@PancakeSwapBD](https://t.me/PancakeSwapBD) di Telegram, dengan nama proyek Anda, situs web proyek, dan tanggal Anda mendaftar.

#### Bisakah saya memperpanjang Syrup Pool saya?

Jika Anda sudah memiliki Syrup Pool yang sedang berjalan, Anda dapat memperpanjang jangka waktunya dengan rilis token tambahan. Hubungi kami melalui saluran komunikasi PancakeSwap yang ada untuk pertanyaan lebih lanjut.

### Daftar di Bursa

#### Bagaimana cara mendaftarkan token saya di bursa?

Siapa pun dapat "mendaftarkan" token jaringan ERC-20 / BEP-20 apa pun di PancakeSwap. Anda tidak perlu menghubungi kami atau meminta izin. Anda hanya perlu [menambahkan Likuiditas ke Pool Likuiditas](https://docs.pancakeswap.finance/products/pancakeswap-exchange/pancakeswap-pools) - hanya itu. Pedagang kemudian dapat memperdagangkan token Anda dengan memasukkan alamat kontrak token Anda.

#### Bagaimana cara menambahkan token saya ke daftar default?

Proyek yang menyelenggarakan Farm biasanya akan ditambahkan ke daftar token Extended, dan token lain yang dipilih oleh tim inti PancakeSwap juga dapat ditambahkan.

Kami tidak menerima aplikasi untuk daftar tersebut. Pengguna tetap dapat menambahkan token Anda secara manual dengan memasukkan alamat kontraknya.

#### Bagaimana cara menambahkan logo/ikon token saya?

Harap tambahkan ikon Anda ke repositori aset Trust Wallet, yang direferensikan oleh PancakeSwap:[ https://github.com/trustwallet/assets](https://github.com/trustwallet/assets)

#### Seseorang membuat salinan palsu token saya! Bisakah Anda memblokirnya?

Karena sifat PancakeSwap sebagai DEX berbasis AMM, kami tidak dapat mencegah perdagangan token apa pun. Kami menyarankan untuk memastikan bahwa kontrak token Anda terlihat jelas dan dapat diverifikasi di situs Anda serta mendidik pengguna Anda tentang cara memperdagangkan token Anda dengan aman.

#### Pengguna mendapatkan error saat memperdagangkan token saya. Apa yang bisa saya lakukan?

Periksa [halaman Pemecahan Masalah](https://docs.pancakeswap.finance/readme/help/troubleshooting) kami untuk daftar kesalahan umum di bursa, dan cara mengatasinya.

#### Mengapa beberapa statistik token saya tidak ditampilkan di halaman Info?

Token perlu dipasangkan dengan token "umum", dan memiliki jumlah Likuiditas minimum yang denominasi dalam token "umum" agar halaman Info mulai mengindeks pasangan token. Statistik token yang mendasarinya akan ditampilkan setelah pasangan token diindeks.&#x20;
