# アンバサダープログラム

PancakeSwapアンバサダープログラムは、最も熱心なユーザーや支持者を支援するために設計されており、エコシステムの成長に積極的に貢献する機会を提供しています。アンバサダーはPancakeSwapを代表し、新しいユーザーへの教育を行い、世界中でコミュニティのエンゲージメントを促進する重要な役割を担っています。

#### 🔹 アンバサダーの役割

責任の明確化のため、プログラムは以下の異なる役割に分けられています：

🔹 モデレーション – コミュニティモデレーターは、プラットフォーム全体で安全で歓迎的かつ有益な環境を維持するお手伝いをします。ユーザーをサポートし、コミュニティガイドラインを遵守し、円滑なコミュニケーションを確保します。

📢 コンテンツ制作 – コンテンツに情熱を持つアンバサダーは、PancakeSwapを宣伝しコミュニティを教育する記事、動画、ソーシャルメディア投稿、その他のクリエイティブな素材を通じて貢献できます。

🎤 イベント（オンライン＆オフライン） – アンバサダーはワークショップ、ミートアップ、地域イベントを企画・参加することで、認知度を高めPancakeSwapへの新規ユーザーのオンボーディングを促進できます。
