# Dashboard & Link

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/affiliate-landing-page-07.png" alt=""><figcaption></figcaption></figure>

Das Affiliate-Dashboard ist die Zentrale des Affiliate-Programms. Hier können Sie Links erstellen und teilen sowie Belohnungen verfolgen und einlösen.

Hier sind die Schritte zum Zugriff auf das Dashboard und zur Erstellung eines Affiliate-Links:

1. **Zugriff auf das Affiliate-Dashboard**&#x20;
   1. Gehen Sie zur Seite [Affiliate-Programm](https://pancakeswap.finance/affiliates-program)&#x20;
   2. Melden Sie sich mit der Wallet an, die in der Programmbewerbung verwendet wurde
   3. Klicken Sie auf den Tab 'Dashboard'
   4. Sie werden möglicherweise zur Anmeldung aufgefordert. Melden Sie sich mit Ihrer bevorzugten Krypto-Wallet an.
2.  **Link generieren**

    1. Gehen Sie auf der Dashboard-Seite zum Abschnitt "Link generieren".&#x20;
    2.  Legen Sie den einzigartigen Code und die Gewinnbeteiligungsrate für den spezifischen Link fest. Weitere Informationen dazu finden Sie [hier](commission-structure-and-payment.md)\
        &#x20;

        <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/affiliate-landing-page-10.png" alt=""><figcaption></figcaption></figure>
    3. Klicken Sie auf "Link generieren" und bestätigen Sie die Signatur. Es sollte ein Popup erscheinen, das Sie darüber informiert, dass ein Link generiert wurde.
    4.  Gehen Sie zum Link-Bereich unten und kopieren Sie den erstellten Link. <br>

        <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/affiliate-landing-page-09.png" alt=""><figcaption></figcaption></figure>

    Sobald dies abgeschlossen ist, können Sie den Affiliate-Link mit Ihrer Community teilen und eine Provision verdienen, wenn Ihre Freunde auf PancakeSwap handeln. Weitere Informationen darüber, wie wir einen neuen Nutzer qualifizieren, finden Sie auf der Seite [Nutzungsbedingungen](terms-and-conditions.md).
