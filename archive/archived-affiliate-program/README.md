# 推广计划

PancakeSwap 的推广计划旨在奖励那些持续帮助壮大社区、分享我们产品的人。该计划起初将面向一批精选的 PancakeSwap 拥护者开放，Kitchen 计划之后向更多用户推出。作为推广者，你将加入一个由志同道合的人组成的网络，共同致力于打造更强大的 DeFi 社区。

### 成为推广者

成为推广者很简单。你只需访问我们的[推广页面](https://pancakeswap.finance/affiliates-program)，那里有开始所需的全部信息。你也可以填写这份 [google form](https://docs.google.com/forms/d/e/1FAIpQLSfP43IciQ5cH0JhTf1fDgUpwapBx-yD3ybv24pBdiVW7Th5jQ/viewform)。&#x20;

提交申请后，Kitchen 会审核你的申请，并判断你是否适合该计划。这个过程可能需要一些时间，请耐心等待！如果申请通过，我们会通过你的电子邮件或 telegram 联系你。

如果 Kitchen 批准了你的申请，你将通过连接在申请中提交的钱包获得推广者仪表板的访问权限。&#x20;

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/affiliate-landing-page-07.png" alt=""><figcaption></figcaption></figure>

该仪表板将为你提供一系列工具和资源，用于分享协议的产品或服务并追踪你的佣金。

进入仪表板后，你可以创建推广链接分享给你的社区。当**新用户点击**你的推广链接并完成特定交易时，你将获得佣金。分享你对 PancakeSwap 的喜爱时，请务必始终使用你的推广链接！
