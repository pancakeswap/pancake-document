# Affiliate-Programm

Das Affiliate-Programm von PancakeSwap wurde entwickelt, um diejenigen zu belohnen, die weiterhin dabei helfen, die Community zu erweitern und unsere Produkte zu teilen. Das Programm wird zunächst einer ausgewählten Gruppe von PancakeSwap-Unterstützern zur Verfügung stehen, und das Kitchen plant, es auf weitere Nutzer auszuweiten. Als Affiliate sind Sie Teil eines Netzwerks Gleichgesinnter, die dem Aufbau einer stärkeren DeFi-Community verpflichtet sind.

### Affiliate werden

Affiliate zu werden ist einfach. Besuchen Sie einfach unsere [Affiliate-Seite](https://pancakeswap.finance/affiliates-program), auf der Sie alle Informationen finden, die Sie für den Einstieg benötigen. Alternativ können Sie ein [Google-Formular](https://docs.google.com/forms/d/e/1FAIpQLSfP43IciQ5cH0JhTf1fDgUpwapBx-yD3ybv24pBdiVW7Th5jQ/viewform) ausfüllen.&#x20;

Nachdem Sie Ihre Bewerbung eingereicht haben, prüft das Kitchen Ihre Bewerbung und entscheidet, ob Sie gut zum Programm passen. Dieser Prozess kann einige Zeit in Anspruch nehmen, bitte haben Sie Geduld! Wenn Sie genehmigt werden, werden wir uns per E-Mail oder Telegram an Sie wenden.

Wenn das Kitchen Ihre Bewerbung genehmigt, erhalten Sie Zugang zum Affiliate-Dashboard, indem Sie die in der Programmbewerbung angegebene Wallet verbinden.&#x20;

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/affiliate-landing-page-07.png" alt=""><figcaption></figcaption></figure>

Dieses Dashboard bietet Ihnen eine Reihe von Tools und Ressourcen, mit denen Sie die Produkte oder Dienste des Protokolls teilen und Ihre Provision verfolgen können.

Sobald Sie auf das Dashboard zugreifen können, können Sie Affiliate-Links erstellen, die Sie mit Ihrer Community teilen können. Sie verdienen eine Provision, wenn ein **neuer Nutzer** auf Ihren Affiliate-Link klickt und eine bestimmte Transaktion durchführt. Stellen Sie sicher, dass Sie immer Ihren Affiliate-Link verwenden, wenn Sie Ihre Begeisterung für PancakeSwap teilen!
