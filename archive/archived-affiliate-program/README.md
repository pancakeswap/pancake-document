# アフィリエイトプログラム

PancakeSwapのアフィリエイトプログラムは、コミュニティの拡大とプロダクトの普及に貢献し続けている方々を報奨するために設計されています。このプログラムは最初は選ばれたPancakeSwapの支持者グループを対象に提供され、Kitchenはより多くのユーザーに展開していく予定です。アフィリエイトとして、より強力なDeFiコミュニティの構築に取り組む同志のネットワークの一員となります。

### アフィリエイトになる方法

アフィリエイトになるのは簡単です。[アフィリエイトページ](https://pancakeswap.finance/affiliates-program)にアクセスするだけで、始めるために必要なすべての情報が見つかります。または、[Googleフォーム](https://docs.google.com/forms/d/e/1FAIpQLSfP43IciQ5cH0JhTf1fDgUpwapBx-yD3ybv24pBdiVW7Th5jQ/viewform)に記入することもできます。

申請を送信すると、Kitchenが審査してプログラムへの適性を判断します。このプロセスには時間がかかる場合がありますのでご了承ください！承認された場合は、メールまたはTelegramでご連絡します。

Kitchenが申請を承認すると、プログラム申請時に提出したウォレットを接続することでアフィリエイトダッシュボードへのアクセスが付与されます。

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/affiliate-landing-page-07.png" alt=""><figcaption></figcaption></figure>

このダッシュボードでは、プロトコルのプロダクトやサービスを紹介してコミッションを追跡するために使用できるさまざまなツールやリソースが提供されます。

ダッシュボードにアクセスできるようになると、コミュニティと共有するためのアフィリエイトリンクを作成できます。**新規ユーザーがアフィリエイトリンクをクリック**して特定のトランザクションを実行すると、コミッションを獲得できます。PancakeSwapへの愛を共有する際は、必ずアフィリエイトリンクをご使用ください！
