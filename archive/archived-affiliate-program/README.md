# Affiliate Program

PancakeSwap का Affiliate Program उन लोगों को पुरस्कृत करने के लिए बनाया गया है जो community को expand करने और हमारे product को share करने में मदद करते रहते हैं। यह program पहले PancakeSwap advocates के एक select group के लिए उपलब्ध होगा, और Kitchen इसे अधिक उपयोगकर्ताओं तक rollout करने की योजना बना रहा है। एक affiliate के रूप में, आप एक मजबूत DeFi community बनाने के लिए committed समान विचारधारा वाले व्यक्तियों के network का हिस्सा होंगे।

### Affiliate बनना

Affiliate बनना आसान है। आपको बस हमारे [affiliate page](https://pancakeswap.finance/affiliates-program) पर जाना है, जहाँ आपको शुरू करने के लिए सभी जानकारी मिलेगी। वैकल्पिक रूप से, आप [google form](https://docs.google.com/forms/d/e/1FAIpQLSfP43IciQ5cH0JhTf1fDgUpwapBx-yD3ybv24pBdiVW7Th5jQ/viewform) भर सकते हैं।

आपका application submit करने के बाद, Kitchen आपके application की समीक्षा करेगा और निर्धारित करेगा कि आप program के लिए उपयुक्त हैं या नहीं। इस process में कुछ समय लग सकता है, इसलिए कृपया हमारे साथ धैर्य रखें! यदि approved हो जाते हैं, तो हम आपको आपके email या telegram के माध्यम से संपर्क करेंगे।

यदि Kitchen आपके application को approve करता है, तो आपको program application में submit किए गए वॉलेट को connect करके affiliate dashboard तक पहुँच दी जाएगी।

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/affiliate-landing-page-07.png" alt=""><figcaption></figcaption></figure>

यह dashboard आपको protocol के products या services share करने और अपनी commission track करने के लिए tools और resources की एक range प्रदान करेगा।

एक बार जब आप dashboard तक पहुँच सकते हैं, तो आप अपने community के साथ share करने के लिए affiliate links बना सकते हैं। जब एक **नया उपयोगकर्ता** आपके affiliate link पर click करता है और एक specific ट्रांजेक्शन करता है तो आप एक commission अर्जित करेंगे। PancakeSwap के लिए अपना प्यार share करते समय हमेशा अपना affiliate link उपयोग करना सुनिश्चित करें!
