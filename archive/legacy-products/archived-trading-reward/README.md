# 🧈 \[アーカイブ済み] Trading Reward

{% hint style="danger" %}
\[アーカイブ済み] Trading Reward – 2024年8月23日をもって
{% endhint %}

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/trading-reward.png" alt=""><figcaption></figcaption></figure>

Trading Rewardは、PancakeSwapの忠実なユーザーとステーカーに報いるために設計された新しいキャンペーンシリーズです。ご自身に合ったキャンペーンを選択し、取引を開始して条件を満たすと、BNBチェーンおよびEthereumメインネットの対象PancakeSwap V3ペアでの取引から最大10%の取引手数料リベートをCAKEで受け取ることができます。

各キャンペーンへの参加方法については、以下のチュートリアルをご覧ください：

{% content-ref url="how-to-participate/top-traders-campaign.md" %}
[top-traders-campaign.md](how-to-participate/top-traders-campaign.md)
{% endcontent-ref %}

{% content-ref url="how-to-participate/cake-stakers-campaign.md" %}
[cake-stakers-campaign.md](how-to-participate/cake-stakers-campaign.md)
{% endcontent-ref %}

{% hint style="warning" %}
**注意：** 上記2種類のキャンペーンは通常並行して実施されます。取引量/手数料は両方のキャンペーンで共有されますが、キャンペーン終了時に報酬を請求できるのは**1つのキャンペーンのみ**です。一方のキャンペーンで請求すると、もう一方のキャンペーンからは請求できなくなります。
{% endhint %}
