# 🧈 \[Arquivado] Trading Reward

{% hint style="danger" %}
\[Arquivado] Trading Reward – A partir de 23 de agosto de 2024
{% endhint %}

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/trading-reward.png" alt=""><figcaption></figcaption></figure>

O Trading Reward é uma nova série de campanhas criada para recompensar usuários e stakers fiéis da PancakeSwap. Você pode escolher a campanha que combina com você, começar a negociar, se tornar elegível e resgatar até 10% de reembolso das taxas de negociação em CAKE ao negociar pares elegíveis da PancakeSwap V3 na BNB Chain e na mainnet da Ethereum.

Confira o tutorial a seguir para saber como participar de cada uma delas:

{% content-ref url="how-to-participate/top-traders-campaign.md" %}
[top-traders-campaign.md](how-to-participate/top-traders-campaign.md)
{% endcontent-ref %}

{% content-ref url="how-to-participate/cake-stakers-campaign.md" %}
[cake-stakers-campaign.md](how-to-participate/cake-stakers-campaign.md)
{% endcontent-ref %}

{% hint style="warning" %}
**Observação:** Os dois tipos de campanha mencionados acima geralmente acontecem em paralelo. Embora o seu volume de negociação/taxas geradas seja compartilhado entre ambas, quando as campanhas terminarem você só poderá resgatar recompensas de **UMA** delas. Depois de resgatar de uma campanha, você NÃO poderá resgatar da outra.
{% endhint %}
