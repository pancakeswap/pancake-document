# 🧈 \[아카이브] 트레이딩 리워드

{% hint style="danger" %}
\[보관됨] 트레이딩 리워드 – 2024년 8월 23일 기준
{% endhint %}

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/trading-reward.png" alt=""><figcaption></figcaption></figure>

트레이딩 리워드는 충성도 높은 PancakeSwap 사용자와 스테이커에게 보상하기 위해 설계된 새로운 캠페인 시리즈입니다. 자신에게 맞는 캠페인을 선택하고 트레이딩을 시작하여 자격을 갖추면, BNB 체인과 Ethereum 메인넷의 적격 PancakeSwap V3 페어를 거래하여 거래 수수료의 최대 10%를 CAKE로 리베이트 받을 수 있습니다.

각 캠페인에 참여하는 방법은 다음 튜토리얼을 확인하세요.

[top-traders-campaign.md](how-to-participate/top-traders-campaign.md)
{% endcontent-ref %}

{% content-ref url="how-to-participate/cake-stakers-campaign.md" %}
[cake-stakers-campaign.md](how-to-participate/cake-stakers-campaign.md)
{% endcontent-ref %}

{% hint style="warning" %}
**참고:** 위에서 언급한 두 가지 유형의 캠페인은 보통 동시에 진행됩니다. 거래량/발생한 수수료는 두 캠페인에 모두 공유되지만, 캠페인이 종료되면 **한** 캠페인에서만 보상을 수령할 수 있습니다. 한 캠페인에서 수령하고 나면 다른 캠페인에서는 수령할 수 없습니다.
{% endhint %}
