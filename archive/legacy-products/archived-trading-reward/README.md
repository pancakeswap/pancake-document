# 🧈 [Archiviert] Trading Reward

{% hint style="danger" %}
[Archiviert] Trading Reward – Stand 23. August 2024
{% endhint %}

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/trading-reward.png" alt=""><figcaption></figcaption></figure>

Trading Rewards ist eine neue Reihe von Kampagnen, die darauf ausgelegt sind, treue PancakeSwap-Nutzer und Staker zu belohnen. Sie können eine Kampagne wählen, die zu Ihnen passt, mit dem Handel beginnen, berechtigt werden und bis zu 10 % der Handelsgebühren in CAKE aus dem Handel mit berechtigten PancakeSwap-V3-Paaren auf der BNB Chain und dem Ethereum-Mainnet zurückerhalten.

Sehen Sie sich die folgenden Tutorials an, um zu erfahren, wie Sie an den jeweiligen Kampagnen teilnehmen können:

[top-traders-campaign.md](how-to-participate/top-traders-campaign.md)
{% endcontent-ref %}

{% content-ref url="how-to-participate/cake-stakers-campaign.md" %}
[cake-stakers-campaign.md](how-to-participate/cake-stakers-campaign.md)
{% endcontent-ref %}

{% hint style="warning" %}
**Hinweis:** Die beiden oben genannten Kampagnentypen werden normalerweise parallel durchgeführt. Obwohl Ihr Handelsvolumen/Ihre generierten Gebühren auf beide aufgeteilt werden, können Sie nach dem Ende der Kampagnen nur Belohnungen aus **EINER** der Kampagnen beanspruchen. Sobald Sie von einer Kampagne beansprucht haben, können Sie NICHT von der anderen beanspruchen.
{% endhint %}
