# 🧈 \[Архив] Trading Reward

{% hint style="danger" %}
\[Архив] Trading Reward – по состоянию на 23 августа 2024 года
{% endhint %}

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/trading-reward.png" alt=""><figcaption></figcaption></figure>

Trading Reward — это новая серия кампаний, созданная, чтобы вознаграждать лояльных пользователей и стейкеров PancakeSwap. Ты можешь выбрать подходящую кампанию, начать торговать, стать участником и получить до 10% ребейта торговой комиссии в CAKE за торговлю на подходящих парах PancakeSwap V3 в BNB Chain и основной сети Ethereum.

Изучи следующие инструкции, чтобы узнать, как участвовать в каждой из них:

{% endcontent-ref %}

{% hint style="warning" %}
**Примечание:** Две упомянутые выше кампании обычно проходят параллельно, при этом твой торговый объём и сгенерированные комиссии учитываются в обеих. Когда кампании завершатся, ты сможешь получить награды только из **ОДНОЙ** из них. Как только ты забрал награду в одной кампании, забрать её в другой уже НЕЛЬЗЯ.
