# 🧈 \[Archivado] Trading Reward

{% hint style="danger" %}
\[Archivado] Trading Reward – A partir del 23 de agosto de 2024
{% endhint %}

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/trading-reward.png" alt=""><figcaption></figcaption></figure>

Trading Reward es una nueva serie de campañas diseñadas para recompensar a los usuarios y stakers leales de PancakeSwap. Puedes elegir la campaña que mejor se adapte a ti, empezar a operar, ser elegible y reclamar hasta un 10% de reembolso de comisiones de trading en CAKE por operar en pares elegibles de PancakeSwap V3 en BNB Chain y en la red principal de Ethereum.

Consulta el siguiente tutorial para saber cómo participar en cada una de ellas:

{% content-ref url="how-to-participate/top-traders-campaign.md" %}
[top-traders-campaign.md](how-to-participate/top-traders-campaign.md)
{% endcontent-ref %}

{% content-ref url="how-to-participate/cake-stakers-campaign.md" %}
[cake-stakers-campaign.md](how-to-participate/cake-stakers-campaign.md)
{% endcontent-ref %}

{% hint style="warning" %}
**Nota:** Los dos tipos de campañas mencionados arriba suelen ejecutarse en paralelo. Tu volumen de trading y las comisiones generadas se compartirán entre ambas. Cuando terminen las campañas, solo podrás reclamar recompensas de **UNA** de ellas. Una vez que hayas reclamado en una campaña, NO podrás reclamar en la otra.
{% endhint %}
