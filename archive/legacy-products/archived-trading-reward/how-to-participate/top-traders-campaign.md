# Top Tradersキャンペーン

{% hint style="danger" %}
\[アーカイブ済み] Trading Reward – 2024年8月23日をもって
{% endhint %}

## 進行中のキャンペーンを確認する <a href="#id-978733be-1ca0-4eb6-a35e-44b7f8365222" id="id-978733be-1ca0-4eb6-a35e-44b7f8365222"></a>

「Trading Competition」と同様に、Trading Rewardプログラムは個別のキャンペーン形式で実施されます。Top Tradersキャンペーンが進行中の場合、対象の取引ペアで取引することで取引手数料の一定割合を報酬として積み上げることができます。キャンペーン終了時に全トレーダーの中で十分に上位にランクインしていれば、その報酬を獲得できます。

進行中のキャンペーンを確認するには：

* [Trading Rewardページ](https://pancakeswap.finance/trading-reward/top-traders)を直接確認する
*   [PancakeSwapホームページ](https://pancakeswap.finance/)のバナーを確認する

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28258%29.png" alt=""><figcaption></figcaption></figure>
*   [スワップページ](https://pancakeswap.finance/swap)の「Hot Token」リストから💝アイコンを探す。またはフィルターを使用してTrading Rewardのあるペアを確認する。<br>

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2831%29.png" alt=""><figcaption></figcaption></figure>

## 取引を開始する <a href="#id-5be1710d-25f3-485d-8184-91015c4dceca" id="id-5be1710d-25f3-485d-8184-91015c4dceca"></a>

BNBチェーンおよびEthereumの特定のPancakeSwap V3ペアで取引してCAKEを獲得しましょう！

キャンペーンによって対象ペアが異なる場合があります。対象ペアを確認するには：

* [Trading Rewardページ](https://pancakeswap.finance/trading-reward/top-traders)の「Reward Breakdown」セクションを確認する
* [スワップページ](https://pancakeswap.finance/swap)の「Hot Token」リストから💝アイコンを探す。またはフィルターを使用してTrading Rewardのあるペアを確認する。

## 獲得できる報酬数を確認する <a href="#id-7d7c7391-5454-4fa7-8928-c79885a00875" id="id-7d7c7391-5454-4fa7-8928-c79885a00875"></a>

[Trading Rewardページ](https://pancakeswap.finance/trading-reward/top-traders)で積み上げた報酬数を確認できます。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28222%29.png)

さらに、「Rewards Breakdown」セクションで取引した各ペアの詳細を確認できます。

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28259%29.png" alt=""><figcaption></figcaption></figure>

リベート率、終了時刻、勝利に必要なランク数などのキャンペーン詳細は「Current Reward Pool」セクションで確認できます。

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28221%29.png" alt=""><figcaption></figcaption></figure>

## ランクを確認する <a href="#d7d60391-c3fc-4acb-9dfb-5c95a09403d5" id="d7d60391-c3fc-4acb-9dfb-5c95a09403d5"></a>

キャンペーンに勝利して積み上げた報酬をすべて請求するには、一定のランキング以上を維持してキャンペーン終了まで維持する必要があります。

ランクを確認し、現在対象かどうかを確認するには、[Trading Rewardページ](https://pancakeswap.finance/trading-reward/top-traders)にアクセスしてください。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28218%29.png)

ランクが十分に高くない場合、このキャンペーンで勝利するための最低ランクと現在のキャンペーン終了時刻がポップアップで通知されます。

より上位にランクインするために取引を続けてください。キャンペーン終了まで定期的に確認してランクを維持することを忘れないでください。

## 報酬を請求する <a href="#id-5a0d1633-dba9-46c0-919c-77fee912f986" id="id-5a0d1633-dba9-46c0-919c-77fee912f986"></a>

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28185%29.png)

キャンペーン終了後、データ集計と報酬注入が完了するまで最大72時間かかる場合があります。

報酬の請求が可能になると「Claim All」ボタンが点灯します。クリックして報酬を請求してください。

{% hint style="info" %}
有効期限が切れる前に報酬を請求してください。
{% endhint %}

{% hint style="warning" %}
すべての報酬はBNBチェーンで請求されます。EthereumやBNBチェーン以外のチェーンで取引していた場合は、請求のためにBNBチェーンにネットワークを切り替えてください。
{% endhint %}
