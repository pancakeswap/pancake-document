# 탑 트레이더 캠페인

{% hint style="danger" %}
\[보관됨] 트레이딩 리워드 – 2024년 8월 23일 기준
{% endhint %}

## 진행 중인 캠페인 확인하기 <a href="#id-978733be-1ca0-4eb6-a35e-44b7f8365222" id="id-978733be-1ca0-4eb6-a35e-44b7f8365222"></a>

"트레이딩 대회"와 마찬가지로 트레이딩 리워드 프로그램은 개별 캠페인으로 진행됩니다. 진행 중인 탑 트레이더 캠페인이 있으면 적격 거래 페어를 거래하여 거래 수수료의 일정 비율을 보상으로 누적할 수 있습니다. 캠페인이 종료되었을 때 전체 트레이더 중 충분히 높은 순위에 있다면 해당 보상을 받게 됩니다.

진행 중인 캠페인이 있는지 확인하려면 다음을 할 수 있습니다.

* [트레이딩 리워드 페이지](https://pancakeswap.finance/trading-reward/top-traders)에서 직접 확인
*   [PancakeSwap 홈페이지](https://pancakeswap.finance/) 배너 확인

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20(258).png" alt=""><figcaption></figcaption></figure>
*   [스왑 페이지](https://pancakeswap.finance/swap)의 "핫 토큰" 목록에서 💝 아이콘 찾기. 또는 필터를 사용하여 트레이딩 리워드가 있는 페어 확인<br>

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20(31).png" alt=""><figcaption></figcaption></figure>

## 트레이딩 시작하기 <a href="#id-5be1710d-25f3-485d-8184-91015c4dceca" id="id-5be1710d-25f3-485d-8184-91015c4dceca"></a>

이제 BNB 체인과 Ethereum의 특정 PancakeSwap V3 페어를 거래하여 CAKE를 얻을 수 있습니다!

캠페인마다 적격 페어가 다를 수 있습니다. 적격 페어를 확인하려면 다음을 할 수 있습니다.

* [트레이딩 리워드 페이지](https://pancakeswap.finance/trading-reward/top-traders)의 "보상 상세" 섹션 확인
* [스왑 페이지](https://pancakeswap.finance/swap)의 "핫 토큰" 목록에서 💝 아이콘 찾기. 또는 필터를 사용하여 트레이딩 리워드가 있는 페어 확인

## 받을 수 있는 잠재적 보상 수량 확인하기 <a href="#id-7d7c7391-5454-4fa7-8928-c79885a00875" id="id-7d7c7391-5454-4fa7-8928-c79885a00875"></a>

[트레이딩 리워드 페이지](https://pancakeswap.finance/trading-reward/top-traders)에서 누적한 보상 수량을 확인할 수 있습니다.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20\(222\).png)

또한 "보상 상세" 섹션에서 거래한 각 페어에 대한 자세한 내용을 확인할 수 있습니다.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20(259).png" alt=""><figcaption></figcaption></figure>

리베이트 비율, 종료 시간, 당첨 순위 수와 같은 캠페인 세부 정보는 "현재 보상 풀" 섹션에서 확인하세요.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20(221).png" alt=""><figcaption></figcaption></figure>

## 내 순위 확인하기 <a href="#d7d60391-c3fc-4acb-9dfb-5c95a09403d5" id="d7d60391-c3fc-4acb-9dfb-5c95a09403d5"></a>

캠페인에서 우승하여 누적한 모든 보상을 수령하려면 일정 순위보다 높은 순위에 올라 캠페인이 끝날 때까지 유지해야 합니다.

내 순위를 확인하고 현재 자격이 되는지 보려면 [트레이딩 리워드 페이지](https://pancakeswap.finance/trading-reward/top-traders)로 이동하세요.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20\(218\).png)

순위가 충분히 높지 않다면 팝업에서 이 캠페인에서 우승하기 위한 최소 순위와 현재 캠페인의 종료 시간을 알려 드립니다.

더 높은 순위에 오르려면 계속 거래하세요. 그리고 캠페인이 끝날 때까지 순위를 유지하기 위해 자주 확인하는 것을 잊지 마세요.

## 보상 수령하기 <a href="#id-5a0d1633-dba9-46c0-919c-77fee912f986" id="id-5a0d1633-dba9-46c0-919c-77fee912f986"></a>

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20\(185\).png)

캠페인이 종료되면 데이터 집계와 보상 주입이 진행되는 동안 최대 72시간을 기다려야 할 수 있습니다.

보상을 수령할 수 있게 되면 "모두 수령" 버튼이 활성화됩니다. 클릭하여 보상을 수령하기만 하면 됩니다.

{% hint style="info" %}
보상이 만료되기 전에 제때 수령하세요.
{% endhint %}

{% hint style="warning" %}
모든 보상은 BNB 체인에서 수령합니다. Ethereum 또는 다른 체인에서 거래했다면 수령을 위해 네트워크를 BNB 체인으로 전환하세요.
{% endhint %}
