# Top Traders 活动

{% hint style="danger" %}
\[已归档] 交易奖励 – 截至 2024 年 8 月 23 日
{% endhint %}

## 查看是否有正在进行的活动 <a href="#id-978733be-1ca0-4eb6-a35e-44b7f8365222" id="id-978733be-1ca0-4eb6-a35e-44b7f8365222"></a>

与"交易竞赛"类似，交易奖励计划以单独的活动形式举办。当有正在进行的 Top Traders 活动时，你可以通过交易符合条件的交易对，累积一定比例的交易手续费作为奖励。活动结束后，如果你在所有交易者中排名足够靠前，就能赢得这些奖励。

查看是否有正在进行的活动，你可以：

* 直接查看[交易奖励页面](https://pancakeswap.finance/trading-reward/top-traders)
*   查看 [PancakeSwap 首页](https://pancakeswap.finance/)横幅

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28258%29.png" alt=""><figcaption></figcaption></figure>
*   在[兑换页面](https://pancakeswap.finance/swap)的"热门代币"列表中寻找 💝 图标。或使用筛选器查看带有交易奖励的交易对。<br>

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2831%29.png" alt=""><figcaption></figcaption></figure>

## 开始交易 <a href="#id-5be1710d-25f3-485d-8184-91015c4dceca" id="id-5be1710d-25f3-485d-8184-91015c4dceca"></a>

现在你可以通过在 BNB 链和 Ethereum 上交易特定的 PancakeSwap V3 交易对来赚取 CAKE！

每次活动的合格交易对可能不同。查看哪些交易对符合条件，你可以：

* 查看[交易奖励页面](https://pancakeswap.finance/trading-reward/top-traders)中的"奖励明细"部分
* 在[兑换页面](https://pancakeswap.finance/swap)的"热门代币"列表中寻找 💝 图标。或使用筛选器查看带有交易奖励的交易对。

## 查看你的排名 <a href="#d7d60391-c3fc-4acb-9dfb-5c95a09403d5" id="d7d60391-c3fc-4acb-9dfb-5c95a09403d5"></a>

要赢得活动并领取你累积的全部奖励，你需要让自己的排名高于某个特定名次，并保持到活动结束。

要查看你的排名以及当前是否符合资格，请前往[交易奖励页面](https://pancakeswap.finance/trading-reward/top-traders)。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28218%29.png)

如果你的排名不够靠前，弹窗会告知你赢得本次活动所需的最低排名以及当前活动的结束时间。

继续交易以提升排名。并且别忘了经常回来查看，以便保持排名直到活动结束。

## 领取你的奖励 <a href="#id-5a0d1633-dba9-46c0-919c-77fee912f986" id="id-5a0d1633-dba9-46c0-919c-77fee912f986"></a>

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28185%29.png)

活动结束后，你可能需要等待最长 72 小时，以便统计数据并发放奖励。

当奖励可领取时，"Claim All"按钮会亮起。只需点击即可领取你的奖励。

{% hint style="info" %}
请在奖励过期前及时领取。
{% endhint %}

{% hint style="warning" %}
所有奖励都在 BNB 链上领取，如果你在 Ethereum 或其他链上交易，请将网络切换到 BNB 链后再领取
{% endhint %}
