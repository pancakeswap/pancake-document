現在、2種類のキャンペーンがあります：

### Top Traders

Top Tradersキャンペーンでは、すべてのトレーダーの中で一定のランキング内に入ったユーザーが、BNBチェーンおよびEthereumメインネットの対象PancakeSwap V3ペアでの取引から最大3%の取引手数料リベートをCAKEで受け取ることができます。

### CAKE Stakers

CAKE Stakersキャンペーンでは、アクティブなCAKEステーキングポジションを持つ対象ユーザーが、BNBチェーンおよびEthereumメインネットの対象PancakeSwap V3ペアでの取引から最大~~5%~~10%の取引手数料リベートをCAKEで受け取ることができます。

{% hint style="warning" %}
**注意：** 上記2種類のキャンペーンは通常並行して実施されます。取引量/手数料は両方のキャンペーンで共有されますが、キャンペーン終了時に報酬を請求できるのは**1つのキャンペーンのみ**です。一方のキャンペーンで請求すると、もう一方のキャンペーンからは請求できなくなります。
{% endhint %}
