# CAKE Stakersキャンペーン

{% hint style="danger" %}
\[アーカイブ済み] Trading Reward – 2024年8月23日をもって
{% endhint %}

{% hint style="info" %}
CAKE StakersキャンペーンはveCAKE Stakersキャンペーンになりました。固定期間ステーキングプールの代わりに、ユーザーはCAKEを新しいveCAKEステーキングプールにロックしてキャンペーンに参加できます。
{% endhint %}

## 進行中のキャンペーンを確認する <a href="#id-978733be-1ca0-4eb6-a35e-44b7f8365222" id="id-978733be-1ca0-4eb6-a35e-44b7f8365222"></a>

「Trading Competition」と同様に、Trading Rewardプログラムは個別のキャンペーン形式で実施されます。進行中のキャンペーンがある場合、対象ユーザーは特定のPancakeSwap V3取引ペアで取引することで報酬を獲得できます。

進行中のキャンペーンを確認するには：

* [Trading Rewardページ](https://pancakeswap.finance/trading-reward)を直接確認する
*   [PancakeSwapホームページ](https://pancakeswap.finance/)のイベントバナーを確認する<br>

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/rebate-homepage.png" alt=""><figcaption></figcaption></figure>
*   [スワップページ](https://pancakeswap.finance/swap)の「Hot Token」リストから💝アイコンを探す。またはフィルターを使用してTrading Rewardのあるペアを確認する。

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28183%29.png" alt=""><figcaption></figcaption></figure>
* [ソーシャルメディアチャンネル](/broken/pages/QqND39S2UhktBbu09Doj)を確認する。

## アドレスが対象かどうかを確認する <a href="#ced8a6c5-803a-4a60-80d0-44e823571d84" id="ced8a6c5-803a-4a60-80d0-44e823571d84"></a>

Trading Rewardキャンペーンに参加するには、アドレスが以下の要件を満たす必要があります：

* アクティブなPancakeプロフィールを持っていること
* アクティブなCAKEステーキングポジションを持っていること
* スナップショット時のveCAKE残高が必要なしきい値を超えていること（「スナップショット時のveCAKE残高」についての詳細は[こちら](../faq.md#cake-stakers-campaign)をご確認ください）

アドレスが対象かどうかを確認する最も簡単な方法は、[Trading Rewardページ](https://pancakeswap.finance/trading-reward)にアクセスしてウォレットを接続することです。ページ上でアドレスをCAKE報酬獲得対象にするためのプロセスが案内されます。

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%281%29%20%281%29%20%281%29%20%281%29%20%281%29%20%281%29%20%281%29.png" alt="" width="375"><figcaption></figcaption></figure>

例えば、アクティブなveCAKEステーキングポジションがない場合や、スナップショット時のveCAKE残高が0の場合は、上記の画面が表示されます。CAKEのロックを開始するには、ガイドに従ってください。

veCAKEは時間とともに減少するため、スナップショット時のveCAKE量がしきい値を満たすようにするには、スナップショット量のプレビューを確認しながらガイダンスに従ってください。

キャンペーンが進行中であれば、いつでもCAKEのロックを開始してキャンペーンに参加できます。Trading Rewardはキャンペーン開始時点から計算されます。

## 取引を開始する <a href="#id-5be1710d-25f3-485d-8184-91015c4dceca" id="id-5be1710d-25f3-485d-8184-91015c4dceca"></a>

これで対象チェーン上の特定のPancakeSwap V3ペアで取引してCAKEを獲得できます。

キャンペーンによって対象ペアが異なる場合があります。対象ペアを確認するには：

* [Trading Rewardページ](https://pancakeswap.finance/trading-reward#rewards-breakdown)の「Reward Breakdown」セクションを確認する
* [スワップページ](https://pancakeswap.finance/swap)の「Hot Token」リストから💝アイコンを探す。またはフィルターを使用してTrading Rewardのあるペアを確認する。

## 報酬数を確認する <a href="#id-7d7c7391-5454-4fa7-8928-c79885a00875" id="id-7d7c7391-5454-4fa7-8928-c79885a00875"></a>

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28256%29.png)

[Trading Rewardページ](https://pancakeswap.finance/trading-reward)で以下の数値を確認できます：

* 獲得したCAKE報酬数
* キャンペーンから獲得できる最大CAKE量（スナップショット時のveCAKE量によって決まります。上限を超えている場合のみ表示されます）
* 対象ペア全体での取引量

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28291%29.png" alt=""><figcaption></figcaption></figure>

さらに、「Rewards Breakdown」セクションで取引した各ペアの詳細を確認できます。

## 報酬を請求する <a href="#id-5a0d1633-dba9-46c0-919c-77fee912f986" id="id-5a0d1633-dba9-46c0-919c-77fee912f986"></a>

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2892%29.png)

キャンペーン終了後、データ集計と報酬注入が完了するまで最大72時間かかる場合があります。

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28177%29.png)

報酬の請求が可能になると「Claim All」ボタンが点灯します。クリックして報酬を請求してください。

**有効期限が切れる前に報酬を請求してください。**
