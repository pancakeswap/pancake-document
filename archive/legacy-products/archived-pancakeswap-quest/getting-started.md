## Premiers pas

### Comment créer votre profil PancakeSwap Quest

1. Rendez-vous sur [https://quest.pancakeswap.finance/quests](https://quest.pancakeswap.finance/quests)
2. Cliquez sur « Join Quest », ou cliquez sur « Make a Profile » dans les paramètres (référence ci-dessous)
   1. Créez un profil depuis la page principale
   2.  Cliquez sur « Make a Profile » en haut à droite

       <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/unnamed%20%288%29.png" alt=""><figcaption></figcaption></figure>
   3.  Pour les utilisateurs qui ont cliqué sur une quête, cliquez sur « Start the Quest » et sélectionnez « Make a Profile » lorsque vous y êtes invité

       <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/unnamed%20%287%29.png" alt=""><figcaption></figcaption></figure>

       <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/unnamed%20%286%29.png" alt="" width="375"><figcaption></figcaption></figure>
3.  Suivez les étapes de l'écran de configuration du profil ou consultez le guide de création de profil [ici](/broken/pages/-MYdfYNF3jEh_f1HFdcj "mention"), à partir de l'étape 7. La configuration est gratuite, cependant une petite quantité de gaz sur BNB Chain est requise pour configurer les profils.

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/unnamed%20%285%29.png" alt="" width="375"><figcaption><p>Choisissez le Bunny - Un bunny de départ générique pour votre aventure de quêtes</p></figcaption></figure>


4. Une fois le profil créé, les utilisateurs peuvent choisir de lier leurs comptes de réseaux sociaux. Notez que toutes les quêtes ne nécessitent pas de vérification sociale.&#x20;
   1.  Sélectionnez le bouton « Settings » sur la page de profil

       <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/unnamed%20%284%29.png" alt="" width="375"><figcaption></figcaption></figure>
   2.  Liez les réseaux sociaux en sélectionnant le bouton de connexion pour chaque plateforme sociale. Suivez les étapes à l'écran et les signatures pour connecter votre compte. Veuillez noter que la connexion peut prendre un certain temps à se refléter sur les services des réseaux sociaux. Si la connexion échoue la première fois, essayez un rafraîchissement forcé avec Cmd/Ctrl + Shift + R.

       <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/unnamed%20%289%29.png" alt="" width="375"><figcaption></figcaption></figure>

       <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/unnamed%20%2810%29.png" alt="" width="375"><figcaption></figcaption></figure>

       **Remarque : La connexion peut prendre un certain temps à se refléter sur les services des réseaux sociaux.**
