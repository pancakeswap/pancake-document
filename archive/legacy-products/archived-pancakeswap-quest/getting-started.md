## Getting Started

### अपना PancakeSwap Quest Profile कैसे बनाएं

1. [https://quest.pancakeswap.finance/quests](https://quest.pancakeswap.finance/quests) पर जाएं
2. Join Quest पर क्लिक करें, या settings पर Make a Profile पर क्लिक करें (नीचे दिखाया गया है)
   1. Main page से profile बनाएं
   2.  Top right पर "Make a Profile" पर क्लिक करें

       <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/unnamed%20%288%29.png" alt=""><figcaption></figcaption></figure>
   3.  किसी भी quest पर क्लिक करने वाले उपयोगकर्ताओं के लिए, "Start the Quest" पर क्लिक करें और prompt होने पर "Make a Profile" चुनें

       <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/unnamed%20%287%29.png" alt=""><figcaption></figcaption></figure>

       <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/unnamed%20%286%29.png" alt="" width="375"><figcaption></figcaption></figure>
3.  Profile setup screen पर दिए गए steps follow करें या step 7 से यहाँ[Broken link](/broken/pages/-MYdfYNF3jEh_f1HFdcj "mention") make profile guide देखें। Setup free है, हालाँकि profiles setup करने के लिए BNB Chain पर थोड़ी gas की आवश्यकता होती है।

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/unnamed%20%285%29.png" alt="" width="375"><figcaption><p>Bunny चुनें - आपकी quest journey के लिए एक generic starter bunny</p></figcaption></figure>


4. Profile बन जाने के बाद, उपयोगकर्ता अपने social media accounts link करने का विकल्प चुन सकते हैं। ध्यान दें कि सभी quests के लिए social verification की आवश्यकता नहीं है।&#x20;
   1.  Profile page पर "Settings" button select करें

       <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/unnamed%20%284%29.png" alt="" width="375"><figcaption></figcaption></figure>
   2.  प्रत्येक social platform के लिए connect button select करके socials link करें। अपना account connect करने के लिए on-screen steps और signatures से आगे बढ़ें। कृपया ध्यान दें कि social network services में connection reflect होने में कुछ समय लग सकता है। यदि पहली बार connection में समस्या हो, तो Cmd/Ctrl + Shift + R दबाकर hard refresh करें।

       <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/unnamed%20%289%29.png" alt="" width="375"><figcaption></figcaption></figure>
