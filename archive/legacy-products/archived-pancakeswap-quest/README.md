PancakeSwap Quest (Beta) adalah platform quest DeFi yang memungkinkan pengguna untuk menjelajahi, mendapatkan penghasilan, dan terlibat dalam produk-produk DeFi di PancakeSwap. Platform ini menyediakan pengalaman yang digamifikasi untuk memungkinkan pengguna baru maupun yang berpengalaman berinteraksi dengan PancakeSwap dan produk mitra di berbagai rantai.

### Fitur Utama

**Bangun Profil DeFi Anda:** Pengguna dapat membuat dan mempersonalisasi profil mereka, memilih nama pengguna, dan membuat NFT sebagai foto profil untuk menampilkan identitas DeFi mereka.

**Berpartisipasi**: Pengguna dapat terlibat dalam tugas dan tantangan di seluruh PancakeSwap, termasuk kampanye media sosial dan petualangan on-chain.

**Dukungan Multi-Chain**: PancakeSwap Quest Beta mendukung delapan rantai: Ethereum, BNB Chain, Arbitrum, Base, Linea, ZKsync, Polygon zkEVM, dan opBNB, memastikan kompatibilitas yang luas dan kemudahan penggunaan.

PancakeSwap saat ini berada dalam fase beta, di mana pengguna dapat berpartisipasi dalam berbagai tugas dan kampanye. Kitchen mencari masukan untuk produk ini dari pengguna awal melalui Telegram dan Discord. Untuk informasi lebih lanjut, silakan merujuk ke [posting blog](https://blog.pancakeswap.finance/articles/introducing-pancake-swap-quest-beta-your-ultimate-de-fi-quest-platform) kami.

### Gambaran Quest

PancakeSwap Quest (beta) akan menawarkan beberapa jenis tantangan berbeda bagi pengguna, termasuk:

* Mengikuti media sosial
* Memegang token
* Swap untuk mendapatkan token

Pengguna akan melakukan tugas yang diperlukan untuk menyelesaikan quest. Setelah selesai, pengguna akan menerima hadiah token untuk quest tertentu atau insentif potensial jika quest tersebut saat ini tidak memiliki hadiah token.

Tantangan-tantangan ini akan berupaya mendorong pengguna untuk berpartisipasi dalam komunitas PancakeSwap dan mempelajari lebih lanjut tentang berbagai jenis produk secara bersamaan. Kitchen akan berupaya menambahkan lebih banyak cara unik untuk melibatkan pengguna melalui tugas-tugas lain dalam iterasi mendatang. PancakeSwap Quest akan berada di BNB Chain, Ethereum, Zksync, Arbitrum, Base, dan Polygon zkEVM dalam mode beta.
