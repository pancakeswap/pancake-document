# 플렉시블 스테이킹 옵션 사용 방법

1\. [여기](https://pancakeswap.finance/pools)에서 풀 페이지로 이동합니다.

2\. 오른쪽 상단의 **연결** 버튼을 클릭하여 BNB Smart Chain 호환 지갑에 연결합니다.

3\. 지갑을 선택하고 연결합니다.

4\. CAKE 시럽 풀을 선택하고 **활성화** 버튼을 클릭합니다. 지갑에서 작업을 확인하라는 메시지가 표시됩니다.

5\. **활성화** 버튼이 **플렉시블**과 락으로 바뀝니다. 버튼을 클릭하여 스테이킹 메뉴를 엽니다.

![Note that actual values will vary](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Stake%20-%20before%20enable.png)

6\. 플렉시블 스테이킹은 **플렉시블**을 누르기만 하면 새 창이 표시되며, 스테이킹하려는 CAKE 수량을 입력하고 **확인**을 클릭한 다음 지갑에서 거래를 확인합니다.

플렉시블 스테이킹을 고정 기간 스테이킹으로 전환하여 더 많은 CAKE를 얻고 싶으신가요? **락으로 전환**을 클릭하고 CAKE를 얼마 동안 락할지 선택하기만 하면 됩니다.

![Note that actual values will vary](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/cake-pool-flex-convert.png)
