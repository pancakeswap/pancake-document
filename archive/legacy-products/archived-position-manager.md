## Завершение работы Position Managers

**Обзор**\
Position Managers на PancakeSwap — **Bril, Defiedge, Teahouse, Range и Alpaca** — были интегрированными сторонними стратегиями-хранилищами, которые автоматически управляли позициями ликвидности V3. Они помогали оптимизировать размещение ликвидности, ребалансировать диапазоны и снижали необходимость в ручном управлении позициями.

**Что меняется?**\
В рамках упрощения продуктов Position Managers будут убраны из интерфейса PancakeSwap.

**Ключевые даты**

* **21 мая 2025, 08:00 UTC** — внесение средств в хранилища Position Manager через PancakeSwap будет отключено. Вывод остаётся доступным.
* **21 июня 2025, 08:00 UTC** — последний срок для вывода через основной интерфейс. После этого функция будет удалена из основного UI, но вывод по-прежнему будет возможен через [**pancakeswap.finance/position-managers**](https://pancakeswap.finance/position-managers).

**После даты завершения работы**

* Новые депозиты через интерфейс PancakeSwap будут невозможны.
* Вывод будет доступен только через [**pancakeswap.finance/position-managers**](https://pancakeswap.finance/position-managers)
* Поскольку position managers могут не управлять твоими позициями активно, хранилища могут перейти на широкие неуправляемые диапазоны. Пожалуйста, выведи свои позиции, чтобы избежать возможных потерь от ребалансировки.

**Что тебе нужно сделать?**

* Выведи активы из хранилищ Position Manager до **21 июня 2025**, чтобы сохранить полный контроль.
* После вывода ты можешь управлять своей ликвидностью V3 вручную на PancakeSwap
