PancakeSwap 与 Binance Earn 合作，为 WBETH（Wrapped Beacon Ethereum）代币提供流动性质押集成。这让 PancakeSwap 用户可以在 Ethereum 网络和 BNB 链上轻松将 ETH 转换并兑换为 WBETH。

### 什么是流动性质押？

流动性质押是一种让用户在质押的同时，仍能通过代表性代币使用或交易其资产的方式。这样既能灵活动用资金，又能继续获得质押奖励。自 Ethereum 网络完成 Merge（即 ETH 的共识机制升级为权益证明）以来，流动性质押为用户提供了质押 ETH 以获取奖励的选择。而且与传统质押方式不同，用户的 ETH 在质押期间仍然可以使用并保有流动性。WBETH 代币正是为解决这一问题而生。

在原始 ETH 代币被质押期间，该代币可以用于交易、DeFi 应用，或者直接持有。因此，流动性质押带来了灵活性，让代币持有者无需解除质押、也不必错失质押奖励，就能以多种方式利用已质押的代币。[点击此处了解更多关于 Ethereum 权益证明的信息](https://academy.binance.com/en/articles/what-is-ethereum-2-0-and-why-does-it-matter)。
