### Apa itu Liquid Staking?

Liquid Staking adalah metode yang memungkinkan pengguna untuk Staking sambil tetap dapat menggunakan atau memperdagangkan aset mereka melalui token representatif. Ini memberikan fleksibilitas dan akses ke dana untuk kegunaan lain sambil tetap mendapatkan hadiah Staking. Karena jaringan Ethereum telah menyelesaikan Merge (yaitu mekanisme konsensus ETH telah ditingkatkan ke Proof of Stake), Liquid Staking menawarkan pengguna pilihan untuk melakukan Staking ETH mereka untuk mendapatkan hadiah. Dan, tidak seperti metode Staking tradisional, pengguna masih dapat menggunakan dan memiliki Likuiditas atas ETH mereka sementara ETH tersebut sedang di-staking. Token WBETH memecahkan masalah ini.

Token ini dapat diperdagangkan, digunakan dalam aplikasi DeFi, atau dipegang sementara token ETH asli sedang di-staking. Liquid Staking dengan demikian memberikan fleksibilitas dan memungkinkan pemegang token untuk memanfaatkan token yang di-staking dengan berbagai cara tanpa harus melakukan unstaking dan berpotensi kehilangan hadiah Staking.
