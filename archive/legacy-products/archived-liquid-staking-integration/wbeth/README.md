# WBETH

\*\*Wrapped Beacon Ethereum(WBETH)\*\*은 스테이킹된 ETH와 그 보상을 나타내는 리퀴드 스테이킹 파생 토큰입니다. BETH의 래핑 버전으로 1 WBETH가 1 BETH를 나타내며, 사용자가 Ethereum 네트워크의 ETH 스테이킹 보상에 참여할 수 있도록 Binance Earn이 만들었습니다. 래핑된 토큰은 원래 구축된 블록체인이 아닌 다른 블록체인에서 암호화폐를 사용하면서도 기초 자산으로 뒷받침되도록 하는 방식입니다.\
\
WBETH는 또한 2023-04-27 08:00(UTC) 이후 ETH 스테이킹에서 BETH 토큰이 누적한 스테이킹 보상을 나타냅니다. BETH 보유자를 위해 BETH를 WBETH로 1:1 고정 비율로 전환하는 추가 지원이 향후 몇 주 내에 제공될 예정입니다.\
