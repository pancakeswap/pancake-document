# WBETH

**Wrapped Beacon Ethereum (WBETH)** ist ein Liquid-Staking-Derivat-Token, der gestaktes ETH und seine Belohnungen repräsentiert. Es handelt sich um eine Wrapped-Version von BETH, bei der 1 WBETH 1 BETH entspricht, erstellt von Binance Earn, die es Nutzern ermöglicht, an ETH-Staking-Belohnungen aus dem Ethereum-Netzwerk teilzunehmen. Wrapped Token sind eine Möglichkeit, Kryptowährungen auf anderen Blockchains als der Blockchain zu nutzen, auf der sie ursprünglich aufgebaut wurden, während sie durch ihr zugrundeliegendes Vermögenswert gesichert sind.\
\
WBETH repräsentiert auch die von BETH-Token angesammelten Staking-Belohnungen beim ETH-Staking nach dem 27. April 2023 um 08:00 Uhr (UTC). Für BETH-Inhaber wird in den kommenden Wochen weitere Unterstützung zur Konvertierung von BETH zu WBETH zu einem festen 1:1-Kurs verfügbar sein.\
