# WBETH

**Wrapped Beacon Ethereum（WBETH）**はステーキングされたETHとその報酬を表すLiquid Stakingデリバティブトークンです。BETHのラップバージョンで、1WBETHは1BETHを表し、Binance Earnによって作成されており、ユーザーがEthereumネットワークのETHステーキング報酬に参加できるようにします。ラップトークンとは、元々構築されたブロックチェーン以外のブロックチェーンで暗号通貨を使用する方法で、基礎資産によって裏付けられています。\
\
WBETHはまた、2023年04月27日 08:00（UTC）以降のETHステーキングによるBETHトークンの蓄積されたステーキング報酬も表します。BETHホルダーについては、1:1の固定レートでBETHをWBETHに変換するためのサポートが数週間以内に提供される予定です。\
\
WBETHの詳細については、[こちらのリンク](https://www.binance.com/en/support/faq/what-is-wbeth-e252366155174ba6887f6b32e3798273)をご覧ください。

Binance ETHステーキングの詳細については、[こちらのリンク](https://www.binance.com/en/support/faq/binance-eth-2-0-staking-eecd04618b5042c79f2a5b07f895c498)をご覧ください。

ETHステーキングの利用規約についての詳細は、[こちらのリンク](https://www.binance.com/en/support/faq/binance-eth-2-0-staking-terms-and-conditions-74b48ca392874849aba9560e7a8fc11b)をご覧ください。
