# WBETH

**Wrapped Beacon Ethereum (WBETH)** 是一种流动性质押衍生代币，代表已质押的 ETH 及其奖励。它是 BETH 的包装版本，1WBETH 代表 1 BETH，由 Binance Earn 创建，让用户可以参与以太坊网络的 ETH 质押奖励。包装代币是一种让加密货币能够在其原生区块链之外的其他区块链上使用的方式，同时由其底层资产提供支持。\
\
WBETH 同时代表 BETH 代币在 2023-04-27 08:00 (UTC) 之后在 ETH 质押中累积的质押奖励。对于 BETH 持有者，未来几周内将进一步支持以 1:1 的固定汇率将 BETH 转换为 WBETH。\
