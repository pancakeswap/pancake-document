# WBETH

**Wrapped Beacon Ethereum (WBETH)** é um token derivativo de liquid staking que representa ETH em staking e suas recompensas. É uma versão wrapped do BETH, em que 1 WBETH representa 1 BETH, e foi criado pela Binance Earn para permitir que os usuários participem das recompensas de staking de ETH da rede Ethereum. Tokens wrapped são uma forma de usar criptomoedas em blockchains diferentes daquela em que foram originalmente construídas, mantendo o lastro no ativo subjacente. \
\
O WBETH também representa as recompensas de staking acumuladas pelo token BETH no Staking de ETH após 27/04/2023 às 08:00 (UTC). Para os detentores de BETH, o suporte adicional para converter BETH em WBETH a uma taxa fixa de 1:1 estará disponível nas próximas semanas.\
