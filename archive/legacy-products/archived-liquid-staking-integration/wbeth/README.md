# WBETH

**Wrapped Beacon Ethereum (WBETH)** एक liquid staking derivative token है जो staked ETH और उसकी rewards को represent करता है। यह BETH का wrapped version है, जहाँ 1 WBETH, 1 BETH को represent करता है, और इसे Binance Earn द्वारा बनाया गया है जो उपयोगकर्ताओं को Ethereum network से ETH staking rewards में participate करने की अनुमति देता है। Wrapped tokens किसी cryptocurrency को उनके मूल blockchain के अलावा अन्य blockchains पर उपयोग करने का एक तरीका है, जबकि वे अपनी underlying asset द्वारा backed रहती हैं।\
\
WBETH, 2023-04-27 08:00 (UTC) के बाद ETH Staking पर BETH token द्वारा अर्जित staking rewards को भी represent करता है। BETH holders के लिए, 1:1 fixed rate पर BETH को WBETH में convert करने के लिए आगामी सप्ताहों में और support उपलब्ध होगी।\
