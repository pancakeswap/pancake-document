# WBETH

**Wrapped Beacon Ethereum (WBETH)** adalah token turunan Liquid Staking yang mewakili ETH yang di-staking beserta hadiahnya. Ini adalah versi terbungkus dari BETH, di mana 1WBETH mewakili 1 BETH, dan dibuat oleh Binance Earn yang memungkinkan pengguna untuk berpartisipasi dalam hadiah Staking ETH dari jaringan Ethereum. Token terbungkus adalah cara untuk menggunakan mata uang kripto di blockchain selain blockchain asalnya sambil didukung oleh aset dasarnya. \
\
WBETH juga mewakili hadiah Staking yang terakumulasi oleh token BETH pada ETH Staking setelah 2023-04-27 08:00 (UTC). Untuk pemegang BETH, dukungan lebih lanjut untuk mengonversi BETH ke WBETH dengan rasio tetap 1:1 akan tersedia dalam beberapa minggu ke depan.\
\
