# SnBNB

SnBNB 是 Synclub 的生息型流动性质押代币,其价值会随着 BNB 的质押 APR 相对 BNB 不断增长。与传统质押将质押资产锁定在合约中不同,流动性质押代币可以进行交易,或在整个 DeFi 生态中用作抵押品来赚取收益。

[Synclub 最近与 Helio Protocol 合并](https://finance.yahoo.com/news/helio-protocol-synclub-merge-paving-035000139.html?guccounter=1\&guce\_referrer=aHR0cHM6Ly93d3cuZ29vZ2xlLmNvbS8\&guce\_referrer\_sig=AQAAABDEZ\_TarGE4xWbi6AKki0RiL3fgR0aI\_vnW46DZGoJdbiZqererl49lv3VoXA3I87QMm2EmggovhnRg2bd1vMxRJcnhuApH4bzjUufQMGzKMPkxHaP7f6zeYVTh-BwIMrVvEOkRjgoEgf6KeKHarqhV5IWkYcIoA3npFuk0Bg1i),成为引领 LSTFi 趋势的 DeFi 领军者,借助流动性质押代币的力量,为其去中心化稳定币 HAY 高效产生收益。\
