# SnBNB

SnBNB est le token de Liquid Staking et de rendement pour Synclub, qui s'apprécie par rapport au BNB en ligne avec l'APR de staking du BNB. Contrairement au staking traditionnel où les actifs stakés sont bloqués dans le contrat, les tokens de Liquid Staking peuvent être transférés ou utilisés comme garantie pour générer du rendement dans l'écosystème DeFi.

[Synclub a récemment fusionné avec Helio Protocol](https://finance.yahoo.com/news/helio-protocol-synclub-merge-paving-035000139.html?guccounter=1\&guce\_referrer=aHR0cHM6Ly93d3cuZ29vZ2xlLmNvbS8\&guce\_referrer\_sig=AQAAABDEZ\_TarGE4xWbi6AKki0RiL3fgR0aI\_vnW46DZGoJdbiZqererl49lv3VoXA3I87QMm2EmggovhnRg2bd1vMxRJcnhuApH4bzjUufQMGzKMPkxHaP7f6zeYVTh-BwIMrVvEOkRjgoEgf6KeKHarqhV5IWkYcIoA3npFuk0Bg1i), un acteur DeFi de premier plan, pour favoriser les tendances LSTFi, en tirant parti de la puissance des tokens de Liquid Staking pour une génération de rendement efficace de son stablecoin décentralisé, HAY.\
