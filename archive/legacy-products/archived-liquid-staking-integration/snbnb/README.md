# SnBNB

SnBNB, Synclub के लिए yield bearing और liquid staking token है, जो BNB के staking APR के अनुरूप BNB के मुकाबले appreciate होता है। पारंपरिक staking के विपरीत, जहाँ staked assets contract में locked रहती हैं, liquid staked tokens को DeFi ecosystem में yield अर्जित करने के लिए transact किया जा सकता है या collateral के रूप में उपयोग किया जा सकता है।
