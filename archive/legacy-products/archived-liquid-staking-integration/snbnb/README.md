# SnBNB

SnBNB — это приносящий доход ликвидный стейкинговый токен Synclub, который дорожает относительно BNB в соответствии со стейкинговым APR BNB. В отличие от традиционного стейкинга, где застейканные активы заблокированы в контракте, токены ликвидного стейкинга можно переводить или использовать как залог для получения дохода по всей DeFi-экосистеме.

[Synclub недавно объединился с Helio Protocol](https://finance.yahoo.com/news/helio-protocol-synclub-merge-paving-035000139.html?guccounter=1\&guce\_referrer=aHR0cHM6Ly93d3cuZ29vZ2xlLmNvbS8\&guce\_referrer\_sig=AQAAABDEZ\_TarGE4xWbi6AKki0RiL3fgR0aI\_vnW46DZGoJdbiZqererl49lv3VoXA3I87QMm2EmggovhnRg2bd1vMxRJcnhuApH4bzjUufQMGzKMPkxHaP7f6zeYVTh-BwIMrVvEOkRjgoEgf6KeKHarqhV5IWkYcIoA3npFuk0Bg1i) — ведущим игроком DeFi, задающим тренды LSTFi, который использует возможности токенов ликвидного стейкинга для эффективной генерации дохода своего децентрализованного стейблкоина HAY.\
