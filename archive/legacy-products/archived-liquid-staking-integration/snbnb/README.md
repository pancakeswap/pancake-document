# SnBNB

O SnBNB é o token de liquid staking com rendimento da Synclub, que se valoriza em relação ao BNB de acordo com o APR de staking do BNB. Diferentemente do staking tradicional, em que os ativos em staking ficam bloqueados no contrato, os tokens de liquid staking podem ser transacionados ou usados como garantia para gerar rendimento em todo o ecossistema DeFi.

[A Synclub se fundiu recentemente com a Helio Protocol](https://finance.yahoo.com/news/helio-protocol-synclub-merge-paving-035000139.html?guccounter=1\&guce\_referrer=aHR0cHM6Ly93d3cuZ29vZ2xlLmNvbS8\&guce\_referrer\_sig=AQAAABDEZ\_TarGE4xWbi6AKki0RiL3fgR0aI\_vnW46DZGoJdbiZqererl49lv3VoXA3I87QMm2EmggovhnRg2bd1vMxRJcnhuApH4bzjUufQMGzKMPkxHaP7f6zeYVTh-BwIMrVvEOkRjgoEgf6KeKHarqhV5IWkYcIoA3npFuk0Bg1i), uma das principais players de DeFi a impulsionar as tendências de LSTFi, aproveitando o poder dos tokens de liquid staking para a geração eficiente de rendimento da sua stablecoin descentralizada, a HAY.\
