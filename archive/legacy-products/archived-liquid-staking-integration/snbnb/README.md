# SnBNB

SnBNB es el token de liquid staking con rendimiento de Synclub, que se revaloriza frente a BNB en línea con el APR de staking de BNB. A diferencia del staking tradicional, donde los activos en staking quedan bloqueados en el contrato, los tokens de liquid staking pueden transferirse o usarse como colateral para obtener rendimiento en todo el ecosistema DeFi.

[Synclub se fusionó recientemente con Helio Protocol](https://finance.yahoo.com/news/helio-protocol-synclub-merge-paving-035000139.html?guccounter=1\&guce\_referrer=aHR0cHM6Ly93d3cuZ29vZ2xlLmNvbS8\&guce\_referrer\_sig=AQAAABDEZ\_TarGE4xWbi6AKki0RiL3fgR0aI\_vnW46DZGoJdbiZqererl49lv3VoXA3I87QMm2EmggovhnRg2bd1vMxRJcnhuApH4bzjUufQMGzKMPkxHaP7f6zeYVTh-BwIMrVvEOkRjgoEgf6KeKHarqhV5IWkYcIoA3npFuk0Bg1i), un actor líder en DeFi que impulsa las tendencias de LSTFi, aprovechando el poder de los tokens de liquid staking para generar rendimiento de forma eficiente con su stablecoin descentralizada, HAY.\
