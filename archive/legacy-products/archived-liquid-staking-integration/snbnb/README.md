# SnBNB

SnBNB는 Synclub의 수익형 리퀴드 스테이킹 토큰으로, BNB의 스테이킹 APR에 맞춰 BNB 대비 가치가 상승합니다. 스테이킹된 자산이 컨트랙트에 잠기는 기존 스테이킹과 달리, 리퀴드 스테이킹 토큰은 거래하거나 담보로 사용하여 DeFi 생태계 전반에서 수익을 얻을 수 있습니다.

[Synclub은 최근 Helio Protocol과 합병](https://finance.yahoo.com/news/helio-protocol-synclub-merge-paving-035000139.html?guccounter=1\&guce\_referrer=aHR0cHM6Ly93d3cuZ29vZ2xlLmNvbS8\&guce\_referrer\_sig=AQAAABDEZ\_TarGE4xWbi6AKki0RiL3fgR0aI\_vnW46DZGoJdbiZqererl49lv3VoXA3I87QMm2EmggovhnRg2bd1vMxRJcnhuApH4bzjUufQMGzKMPkxHaP7f6zeYVTh-BwIMrVvEOkRjgoEgf6KeKHarqhV5IWkYcIoA3npFuk0Bg1i)했으며, LSTFi 트렌드를 이끄는 선도적인 DeFi 플레이어로서 리퀴드 스테이킹 토큰의 힘을 활용하여 탈중앙화 스테이블코인 HAY의 효율적인 수익을 창출합니다.\
