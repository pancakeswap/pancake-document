# SnBNB

SnBNB, BNB'nin Staking APR'siyle orantılı olarak BNB karşısında değer kazanan, Synclub'ın getiri sağlayan ve Liquid Staking tokenidir. Geleneksel Staking'den farklı olarak stake edilen varlıkların sözleşmede kilitlendiği yerde, Liquid Staking tokenleri DeFi ekosisteminde getiri kazanmak için teminat olarak kullanılabilir veya işlem görebilir.

[Synclub yakın zamanda Helio Protocol ile birleşerek](https://finance.yahoo.com/news/helio-protocol-synclub-merge-paving-035000139.html?guccounter=1\&guce_referrer=aHR0cHM6Ly93d3cuZ29vZ2xlLmNvbS8\&guce_referrer_sig=AQAAABDEZ\_TarGE4xWbi6AKki0RiL3fgR0aI\_vnW46DZGoJdbiZqererl49lv3VoXA3I87QMm2EmggovhnRg2bd1vMxRJcnhuApH4bzjUufQMGzKMPkxHaP7f6zeYVTh-BwIMrVvEOkRjgoEgf6KeKHarqhV5IWkYcIoA3npFuk0Bg1i) merkezî olmayan sabit parasının verimli getiri üretimi için Liquid Staking tokenlarının gücünden yararlanan, LSTFi trendlerini yönlendiren önde gelen bir DeFi oyuncusu haline geldi: HAY.\
