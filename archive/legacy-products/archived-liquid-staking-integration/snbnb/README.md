# SnBNB

SnBNBはSynclubのイールドを生み出すLiquid Stakingトークンで、BNBのステーキングAPRに合わせてBNBに対して価値が上昇します。資産がコントラクトにロックされる従来のステーキングとは異なり、Liquid Stakingトークンは取引したり、DeFiエコシステム全体でイールドを得るための担保として使用したりできます。

[SynclubはHelioプロトコルと最近合併し](https://finance.yahoo.com/news/helio-protocol-synclub-merge-paving-035000139.html?guccounter=1\&guce_referrer=aHR0cHM6Ly93d3cuZ29vZ2xlLmNvbS8\&guce_referrer_sig=AQAAABDEZ\_TarGE4xWbi6AKki0RiL3fgR0aI\_vnW46DZGoJdbiZqererl49lv3VoXA3I87QMm2EmggovhnRg2bd1vMxRJcnhuApH4bzjUufQMGzKMPkxHaP7f6zeYVTh-BwIMrVvEOkRjgoEgf6KeKHarqhV5IWkYcIoA3npFuk0Bg1i)、分散型ステーブルコインHAYの効率的なイールド生成のためにLiquid Stakingトークンの力を活用してLSTFiのトレンドを牽引する主要なDeFiプレーヤーとなっています。\
