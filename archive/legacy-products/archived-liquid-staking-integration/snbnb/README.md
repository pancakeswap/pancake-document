# SnBNB

SnBNB adalah token Liquid Staking berimbalan hasil untuk Synclub, yang nilainya meningkat terhadap BNB sesuai dengan APR Staking BNB. Tidak seperti Staking tradisional, di mana aset yang di-staking dikunci dalam kontrak, token yang di-staking secara likuid dapat ditransaksikan atau digunakan sebagai agunan untuk mendapatkan hasil di seluruh ekosistem DeFi.

[Synclub baru-baru ini bergabung dengan Helio Protocol](https://finance.yahoo.com/news/helio-protocol-synclub-merge-paving-035000139.html?guccounter=1\&guce\_referrer=aHR0cHM6Ly93d3cuZ29vZ2xlLmNvbS8\&guce\_referrer\_sig=AQAAABDEZ\_TarGE4xWbi6AKki0RiL3fgR0aI\_vnW46DZGoJdbiZqererl49lv3VoXA3I87QMm2EmggovhnRg2bd1vMxRJcnhuApH4bzjUufQMGzKMPkxHaP7f6zeYVTh-BwIMrVvEOkRjgoEgf6KeKHarqhV5IWkYcIoA3npFuk0Bg1i), pemain DeFi terkemuka untuk mendorong tren LSTFi, memanfaatkan kekuatan token Liquid Staking untuk menghasilkan yield yang efisien dari stablecoin terdesentralisasinya, HAY.\
