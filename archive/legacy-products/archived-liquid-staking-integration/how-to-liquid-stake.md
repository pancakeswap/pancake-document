# 如何进行流动性质押

{% hint style="danger" %}
\[已归档] 流动性质押
{% endhint %}

在 PancakeSwap 上将 ETH 转换并兑换为 WBETH 非常简单。操作方法如下:

质押 ETH 并获得 WBETH:

1. 前往 [PancakeSwap](https://pancakeswap.finance/) 并连接你的钱包。请确保你的钱包中在以太坊或 BNB 链网络上持有 ETH,以便转换为 WBETH。&#x20;
2. 进入 "Earn" 标签页,选择 ["Liquid Staking”](https://pancakeswap.finance/liquid-staking)&#x20;
3.  确认所选的质押交易对为 ETH/WBETH,然后点击 “proceed”。&#x20;

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/liquid-staking%20%281%29.png" alt=""><figcaption></figcaption></figure>
4.  输入你想转换的 ETH 数量,并查看对应的 WBETH 数量。提醒:由于累积的质押奖励,WBETH 代币相对于 ETH 的价值会不断增长。&#x20;

    <figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/liquid-staking%20%282%29.png" alt=""><figcaption></figcaption></figure>
5. 点击 stake 以启用 WBETH 代币。再次点击 stake,在你的钱包中确认交易,大功告成!你的 WBETH 代币将会存入你的钱包。

将 WBETH 兑换为 ETH:

1. 进入 ["Trade"](https://pancakeswap.finance/swap?inputCurrency=0xa2E3356610840701BDf5611a53974510Ae27E2e1\&outputCurrency=0x2170Ed0880ac9A755fd29B2688956BD959F933F8) 标签页。&#x20;
2. 选择 "WBETH" 作为输入代币,"ETH" 作为输出代币。&#x20;
3. 输入你想兑换的 WBETH 数量,然后点击 "Swap"。&#x20;
4. 在你的钱包中确认交易,兑换得到的 ETH 将被添加到你的钱包余额中
