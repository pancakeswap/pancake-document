# 이전 토크노믹스

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/tokenomics-header.png)

* **티커:** CAKE
* **컨트랙트 주소:** [https://bscscan.com/token/0x0e09fabb73bd3ade0a17ecc321fd13a19e81ce82](https://bscscan.com/token/0x0e09fabb73bd3ade0a17ecc321fd13a19e81ce82)
* **체인:** BNB Smart Chain (BEP20)

## 기본 사항

CAKE는 PancakeSwap 생태계를 움직이는 맛있는 토큰입니다.

파밍과 시럽 풀에서 CAKE를 얻거나, 복권에서 당첨되거나, [거래소에서 구매](../../undefined/pancakeswap-exchange/)한 다음 활용 사례를 살펴보세요.

* [시럽 풀](../../undefined-2/cake-staking/syrup-pool/)에서 스테이킹하여 무료 토큰 얻기
* [일드 파밍](https://docs.pancakeswap.finance/earn/yield-farming)에서 사용하여 더 많은 CAKE 얻기
* [PancakeSwap 복권](../../undefined-3/lottery/)에서 복권 티켓 구매
* [IFO 토큰 세일](../../undefined-2/cakepad/) 참여
* Pancake 프로필을 만들고 NFT 민팅
* PancakeSwap 생태계와 관련된 [제안에 투표](../../undefined-5/voting/)

하지만 이게 전부가 아닙니다. CAKE에는 앞으로 훨씬 더 많은 계획이 있습니다!
