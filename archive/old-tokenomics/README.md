# 旧トークノミクス

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/tokenomics-header.png)

* **ティッカー：** CAKE
* **コントラクトアドレス：** [https://bscscan.com/token/0x0e09fabb73bd3ade0a17ecc321fd13a19e81ce82](https://bscscan.com/token/0x0e09fabb73bd3ade0a17ecc321fd13a19e81ce82)
* **チェーン：** BNB Smart Chain (BEP20)

## 基本情報

CAKEはPancakeSwapエコシステムを支えるトークンです。

ファームやシロッププールでCAKEを獲得したり、宝くじで当選したり、[取引所で購入](../../trade/pancakeswap-exchange/)して、その用途を探求してください：

* [シロッププール](../../earn/cake-staking/syrup-pool/)でステーキングして無料のトークンを獲得する
* [イールドファーム](https://docs.pancakeswap.finance/products/yield-farming)を使ってさらに多くのCAKEを獲得する
* [PancakeSwap宝くじ](../../play/lottery/)で宝くじチケットを購入する
* [IFOトークンセール](../../earn/cakepad/)に参加する
* [Pancakeプロフィール](/broken/pages/-MYccH_bJjPXGyPCweA8)を作成してNFTをミントする
* PancakeSwapエコシステムに関する[提案に投票](../../protocol/voting/)する

これだけではありません — CAKEにはさらに多くの展開が待っています！
