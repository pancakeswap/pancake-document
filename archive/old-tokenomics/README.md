* **チェーン:**BNB Smart Chain(BEP20)

## 基本情報

CAKEは、PancakeSwapエコシステムを支える美味しいトークンです。

ファームやシロッププールで獲得したり、宝くじで当てたり、[取引所で購入](../../trade/pancakeswap-exchange/)したりして入手し、その活用方法を探ってみましょう。

* [シロッププール](../../earn/cake-staking/syrup-pool/)でステーキングして、無料のトークンを獲得する
* [イールドファーム](https://docs.pancakeswap.finance/earn/yield-farming)で使って、さらにCAKEを獲得する
* [PancakeSwap宝くじ](../../play/lottery/)で宝くじのチケットを購入する
* [IFOトークンセール](../../earn/cakepad/)に参加する
* Pancakeプロフィールを作成し、NFTをミントする
* PancakeSwapエコシステムに関する[提案に投票](../../protocol/voting/)する

しかし、これだけではありません。CAKEにはこれからさらに多くの展開が控えています。
