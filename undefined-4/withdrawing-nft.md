# 🧙 NFT 출금

## PancakeSwap NFT 마켓플레이스에서 NFT 출금하는 방법

PancakeSwap NFT 마켓플레이스 페이지는 더 이상 이용할 수 없지만 마켓플레이스 스마트 컨트랙트는 여전히 작동하고 있습니다. NFT를 판매 등록했지만 팔리지 않았다면 해당 NFT는 여전히 마켓플레이스 컨트랙트에 보관되어 있습니다. BscScan에서 직접 등록을 취소하여 NFT를 되찾을 수 있습니다.

NFT 하나당 몇 분이 걸리며 가스비로 소량의 BNB만 필요합니다.

### 시작하기 전에

다음이 필요합니다.

* **NFT를 등록할 때 사용한 동일한 지갑.** 등록을 생성한 지갑만 취소할 수 있습니다.
* **BNB Smart Chain**으로 설정된 **브라우저 지갑**(예: MetaMask, Trust Wallet 확장 프로그램 또는 Binance Wallet 확장 프로그램).
* 가스비를 지불할 **소량의 BNB**. 각 NFT는 별도의 거래로 출금됩니다.

다음 주소를 준비해 두세요.

| 항목                  | 주소                                           |
| ------------------- | -------------------------------------------- |
| 마켓플레이스 컨트랙트         | `0x17539cCa21C7933Df5c980172d22659B8C345C5A` |
| Pancake Squad 컬렉션   | `0x0a8901b0E25DEb55A87524f0cC164E9644020EBA` |
| Pancake Bunnies 컬렉션 | `0xDf7952B35f24aCF7fC0487D01c8d5690a60DBa07` |

> **안전 수칙**
>
> * 마켓플레이스 컨트랙트 `0x17539cCa21C7933Df5c980172d22659B8C345C5A`하고만 상호작용하세요. BscScan URL의 주소를 항상 확인하세요.
> * NFT를 출금하는 데는 BNB나 토큰을 보낼 필요가 **전혀 없으며**, 승인(`approve` 또는 `setApprovalForAll`)에 서명할 필요도 없습니다. 웹사이트나 사람이 이를 요구한다면 사기입니다.
> * PancakeSwap은 절대 DM을 보내거나 시드 구문을 요구하지 않습니다.

### 1단계: 아직 등록되어 있는 NFT 찾기

출금하려는 각 NFT에 대해 **컬렉션 주소**와 **토큰 ID** 두 가지 정보가 필요합니다.

1. BscScan에서 마켓플레이스 컨트랙트의 [Read Contract 페이지](https://bscscan.com/address/0x17539cCa21C7933Df5c980172d22659B8C345C5A#readContract)를 엽니다.
2. \*\*`viewAsksByCollectionAndSeller`\*\*를 찾아 펼칩니다.
3. 필드를 입력합니다.
   * `collection`: 위 표의 컬렉션 주소(예: Pancake Squad는 `0x0a8901b0E25DEb55A87524f0cC164E9644020EBA`)
   * `seller`: 내 지갑 주소
   * `cursor`: `0`
   * `size`: `100`
4. **Query**를 클릭합니다.
5. `tokenIds` 결과를 확인합니다. 이는 해당 컬렉션에서 아직 등록되어 있는 토큰 ID이며, 출금할 수 있는 NFT입니다.
6. 두 개 이상의 컬렉션에 NFT를 등록했다면 각 컬렉션에 대해 3\~5단계를 반복합니다.

**`tokenIds`가 비어 있다면(`[]`)** 해당 컬렉션에 활성 등록이 없다는 의미입니다. NFT가 판매되었거나(이 경우 이미 BNB를 받았습니다) 이전에 등록을 취소했을 것입니다(이 경우 이미 지갑으로 돌아와 있습니다).

한 컬렉션에 **등록이 100개를 넘는 경우** 결과의 마지막 숫자가 다음 커서입니다. 해당 숫자를 `cursor`로 사용하여 다시 조회하면 나머지를 볼 수 있습니다.

**NFT가 Pancake Squad 또는 Pancake Bunnies가 아닌 다른 컬렉션의 것이라면** 같은 페이지에서 \*\*`viewCollections`\*\*를 펼치고 `cursor = 0`, `size = 100`을 입력한 후 **Query**를 클릭하여 마켓플레이스가 지원하는 모든 컬렉션을 확인하세요.

### 2단계: NFT 출금하기

1. BscScan에서 마켓플레이스 컨트랙트의 [Write Contract 페이지](https://bscscan.com/address/0x17539cCa21C7933Df5c980172d22659B8C345C5A#writeContract)를 엽니다.
2. **Connect to Web3**를 클릭하고 NFT를 등록한 동일한 지갑을 연결합니다. 지갑이 BNB Smart Chain에 있는지 확인하세요.
3. \*\*`cancelAskOrder`\*\*를 찾아 펼칩니다.
4. 필드를 입력합니다.
   * `_collection`: 1단계의 컬렉션 주소
   * `_tokenId`: 1단계의 토큰 ID(일반 숫자로, 예: `1234`)
5. **Write**를 클릭하고 지갑에서 거래를 확인합니다. BNB를 보내지 않으며 가스비만 지불합니다.
6. 거래가 성공하면 NFT가 지갑으로 돌아옵니다.
7. 출금하려는 각 NFT에 대해 반복합니다.

제대로 처리되었는지 확인하려면 1단계를 다시 실행하세요. 해당 토큰 ID가 더 이상 목록에 나타나지 않아야 합니다.

### 문제 해결

| 문제                            | 의미 및 해결 방법                                                                                            |
| ----------------------------- | ----------------------------------------------------------------------------------------------------- |
| 오류: `Order: Token not listed` | 연결된 지갑이 이 컬렉션의 해당 토큰 ID를 등록하지 않았거나 NFT가 이미 판매되었거나 출금되었습니다. 원래 지갑과 올바른 컬렉션 주소 및 토큰 ID를 사용하고 있는지 확인하세요. |
| Write 버튼이 아무 반응이 없음           | 지갑이 잘못된 네트워크에 있을 가능성이 높습니다. BNB Smart Chain으로 전환한 후 다시 연결하세요.                                         |
| 가스 부족 또는 잔액 부족                | 가스비를 충당할 수 있도록 지갑에 소량의 BNB를 추가하세요.                                                                    |
| NFT를 등록한 지갑에 더 이상 접근할 수 없음    | 원래 지갑만 등록을 취소할 수 있습니다. PancakeSwap을 포함한 누구도 대신 출금해 드릴 수 없습니다.                                         |
