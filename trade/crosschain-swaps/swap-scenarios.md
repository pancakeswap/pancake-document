# 🔁 スワップシナリオ

クロスチェーントランザクションには4つのシナリオがあります。

#### 1️⃣ ブリッジのみ

* 例：**Base上のETHをArbitrum上のETHにブリッジ**
* サポートされているトークン（USDC、USDT、WETHなど）のみ直接ブリッジできます。これらのトークンは送信元・送信先チェーンによって異なります。

#### 2️⃣ Swap → Bridge

* 例：**BNB Chain上のBNBをArbitrum上のUSDCにスワップ**
* BNB Chain上のPancakeSwapプールを使用してBNBをサポートされているブリッジトークン（例：USDC）にスワップ
* AcrossでUSDCをArbitrumへブリッジ

#### 3️⃣ Bridge → Swap

* 例：**BNB Chain上のUSDCをArbitrum上のARBにスワップ**
* Acrossで USDCをブリッジ
* Arbitrum上のPancakeSwapプールを使用してUSDCをARBにスワップ

#### 4️⃣ Swap → Bridge → Swap

* 例：**BNB Chain上のBNBをArbitrum上のARBにスワップ**
* BNBをブリッジトークンにスワップ（ユーザーのアウトプットを最大化）
* Acrossでブリッジ
* Arbitrum上のPancakeSwapプールを使用してブリッジされたトークンをARBにスワップ

***

### ⚠️ 失敗ケース

| シナリオ                              | 結果                                                                                                                                                                                         |
| ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **送信元チェーンでのスワップ／トランザクション失敗**   | ユーザーは送信元チェーンで元のトークンを即座に受け取ります                                                                                                                                      |
| **ブリッジトランザクション失敗**                 | Acrossが90分〜2時間以内に返金処理を行い、ユーザーは送信元チェーンでブリッジされたアセットを受け取ります。SOL〜EVM間のシナリオでは、Relayが1分以内に返金処理を行います。 |
| **送信先チェーンでのスワップ失敗** | ユーザーは送信先チェーンでブリッジされたアセットを受け取ります                                                                                                                                        |
