# 👉 Cara Melakukan Crosschain Swap?

1. Kunjungi [https://pancakeswap.finance/swap](https://pancakeswap.finance/swap)
2. Pilih **Jaringan Asal / Tujuan** dan **Token** di pemilih token

3. Tinjau Detail Swap:
   1. Jaringan Asal / Tujuan, Token, dan jumlah masing-masing
   2. Total Biaya
   3. Dampak harga
   4. Toleransi Slippage

4. Klik **Swap** → Konfirmasi
