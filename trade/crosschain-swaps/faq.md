# ❓ FAQ

### 1. 跨链兑换的滑点容差是如何运作的？

对于跨链兑换，您选择的滑点容差百分比会分别独立地应用于源链和目标链上的兑换。

**示例：**

* 将 BNB Chain 上的 BNB 兑换为 Arbitrum 上的 ARB
* 滑点容差设置为 1%
* 路由可能是：
  1. 在 BNB Chain 上将 BNB 兑换为 USDC
  2. 通过 Across 将 USDC 从 BNB Chain 桥接到 Arbitrum
  3. 在 Arbitrum 上将 USDC 兑换为 ARB
* 在这种情况下，1% 的滑点容差会分别应用于：
  * BNB Chain 上的兑换
  * Arbitrum 上的兑换

这确保您在交易的两端都免受过度的价格波动影响，同时桥接过程本身不受滑点设置的影响。

### 2. 如果我的交易失败会怎样？

如果您的跨链兑换在任何阶段遇到失败，处理方式如下：

1.  **源链上的兑换/交易失败**

    ➝ 您将立即在源链上收回您的原始代币。
2.  **桥接交易失败**

    ➝ Across 将在 90 分钟到 2 小时内处理退款，您将在源链上收回桥接资产。而在 SOL <> EVM 之间的此类情形下，Relay 会在一分钟内处理退款。
3.  **目标链上的兑换失败**

    ➝ 您将在目标链上收到桥接资产，但不会执行兑换为目标代币的最后一步。

{% hint style="info" %}
**注意：** 您随时可以通过 wallet connect UI 下的交易历史标签页查看您的交易状态。
{% endhint %}

### 3. 我的跨链兑换受 MEV 保护吗？

MEV Guard 仅在 BNB Chain 上受支持，且兑换需直接从已启用 MEV Guard 的已连接钱包发起。

* 如果您的跨链兑换涉及以 BNB Chain 作为源链的兑换，并且您已启用 MEV Guard，则该兑换将受到 MEV 保护。
* 如果 BNB Chain 是目标链，则该兑换由桥接中继者/系统执行，将不受 MEV 保护，因为它不是由您已连接的钱包发起的。

{% hint style="info" %}
**注意：** Arbitrum 和 Base 等其他链目前不支持 PancakeSwap 上的 MEV Guard 保护。
{% endhint %}

### 4. 我可以在各链之间兑换稳定币吗？

可以——您可以在任何受支持的链之间直接兑换和桥接 USDC、USDT 和 DAI 等稳定币。

您有两种选择：

1.  **直接桥接：**

    将受支持的稳定币（如 USDC、USDT 等）直接从一条链桥接到另一条链。
2.  **兑换为其他代币：**

    您也可以使用 PancakeSwap 的流动性池——在桥接之前或之后——将稳定币兑换为目标链上受支持的任何其他代币。

{% hint style="info" %}
**注意：** 可直接桥接的受支持稳定币可能因链而异。
{% endhint %}

### 5. 我的兑换会使用 PCSX 吗？

不会——PCSX 不支持服务跨链兑换。

PancakeSwap 上的跨链兑换专门通过以下方式路由：

* **PancakeSwap 的流动性池**（v2、v3、Infinity、StableSwap）用于链上兑换，以及
* **Across 和 Relay 协议**用于在各链之间桥接资产。

PCSX 不能用于促成或路由跨链兑换交易的任何部分。

### 6. 兑换金额有最低或最高限制吗？

有——跨链交易同时适用最低和最高限制。

* **最高限制：**\
  取决于所选代币和链的可用桥接流动性。该数值可能会根据网络和流动性状况实时波动。
* **最低限制：**\
  设置该限制是为了确保中继者处理桥接交易在经济上可行。

{% hint style="info" %}
**注意：** 确切的最低和最高限制因桥接代币而异。如果您的交易金额超出允许范围，界面将显示清晰的错误信息并提示您调整金额。
{% endhint %}
