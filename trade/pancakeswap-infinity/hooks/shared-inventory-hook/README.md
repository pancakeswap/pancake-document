# Shared Inventory Hook

Официальный Shared Inventory Hook (SIH) от PancakeSwap позволяет одному пулу капитала выполнять маркет-мейкинг во всех пулах, которые используют его токены, вместо того чтобы блокировать отдельную ликвидность в каждом из них. Трейдеры получают более глубокие котировки и меньшее влияние на цену, а поставщики ликвидности могут задействовать меньше капитала для того же покрытия.

Этот хук создан core-командой PancakeSwap и рассчитан на эмитентов активов и маркет-мейкеров, которые хотят котировать несколько пар ончейн, не дробя свой инвентарь.

#### 🔍 Зачем нужен Shared Inventory?

Классическое предоставление ликвидности в несколько пар означает блокировку отдельного капитала в разных пулах, большая часть которого простаивает между сделками. SIH вместо этого хранит один баланс на токен и вносит его как ликвидность только тогда, когда он нужен для обмена, поэтому один и тот же капитал может обеспечивать каждый пул, где используется этот токен.

#### 📊 Чем это отличается от других моделей?

Классическая концентрированная ликвидность требует вложить весь капитал в один пул. Другие кросс-пуловые подходы, например слои расчёта на виртуальных балансах, обычно находятся вне самого AMM, поэтому такая ликвидность может не отображаться как ончейн-глубина пула и не маршрутизироваться напрямую агрегаторами.

Ликвидность SIH входит в пул PancakeSwap Infinity CLAMM и выходит из него через хук при каждом обмене, поэтому она отображается как настоящая глубина пула, которую видят и с которой работают роутеры.

#### ⚙️ Как это работает

* **Just-in-time (JIT) инъекция**\
  Перед каждым обменом хук создаёт в пуле заданную позицию концентрированной ликвидности; после исполнения обмена он сжигает её и фиксирует чистый результат. Позиция существует только на время одного обмена, и баланс сразу же может обслужить следующий пул, которому он понадобится.
* **Один баланс, много пулов**\
  Инвентарь — это собственный баланс токенов хука, отдельных депозитов по пулам нет. Любой токен, используемый более чем в одном пуле, является общим для всех этих пулов.

{% hint style="success" %}
Это разделяет глубину, которую котирует пул, и капитал, который он непосредственно держит: профинансированный хук может котировать глубокую и плотную ликвидность сразу в нескольких пулах с общим токеном.
{% endhint %}

* **Настраиваемый хук**\
  Для каждого пула, который он обслуживает, хук хранит отдельную настраиваемую конфигурацию диапазона цен и глубины. Для сдвига диапазона достаточно обновить конфигурацию, поэтому котировки легко перецентрировать вокруг изменяющейся опорной цены.

#### 📌 Главное

* Один общий баланс токена обеспечивает каждый пул, использующий этот токен. Добавление нового пула не требует нового капитала.
* Полностью ончейн и компонуемо: ликвидность SIH — это реальная глубина пула, доступная для маршрутизации как PancakeSwap, так и сторонним агрегаторам.
* Трейдеры получают более глубокие котировки и меньшее влияние на цену при крупных сделках; операторы зарабатывают те же торговые комиссии, используя лишь часть капитала, необходимого при традиционном подходе.
