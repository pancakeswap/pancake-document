# Infinity StableSwap

**Infinity StableSwap** 是一种专门的资金池类型，针对稳定币和流动性质押代币等相关联资产进行了优化。<br>

它使用一种 StableSwap 不变量，旨在：

* 最小化价格紧密关联资产之间的滑点
* 提高稳定币对的执行效率
* 为低波动性资产提供资本高效的交易
