# Infinity StableSwap

**Infinity StableSwap** est un type de pool spécialisé, optimisé pour les actifs corrélés tels que les stablecoins et les liquid staking tokens.<br>

Il utilise un invariant StableSwap conçu pour :

* Minimiser le glissement entre des actifs dont les prix sont très proches
* Améliorer l'efficacité d'exécution pour les paires stables
* Offrir un trading efficace en capital pour les actifs à faible volatilité
