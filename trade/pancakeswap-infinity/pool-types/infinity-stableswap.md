# Infinity StableSwap

**Infinity StableSwap** est un type de pool spécialisé optimisé pour les actifs corrélés tels que les stablecoins et les tokens de Staking liquide.<br>

Il utilise un invariant StableSwap conçu pour :

* Minimiser le Glissement entre des actifs dont les prix sont proches
* Améliorer l'efficacité d'exécution pour les paires stables
* Fournir un trading efficace en capital pour les actifs à faible volatilité



👉 En savoir plus sur les mécanismes des pools et la création de pools [ici](https://docs.pancakeswap.finance/~/revisions/E5nc3XhgBcYotE6q89fB/trade/stableswap/infinity-stableswap).
