# Infinity StableSwap

**Infinity StableSwap** — это специализированный тип пула, оптимизированный для коррелированных активов, таких как стейблкоины и токены ликвидного стейкинга.<br>

Он использует инвариант StableSwap, призванный:

* Минимизировать проскальзывание между активами с близкими ценами
* Повысить эффективность исполнения для стабильных пар
* Обеспечить капиталоэффективную торговлю низковолатильными активами
