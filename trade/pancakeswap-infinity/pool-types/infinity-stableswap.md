# Infinity StableSwap

O **Infinity StableSwap** é um tipo de pool especializado, otimizado para ativos correlacionados, como stablecoins e tokens de liquid staking.<br>

Ele usa um invariante StableSwap projetado para:

* Minimizar o slippage entre ativos com preços muito próximos
* Melhorar a eficiência de execução em pares estáveis
* Oferecer negociação com eficiência de capital para ativos de baixa volatilidade
