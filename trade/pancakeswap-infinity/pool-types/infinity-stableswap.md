# Infinity StableSwap

**Infinity StableSwap**は、ステーブルコインや流動性ステーキングトークンなどの相関資産向けに最適化された特殊なプールタイプです。<br>

StableSwap不変式を使用して以下を実現します：

* 価格が近いアセット間のスリッページを最小化
* 安定したペアの取引実行効率を向上
* 低ボラティリティのアセットに対して資本効率の高い取引を提供



👉 プールの仕組みとプール作成の詳細については[こちら](https://docs.pancakeswap.finance/~/revisions/E5nc3XhgBcYotE6q89fB/trade/stableswap/infinity-stableswap)をご覧ください。
