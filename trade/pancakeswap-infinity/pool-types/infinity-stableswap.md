# Infinity StableSwap

**Infinity StableSwap**は、ステーブルコインや流動性ステーキングトークンなど、相関性の高い資産向けに最適化された特殊なプールタイプです。<br>

次の目的で設計されたStableSwapの不変条件を使用しています。

* 価格が近接した資産間のスリッページを最小限に抑える
* ステーブルペアの約定効率を向上させる
* 低ボラティリティ資産に対して、資本効率の高い取引を提供する



👉 プールの仕組みとプールの作成方法の詳細は[こちら](../../stableswap/infinity-stableswap.md)をご覧ください。
