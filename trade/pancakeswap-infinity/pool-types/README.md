# プールタイプ

**PancakeSwap Infinity**は、専用の**Pool Manager**によって機能するモジュラーアーキテクチャを採用しています。各プールタイプは独自のロジックコントラクトによって管理され、異なる価格曲線、流動性の動作、およびHooksによる拡張性を実現しています。



Infinityは現在、以下のプールタイプをサポートしています：

* [Infinity CLAMM & LBAMM](infinity-clamm-and-lbamm.md)
* [Infinity StableSwap](../../stableswap/infinity-stableswap.md)
