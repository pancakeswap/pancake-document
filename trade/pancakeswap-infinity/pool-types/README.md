# Pool Types

**PancakeSwap Infinity** presenta un'architettura modulare basata su **Pool Manager** specializzati. Ogni tipo di pool è governato dal proprio contratto di logica, che abilita curve di prezzo, comportamenti di liquidità ed estensibilità tramite hook differenti.



Infinity attualmente supporta i seguenti tipi di pool:

* [Infinity CLAMM & LBAMM](infinity-clamm-and-lbamm.md)
* [Infinity StableSwap](../../stableswap/infinity-stableswap.md)
