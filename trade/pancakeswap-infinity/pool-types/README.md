# Types de Pools

**PancakeSwap Infinity** dispose d'une architecture modulaire propulsée par des **Gestionnaires de Pools** spécialisés. Chaque type de pool est régi par son propre contrat logique, permettant différentes courbes de tarification, différents comportements de Liquidité et une extensibilité via les hooks.



Infinity prend actuellement en charge les types de pools suivants :

* [Infinity CLAMM & LBAMM](https://docs.pancakeswap.finance/~/revisions/dR1OpdERU6eEn0BRwIs6/trade/pancakeswap-infinity/pool-types/infinity-clamm-and-lbamm)
* [Infinity StableSwap](https://docs.pancakeswap.finance/~/revisions/dR1OpdERU6eEn0BRwIs6/trade/stableswap/infinity-stableswap)
