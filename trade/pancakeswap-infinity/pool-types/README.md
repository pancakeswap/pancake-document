# Типы пулов

**PancakeSwap Infinity** построен на модульной архитектуре со специализированными **Pool Managers**. Каждый тип пула управляется собственным логическим контрактом, что позволяет использовать разные кривые ценообразования, разное поведение ликвидности и расширяемость через хуки.



Сейчас Infinity поддерживает следующие типы пулов:

* [Infinity CLAMM & LBAMM](infinity-clamm-and-lbamm.md)
* [Infinity StableSwap](../../stableswap/infinity-stableswap.md)
