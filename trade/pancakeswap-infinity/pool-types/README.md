# Типы пулов

**PancakeSwap Infinity** использует модульную архитектуру на основе специализированных **Pool Manager'ов**. Каждый тип пула управляется собственным логическим контрактом, что позволяет применять различные ценовые кривые, поведение ликвидности и расширяемость через хуки.



В настоящее время Infinity поддерживает следующие типы пулов:

* [Infinity CLAMM и LBAMM](https://docs.pancakeswap.finance/~/revisions/dR1OpdERU6eEn0BRwIs6/trade/pancakeswap-infinity/pool-types/infinity-clamm-and-lbamm)
* [Infinity StableSwap](https://docs.pancakeswap.finance/~/revisions/dR1OpdERU6eEn0BRwIs6/trade/stableswap/infinity-stableswap)
