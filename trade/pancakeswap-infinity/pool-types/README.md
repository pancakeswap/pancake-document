# Tipos de Pool

O **PancakeSwap Infinity** conta com uma arquitetura modular alimentada por **Pool Managers** especializados. Cada tipo de pool é regido por seu próprio contrato de lógica, permitindo diferentes curvas de preço, comportamento de liquidez e extensibilidade por meio de hooks.



Atualmente, o Infinity oferece suporte aos seguintes tipos de pool:

* [Infinity CLAMM & LBAMM](infinity-clamm-and-lbamm.md)
* [Infinity StableSwap](../../stableswap/infinity-stableswap.md)
