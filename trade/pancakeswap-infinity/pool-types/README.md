# Tipi di Pool

**PancakeSwap Infinity** presenta un'architettura modulare basata su **Pool Manager** specializzati. Ogni tipo di pool è governato dal proprio contratto di logica, che consente diverse curve di prezzo, comportamenti di liquidità ed estensibilità tramite hook.



Infinity supporta attualmente i seguenti tipi di pool:

* [Infinity CLAMM & LBAMM](https://docs.pancakeswap.finance/~/revisions/dR1OpdERU6eEn0BRwIs6/trade/pancakeswap-infinity/pool-types/infinity-clamm-and-lbamm)
* [Infinity StableSwap](https://docs.pancakeswap.finance/~/revisions/dR1OpdERU6eEn0BRwIs6/trade/stableswap/infinity-stableswap)
