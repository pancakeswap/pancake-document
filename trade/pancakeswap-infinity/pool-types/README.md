# Các Loại Pool

**PancakeSwap Infinity** có kiến trúc mô-đun được hỗ trợ bởi các **Pool Manager** chuyên biệt. Mỗi loại pool được điều chỉnh bởi hợp đồng logic riêng của nó, cho phép các đường cong định giá, hành vi thanh khoản và khả năng mở rộng khác nhau thông qua hooks.



Infinity hiện hỗ trợ các loại pool sau:

* [Infinity CLAMM & LBAMM](https://docs.pancakeswap.finance/~/revisions/dR1OpdERU6eEn0BRwIs6/trade/pancakeswap-infinity/pool-types/infinity-clamm-and-lbamm)
* [Infinity StableSwap](https://docs.pancakeswap.finance/~/revisions/dR1OpdERU6eEn0BRwIs6/trade/stableswap/infinity-stableswap)
