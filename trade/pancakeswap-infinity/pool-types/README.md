# Pool Types

**PancakeSwap Infinity** विशेष **Pool Managers** द्वारा संचालित एक मॉड्यूलर architecture की विशेषता रखता है। प्रत्येक pool type अपने स्वयं के लॉजिक कॉन्ट्रैक्ट द्वारा संचालित होता है, जो hooks के माध्यम से विभिन्न pricing curves, तरलता व्यवहार, और extensibility को सक्षम करता है।



Infinity वर्तमान में निम्नलिखित pool types का समर्थन करता है:

* [Infinity CLAMM & LBAMM](https://docs.pancakeswap.finance/~/revisions/dR1OpdERU6eEn0BRwIs6/trade/pancakeswap-infinity/pool-types/infinity-clamm-and-lbamm)
* [Infinity StableSwap](https://docs.pancakeswap.finance/~/revisions/dR1OpdERU6eEn0BRwIs6/trade/stableswap/infinity-stableswap)
