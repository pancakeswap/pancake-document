# Pool Types

**PancakeSwap Infinity** repose sur une architecture modulaire alimentée par des **Pool Managers** spécialisés. Chaque type de pool est régi par son propre contrat de logique, ce qui permet différentes courbes de prix, différents comportements de liquidité et une extensibilité via les hooks.



Infinity prend actuellement en charge les types de pools suivants :

* [Infinity CLAMM & LBAMM](infinity-clamm-and-lbamm.md)
* [Infinity StableSwap](../../stableswap/infinity-stableswap.md)
