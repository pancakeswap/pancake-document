# Các loại Pool

**PancakeSwap Infinity** có kiến trúc mô-đun được vận hành bởi các **Pool Manager** chuyên biệt. Mỗi loại pool được điều khiển bởi hợp đồng logic riêng, cho phép các đường cong định giá, hành vi thanh khoản và khả năng mở rộng khác nhau thông qua hook.



Infinity hiện hỗ trợ các loại pool sau:

* [Infinity CLAMM & LBAMM](infinity-clamm-and-lbamm.md)
* [Infinity StableSwap](../../stableswap/infinity-stableswap.md)
