# Jenis Pool

**PancakeSwap Infinity** menampilkan arsitektur modular yang didukung oleh **Pool Manager** yang terspesialisasi. Setiap jenis pool diatur oleh kontrak logikanya sendiri, memungkinkan kurva penetapan harga yang berbeda, perilaku likuiditas, dan ekstensibilitas melalui hooks.



Infinity saat ini mendukung jenis pool berikut:

* [Infinity CLAMM & LBAMM](https://docs.pancakeswap.finance/~/revisions/dR1OpdERU6eEn0BRwIs6/trade/pancakeswap-infinity/pool-types/infinity-clamm-and-lbamm)
* [Infinity StableSwap](https://docs.pancakeswap.finance/~/revisions/dR1OpdERU6eEn0BRwIs6/trade/stableswap/infinity-stableswap)
