# 풀 유형

**PancakeSwap Infinity**는 특화된 **풀 매니저(Pool Manager)**가 구동하는 모듈식 아키텍처를 갖추고 있습니다. 각 풀 유형은 자체 로직 컨트랙트로 관리되며, 서로 다른 가격 곡선, 유동성 동작, 그리고 Hooks를 통한 확장성을 제공합니다.



Infinity는 현재 다음 풀 유형을 지원합니다.

* [Infinity CLAMM & LBAMM](infinity-clamm-and-lbamm.md)
* [Infinity StableSwap](../../stableswap/infinity-stableswap.md)
