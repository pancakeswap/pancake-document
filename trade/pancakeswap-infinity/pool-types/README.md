# Tipos de pool

**PancakeSwap Infinity** cuenta con una arquitectura modular impulsada por **Pool Managers** especializados. Cada tipo de pool se rige por su propio contrato de lógica, lo que permite distintas curvas de precios, comportamientos de liquidez y extensibilidad mediante Hooks.



Infinity actualmente admite los siguientes tipos de pool:

* [Infinity CLAMM & LBAMM](infinity-clamm-and-lbamm.md)
* [Infinity StableSwap](../../stableswap/infinity-stableswap.md)
