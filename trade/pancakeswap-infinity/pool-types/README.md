# पूल के प्रकार

**PancakeSwap Infinity** में विशेष **Pool Managers** द्वारा संचालित एक मॉड्यूलर आर्किटेक्चर है। प्रत्येक पूल प्रकार अपने स्वयं के लॉजिक कॉन्ट्रैक्ट द्वारा संचालित होता है, जो अलग-अलग प्राइसिंग कर्व, तरलता व्यवहार और Hooks के माध्यम से एक्सटेंसिबिलिटी को सक्षम बनाता है।



Infinity वर्तमान में निम्नलिखित पूल प्रकारों को सपोर्ट करता है:

* [Infinity CLAMM & LBAMM](infinity-clamm-and-lbamm.md)
