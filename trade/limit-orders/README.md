{% hint style="success" %}
**Gli Ordini Limite con Guadagno di Commissioni** sono una **funzionalità di trading unica nel suo genere** disponibile esclusivamente su PancakeSwap.
{% endhint %}

#### Di cosa si tratta?

Gli Ordini Limite con Guadagno di Commissioni ti consentono di impostare un prezzo target per acquistare o vendere token automaticamente, **guadagnando commissioni**. Una volta che il prezzo del pool raggiunge il tuo target, l'ordine viene eseguito e i token di output desiderati + le commissioni vengono inviati direttamente al tuo Portafoglio.

* **Chain supportata:** BNB Chain
* **Dimensione minima dell'ordine:** $50

#### Perché usarlo?

* Non è necessario monitorare costantemente i grafici.
* Nessuna commissione di esecuzione — invece, **guadagni commissioni (0,1%)** quando il tuo ordine viene eseguito.
* Funziona senza problemi — completamente on-chain, alimentato dall'architettura PancakeSwap Infinity.

***

TWAP (Time-weighted Average Price) è un tipo di ordine comune che suddivide un ordine in dimensioni di trade più piccole e le esegue a intervalli regolari. L'obiettivo principale di un ordine TWAP è ridurre l'impatto sul prezzo dell'ordine.

{% hint style="info" %}
La funzionalità TWAP è sviluppata da [Orbs](https://www.orbs.com/) ed è alimentata dalla [tecnologia L3](https://www.orbs.com/overview/) di Orbs.
{% endhint %}
