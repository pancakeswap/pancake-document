**Gebührengenerierende Limit Orders** sind eine **einzigartige Handelsfunktion**, die exklusiv auf PancakeSwap verfügbar ist.
{% endhint %}

#### Was ist das?

Gebührengenerierende Limit Orders ermöglichen es Ihnen, einen Zielpreis festzulegen, zu dem Token automatisch gekauft oder verkauft werden, während Sie gleichzeitig **Gebühren verdienen**. Sobald der Pool-Preis Ihr Ziel erreicht, wird Ihre Order ausgeführt und die gewünschten Ausgabe-Token plus Gebühren werden direkt an Ihre Wallet gesendet.

* **Unterstützte Chain:** BNB Chain
* **Mindestordergröße:** 50 $

#### Warum sollten Sie es verwenden?

* Kein ständiges Beobachten von Charts erforderlich.
* Keine Ausführungsgebühren – stattdessen **verdienen Sie Gebühren (0,1 %)**, wenn Ihre Order ausgeführt wird.
* Funktioniert nahtlos – vollständig Onchain, betrieben von der PancakeSwap Infinity-Architektur.

***

TWAP (Time-weighted Average Price) ist ein gängiger Ordertyp, der eine Order in kleinere Trade-Größen aufteilt und diese in regelmäßigen Abständen ausführt. Das Hauptziel einer TWAP-Order ist es, den Preiseinfluss der Order zu reduzieren.

{% hint style="info" %}
Die TWAP-Funktion wird von [Orbs](https://www.orbs.com/) entwickelt und durch Orbs' [L3-Technologie](https://www.orbs.com/overview/) betrieben.
{% endhint %}
