# 🎯 Limit & TWAP Orders

{% hint style="warning" %}
**Limit Order (Orbs) telah dihentikan.** Jika Anda memiliki order yang tertunda, harap kelola [di sini](https://pancakeswap.finance/swap/limit-v1). Pastikan Anda menggunakan fitur limit order terbaru di sini: [https://pancakeswap.finance/swap/limit](https://pancakeswap.finance/swap/limit)
{% endhint %}

{% hint style="success" %}
**Limit Order Penghasil Biaya** adalah **fitur trading pertama dari jenisnya** yang tersedia secara eksklusif di PancakeSwap.
{% endhint %}

#### Apa itu?

Limit Order Penghasil Biaya memungkinkan Anda menetapkan harga target untuk membeli atau menjual token secara otomatis, sambil **mendapatkan biaya**. Begitu harga pool mencapai target Anda, order Anda dieksekusi dan token output yang diinginkan beserta biaya dikirim langsung ke dompet Anda.

* **Rantai yang didukung:** BNB Chain
* **Ukuran order minimum:** $50

#### Mengapa menggunakannya?

* Tidak perlu terus-menerus memantau grafik.
* Tidak ada biaya eksekusi — sebaliknya, Anda **mendapatkan biaya (0,1%)** saat order Anda terisi.
* Bekerja dengan mulus — sepenuhnya on-chain, didukung oleh arsitektur PancakeSwap Infinity.

***

TWAP (Time-weighted Average Price) adalah jenis order umum yang membagi order menjadi ukuran perdagangan yang lebih kecil dan mengeksekusinya pada interval teratur. Tujuan utama order TWAP adalah untuk mengurangi dampak harga order.

{% hint style="info" %}
Fitur TWAP dikembangkan oleh [Orbs](https://www.orbs.com/) dan didukung oleh [teknologi L3](https://www.orbs.com/overview/) Orbs.
{% endhint %}
