# 🏦 StableSwap

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/en-stableswap.png" alt=""><figcaption></figcaption></figure>

PancakeSwapのStableSwapは、不変曲線スリッページ関数に基づいて低スリッページでステーブルペアを取引するための機能です。USDステーブルコイン（例：HAY、BUSD、USDT）や流動性ステーキングトークン（例：stkBNB、BNBx）など、価格が近い特定のアセットをスワップするために設計されています。



PancakeSwapは現在、2つのStableSwapモデルを提供しています：[**Infinity StableSwap**](https://docs.pancakeswap.finance/~/revisions/4JQRJCuMPHEJgYdxdVME/trade/stableswap/infinity-stableswap)と[**Classic StableSwap**](https://docs.pancakeswap.finance/~/revisions/4JQRJCuMPHEJgYdxdVME/trade/stableswap/classic-stableswap)です。Infinity StableSwapはPancakeSwapの最新Infinityアーキテクチャ上に構築され、柔軟性、効率性、将来の拡張性が向上しています。Classic StableSwapはオリジナルのStableSwap実装を指し、既存のプールと流動性のサポートを継続しています。
