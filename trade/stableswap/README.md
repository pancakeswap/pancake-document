# 🏦 StableSwap

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/en-stableswap.png" alt=""><figcaption></figcaption></figure>

PancakeSwapのStableSwapは、インバリアントカーブのスリッページ関数に基づき、ステーブルペアを低いスリッページで取引できる機能です。USDステーブルコイン（例：HAY、BUSD、USDT）や、リキッドステーキングトークン（例：stkBNB、BNBx）など、価格が近い特定の資産をスワップするために設計されています。



PancakeSwapでは現在、2種類のStableSwapモデル、[**Infinity StableSwap**](infinity-stableswap.md)と[**Classic StableSwap**](classic-stableswap.md)を提供しています。Infinity StableSwapはPancakeSwapの最新のInfinityアーキテクチャ上に構築されており、柔軟性、効率性、将来的な拡張性が向上しています。Classic StableSwapは元のStableSwap実装を指し、既存のプールと流動性を引き続きサポートします。
