# 🏦 Stableswap

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/en-stableswap.png" alt=""><figcaption></figcaption></figure>

PancakeSwap 上的 StableSwap 是一项功能，可基于不变量曲线滑点函数以更低的滑点交易稳定币对。它专为兑换价格相近的特定资产而设计——例如美元稳定币（如 HAY、BUSD 和 USDT）或流动性质押代币（如 stkBNB 和 BNBx）。



PancakeSwap 目前提供两种 StableSwap 模式：[**Infinity StableSwap**](https://docs.pancakeswap.finance/~/revisions/4JQRJCuMPHEJgYdxdVME/trade/stableswap/infinity-stableswap) 和 [**Classic StableSwap**](https://docs.pancakeswap.finance/~/revisions/4JQRJCuMPHEJgYdxdVME/trade/stableswap/classic-stableswap)。Infinity StableSwap 构建于 PancakeSwap 最新的 Infinity 架构之上，提供更高的灵活性、效率和未来的可扩展性。Classic StableSwap 指的是最初的 StableSwap 实现，它继续支持现有的池和流动性。
