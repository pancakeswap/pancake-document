# 🏦 StableSwap

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/en-stableswap.png" alt=""><figcaption></figcaption></figure>

StableSwap auf PancakeSwap ist eine Funktion zum Handel stabiler Paare mit geringerer Kursabweichung, basierend auf einer Invarianzkurven-Kursabweichungsfunktion. Sie ist darauf ausgelegt, bestimmte Assets zu tauschen, deren Preise nahe beieinander liegen – wie USD-Stablecoins (z. B. HAY, BUSD und USDT) oder Liquid-Staking-Token (z. B. stkBNB und BNBx).



PancakeSwap bietet derzeit zwei StableSwap-Modelle an: [**Infinity StableSwap**](https://docs.pancakeswap.finance/~/revisions/4JQRJCuMPHEJgYdxdVME/trade/stableswap/infinity-stableswap) und [**Classic StableSwap**](https://docs.pancakeswap.finance/~/revisions/4JQRJCuMPHEJgYdxdVME/trade/stableswap/classic-stableswap). Infinity StableSwap basiert auf der neuesten Infinity-Architektur von PancakeSwap und bietet verbesserte Flexibilität, Effizienz und zukünftige Erweiterbarkeit. Classic StableSwap bezeichnet die ursprüngliche StableSwap-Implementierung, die weiterhin bestehende Pools und Liquidität unterstützt.
