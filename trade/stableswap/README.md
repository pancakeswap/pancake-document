# 🏦 StableSwap

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/en-stableswap.png" alt=""><figcaption></figcaption></figure>

StableSwap en PancakeSwap es una función para intercambiar pares estables con un menor deslizamiento basado en una función de deslizamiento de curva invariante. Está diseñado para intercambiar activos específicos con precios similares — como stablecoins en USD (p. ej., HAY, BUSD y USDT) o tokens de staking líquido (p. ej., stkBNB y BNBx).



PancakeSwap ofrece actualmente dos modelos de StableSwap: [**Infinity StableSwap**](https://docs.pancakeswap.finance/~/revisions/4JQRJCuMPHEJgYdxdVME/trade/stableswap/infinity-stableswap) y [**Classic StableSwap**](https://docs.pancakeswap.finance/~/revisions/4JQRJCuMPHEJgYdxdVME/trade/stableswap/classic-stableswap). Infinity StableSwap está construido sobre la última arquitectura Infinity de PancakeSwap, ofreciendo mayor flexibilidad, eficiencia y extensibilidad futura. Classic StableSwap se refiere a la implementación original de StableSwap, que continúa admitiendo pools y liquidez existentes.
