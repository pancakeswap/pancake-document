# ✖️ PancakeSwap X

PancakeSwap X, geniş bir üçüncü taraf likiditesini bir araya getirerek ve bunu popüler PancakeSwap dApp'e doğrudan entegre ederek PancakeSwap'ta favori varlıklarını işlem yapmanın tamamen yeni bir yolunu sunuyor. Daha fazla varlık işlemi, daha derin likidite, gaz gerektirmeyen Swap'lar ve çok daha fazlası:

* Daha iyi fiyatlar
* Takas edilecek daha fazla token
* Dahili MEV koruması
* Gaz ücretsiz Swap'lar

{% hint style="success" %}
**PancakeSwap X; Arbitrum, Ethereum, BNB Chain, Base ve Robinhood Chain'de kripto token Swap'larını destekleyerek yayında. Gerçek dünya varlıkları (RWA'lar) ayrıca BNB Chain, Ethereum ve Robinhood Chain'de desteklenmektedir.**
{% endhint %}
