# ✖️ PancakeSwap X

PancakeSwap X memperkenalkan cara baru yang sepenuhnya berbeda untuk memperdagangkan aset favorit Anda di PancakeSwap dengan mengagregasi berbagai sumber likuiditas pihak ketiga yang dibangun langsung ke dalam dApp PancakeSwap yang populer. Platform ini memungkinkan lebih banyak aset untuk diperdagangkan, likuiditas yang lebih dalam, Swap tanpa gas, dan masih banyak lagi:

* Harga lebih baik
* Lebih banyak token untuk di-Swap
* Perlindungan MEV bawaan
* Swap bebas gas

{% hint style="success" %}
**PancakeSwap X tersedia di Arbitrum, Ethereum, BNB Chain, Base, dan Robinhood Chain, mendukung swap token kripto. Real-world assets (RWA) juga didukung di BNB Chain, Ethereum, dan Robinhood Chain.**
{% endhint %}
