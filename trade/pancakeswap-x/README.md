# ✖️ PancakeSwap X

PancakeSwap X introduce un modo completamente nuovo di scambiare i tuoi asset preferiti su PancakeSwap, aggregando un'ampia gamma di liquidità di terze parti e integrandola direttamente nella popolare dApp PancakeSwap. Consente di scambiare più asset, liquidità più profonda, Swap senza gas e molto altro:

* Prezzi migliori
* Più token da scambiare
* Protezione MEV integrata
* Swap senza gas

{% hint style="success" %}
**PancakeSwap X è attivo su Arbitrum, Ethereum e Base, supportando token crypto, e su BNB Chain supporta solo real-world asset (RWA).**
{% endhint %}
