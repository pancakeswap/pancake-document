# ✖️ PancakeSwap X

PancakeSwap X stellt eine völlig neue Art vor, Ihre bevorzugten Assets auf PancakeSwap zu handeln, indem es ein breites Spektrum an Drittanbieter-Liquidität aggregiert und direkt in die beliebte PancakeSwap-dApp integriert. Es ermöglicht den Handel mit mehr Assets, tiefere Liquidität, gasfreie Swaps und vieles mehr:

* Bessere Preise
* Mehr Token zum Swappen
* Eingebauter MEV-Schutz
* Gasfreie Swaps

{% hint style="success" %}
**PancakeSwap X ist live auf Arbitrum, Ethereum, BNB Chain, Base und Robinhood Chain und unterstützt Krypto-Token-Swaps. Real-World-Assets (RWAs) werden zusätzlich auf BNB Chain, Ethereum und Robinhood Chain unterstützt.**
{% endhint %}
