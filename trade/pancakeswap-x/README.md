# ✖️ PancakeSwap X

PancakeSwap Xは、幅広いサードパーティ流動性を集約し、人気のPancakeSwap dAppに直接組み込むことで、PancakeSwapでお好みのアセットを取引する全く新しい方法を提供します。より多くのアセットの取引、より深い流動性、ガスレスのスワップなど、多くのメリットがあります：

* より良い価格
* スワップできるトークンの増加
* 組み込みのMEV保護
* ガス不要のスワップ

{% hint style="success" %}
**PancakeSwap XはArbitrum、Ethereum、Baseで稼働しており、暗号通貨トークンをサポートしています。BNB Chainでは、実物資産（RWA）のみサポートしています。**
{% endhint %}
