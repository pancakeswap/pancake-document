# So verwenden Sie PancakeSwap X

PancakeSwap X ist direkt in die vertraute „Swap"-Oberfläche integriert und für alle Nutzer standardmäßig aktiviert. Um PancakeSwap X zu nutzen, rufen Sie einfach die [Swap](https://pancakeswap.finance/swap)-Seite auf und beginnen Sie mit dem Handel.

### PancakeSwap X aktivieren

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28470%29.png" alt="" width="375"><figcaption></figcaption></figure>

Falls X nicht aktiviert ist: Klicken Sie auf das Einstellungssymbol in „Route", um das Einstellungsmodal zu öffnen, und anschließend auf „Routing anpassen", um die Routing-Einstellungen aufzurufen.

Im Modal „Routing anpassen" erscheint ein neuer Schalter zum Ein- und Ausschalten von PancakeSwap X für Handelsrouten. Klicken oder tippen Sie einfach darauf, um es zu aktivieren.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28471%29.png" alt="" width="375"><figcaption></figcaption></figure>

Sobald es aktiviert ist, können Sie zur Haupt-Swap-Seite zurückkehren. Wenn der aktuelle Swap für PancakeSwap X verfügbar ist, wird im Abschnitt „Route" ein Indikator angezeigt. Preisauswirkung und Gebühren betragen dabei 0.

Bitte beachten Sie, dass PancakeSwap X nicht für alle Swaps verfügbar ist. Die Verfügbarkeit hängt von den Input- und Output-Token sowie der Trade-Größe und dem Netzwerk ab. Wenn der Swap nicht über PancakeSwap X verarbeitet werden kann, wird er über die AMM-Liquiditätspools geleitet.

Wenn ein Trade über PancakeSwap X abgewickelt wird, wird dies im Abschnitt „Route" hervorgehoben.

### Order einreichen

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28472%29.png" alt="" width="375"><figcaption></figcaption></figure>

Um die Order einzureichen, klicken Sie auf „Swap" und überprüfen Sie dann alle Parameter im Modal „Swap bestätigen". Wenn alles korrekt ist, klicken Sie auf „Swap bestätigen", um fortzufahren.

Wenn Sie den Input-Token noch nicht freigegeben haben, wird Ihre Wallet Sie zur Genehmigung auffordern. Bitte beachten Sie, dass das Swappen über PancakeSwap X zwar kein Gas-Token erfordert, die Freigabe für Token-Ausgaben jedoch Gas benötigt.

Nach der Token-Genehmigung erscheint ein weiteres Wallet-Popup, das um Unterzeichnung der Order bittet. Klicken Sie einfach auf „Bestätigen", um fortzufahren. Es entstehen keine Gaskosten und keine On-Chain-Transaktion.

Sobald die Order eingereicht wurde, erscheint ein Modal mit Fortschrittsbalken. Sie können das Modal schließen, während Ihre Order weiterhin im Hintergrund gefüllt wird.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28473%29.png" alt="" width="367"><figcaption></figcaption></figure>

Beachten Sie, dass im Gegensatz zu regulären AMM-DEX-Liquiditätspool-Swaps eine eingereichte PancakeSwap X-Order etwas Zeit benötigt, bis Liquiditätsanbieter antworten und Ihre Order füllen. Es können bis zu 2 Minuten dauern, bis die Order erfolgreich gefüllt ist.

### Ihren Auftragsstatus verfolgen

Um Ihren Auftragsstatus zu verfolgen, öffnen Sie das Wallet-Modal über das Wallet-Dropdown oben rechts. Klicken Sie auf die Schaltfläche „Transaktion", um die Liste der Orders aufzurufen. Um mehr Details zu einer bestimmten Order zu sehen, klicken Sie einfach darauf, um das Detail-Modal zu öffnen.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28474%29.png" alt="" width="375"><figcaption></figcaption></figure>

Sobald eine Order erfolgreich gefüllt wurde, sehen Sie ein grünes Häkchen bei der Order, während die gekauften Token automatisch an Ihre Wallet gesendet werden.
