# Cara menggunakan PancakeSwap X

PancakeSwap X dibangun langsung ke dalam antarmuka "Swap" yang sudah familiar dan diaktifkan untuk semua pengguna secara default. Untuk menggunakan PancakeSwap X, cukup buka halaman [Swap](https://pancakeswap.finance/swap) dan mulai berdagang.

### Mengaktifkan PancakeSwap X

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28470%29.png" alt="" width="375"><figcaption></figcaption></figure>

Jika X belum diaktifkan. Klik ikon pengaturan di "Route" untuk membuka modal pengaturan, lalu klik "Customise Routing" untuk menampilkan preferensi perutean.

Dalam modal "Customize Routing", akan ada tombol switch baru untuk mengaktifkan atau menonaktifkan PancakeSwap X untuk rute trading. Cukup klik atau ketuk untuk mengaktifkannya.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28471%29.png" alt="" width="375"><figcaption></figcaption></figure>

Setelah diaktifkan, Anda dapat kembali ke halaman Swap utama. Jika Swap saat ini tersedia untuk PancakeSwap X, sebuah indikator akan muncul di bagian "Route". Dengan dampak harga dan biaya keduanya bernilai 0.

Harap diperhatikan bahwa PancakeSwap X tidak tersedia untuk semua Swap. Ketersediaannya bergantung pada token input dan output, serta ukuran transaksi dan jaringan. Jika Swap tidak dapat diproses oleh PancakeSwap X, Swap akan dirutekan melalui pool likuiditas AMM.

Ketika transaksi melalui PancakeSwap X, hal tersebut akan disorot di bagian "Route".

### Kirim Pesanan

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28472%29.png" alt="" width="375"><figcaption></figcaption></figure>

Untuk mengirim pesanan, klik "Swap", kemudian verifikasi semua parameter di modal "Confirm Swap". Jika semuanya terlihat baik, klik "Confirm Swap" untuk melanjutkan.

Jika Anda belum menyetujui token input, dompet Anda akan meminta Anda untuk menyetujui. Harap diperhatikan bahwa meskipun Swap melalui PancakeSwap X tidak memerlukan token gas apa pun, menyetujui pengeluaran token memerlukan gas.

Setelah persetujuan token, popup dompet lain akan muncul untuk meminta tanda tangan pada pesanan. Cukup klik "Confirm" untuk melanjutkan. Tidak ada biaya gas atau transaksi on-chain yang akan terlibat.

Setelah pesanan dikirim, modal dengan progress bar akan muncul. Anda dapat menutup modal tersebut, sementara pesanan Anda akan terus diproses di latar belakang.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28473%29.png" alt="" width="367"><figcaption></figcaption></figure>

Perlu diperhatikan bahwa tidak seperti Swap pool likuiditas DEX AMM biasa, setelah pesanan PancakeSwap X dikirim, diperlukan beberapa waktu bagi penyedia likuiditas untuk merespons dan memenuhi pesanan Anda. Mungkin diperlukan hingga 2 menit hingga pesanan berhasil dipenuhi.

### Pantau status pesanan Anda

Untuk memantau status pesanan Anda, buka modal dompet dari dropdown dompet di kanan atas. Klik tombol "Transaction" untuk menampilkan daftar pesanan. Untuk melihat detail pesanan tertentu, cukup klik dan buka modal detail.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28474%29.png" alt="" width="375"><figcaption></figcaption></figure>

Setelah pesanan berhasil dipenuhi, Anda akan melihat tanda centang hijau pada pesanan, sementara token yang dibeli dikirim secara otomatis ke dompet Anda.
