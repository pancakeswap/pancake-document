# Comment utiliser PancakeSwap X

PancakeSwap X est intégré directement dans l'interface « Swap » habituelle et activé pour tous les utilisateurs par défaut. Pour utiliser PancakeSwap X, rendez-vous simplement sur la page [Swap](https://pancakeswap.finance/swap) et commencez à trader.

### Activer PancakeSwap X

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28470%29.png" alt="" width="375"><figcaption></figcaption></figure>

Si PancakeSwap X n'est pas activé, cliquez sur l'icône des paramètres dans la section « Route » pour ouvrir le modal de paramètres, puis cliquez sur « Personnaliser le Routage » pour afficher les préférences de routage.

Dans le modal « Personnaliser le Routage », un nouveau commutateur apparaît pour activer/désactiver PancakeSwap X pour les routes de trading. Cliquez ou appuyez simplement dessus pour l'activer.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28471%29.png" alt="" width="375"><figcaption></figcaption></figure>

Une fois activé, vous pouvez revenir à la page principale de Swap. Si le Swap actuel est disponible via PancakeSwap X, un indicateur s'affichera dans la section « Route », avec un impact sur le prix et des frais à 0.

Veuillez noter que PancakeSwap X n'est pas disponible pour tous les Swaps. Sa disponibilité dépend des tokens d'entrée et de sortie, ainsi que de la taille de l'échange et du réseau. Si le Swap ne peut pas être traité par PancakeSwap X, il sera acheminé via les pools de Liquidité AMM.

Lorsqu'un échange passe par PancakeSwap X, il sera mis en évidence dans la section « Route ».

### Soumettre un Ordre

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28472%29.png" alt="" width="375"><figcaption></figcaption></figure>

Pour soumettre l'ordre, cliquez sur « Swap », puis vérifiez tous les paramètres dans le modal « Confirmer le Swap ». Si tout vous convient, cliquez sur « Confirmer le Swap » pour continuer.

Si vous n'avez pas encore approuvé le token d'entrée, votre portefeuille vous invitera à l'approuver. Veuillez noter que même si les échanges via PancakeSwap X ne nécessitent pas de token de gas, l'approbation des dépenses de tokens requiert du gas.

Après l'approbation du token, une autre fenêtre contextuelle de portefeuille apparaîtra pour vous demander de signer l'ordre. Cliquez simplement sur « Confirmer » pour continuer. Aucun coût de gas ni transaction on-chain ne sera impliqué.

Une fois l'ordre soumis, un modal avec une barre de progression apparaîtra. Vous pouvez fermer le modal pendant que votre ordre continuera à être exécuté en arrière-plan.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28473%29.png" alt="" width="367"><figcaption></figcaption></figure>

Notez que, contrairement aux Swaps classiques de pools de Liquidité AMM DEX, une fois qu'un ordre PancakeSwap X est soumis, il faudra un certain temps pour que les fournisseurs de Liquidité répondent et exécutent votre ordre. L'exécution peut prendre jusqu'à 2 minutes.

### Suivre le statut de votre ordre

Pour suivre le statut de votre ordre, ouvrez le modal du portefeuille depuis le menu déroulant du portefeuille en haut à droite. Cliquez sur le bouton « Transaction » pour afficher la liste des ordres. Pour voir plus de détails sur un ordre spécifique, cliquez simplement dessus pour ouvrir le modal de détail.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28474%29.png" alt="" width="375"><figcaption></figcaption></figure>

Une fois qu'un ordre est exécuté avec succès, vous verrez une coche verte sur l'ordre, tandis que les tokens achetés seront automatiquement envoyés à votre portefeuille.
