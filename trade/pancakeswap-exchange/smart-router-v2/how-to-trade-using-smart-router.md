# Handel mit Smart Router

## Handel über den Smart Router

Smart Router ist auf der Swap-Seite standardmäßig deaktiviert. Die Nutzung ähnelt der des bestehenden PancakeSwap AMM.

Zu Beginn wird eine **BNB Chain-kompatible Wallet sowie BNB für Gasgebühren** benötigt. Weitere Details finden Sie in unserem [Wallet-Leitfaden](../../../welcome-to-pancakeswap/how-to-guides/get-started/wallet-guide.md).

1. Rufen Sie die Swap-Seite [hier](https://pancakeswap.finance/swap#/swap) auf.
2. Wählen Sie die Token-Paare aus, die Sie handeln möchten. Zum Start wird beim Smart Router aufgrund von Kursabweichungsbedenken nur die exakte Eingabe akzeptiert.&#x20;
3. Geben Sie den Wert der Token ein, die Sie handeln möchten. Aktivieren Sie das Kontrollkästchen **„StableSwap für bessere Gebühren verwenden"**.

4\.  Überprüfen Sie die neue Route über das Symbol im Routenfeld in der unteren Zeile. Sie sind startklar! Der nachfolgende Swap-Vorgang ist wie gewohnt. Wenn Sie zum ersten Mal handeln, lesen Sie bitte die [Anleitung hier](../trade-guide.md).

## Smart Router deaktivieren

Durch Deaktivieren des Smart Routers werden alle Trades über V2-Pfade geleitet. StableSwap-Paare werden nicht aktiviert.

1. Klicken Sie auf das **Einstellungs**-Symbol oben rechts im Swap-Menü.
2. **Deaktivieren Sie den Smart Router** im erscheinenden Popup.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Screenshot%202022-11-25%20at%202.02.11%20PM.png)

3\. Schließen Sie die Einstellungsseite.
