# 🔄 Exchange

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/pancakeswap-exchange-header.png)

PancakeSwap ist ein Automated Market Maker (AMM), und die Exchange steht im Mittelpunkt von PancakeSwap. PancakeSwap ist der führende AMM auf der BNB Smart Chain und laut Statistiken die meistgenutzte dezentralisierte Börse (DEX) aller Zeiten!

Die PancakeSwap Exchange bietet mehrere Funktionen, die den dezentralisierten Handel unterstützen:

### Swapping/Trading

PancakeSwap ermöglicht es Nutzern, zu handeln, ohne eine Zentralisierte Börse nutzen zu müssen. Alles, was Sie auf PancakeSwap tun, wird direkt über Ihre eigene Wallet abgewickelt – Sie müssen niemandem Ihre Coins anvertrauen!

### Liquiditätspools

Sie können Token auf PancakeSwap nur swappen, wenn für diese Token ausreichend Liquidität vorhanden ist. Wenn niemand ausreichend Liquidität für den Token oder die Token, die Sie swappen möchten, bereitgestellt hat, wird dies schwierig, teuer oder unmöglich sein.

Durch die Bereitstellung von Liquidität erhalten Sie LP-Token, mit denen Sie Belohnungen in Form von Trading-Gebühren verdienen – dafür, dass immer ausreichend Liquidität für die Exchange zur Verfügung steht.

### Yield Farming

Yield Farming ermöglicht es Nutzern, die Liquidität bereitstellen, CAKE-Belohnungen zu verdienen, indem sie ihre LP-Token in einem Smart Contract sperren. Der Anreiz besteht darin, das Risiko eines [Impermanent Loss](https://academy.binance.com/en/articles/impermanent-loss-explained) auszugleichen, das mit dem Sperren Ihrer Liquidität einhergeht.

### Initial Farm Offerings (IFOs)

Ein Initial Farm Offering ist ein Event, das es Nutzern ermöglicht, neue Token zu einem zeitlich begrenzten Angebot zu kaufen. Der IFO-Preis ist in der Regel sehr attraktiv.
