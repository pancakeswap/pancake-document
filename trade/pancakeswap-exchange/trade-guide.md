# Anleitung zum Handel

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-trade-on-pancakeswap-header.png)

Der Handel auf PancakeSwap ist im Vergleich zu den meisten Börsen sehr einfach. Sie werden nicht von Charts oder Fachbegriffen überwältigt, und Handelsrouten sowie Berechnungen werden alle vom PancakeSwap Smart Router für Sie übernommen.

**Vorbereitung für den Handel**

Bevor Sie handeln können, benötigen Sie eine Wallet, die mit BNB Chain oder Ethereum kompatibel ist. Sie können [hier](https://docs.pancakeswap.finance/get-started/wallet-guide) erfahren, wie Sie eine solche erhalten. Sie benötigen außerdem BEP-20- oder ERC-20-Token für den Handel. Sie können [hier](https://docs.pancakeswap.finance/get-started/bep20-guide) erfahren, wie Sie diese erhalten.

Alternativ können Sie [hier](https://docs.pancakeswap.finance/get-started-aptos/wallet-guide) erfahren, wie Sie eine Aptos-kompatible Wallet erhalten, und [hier](https://docs.pancakeswap.finance/get-started-aptos/aptos-coin-guide), wie Sie Aptos-Coins zum Swappen erhalten.

## Handel auf der PancakeSwap Exchange

1 - Rufen Sie die Exchange-Seite [hier](https://pancakeswap.finance/swap) auf.



2 - Entsperren Sie Ihre Wallet, indem Sie auf **Wallet verbinden** klicken (Sie können auch oben rechts auf **Verbinden** klicken). Wenn Sie Ihre Wallet noch nicht mit PancakeSwap verbunden haben, können Sie die Anleitung [hier](https://docs.pancakeswap.finance/get-started/connection-guide) einsehen.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28200%29.png)



3 - Wählen Sie den Token, den Sie handeln möchten, aus dem Dropdown-Menü im oberen Bereich aus. Für welchen Token Sie sich auch entscheiden, Sie müssen sicherstellen, dass Sie eine ausreichende Menge davon in Ihrer Wallet zum Handeln haben. Ihr Guthaben wird über dem Token-Dropdown-Menü angezeigt.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2850%29.png)



4 - Wählen Sie im unteren Bereich wie oben den Token aus, gegen den Sie handeln möchten.



5 - Geben Sie als Nächstes entweder einen Betrag im oberen Bereich ein, um die Anzahl der Token anzugeben, die Sie swappen möchten (Ausgabebetrag), oder geben Sie einen Betrag im unteren Bereich ein, um die Anzahl der Token anzugeben, die Sie erhalten möchten (Empfangsbetrag).&#x20;

Unabhängig davon, in welchem Bereich Sie Ihren Betrag eingeben, wird der Betrag im anderen Bereich automatisch geschätzt.



6 - Überprüfen Sie alle Details und klicken Sie auf die Schaltfläche **Swap**.

Wenn Sie einen Token zum ersten Mal handeln, müssen Sie möglicherweise zunächst auf „XXX aktivieren (Ihr Token)" klicken, um die Genehmigung zu erteilen.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28272%29.png)



7 - Es erscheint ein Fenster mit weiteren Details. Überprüfen Sie, ob die Details korrekt sind. Wenn Sie bereit sind, klicken Sie auf die Schaltfläche **Swap bestätigen**. Ihre Wallet wird Sie auffordern, die Aktion zu bestätigen.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2827%29.png)



8 - Fertig! Sie können Ihre Transaktion auf dem Block-Explorer überprüfen, indem Sie auf den oben angezeigten Link klicken.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28209%29.png)

## **Was ist Smart Router V3, und wie wird er verwendet?**

PancakeSwap Smart Router ist ein Routing-Algorithmus, der V3, V2, StableSwap (BNB Chain) sowie den AMM und Market Maker (BNB Chain & Ethereum) verknüpft, um stets Liquidität und Preisfindung bereitzustellen. Standardmäßig führt er Trades über mehrere Pools aus, um den besten Preis für Trader zu finden.

Smart Router ist nun die Standardroute für PancakeSwap Exchange V3. Nutzer können ihn jedoch frei nach ihren Bedürfnissen anpassen.

Weitere Informationen zur Anpassung Ihrer Handelsrouten finden Sie [hier](fees-and-routes.md).&#x20;

Weitere Informationen zu StableSwap finden Sie [hier](/broken/pages/nNPogTZMxocdyFIBYbkE), und zur Market-Maker-Integration [hier](market-maker-integration.md).
