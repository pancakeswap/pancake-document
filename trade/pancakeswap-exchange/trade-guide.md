# Comment Trader

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-trade-on-pancakeswap-header.png)

Trader sur PancakeSwap est très simple comparé à la plupart des plateformes d'échange. Vous ne serez pas submergé par des graphiques ou du jargon technique, et toutes les routes de trading ainsi que les calculs sont gérés automatiquement par le Smart Router de PancakeSwap.

**Préparer votre configuration pour trader**

Avant de pouvoir trader, vous aurez besoin d'un portefeuille compatible avec BNB Chain ou Ethereum. Vous pouvez apprendre à en obtenir un [ici](https://docs.pancakeswap.finance/get-started/wallet-guide). Vous aurez également besoin de tokens BEP-20 ou ERC-20 pour trader. Vous pouvez apprendre à en obtenir [ici](https://docs.pancakeswap.finance/get-started/bep20-guide).

Vous pouvez également apprendre à obtenir un portefeuille compatible avec Aptos [ici](https://docs.pancakeswap.finance/get-started-aptos/wallet-guide), et comment obtenir des coins Aptos pour les échanger [ici](https://docs.pancakeswap.finance/get-started-aptos/aptos-coin-guide).

## Trader sur l'Exchange PancakeSwap

1 - Accédez à la page d'échange [ici](https://pancakeswap.finance/swap).



2 - Déverrouillez votre portefeuille en cliquant sur **Connecter le Portefeuille** (vous pouvez également cliquer sur **Connecter** en haut à droite). Si vous n'avez pas encore connecté votre portefeuille à PancakeSwap, consultez le guide [ici](https://docs.pancakeswap.finance/get-started/connection-guide).

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28200%29.png)



3 - Choisissez le token que vous souhaitez échanger dans le menu déroulant de la section supérieure. Quel que soit le token choisi, vous devrez vous assurer de disposer d'une quantité suffisante dans votre portefeuille. Votre solde est affiché au-dessus du menu déroulant de sélection de token.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2850%29.png)



4 - Choisissez le token que vous souhaitez recevoir dans la section inférieure, comme indiqué ci-dessus.



5 - Ensuite, saisissez un montant dans la section supérieure pour indiquer le nombre de tokens que vous souhaitez échanger (montant dépensé). Ou saisissez un montant dans la section inférieure pour indiquer le nombre de tokens que vous souhaitez recevoir (montant reçu).&#x20;

Quel que soit le champ dans lequel vous saisissez un montant, l'autre sera estimé automatiquement.



6 - Vérifiez tous les détails, puis cliquez sur le bouton **Swap**.

Si vous tradez un token pour la première fois, il vous sera peut-être d'abord demandé de cliquer sur « Activer XXX (votre token) » pour l'approuver.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28272%29.png)



7 - Une fenêtre avec plus de détails apparaîtra. Vérifiez que les informations sont correctes. Lorsque vous êtes prêt, cliquez sur le bouton **Confirmer le Swap**. Votre portefeuille vous demandera de confirmer l'action.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2827%29.png)



8 - Terminé ! Vous pouvez vérifier votre transaction sur l'Explorateur de Blocs en cliquant sur le lien affiché ci-dessus.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28209%29.png)

## **Qu'est-ce que le Smart Router V3 et comment l'utiliser ?**

Le Smart Router de PancakeSwap est un algorithme de routage qui relie V3, V2, StableSwap (BNB Chain), ainsi que l'AMM et les teneurs de marché (BNB Chain et Ethereum), afin de toujours fournir Liquidité et tarification. Par défaut, il exécute les échanges sur plusieurs pools pour trouver le meilleur prix pour les traders.

Le Smart Router est désormais la route par défaut pour PancakeSwap Exchange V3. Cependant, les utilisateurs sont libres de le personnaliser selon leurs besoins.

Pour en savoir plus sur la personnalisation de vos routes de trading, [cliquez ici](fees-and-routes.md).&#x20;

Pour plus d'informations sur StableSwap, [cliquez ici](/broken/pages/nNPogTZMxocdyFIBYbkE), et pour l'intégration des teneurs de marché, [cliquez ici](market-maker-integration.md).
