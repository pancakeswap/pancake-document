# Token Swaps

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/swap-trade-header.png)

[**Token Swaps**](https://pancakeswap.finance/swap) auf PancakeSwap sind eine einfache Möglichkeit, einen Token gegen einen anderen über automatisierte Liquiditätspools auf BNB Smart Chain, Ethereum und Aptos zu tauschen – sowie mit Market Makern beim Handel von Token auf BNB Smart Chain und Ethereum.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%2853%29.png)

Wenn Sie einen Token Swap (Trade) auf der [BNB Smart Chain](https://pancakeswap.finance/swap?chain=bsc) oder [Ethereum](https://pancakeswap.finance/swap?chain=eth) PancakeSwap Exchange durchführen, zahlen Sie Trading-Gebühren entsprechend dem Typ des Liquiditätspools, durch den Ihr Trade geleitet wird. Sie können die Routendetails einsehen, indem Sie auf das Lupen-Symbol im Abschnitt „Route" klicken.

Für Exchange V3-Liquiditätspools gibt es derzeit vier verschiedene Gebührenstufen: 0,01%, 0,05%, 0,25% und 1%.

Für StableSwap-Liquiditätspools hängt der Gebührensatz von der individuellen Pool-Konfiguration ab. Weitere Details finden Sie im Abschnitt „Gebühr".

Für Exchange V2-Liquiditätspools wird eine feste Trading-Gebühr von 0,25% erhoben, die sich wie folgt aufschlüsselt:

* **0,17%** – Werden dem Liquiditätspool in Form einer Gebührenbelohnung für Liquiditätsanbieter zurückgegeben.
* **0,0225%** – Werden an den PancakeSwap Treasury gesendet.
* **0,0575%** – Werden für den CAKE-Rückkauf und -Burn verwendet.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28277%29.png)

Bitte beachten Sie, dass auf [Aptos](https://aptos.pancakeswap.finance/swap) nur PancakeSwap Exchange V2 eingesetzt ist. Daher haben alle Token Swaps auf Aptos eine feste Trading-Gebühr von 0,25% mit der oben genannten Aufschlüsselung.
