# Wie kann ich es nutzen?

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-pancakeswap-without-cex-header%20%281%29.png)

Die Nutzung dieser Funktion ist sehr einfach (das Schwierige ist es, gut zu handeln). Sie müssen lediglich eine Reihe von Schritten befolgen, damit Ihr Erlebnis vollständig ist.

### Zur Perpetual Trading-Seite navigieren

Sie können über die [Website](https://pancakeswap.finance) im Bereich Handel → Perpetual einsteigen oder diesen [Link](https://perp.pancakeswap.finance/en/futures/BTCUSDT) verwenden.

### Guthaben einzahlen

Sie müssen zunächst Guthaben in das Futures-Konto einzahlen – über das Feld unten rechts auf dem Bildschirm.

![](https://lh6.googleusercontent.com/cz-OoCaRg3AfqTcETGTQVvsX_gfbm28fNJrUAxcljM823Bw1etFN3gArU5v8HljjzJU-lE3aV_5ENUySwioNYo_cQp__KwzEwo60ABmuWsqAzT5nM-nUse3ROcMdj2FhUChgsdGo)

USDT, BUSD, APX oder CAKE (mit Bonus!) können als Sicherheit zur Zahlung des Handels verwendet werden.

![](https://lh6.googleusercontent.com/3tFEo_gYD7r41o7RCFnd61NiEzJkqGc5uiZP3tRzEomAI805HPikW6tEDBzbyxK-kL5hptEqCIXax2wgASbbHcuN8FpKT4-hK6bFmkNyxmXJ2QIQxZRr38VTA_qg9HKmEbN2kNev)

Wie bereits erwähnt, gibt Ihnen die Verwendung von CAKE für Gebühren einen Rabatt von 5 %! Also, warum nicht?

![](https://lh3.googleusercontent.com/UiwXc1dgPqm07Ai0XKGuYAHLDbENm51_v93vMwHkUdb2HI-Hm5qEI2gbEVtzboatzv0-E9iesik8NF3ON74QXaXaW5jLcOJ5JjegI-8oMiidUf-MiZHjvvxnmd1HTfdnFrNgF8cG)

> Hinweis: Die Handelsgebühren betragen 0,02 % des Nominalwerts für Market Maker und 0,07 % für Market Taker. CAKE ist die Standardzahlungsoption für Handelsgebühren, gefolgt von APX (ApolloX-Token) und USDT. Nutzer, die Handelsgebühren in CAKE bezahlen, erhalten einen Rabatt von 5 % auf die Handelsgebühren.

### Das Handelspaar auswählen

Sie können ein handelbares Paar auswählen, indem Sie auf den Pfeil neben dem Paar oben auf der Seite klicken.

### Ihre Position eröffnen

Im oberen rechten Bereich finden Sie das Board, um Ihre Order zu platzieren.

![](https://lh3.googleusercontent.com/rQXCNgMoR4OzR_wXu92Mtgb22O7rAnOlrP0pL0VpXnurfrekOG0HwzUOBWQV-PtMinA1s8lo6KmtT78h3pGmTOF-ajO-G3EDg9CK56q-cPZNLUWJanE9-mEjOhJ4rWncb35PZEfq)

Hier müssen Sie mehrere Parameter einstellen, zum Beispiel:

_Nicht in einer bestimmten Reihenfolge_

1. Den Margin-Modus: Cross oder Isolated

![](https://lh4.googleusercontent.com/tplKHXPvrTQXPkNL9BSjVsIBAqfVDWyfh0mU0HDYDRXf4KRUEyu5xzDivGkzfw7JNsEUpQWXvPt8q1Wn26yeX21-DrhhwMTtMpFvFLyTKUxSOteAugTrlTgwvKro0zOluqFmELJQ)

2\. Den Hebelfaktor (x)

![](https://lh5.googleusercontent.com/ikaG0tpWYcynBZbEOmoR1XLYZzaFXwHwD6MCrlqDCLGDOa3LA1KQh4Gp8uv_BAPNo8z3r1bLe_DzEGjNyI22ja_oIOF9A4vfdLEpsoAxcKj5rboH9Ip2eLkBZUfBPZJpXwL_KJ0s)

Hinweis: Ein hoher Hebel trägt ein sehr hohes Risiko – setzen Sie ihn mit Bedacht ein.

3\. Den Ordertyp

![](https://lh3.googleusercontent.com/If2SXl-FUCTuy0eNJkmF0ONspdYPeIWFBXvyLkH6Hc0B1CwAzd9EP5rMQGSjr23hK9sDDUmL0rSN9R28AL9_-x_f0jsFdfrn7WFOjEcqfPaxerPjGSq1iIpxz6tcN_A839ASRF3B)

4\. Einen Preis für Ihre Order festlegen.

![](https://lh4.googleusercontent.com/J8rbXc_DhROHaZRoVCBELwIIraVg_uL2V-8bn2Ci2sm80jEmbS6q4CMuJ-Njv3Dx2L_OeoS-PTh-haPuW4uYsKIxQdWQdFttyFrTPFHp19u1nVz_V0MM6QsQdmKiyUD-imRSryU1)

Hinweis: Sie können „Last" verwenden, um den aktuellen letzten Preis einzufügen.

5\. Die Ordergröße festlegen

![](https://lh5.googleusercontent.com/OBtTNov5_h4-yWaOl17W8yZt2hnThsSiTF_ydyJdlrDEOi2mZAHRdBV8P23FtD3eteEt-u3HPWutUWpFwu0)

Sie können auch die Referenzwährung für die Anzeige Ihrer Position wählen.

> Hinweis: Es gibt noch einige weitere Optionen zu berücksichtigen – diese finden Sie im [Handels-Glossar](perpetuals-glossary.md)<br>

### Ihre Order absenden

Wenn alle Parameter eingestellt sind, können Sie die Order absenden, indem Sie auf „Long" klicken – bei einer Long-Order – oder auf „Short", bei einer Short-Order.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28114%29.png)

### Ihre Position prüfen

Sobald die Order abgeschickt wurde, erscheint sie unter „Offene Orders", bis sie ausgeführt wird.

![](https://lh6.googleusercontent.com/dIGg0mdxTNk7N3v3RI2eQ_CUmktxBiOQ-mDVQb_aBKPQuFYNIuOdTL55KLSjFPfxZp4DwrbfImykOPaWJl35iljOA8gv7nqgXYWGtgpFdLzxSebqjOy2KzIS7oqFAhwNd3cz2wRK)

### Live!

Sobald die Order ausgeführt wurde, ist Ihre Position aktiv. Sie können sie im Positionspanel einsehen, bearbeiten oder schließen.

![](https://lh4.googleusercontent.com/Bx9Ri4__6BG1Z1mVcIJh42xpyP-H6ijFv7iI9JxAlHvZkYs2lxnSQm8fQjXZ7TGjCHwf7DmNuSFdb0dtw60R5Duy0VO__GvSaKwFzzgt9ovbfm9j-U93r5mLlxKZzF6r4VfZQHjz)

Viel Erfolg beim Handel!
