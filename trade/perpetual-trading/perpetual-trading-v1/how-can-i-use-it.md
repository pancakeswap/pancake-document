# Comment l'utiliser ?

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-pancakeswap-without-cex-header%20%281%29.png)

Utiliser cette fonctionnalité est vraiment simple (la partie difficile, c'est de bien trader). Il vous suffit de suivre une série d'étapes pour profiter pleinement de l'expérience.

### Accéder à la page de Trading Perpétuel

Vous pouvez y accéder depuis le [site](https://pancakeswap.finance), dans la section Trade → Perpetual, ou via ce [lien](https://perp.pancakeswap.finance/en/futures/BTCUSDT).

### Déposer des fonds

Vous devez d'abord déposer des fonds sur votre compte Futures, dans le panneau en bas à droite de l'écran.

![](https://lh6.googleusercontent.com/cz-OoCaRg3AfqTcETGTQVvsX_gfbm28fNJrUAxcljM823Bw1etFN3gArU5v8HljjzJU-lE3aV_5ENUySwioNYo_cQp__KwzEwo60ABmuWsqAzT5nM-nUse3ROcMdj2FhUChgsdGo)

Il est possible d'utiliser USDT, BUSD, APX ou CAKE (avec un bonus !) comme garantie pour financer le trade.

![](https://lh6.googleusercontent.com/3tFEo_gYD7r41o7RCFnd61NiEzJkqGc5uiZP3tRzEomAI805HPikW6tEDBzbyxK-kL5hptEqCIXax2wgASbbHcuN8FpKT4-hK6bFmkNyxmXJ2QIQxZRr38VTA_qg9HKmEbN2kNev)

Comme mentionné, utiliser CAKE pour les frais vous offre une remise de 5% ! Alors, pourquoi s'en priver ?

![](https://lh3.googleusercontent.com/UiwXc1dgPqm07Ai0XKGuYAHLDbENm51_v93vMwHkUdb2HI-Hm5qEI2gbEVtzboatzv0-E9iesik8NF3ON74QXaXaW5jLcOJ5JjegI-8oMiidUf-MiZHjvvxnmd1HTfdnFrNgF8cG)

> Remarque : les frais de trading sont de 0,02% de la valeur notionnelle pour les makers et de 0,07% pour les takers. CAKE sera l'option de paiement par défaut pour les frais de trading, suivi d'APX (le token d'ApolloX) et de l'USDT. Les utilisateurs qui règlent leurs frais en CAKE bénéficient d'une remise de 5%.

### Choisir la paire à trader

Vous pouvez sélectionner une paire tradable en cliquant sur la flèche à côté de la paire, en haut de la page.

![](https://lh4.googleusercontent.com/OtHWwOgKp13zb-f-lVkgYShNPYD05B5hYrZIKasq2H-ev-05P1s4cYedXIwt4xsuGU2__7O7JwLwy66ERraUl2edkSmQSiaXcU5ilVXpTs39D-xiHB7q4p1q8NA7lpjCWuVe3E2z)

D'autres paires tradables seront ajoutées prochainement !

![](https://lh5.googleusercontent.com/yqnCEMigm39LpeG2tPHzXjgZOH08Je3Hhyj0tUxnqjFD2xBqwImoo4xMwjabnNWd0rXtyVcgBj5y4QuNod4QD0js4x-75S9VjsaF1LaLPbiL5G4c2KZUN9Aclqj3cf4EdUGg08Ia)

### Ouvrir votre position

Ensuite, dans la partie supérieure droite, vous trouverez le panneau pour saisir votre ordre.

![](https://lh3.googleusercontent.com/rQXCNgMoR4OzR_wXu92Mtgb22O7rAnOlrP0pL0VpXnurfrekOG0HwzUOBWQV-PtMinA1s8lo6KmtT78h3pGmTOF-ajO-G3EDg9CK56q-cPZNLUWJanE9-mEjOhJ4rWncb35PZEfq)

Vous devez y configurer plusieurs paramètres, notamment :

_Sans ordre particulier_

1. Le Mode de Marge : Cross ou Isolated

![](https://lh4.googleusercontent.com/tplKHXPvrTQXPkNL9BSjVsIBAqfVDWyfh0mU0HDYDRXf4KRUEyu5xzDivGkzfw7JNsEUpQWXvPt8q1Wn26yeX21-DrhhwMTtMpFvFLyTKUxSOteAugTrlTgwvKro0zOluqFmELJQ)

2\. Le multiplicateur de Levier

![](https://lh5.googleusercontent.com/ikaG0tpWYcynBZbEOmoR1XLYZzaFXwHwD6MCrlqDCLGDOa3LA1KQh4Gp8uv_BAPNo8z3r1bLe_DzEGjNyI22ja_oIOF9A4vfdLEpsoAxcKj5rboH9Ip2eLkBZUfBPZJpXwL_KJ0s)

Avertissement : N'oubliez pas qu'un Levier élevé comporte un risque très important — utilisez-le avec prudence.

3\. Le type d'ordre

![](https://lh3.googleusercontent.com/If2SXl-FUCTuy0eNJkmF0ONspdYPeIWFBXvyLkH6Hc0B1CwAzd9EP5rMQGSjr23hK9sDDUmL0rSN9R28AL9_-x_f0jsFdfrn7WFOjEcqfPaxerPjGSq1iIpxz6tcN_A839ASRF3B)

4\. Définir le prix de votre ordre.

![](https://lh4.googleusercontent.com/J8rbXc_DhROHaZRoVCBELwIIraVg_uL2V-8bn2Ci2sm80jEmbS6q4CMuJ-Njv3Dx2L_OeoS-PTh-haPuW4uYsKIxQdWQdFttyFrTPFHp19u1nVz_R0MM6QsQdmKiyUD-imRSryU1)

Remarque : vous pouvez utiliser "Last" pour remplir automatiquement avec le dernier prix disponible.

5\. Définir la taille de l'ordre

![](https://lh5.googleusercontent.com/OBtTNov5_h4-yWaOl17W8yZt2hnThsSiTF_ydyJdlrDEOi2mZAHRoIik0-9-bzGRFfbBAJ3QvzC7x4G65fHjrKeLAYNMsvTszr_7N8GIRdBV8P23FtD3eteEt-u3HPWutUWpFwu0)

Vous pouvez également choisir la devise de référence pour visualiser votre position.

> Remarque : il existe quelques options supplémentaires à prendre en compte, que vous pouvez consulter dans le [glossaire du trading](perpetuals-glossary.md)<br>

### Envoyer votre ordre

Une fois tous les paramètres configurés, vous pouvez envoyer l'ordre en cliquant sur Long, s'il s'agit d'un ordre long, ou sur Short, s'il s'agit d'un ordre short.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/image%20%28114%29.png)

### Vérifier votre position

Une fois l'ordre envoyé, il apparaîtra dans "Open Orders" jusqu'à ce qu'il soit exécuté.

![](https://lh6.googleusercontent.com/dIGg0mdxTNk7N3v3RI2eQ_CUmktxBiOQ-mDVQb_aBKPQuFYNIuOdTL55KLSjFPfxZp4DwrbfImykOPaWJl35iljOA8gv7nqgXYWGtgpFdLzxSebqjOy2KzIS7oqFAhwNd3cz2wRK)

### En direct !

Lorsque l'ordre est exécuté, votre position est active. Vous pouvez la consulter dans le panneau des positions, et également la visualiser, la modifier ou la clôturer.

![](https://lh4.googleusercontent.com/Bx9Ri4__6BG1Z1mVcIJh42xpyP-H6ijFv7iI9JxAlHvZkYs2lxnSdbO__GvSaKwFzzgt9ovbfm9j-U93r5mLlxKZzF6r4VfZQHjz)

Bonne chance dans vos trades !
