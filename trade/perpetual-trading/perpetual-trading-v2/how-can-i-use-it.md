# Wie kann ich es nutzen?

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/how-to-pancakeswap-without-cex-header%20%281%29.png)

Die Nutzung dieser Funktion ist sehr einfach (das Schwierige ist es, gut zu handeln). Sie müssen lediglich eine Reihe von Schritten befolgen, damit Ihr Erlebnis vollständig ist. Weitere Informationen finden Sie im [V2-Glossar](perpetuals-glossary.md).

### Zur Perpetual Trading-Seite navigieren&#x20;

Sie können über die [Website](https://pancakeswap.finance) im Bereich Handel → Perpetual einsteigen oder diesen [Link  ](https://perp.pancakeswap.finance/en/futures/BTCUSDT) verwenden.

### Das Handelspaar auswählen&#x20;

Sie können ein handelbares Paar auswählen, indem Sie auf den Pfeil neben dem Paar oben auf der Seite klicken.

### Ihre Position eröffnen&#x20;

Im oberen rechten Bereich finden Sie das Board, um Ihre Order zu platzieren.

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Perp1.png" alt=""><figcaption></figcaption></figure>

Hier müssen Sie mehrere Parameter einstellen, zum Beispiel:

_Nicht in einer bestimmten Reihenfolge_

1. Long oder Short&#x20;

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Perp2.png" alt=""><figcaption></figcaption></figure>

Wählen Sie die Handelsposition, die Sie einnehmen möchten.

&#x20; 2\. Den Hebelfaktor (x)

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Perp3.png" alt=""><figcaption></figcaption></figure>

Bewegen Sie den Schieberegler, um die passende Hebelposition zu wählen. Sie können die Position auch manuell in das Feld auf der linken Seite eingeben.

Hinweis: Ein hoher Hebel trägt ein sehr hohes Risiko – setzen Sie ihn mit Bedacht ein.

&#x20;   3\. Den Ordertyp

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Perp10.png" alt=""><figcaption></figcaption></figure>

&#x20;  4\. Die Ordergröße festlegen und einen Preis für Ihre Order angeben (bei Limit Orders)

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Perp3.png)

Sie können auch die Referenzwährung für die Anzeige Ihrer Position wählen.

5. Take Profit/Stop Loss & Kursabweichung

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Perp6.png" alt=""><figcaption></figcaption></figure>

Nutzer können beim Eröffnen einer Position einen Take-Profit- oder Stop-Loss-Preis festlegen.

* Take Profit: Die Position des Nutzers wird liquidiert, sobald der festgelegte P\&L-Prozentsatz an Gewinn erreicht wird.
* Stop Loss: Die Position des Nutzers wird liquidiert, sobald der festgelegte P\&L-Prozentsatz an Verlust erreicht wird.
* Kursabweichung: Wird verwendet, um eine Market Order automatisch zu stornieren, wenn sich der Preis vor der Eröffnung des Trades zu schnell in Richtung des Trades bewegt hat. Wenn Sie beispielsweise den aktuellen Preis als Long-Market-Order kaufen möchten, aber der Preis vor der Eröffnung Ihres Trades um 1 % gestiegen ist, wird die Order automatisch storniert.

Hinweis: Sie können mit der Maus über jede Option fahren, um weitere Informationen zu erhalten. Bitte beachten Sie das [Perpetuals V2 Glossar](perpetuals-glossary.md) für einen ausführlichen Leitfaden.

### Ihre Order absenden

Wenn alle Parameter eingestellt sind, können Sie die Order absenden, indem Sie auf „Position eröffnen" klicken.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Perp4.png)

### Ihre Position prüfen

Sobald die Order abgeschickt wurde, erscheint sie unter „Offene Orders", bis sie ausgeführt wird.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Perp11.png)

### Live!

Sobald die Order ausgeführt wurde, ist Ihre Position aktiv. Sie können sie im Positionspanel einsehen, bearbeiten oder schließen.

![](https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/Perp5.png)

Viel Erfolg beim Handel!
