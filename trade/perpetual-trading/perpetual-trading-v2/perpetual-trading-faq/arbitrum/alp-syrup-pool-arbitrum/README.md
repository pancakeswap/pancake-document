# ALP Syrup Pool (Arbitrum)

ALP adalah token yang menggerakkan likuiditas di PancakeSwap Perpetuals V2. Pengguna mencetak/membeli ALP menggunakan token jaminan seperti USDC, USDT, DAI, ETH, dan BTC. Token-token ini menyuplai likuiditas ke mesin trading PancakeSwap Perpetuals yang didukung oleh ApolloX. Token ALP **tidak dapat ditransfer antar dompet** dan hanya dapat **dicetak/dijual melalui kontrak ALP dan di-stake di pool ALP**.

### Panduan Langkah demi Langkah

#### Membeli/Mencetak ALP

1. Klik untuk mengakses halaman [PancakeSwap ALP Pool (V2)](https://perp.pancakeswap.finance/en/ALP) dan hubungkan dompet Anda
2. Setelah menghubungkan dompet Anda, klik **Buy ALP**. Anda dapat menggunakan aset pool ALP apa pun untuk membeli ALP.
3. Setelah mengonfirmasi informasi, klik **Buy ALP** untuk menyelesaikan transaksi.

**Staking ALP (Arbitrum)**

1. Klik **Stake Now** di Halaman Dashboard Pancake ALP, atau klik [di sini](https://pancakeswap.finance/pools?chain=arb)

<figure><img src="https://raw.githubusercontent.com/pancakeswap/pancake-document/en/.gitbook/assets/png%20%284%29.png" alt=""><figcaption></figcaption></figure>

2. Pilih Syrup Pool CAKE-ALP
3. **Aktifkan** ALP dan klik **Stake**
4. Pilih jumlah ALP untuk di-stake dan klik **konfirmasi**

**Menjual ALP**

1. &#x20;Klik untuk mengakses halaman ALP Pool (V2) dan hubungkan dompet Anda
2. Setelah menghubungkan dompet Anda, klik **Sell ALP**.

Kondisi Penjualan ALP:

* &#x20;Pengguna dapat menjual ALP 48 jam sejak waktu pembelian
* &#x20;Jumlah token ALP yang dapat dijual: min\[(Nilai pool likuiditas - Nilai posisi pengguna)\*50%]/Harga Pasar ALP. Misalnya, nilai pool likuiditas adalah 10.000.000 USDT, nilai posisi pengguna adalah 5.000.000 USDT, dan Harga Pasar ALP adalah 2 USDT, maka jumlah maksimum ALP yang dapat dijual pengguna adalah 1.250.000.&#x20;
* Pada saat yang sama, jumlah aset yang diterima pengguna setelah menjual token ALP mereka tidak dapat melebihi pool likuiditas ALP. Misalnya, jika pool likuiditas hanya memiliki 1000 USDT, jumlah maksimum USDT yang diterima pengguna adalah 1000 USDT dan ALP yang tersisa dapat dijual untuk mata uang kripto lainnya.
