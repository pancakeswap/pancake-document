# Degen Mode

Der Degen-Handelsmodus bietet Händlern eine alternative Handelsmethode im Vergleich zu herkömmlichen Handelsmethoden. Händler, die die Zeit vor dem Bildschirm für die Marktanalyse reduzieren und einen weniger intensiven Ansatz bevorzugen, können diesen Handelsmodus wählen. In Phasen hoher Volatilität können Händler ihre Gewinne mit 0 Kursabweichung, hohem Hebel und extrem niedrigen Gebühren maximieren. Bei niedriger Volatilität können Händler auf geringfügige Kursbewegungen spekulieren.

Zunächst ist der Degen-Handelsmodus für BTCUSD verfügbar und unterstützt einen maximalen Hebel von 1001-fach für Long- und Short-Market-Orders. Händler müssen den Einsatz (Sicherheitsbetrag) eingeben, bevor sie eine Position mit null Kursabweichung eröffnen.

Degen Mode ist auf BNB Chain, Arbitrum, opBNB und Base Chain für Perpetuals V2 verfügbar.

### Degen Mode-Format

Degen Mode bietet unseren Perpetual-Händlern folgende Spielmerkmale und Vorteile:

**Hoher Hebel, geringere anfängliche Sicherheitsleistung –** Mit einem höheren Hebel von 1001-fach können Nutzer am Degen Mode teilnehmen und ihre Handelsstrategien verstärken. Nutzer können jetzt von einem höheren Aufwärtspotenzial profitieren, ohne eine erhebliche anfängliche Sicherheitsleistung zu hinterlegen.

**Niedrigere Gebühren –** Mit dem Handel ohne Kursabweichung können Nutzer ein besseres Handelserlebnis genießen. Für das Öffnen von Positionen werden keine Gebühren erhoben. Dies erhöht das Aufwärtspotenzial der Nutzer, da die eingesparten Positionseröffnungsgebühren als Sicherheitsleistung verwendet werden können.

**Dynamische Gebührenstruktur –** Speziell für den Degen Mode entwickelt, ist die dynamische Gebührenstruktur für das Schließen von Positionen darauf ausgelegt, Gebühren basierend auf Gewinn und Verlust (PnL) zu erheben. Weitere Informationen zur dynamischen Gebührenstruktur finden Sie [hier](degen-mode-dynamic-fee.md).

**Paare –** Degen Mode ist für BTCUSD auf BNB Chain, Arbitrum, opBNB und Base Chain verfügbar.

### So funktioniert es

1. Gehen Sie zu [https://perp.pancakeswap.finance/en/futures/v2/](https://perp.pancakeswap.finance/en/futures/v2/) oder wählen Sie „Perpetuals" auf unserer Startseite.
2. Wählen Sie oben rechts auf dem Bildschirm die Position „Long" oder „Short" und klicken Sie auf den Hebeleditor, um den 1001-fachen Hebel zu wählen.
3. Wählen Sie den Betrag und den passenden Hebel.
4. Wählen Sie den Take-Profit-Betrag (zwischen 50 % und 300 %) und wählen Sie **Position eröffnen**.
5. Ihre Position wird auf der Registerkarte „Positionen" am unteren Bildschirmrand angezeigt.
6. Um die Position zu schließen, drücken Sie die Schaltfläche „Schließen" neben der Position. Andernfalls wird der Degen Mode automatisch beim Take-Profit oder während des Liquidierungszeitraums ausgeführt. Weitere Informationen finden Sie im [perpetuals-glossary.md](../perpetuals-glossary.md "mention") und in der [perpetual-trading-faq](../perpetual-trading-faq/ "mention").
