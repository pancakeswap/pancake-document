# Degen Mode

Режим Degen Mode предлагает трейдерам альтернативный способ торговли по сравнению с традиционными методами. Трейдеры, предпочитающие меньше времени проводить за анализом рынка и торгующие в более пассивном режиме, могут выбрать этот режим. В периоды высокой волатильности трейдеры могут максимизировать прибыль с нулевым проскальзыванием, высоким кредитным плечом и крайне низкими комиссиями. При низкой волатильности трейдеры могут спекулировать на незначительных ценовых движениях.

Изначально Degen Mode будет доступен для BTCUSD с максимальным кредитным плечом 1001x для рыночных ордеров лонг и шорт. Трейдеры должны ввести сумму основного долга (залог) перед открытием позиции с нулевым проскальзыванием.

Degen Mode доступен на BNB Chain, Arbitrum, opBNB и Base в Perpetuals V2.

### Формат Degen Mode

Degen Mode предлагает следующие особенности и преимущества для трейдеров бессрочных контрактов:

**Высокое кредитное плечо, меньший начальный залог —** с кредитным плечом до 1001x пользователи могут участвовать в торговле и усиливать свои стратегии через Degen Mode. Теперь пользователи могут получать более высокий потенциал прибыли без значительного начального залога.

**Низкие комиссии —** благодаря торговле с нулевым проскальзыванием пользователи получают лучший торговый опыт. Комиссии за открытие позиции не взимаются. Это увеличивает потенциал прибыли пользователей, так как сэкономленные комиссии за открытие можно использовать в качестве залога.

**Динамическая структура комиссий —** уникально разработанная для Degen Mode, динамическая структура комиссий для закрытия позиций тщательно спроектирована для начисления комиссий на основе прибыли и убытка (PnL). Подробнее о динамической структуре комиссий [здесь](degen-mode-dynamic-fee.md).

**Торговые пары —** Degen Mode доступен для BTCUSD на BNB Chain, Arbitrum, opBNB и Base.

### Как это работает

1. Перейди на [https://perp.pancakeswap.finance/en/futures/v2/](https://perp.pancakeswap.finance/en/futures/v2/) или выбери «Perpetuals» на нашей главной странице.
2. В правом верхнем углу экрана выбери позицию «Long» или «Short» и нажми на редактор кредитного плеча, чтобы установить 1001x.
3. Выбери сумму и подходящее кредитное плечо.
4. Выбери уровень фиксации прибыли (от 50% до 300%) и нажми **открыть позицию**.
5. Твоя позиция отобразится на вкладке «positions» в нижней части экрана.
6. Чтобы закрыть позицию, нажми кнопку «close» рядом с позицией. В противном случае Degen Mode автоматически закроет позицию при достижении уровня фиксации прибыли или ликвидации. Подробнее см. в [perpetuals-glossary.md](../perpetuals-glossary.md "mention") и [perpetual-trading-faq](../perpetual-trading-faq/ "mention").
