# MADBTCUSD

**1. Was ist der MADBTCUSD-Index?**

Der MADBTCUSD-Index ist ein algorithmisch generierter Preisindex, der die dynamischen Bewegungen von BTC abbildet, jedoch mit einem besonderen Merkmal – er weist eine erheblich höhere Volatilität auf. Dieser Index wird mithilfe der Preismethodik der Geometrischen Brownschen Bewegung (GBM) abgeleitet, einem mathematischen Modell, das in der Finanzwelt häufig zur Simulation der unvorhersehbaren Natur von Assets verwendet wird.

**2. Wie funktioniert es?**

Der MADBTCUSD-Index basiert primär auf dem Bitcoin-Preis. Er spiegelt die allgemeinen Auf- und Abwärtsbewegungen von BTCUSD wider, jedoch in einem verstärkten Ausmaß (erwartete Volatilität von 100 %), was zu einem Index mit deutlich ausgeprägteren Preisschwankungen führt. Um Transparenz und Fairness zu gewährleisten, kann der MADBTC-Preis über den BTC-Preis und die historischen MADBTC-Preisdaten ([hier](madbtcusd-faq.md)) kreuzverifiziert werden. Dadurch wird sichergestellt, dass der Index die Bewegungen des zugrunde liegenden BTC-Marktes genau widerspiegelt.

Ein wesentliches Merkmal, das MADBTCUSD von traditionellen Kryptowährungen unterscheidet, ist das Zufallselement. Der Preis des MADBTCUSD-Kontrakts wird algorithmisch mithilfe einer Kombination aus den Daten des entsprechenden Kontrakts und einer Zufallszahl generiert. Käufer und Verkäufer haben keinen Einfluss auf den Preis des MADBTCUSD-Index.

**3. Marktverfügbarkeit:**

Derzeit ist der MADBTCUSD-Index im Classic Mode auf BNB Chain verfügbar, zusammen mit anderen wichtigen Märkten wie BTCUSD und ETHUSD. Der Kontrakt bietet zusätzliche Vorteile wie eine Positionseröffnungsgebühr von null, eine PnL-basierte Positionsschließungsgebühr und einen Hebel von bis zu 250-fach.

Wenn Sie das Konzept von MADBTCUSD interessiert und Sie die Feinheiten dieses Kontrakts genauer erkunden möchten, finden Sie hier eine dedizierte [FAQ](madbtcusd-faq.md)-Seite mit einer umfassenden Methodik.

_**Es ist wichtig zu beachten, dass MADBTCUSD aufgrund seiner extremen Volatilität möglicherweise nicht für alle Händler geeignet ist. Es ist daher unbedingt erforderlich, eigene Recherchen durchzuführen und die damit verbundenen Risiken vollständig zu verstehen, bevor man teilnimmt.**_
