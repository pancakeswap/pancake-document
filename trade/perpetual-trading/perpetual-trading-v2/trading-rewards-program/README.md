# Программа торговых вознаграждений

### Обзор программы вознаграждений

Подробности:

Период активности: даты варьируются от цикла к циклу и для разных сетей.

Время распределения вознаграждений: каждый цикл — ежедневно с 00:00 (UTC) до 23:59 (UTC). Вознаграждения начисляются на следующий день приблизительно в 03:00 (UTC). Пользователи должны получить вознаграждения в течение 30 дней после их начисления. В противном случае платформа отзовёт вознаграждения.&#x20;

Сумма вознаграждений: ограничена $15 000 USD в APX в день.

Правила активности: пользователи, торгующие на V2, зарабатывают из призового фонда вознаграждений. Те, кто стейкает APX в DAO для получения veNFT, будут пользоваться мультипликаторами буста, соответствующими значению Power, рассчитанному из veNFT.&#x20;

| Значение Power            | Мультипликатор буста |
| ------------------------- | -------------------- |
| 50 000 < Power ≤ 100 000  | 1,5                  |
| 100 000 < Power ≤ 300 000 | 2                    |
| Power > 300 000           | 2,5                  |

Формула расчёта торговых вознаграждений:&#x20;

По окончании каждого цикла торговых вознаграждений рассчитываются эффективные торговые комиссии и сумма стейкинга пользователя в этом цикле для определения веса и количества вознаграждений APX. Формула выглядит следующим образом:

r = R\*W / sum(Wi)



Параметры:

| r       | Вознаграждение APX пользователя за этот цикл                                                                                                                                                                                                                                                                                                                                  |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R       | Определяется вкладом пользователя в торговые комиссии V2 за предыдущий день и последней ценой токена APX                                                                                                                                                                                                                                                                      |
| W       | <p>Индивидуальный общий весовой балл W=f*w, где;</p><p>f — эффективные торговые комиссии, внесённые пользователем в этом цикле, конвертированные в USD.</p><p>w — мультипликатор буста, полученный пользователем в этом цикле от стейкинга APX в DAO. (Подробнее см. в таблице выше)</p> |
| sum(Wi) | Общий балл всех пользователей. Wi — балл любого отдельного пользователя, sum(Wi) — сумма всех пользовательских баллов                                                                                                                                                                                                                                                         |

&#x20;

Формула расчёта R выглядит следующим образом:

R=Min(Dollar value multiplier \* Trading Fee, Dollar value Cap)/ Max(APX Last Price, APX Price Floor)

* Dollar value multiplier: 0,70 в этой эпохе
* Trading Fee: стоимость дохода от комиссий V2 за предыдущий день, конвертированная в USD
* Dollar value Cap: 15 000 согласно конфигурации системы
* APX Last Price: на основе последней цены токена APX
* APX Price Floor: 0,04 в этой эпохе

Условия и положения

* После окончания каждого цикла ApolloX может корректировать правила программы в соответствии с отзывами пользователей и рыночными условиями. Вознаграждения будут выпускаться нелинейно.
* В течение активности платформа снизит процент дохода от торговых комиссий V2, направляемых в пул ALP, с 50% до 20%. Оставшиеся 30% будут использованы для выкупа APX.
* Из-за разницы в торговых комиссиях для каждой торговой пары на V2 вознаграждения пользователей могут различаться, даже если их эффективный объём торгов одинаков.
* Вознаграждения для каждого цикла будут храниться на следующем адресе контракта: 0x6bE863e01E17A226c945e3629D0D9Cb6E52Ce90E
* ApolloX оставляет за собой право окончательной интерпретации данной активности.

Предупреждение о рисках: торговля фьючерсами на криптовалюту несёт существенный риск. Все торговые операции выполняются по твоему усмотрению и на твой риск. \
Шаг 1: Перейди на нашу [страницу PancakeSwap Perpetuals](https://perp.pancakeswap.finance/en/futures/v2/)

Шаг 2: Нажми на вкладку Trading Reward (V2) вверху страницы
