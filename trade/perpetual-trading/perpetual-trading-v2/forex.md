# Forex

PancakeSwap Perpetuals V2 propose des paires de trading Forex. Contrairement au marché des cryptomonnaies, le marché des changes n'est pas ouvert au trading 24h/24 et 7j/7. Les traders peuvent se référer aux horaires suivants :

| Jour     | Ouverture/Fermeture pour le trading                                                                     |
| --------- | ---------------------------------------------------------------------------------------- |
| Lundi    | Ouvert                                                                                     |
| Mardi   | Ouvert                                                                                     |
| Mercredi | Ouvert                                                                                     |
| Jeudi  | Ouvert                                                                                     |
| Vendredi    | <p>Fermé à partir de 22h00 UTC (heure d'été)</p><p>Fermé à partir de 23h00 UTC (heure standard)</p> |
| Samedi  | Fermé                                                                                   |
| Dimanche    | <p>Ouvert à partir de 22h00 UTC (heure d'été)</p><p>Ouvert à partir de 23h00 UTC (heure standard)</p>     |

De plus, le marché des changes sera également fermé lors des jours fériés suivants :

* 25 décembre - 27 décembre
* 1er janvier - 2 janvier
