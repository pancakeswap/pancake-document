# Форекс

PancakeSwap Perpetuals V2 предлагает торговые пары форекс. В отличие от рынка криптовалют, рынок иностранных валют доступен для торговли не круглосуточно. Трейдеры могут ориентироваться на следующее расписание:

| День      | Открыто/Закрыто для торговли                                                                                     |
| --------- | ---------------------------------------------------------------------------------------------------------------- |
| Понедельник | Открыто                                                                                                        |
| Вторник   | Открыто                                                                                                          |
| Среда     | Открыто                                                                                                          |
| Четверг   | Открыто                                                                                                          |
| Пятница   | <p>Закрыто с 22:00 UTC (летнее время)</p><p>Закрыто с 23:00 UTC (зимнее время)</p>                              |
| Суббота   | Закрыто                                                                                                          |
| Воскресенье | <p>Открыто с 22:00 UTC (летнее время)</p><p>Открыто с 23:00 UTC (зимнее время)</p>                            |

Кроме того, рынок иностранных валют также будет закрыт в следующие праздничные дни:

* 25 декабря — 27 декабря
* 1 января — 2 января
