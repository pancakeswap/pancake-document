# Forex

PancakeSwap Perpetuals V2 bietet Forex-Handelspaare an. Im Gegensatz zum Kryptowährungsmarkt ist der Devisenmarkt nicht rund um die Uhr geöffnet. Händler können die folgenden Handelszeiten beachten:

| Tag        | Geöffnet/Geschlossen für den Handel                                                                          |
| ---------- | ------------------------------------------------------------------------------------------------------------ |
| Montag     | Geöffnet                                                                                                     |
| Dienstag   | Geöffnet                                                                                                     |
| Mittwoch   | Geöffnet                                                                                                     |
| Donnerstag | Geöffnet                                                                                                     |
| Freitag    | <p>Geschlossen ab 22:00 UTC (Sommerzeit)</p><p>Geschlossen ab 23:00 UTC (Normalzeit)</p>                     |
| Samstag    | Geschlossen                                                                                                  |
| Sonntag    | <p>Geöffnet ab 22:00 UTC (Sommerzeit)</p><p>Geöffnet ab 23:00 UTC (Normalzeit)</p>                           |

Darüber hinaus ist der Devisenmarkt an folgenden Feiertagen ebenfalls geschlossen:

* 25. Dezember – 27. Dezember
* 1. Januar – 2. Januar
