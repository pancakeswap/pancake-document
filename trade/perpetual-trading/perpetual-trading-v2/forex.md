# Forex

PancakeSwap Perpetuals V2はForex（外国為替）取引ペアを提供しています。暗号資産市場とは異なり、外国為替市場は24時間365日取引に開放されているわけではありません。トレーダーは以下の取引時間を参照してください：

| 曜日       | 取引の開閉                                                                                   |
| --------- | ---------------------------------------------------------------------------------------- |
| 月曜日    | 開場                                                                                     |
| 火曜日   | 開場                                                                                     |
| 水曜日 | 開場                                                                                     |
| 木曜日  | 開場                                                                                     |
| 金曜日    | <p>22:00 UTC以降（夏時間）は閉場</p><p>23:00 UTC以降（非夏時間）は閉場</p> |
| 土曜日  | 閉場                                                                                   |
| 日曜日    | <p>22:00 UTC以降（夏時間）は開場</p><p>23:00 UTC以降（非夏時間）は開場</p>     |

また、以下の祝日には外国為替市場も閉場となります：

* 12月25日〜27日
* 1月1日〜2日
