# Forex

PancakeSwap Perpetuals V2 menawarkan pasangan trading forex. Tidak seperti pasar mata uang kripto, pasar valuta asing tidak buka untuk trading 24/7. Trader dapat merujuk pada jadwal berikut:

| Hari       | Buka/Tutup untuk trading                                                                   |
| --------- | ---------------------------------------------------------------------------------------- |
| Senin    | Buka                                                                                     |
| Selasa   | Buka                                                                                     |
| Rabu | Buka                                                                                     |
| Kamis  | Buka                                                                                     |
| Jumat    | <p>Tutup mulai 22:00 UTC (DST)</p><p>Tutup mulai 23:00 UTC (Non-DST)</p> |
| Sabtu  | Tutup                                                                                   |
| Minggu    | <p>Buka mulai 22:00 UTC (DST)</p><p>Buka mulai 23:00 UTC (Non-DST)</p>     |

Selain itu, pasar valuta asing juga akan tutup selama hari libur nasional berikut:

* 25 Desember - 27 Desember
* 1 Januari - 2 Januari
