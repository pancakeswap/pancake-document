# Forex

PancakeSwap Perpetuals V2, forex işlem çiftleri sunar. Kripto para piyasasının aksine, döviz piyasası 7/24 işleme açık değildir. Traderlar aşağıdaki saatlere başvurabilir:

| Gün       | İşlem için Açılış/Kapanış                                                                   |
| --------- | ---------------------------------------------------------------------------------------- |
| Pazartesi    | Açık                                                                                     |
| Salı   | Açık                                                                                     |
| Çarşamba | Açık                                                                                     |
| Perşembe  | Açık                                                                                     |
| Cuma    | <p>22:00 UTC'den itibaren kapalı (DST)</p><p>23:00 UTC'den itibaren kapalı (DST olmayan)</p> |
| Cumartesi  | Kapalı                                                                                   |
| Pazar    | <p>22:00 UTC'den itibaren açık (DST)</p><p>23:00 UTC'den itibaren açık (DST olmayan)</p>     |

Buna ek olarak döviz piyasası, aşağıdaki resmi tatillerde de kapalı olacaktır:

* 25 Aralık - 27 Aralık
* 1 Ocak - 2 Ocak
