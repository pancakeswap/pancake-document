# Форекс

PancakeSwap Perpetuals V2 предлагает торговые пары форекс. В отличие от рынка криптовалют, рынок иностранных валют работает не круглосуточно и не без выходных. Трейдеры могут ориентироваться на следующее расписание:

| День      | Открытие/Закрытие для торговли                                                            |
| --------- | ----------------------------------------------------------------------------------------- |
| Понедельник | Открыт                                                                                  |
| Вторник   | Открыт                                                                                    |
| Среда     | Открыт                                                                                    |
| Четверг   | Открыт                                                                                    |
| Пятница   | <p>Закрыт с 22:00 UTC (летнее время)</p><p>Закрыт с 23:00 UTC (зимнее время)</p>         |
| Суббота   | Закрыт                                                                                    |
| Воскресенье | <p>Открыт с 22:00 UTC (летнее время)</p><p>Открыт с 23:00 UTC (зимнее время)</p>       |

Кроме того, рынок иностранных валют также будет закрыт в следующие праздничные дни:

* 25–27 декабря
* 1–2 января
